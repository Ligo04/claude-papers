# 方法详解

## 1. 标准约束驱动仿真回顾

**运动方程（Eq. 1-2）：**

```
M ü + D u̇ + f_int(u) = M g          (1)
subject to  C u = S x(t)             (2)
```

其中：
- M ∈ ℝ^(3n×3n)：质量矩阵
- D = d_m M + d_s K：Rayleigh 阻尼矩阵
- f_int(u)：内力（取决于材料模型：线性、StVK、neo-Hookean 等）
- u, u̇, ü：位移、速度、加速度
- C ∈ ℝ^(m×3n)：约束矩阵
- S x(t)：几何代理的时变位置

## 2. 四个控制目标的定义

### 2.1 振动频率 ν

求解约束特征值问题（Eq. 3-4）：

```
K u = λ M u
subject to  C u = S x
```

最小特征值 λ 对应的频率：ν = √λ / (2π)

### 2.2 重力下垂 ζ

静态平衡方程：

```
f_int(u) = M g
```

下垂量：ζ = ||u||

### 2.3 惯性振幅 A

定义为动态位移的均方根（Eq. 5）：

```
A = √(1/m ∫₀^t_max ⟨M q, q⟩ dt)
```

其中 q_i 是顶点 i 在局部坐标系中的动态位移：u_i = p_i + R_i q_i

### 2.4 阻尼半衰期 t_D

模态阻尼因子（Eq. 6）：

```
ξ = (1/2)(d_m ω + d_k / ω)
```

半衰期（Eq. 7）：

```
t_D = (log 2) / (ξ ω) = (2 log 2) / (d_m + 4π² d_k ν²)
```

## 3. 非惯性参考系变换推导

### 3.1 局部坐标系分解

将位移分解为静态部分和动态部分：

```
u = p + R q
```

其中：
- p(t)：当前约束下的静态平衡位移
- R(t)：每个顶点的局部旋转矩阵（通过极分解获得）
- q(t)：局部坐标系中的动态位移

### 3.2 变换到非惯性参考系（Eq. 13-14）

将 Eq. 1-2 代入 u = p + R q：

```
M R q̈ + D R q̇ + f_int(p + R q) = 
    M g - M(p̈ + R̈ q + 2 Ṙ q̇) - D(ṗ + Ṙ q)     (13)

subject to  C R q = S x(t) - C p                (14)
```

右端的 M(p̈ + R̈ q + 2 Ṙ q̇) 项包含四种惯性力：
- M p̈：线加速度惯性力
- M R̈ q：角加速度惯性力
- 2 M Ṙ q̇：科里奥利力
- （隐含在 R̈ 中的）离心力

### 3.3 缩放惯性力（Eq. 15-16）

引入缩放因子 ε：

```
M R q̈ + D R q̇ + f_int(p + R q) = 
    M g - ε M(p̈ + R̈ q + 2 Ṙ q̇) - D(ṗ + Ṙ q)   (15)

subject to  C R q = S x(t) - C p                (16)
```

### 3.4 变换回世界坐标系（Eq. 17-18）

代入 q = R^T (u - p)，得到最终修改方程：

```
M ü + D u̇ + f_int(u) = M g + 
    (1-ε) M [p̈ + (R̈ R^T + 2 Ṙ Ṙ^T)(u - p) + 2 Ṙ R^T (u̇ - ṗ)]   (17)

subject to  C u = S x(t)                                          (18)
```

## 4. 最终修改方程（含物理参数缩放）

结合 Eq. 8-9 的物理参数缩放（δ, γ, μ, c_m, c_k），得到 Eq. 22-23：

```
δ M ü + (c_m d_m δ M + c_k d_k γ K) u̇ + γ f_int(u) = μ δ M g + 
    (1-ε) δ M [p̈ + (R̈ R^T + 2 Ṙ Ṙ^T)(u - p) + 2 Ṙ R^T (u̇ - ṗ)]   (22)

subject to  C u = S x(t)                                              (23)
```

## 5. 控制公式汇总

### 5.1 频率控制

```
χ = ν̄ / ν = √(γ / δ)                                    (26)
```

设定 χ 后，可任意选择 γ 和 δ 满足 χ² = γ/δ（通常取 γ=χ², δ=1）

### 5.2 下垂控制

```
μ = χ² (ζ̄ / ζ)                                          (27)
```

### 5.3 阻尼控制

仅使用刚度阻尼（c_m = 0）：

```
c_k = (1 / χ²) (t̄_D / t_D)                              (28)
```

### 5.4 振幅控制（两阶段迭代）

**第一阶段：** 根据约束运动类型选择初始 ε

- 恒定加速度：ε = χ² (Ā / A)
- 脉冲加速度：ε = χ (Ā / A)

**第二阶段：** 运行仿真，测量实际振幅 A_actual，修正：

```
ε' = ε (Ā / A_actual)
```

若仍不精确，可继续用二分法迭代。

## 6. 实现细节

### 6.1 静态求解（每时间步）

```
f_int(p) = M g
subject to  C p = S x(t)
```

使用牛顿法或共轭梯度法求解。

### 6.2 极分解及其时间导数

1. 计算每个四面体的变形梯度 F
2. 对每个顶点，体积加权平均周围四面体的 F
3. 极分解：F = R S（R 为旋转，S 为对称拉伸）
4. 时间导数：
   - Ṙ 和 R̈ 通过 5 点有限差分计算（Eq. 21）：
   
   ```
   p̈_i = (-p_{i+2} + 16 p_{i+1} - 30 p_i + 16 p_{i-1} - p_{i-2}) / (12 h²)
   ```

### 6.3 算法流程

```
伪代码：

for each timestep t:
    1. 静态求解：求 p(t) 满足 f_int(p) = Mg, Cp = Sx(t)
    2. 计算 ṗ, p̈（5点有限差分）
    3. 计算变形梯度 F → 极分解 → R
    4. 计算 Ṙ, R̈（5点有限差分）
    5. 组装修改后的右端项：
       rhs = μδMg + (1-ε)δM[p̈ + (R̈R^T + 2ṘṘ^T)(u-p) + 2ṘR^T(u̇-ṗ)]
    6. 时间积分（隐式欧拉 / Bathe法）：
       求解 δMü + Du̇ + γf_int(u) = rhs, s.t. Cu = Sx(t)
    7. 碰撞检测与响应
    8. 更新 u, u̇
```
