# Adjustable Constrained Soft-Tissue Dynamics

**作者：** Bohan Wang, Mianlun Zheng, Jernej Barbič (USC)  
**发表于：** Pacific Graphics 2020 / Computer Graphics Forum, Vol. 39(7)  
**难度等级：** 高级（需要连续介质力学和振动理论基础）

---

## 论文概述

本文解决了角色动画中长期存在的问题：在约束驱动的软组织仿真中，振动频率和惯性振幅是天然耦合的——仅通过调整材料属性（杨氏模量、质量密度等）无法独立控制二者。论文提出将运动方程变换到每个顶点的非惯性参考系中，对惯性力（虚拟力/d'Alembert力）进行缩放，然后变换回世界坐标系。这一最小改动使动画师能够独立控制四个关键视觉特性：振动频率、惯性振幅、重力下垂和阻尼衰减。

## 关键收获

1. **频率-振幅耦合是物理内禀的**：在正确物理下，1D 弹簧质点模型已能证明振幅 ∝ 1/ω_d，不可独立调控
2. **非惯性参考系变换**：u = p + R q，将方程变换到局部旋转坐标系后，惯性力自然显现（线加速度力、角加速度力、离心力、科里奥利力）
3. **ε 缩放惯性力**：ε=0 消除所有约束驱动动力学，ε=1 原始物理，ε>1 放大
4. **对原始方程的改动极小**：仅在右端加一项 (1−ε)M(...)，不改变时间积分器或接触处理
