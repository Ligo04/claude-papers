# 方法 / 框架 —— 完整的 WAM 解剖

综述的"方法"即其分析机器。本篇拆解形式化对象、四个轴、三种耦合、骨干家族、部署机制和属性审视，并给出每一项的代表性系统。

---

## 0. 形式化对象

一个 WAM 是一个**关于未来预测窗口与未来动作的、参数化的条件联合分布**，以上下文 `c`（过去观测、过去动作、任务/指令）为条件：

```
p_θ ( s_{t+1:t+H} , a_{t:t+H-1} | c )
```

其中 `s` 是**未来基底**（对第 2 节松散使用的观测 `o'` 的推广），`H` 是时域，`a` 是动作块。第 2 节用 `o'` 写一切；第 4 节把 `o'` 实例化为不同基底并展开到时域级记号。第 2 节的三种因式分解都是特例：

```
级联（预测后行动）：  p(o',a|o,l) = p_θ(o'|o,l) · q_ψ(a|o,o',l)        (式 5)
对动作打分：          p(o',a|o,l) = q_ψ(a|o,l) · p_θ(o'|o,a,l)        (式 6)
联合：                L = E[ -log p_θ(o',a|o,l) ]                       (式 7)
```

每个具体 WAM = 在四个轴上各做一个选择 ⇒ 一个**四元组 `(Φ, F, B, D)`**。

---

## 1. 轴 Φ —— 预测基底（"WAM 在哪里做梦"）

未来变量 `s` 所处的空间。**不**由骨干单独决定，也不由动作头看到的最后一个张量决定。判据：按*用于动作预测/评估的未来所形成的表示*来分类。一个去噪 VAE 网格但跳过像素解码的视频扩散模型**仍是像素级**的，只要一个*固定解码器*能把该网格映回视频。一个*没有固定观测解码器*的状态是*特征*。

| 基底 | 形式 | 关键性质 | 代表性 WAM |
|------|------|----------|------------|
| **像素级（Pixel-grounded）** | 解码的 RGB/RGB-D/多视角，或带*固定*视频解码器的 VAE/VQ 隐 | 未来活在观测坐标系中 | UniPi、Vidar、VERA、Veo-Act、EVA（解码）；GR-1/2、WorldVLA、VideoVLA、τ0-WM、PAD、UWM、F1、Motus（像素可解码隐）；SWEET、Audio-WM\*、OmniVTA、HarmoWAM（稀疏/多模态） |
| **特征（Feature）** | 学习到的状态 `∈ ℝ^{H×N_tok×d}`，**无固定观测解码器** | 仅由动作路径/嵌入损失解释 | Fast-WAM（仅编码器）；VPP、mimic-video、Genie Envisioner、WAV（特征抽头）；FLARE、DAWN、LDA-1B、DexWM、CLWM、FRAPPE（教师目标）；CoT-VLA、DUST、ALAM（VLM-token） |
| **几何（Geometric）** | 物理坐标张量：光流 `(u,v)`、点轨迹、深度、6-DoF 位姿、折线、运动矢量 | 未来 = 运动/结构，跨具身迁移 | Im2Flow2Act、3DFlowAction、NovaFlow、Dream2Flow、TraceGen、3PoinTr、RoboFlow4D、3D-FDP、PointWorld、Dex4D、TesserAct、HiF-VLA、ICLR-VR |
| **可供性（Affordance）** | 任务图/分数场：价值图、接触似然、分割、进度、热力图 | *对任务问题的空间回答* | AIM（空间价值图）、PALM（可供性束）、MWM（语义掩码动态）、ActionImages & MV-VDP（RGB ∧ 末端执行器热力图，联合情形） |

*联合基底*（一次前向预测 >1 种未来）在表中标记 `∧`（如 JOPAT = 像素 ∧ 点轨迹）。Audio-WM 是声学观测隐的**边缘情形**，按解码器绑定判据归入像素级。

**权衡：** 像素保留外观 + 广视频先验，但为动作不需要的细节买单；几何/可供性更小、更易监督，但丢语义；特征紧凑且不变，但*没有视觉保真度指标*。

## 2. 轴 F —— 动作耦合（"动作如何进出"）

动作表示在何处绑定到基底预测——这决定延迟、可控性和单步成本。

### (a) 动作条件化 rollout
把一个*动作源*与一个*动作条件化预测器*组合；提出的动作塑造候选未来，然后打分/选择。
```
块级：    q_ψ(a_{t:t+H-1}|c) · p_θ(s_{t+1:t+H} | c, a_{t:t+H-1})
逐步：    Π_k q_ψ(a_{t+k}|h_k,c) · p_θ(s_{t+k+1}|h_k,a_{t+k},c)
```
- *块级*（普查常态）：并行打分多个候选未来；**无法对**窗口内变化的信号做出反应。
- *逐步*（基于模型 RL 谱系：PlaNet/Dreamer）：在每个预测状态后做出反应；**失去**单窗口并行性。
- 系统：PointWorld（MPPI 搜点流）、DreamAvoid（在关键阶段采样）、EgoExo-WM（对身体运动候选做 MPC）、3D-ALP（MCTS + 渲染器神谕）、Feedback-WM（隐转移引导扩散策略）。
- **优势：** 反事实控制——候选动作在选择前塑造未来。

### (b) 联合生成
*共享骨干*上的单一生成过程同时产出基底与动作：`p_θ(s, a | c)`。训练 ≈ `L = L_gen(s) + λ·L_act(a)`。
- *联合扩散：* UWM、CosmosPolicy、VideoVLA、DriveVA、DriveWAM（共享去噪/流匹配状态）；CoVAR、UD-VLA、GigaWorld-Policy、CKT-WAM（通过桥注意力、离散扩散、动作掩码、教师前缀重新路由信息）。
- *联合自回归：* GR-1/2（下一帧 ∧ 下一动作 token）、WorldVLA（Chameleon + 动作块掩码）、PhysGen（NOVA + 逐 token 扩散解码器）、ICLR-VR（序列化状态/推理/动作流）。
- *MoE 混合：* 分离专家/头联合去噪。

### (c) 后置预测头
先合成整个未来，再从中恢复控制（`q_ψ(a | o, o', l)`）。最易拴到预训练生成器上；但可控性*只在付完全部生成成本后才到来*。系统：UniPi、AVDC、VLP、Dreamitate、Gen2Act、RoboEnvision；级联式 NovaFlow/Dream2Flow/TC-IDM；Audio-WM。

> **Φ 与 F 是不同的轴。** Fast-WAM 是*特征基底*且*仅编码器耦合*——正交的选择。

一个有用的谱系从 (c)→(a)→(b)：动作绑定得*越晚*，越便宜越模块化；绑定得*越早*，预测的未来越真正被它要服务的动作所塑造（This&That → ARDuP → CoVAR/VAG → UWM/UVA/F1/Motus → AdaWorld 在*每个*去噪步注入隐动作）。"瓶颈式"设计（AIM 的价值图、GigaWorld-Policy 把视频当副产品、π0.7 的稀疏目标图）买来便宜可控的推理，却也封顶了动作能反应的内容。

## 3. 轴 B —— 架构骨干（"预测如何产生"）

五个家族：

1. **迭代去噪（视频扩散）**——去噪一个片段/隐；丰富，但每步一次完整调度。*扩散强制（diffusion forcing）*（在因果掩码下，对确定的过去施加低噪、对不确定的未来施加高噪）是关键技巧。
2. **自回归（下一帧 / 下一 token）**——因果 token 流 + KV 缓存；天然因果且可流式（GR-1/2、WorldVLA、PhysGen、DreamZero）。
3. **联合嵌入预测（JEPA）**——在学习的嵌入空间中预测，无像素（V-JEPA 谱系、DAWN）。
4. **混合（Hybrid）**——生成头 + 动作头，MoE 路由（F1、UWM、HarmoWAM、NoiseGate）。
5. **LLM- / VLM-骨干**——给一个 (V)LM 拴上轻量动作专家；未来作为 token/特征（CoT-VLA、DUST、LDA-1B、LaMP）。

普查中骨干选择集中于**扩散与混合**。

---

## 4. 轴 D —— 部署机制（"相对控制回路何时被调用"）

| 机制 | 行为 | 注 |
|------|------|----|
| **开环 rollout** | 生成一次计划，执行它 | UniPi、AVDC、Dreamitate、Gen2Act |
| **分块闭环** | 预测一块，执行，重新接地，重复 | 实务主力 |
| **单步闭环** | 每个控制步预测 + 行动 | 最紧的延迟要求（GR-1、PAD、WorldVLA） |
| **交互式模拟器** | 在生成中接受控制信号 | 最高的可交互性门槛 |

## 5. 四元组实战

```
F1        = (像素可解码隐, 联合生成,   混合,     分块)
WorldVLA  = (像素可解码隐, 联合生成,   自回归,   单步)
FLARE     = (教师目标特征, 后置预测头, 联合嵌入, 分块)
UWM       = (像素可解码隐, 联合生成,   混合,     分块)
Wan/CogVideoX = 不是 WAM —— 它们只固定了 Φ 和 B；需要 F 和 D 才合格。
```

**设计不对称：** Φ、B 是训练时且昂贵（保守）；F、D 是推理时且灵活（新机制出现处）。**昂贵的角落** =（解码像素, 联合生成, 扩散, 单步）——很少能直接使用；方法们用模拟、离线 rollout 或更小的推理模型换走一个坐标。

## 6. 五个核心属性（第 5 节）—— 以及方法如何应对

| 属性 | 它要求什么 | 机制 / 系统 | 代价 / 张力 |
|------|-----------|-------------|-------------|
| **可交互性** | 在生成*中*接受控制，而非仅开头 | 生成中控制旋钮：This&That→ARDuP→CoVAR/VAG→UWM/UVA/F1→AdaWorld；瓶颈通道（AIM、π0.7） | 越早绑定越不模块化；瓶颈封顶反应性 |
| **因果性** | 不让未来泄漏进*当下*执行的动作 | 因果 token 流 + KV 缓存（PhysGen 前瞻多 token）；无泄漏掩码（WorldVLA、CoT-VLA）；动作优先推理/提前退出（UD-VLA 约 4×）；预测与执行重叠（DreamZero、LingBot-VA、MotuBrain）；扩散强制 | 非因果模型"在 rollout 里抓取，在推理时落空" |
| **持久性** | 在重复动作 + 重规划下保持状态（对抗漂移、成本增长、遗忘） | 观测替换/重新接地（DreamZero 7 Hz @14B、LingBot-VA）；有界内存（DexWM 900 h、Act2Goal 多尺度哈希、MoT 流） | 全历史对抗漂移但成本增长；滑动上下文限成本但遗忘 |
| **物理合理性** | *身体*能实现的未来 | 抽象阶梯（RGB→RGB-D→光流→掩码→特征）；更丰富模态（OmniVTA 触觉、AdaWorldPolicy 力、DexWM 指级）；本体感受/运动学一致（PAD、Cosmos Policy、DexWM 手部一致性损失、MVISTA-4D 残差逆模型） | "看着合理，身体做不到"——动量、力、关节限位 |
| **泛化性** | 在*两侧*都存活于任务/物体/场景/相机/具身迁移 | 视频先验迁移（GR-1/2、VideoVLA、DreamZero）；基底迁移（光流：Im2Flow2Act/3DFlowAction；掩码：MWM；特征：FRAPPE/LDA-1B）；动作抽象迁移（LDA-1B、DUST、ALAM） | 可迁移抽象 ⇒ 难评测；无设计赢所有迁移 |

> 这些属性是**相互竞争的压力**：更强的动作接口收窄因果性的无泄漏通道；有界内存饿死长程合理性；可迁移抽象击败评测。

## 7. 数据与评测（第 6 节）

**五种数据来源**（各为规模 / 动作标签保真度 / 物理接地 / 可获取性的不同折中）：
1. **机器人遥操作**——最干净的动作标签（Open X-Embodiment、RoboMIND、Human2Robot）；耗机器人+操作员时间。
2. **便携人类示范**——靠可穿戴扩规模（EgoMimic、EgoVerse、EgoDex）；有具身鸿沟待弥合。
3. **互联网第一人称/教学视频**——规模 + 视觉多样性（Ego4D、EPIC-KITCHENS、Egocentric-10k）；*无动作通道* → 需逆动力学或隐动作恢复。
4. **模拟**——精确标签、低边际成本（ManiSkill、LIBERO、RoboCasa、RoboTwin）；仿真到真实鸿沟。
5. **WAM 自身的合成数据**——WAM 当数据引擎（DreamGen、IRASim、RIGVid）；继承生成器的失效模式。

**评测阶梯**（成本 vs 有效性）：
- **视觉保真度**（FVD、FID、LPIPS、PSNR、SSIM、DreamSim）——便宜，与成功*弱*相关。
- **闭环**（LIBERO、ManiSkill、MetaWorld、RoboArena、RoboChallenge；DWorldEval 在学习的世界模型内打分）——更具预测性但消耗任务时长 rollout。
- **物理合理性 / 长程**——欠发达；无标准指标。
- **缺失的 → accuracy-at-budget：** 把成功率、延迟、可持续时域、峰值内存、接触敏感失效标签放到*同一根轴上*。两阶段协议（便宜筛查 → 在显式预算下选择性闭环测试）正在出现；筛查→测试的换算系数是 WAM 评测的核心开放问题。

## 8. 实现陷阱与复现风险（提炼）

- **因果泄漏**是沉默的杀手：通过检查策略从不关注推理时不可得的信息来验证；"rollout 里好用，真机上失败"是症状。
- **基底误分类：** 被绕过的 VAE 解码器仍是像素级；一个辅助隐状态*不是*特征基底，如果推理时面向动作的未来仍是像素可解码的。
- **延迟报告：** 延迟要*与*准确率一起、在同一硬件/任务上报告——否则数字无意义。
- **视觉指标 ≠ 效用：** 永远别用 FVD 选 WAM；稀疏表示能驱动清晰 rollout 驱动不了的成功策略。
- **动量/接触鸿沟：** 单帧条件化的光流模型编码不了速度（接触后推动任务失败）；点云省略力大小/摩擦。
- **数据阶段错配：** 汇集来源会掩盖各自监督的内容；机器人域 vs 通用人类视频*不可互换*（VidMan：错配的第一人称来源可能*有害*）。
