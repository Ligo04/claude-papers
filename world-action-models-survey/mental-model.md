# 心智模型 —— 如何思考 WAM

## 这是*哪一类*工作？

一篇**定义领域的综述**（分类法 + 框架论文），不是方法论文。它的工作是给一个混乱的、约两年大的子领域装上统一的坐标系，让后续工作能被*放置和比较*。把它当作地图和图例，而非菜谱。

精神上最接近的类比：
- "自监督学习"被划分为对比 / 预测 / 生成几个家族的方式，
- 强化学习被组织为无模型 / 基于模型的方式，
- 引入一套记号（这里是**四元组**）、随后被社区采纳的综述。

## 默认的先验知识

如果你已在工作层面掌握以下内容，会收获更多：

- **VLA**——RT-2、OpenVLA、π₀（观测+指令 → 动作，经由预训练 VLM）。
- **视频扩散/生成**——Wan、CogVideoX、Cosmos、Sora；去噪调度、VAE/VQ 隐、扩散强制。
- **基于模型的 RL / 隐想象**——PlaNet、DreamerV3（逐步 rollout 的祖先）。
- **JEPA**——V-JEPA：在嵌入空间而非像素中预测。
- **机器人学习基础**——逆动力学、动作分块、遥操作、闭环控制、仿真到真实。

如果这些陌生，先读 `summary.md`，把出现的系统名当作带标签的例子而非前置要求。

## 脑中要装的那一张图

```
                         WAM = p(o', a | o, l)   [未来留在动作路径中]
                                     │
        ┌────────────────────────────┼────────────────────────────┐
   视角1：哲学                   视角2：四元组解剖              属性审视
   (动作在推理路径               (Φ, F, B, D)                (5 个竞争需求)
    的何处被解码？)
        │                              │                            │
  Render-and-Decode             Φ 基底：像素/特征/             可交互性
   (推到像素)                       几何/可供性                因果性
  Latent-Only                   F 耦合：rollout/联合/          持久性
   (停在隐/特征)                    后置头                     物理合理性
  Video-Generation-Free         B 骨干：扩散/自回归/JEPA/      泛化性
   (无视频生成器)                   混合/LLM-VLM

```

视角 1 固定*模型必须生成什么*；视角 2 固定*它如何构建*。二者互补，不冗余。

## 它在更大研究版图中的位置

```
                 互联网规模预训练
                   /                    \
          视觉-语言                视频生成
              │                           │
            VLA  p(a|o,l)         世界模型  p(o'|o,a,l)
              \                           /
               \      把二者耦合         /
                \    未来 → 动作        /
                 ▼                     ▼
                 世界动作模型  p(o',a|o,l)
                 "预测-动作策略"
```

WAM 是"会行动的策略"与"会预测的模型"的**交集**，受三个约束限制：预测*对动作有用*、*对回路足够快*、*在内存上足够便宜*。

## 如何归类*任意*新 WAM 论文（四步法）

1. **它到底是不是 WAM？** 预测的未来是否*产生 / 打分 / 校验 / 训练*动作？如果未来头被丢弃，或模拟器只是 RL 环境 → 不是 WAM。
2. **属于哪种哲学？** 追踪推理前向过程：动作来自渲染像素（Render-and-Decode）、中间隐/特征（Latent-Only）、还是视频生成器之外（Video-Generation-Free）？
3. **写出四元组** `(Φ, F, B, D)`。这就是比较的把手。
4. **审视五个属性。** 它实际*展示*（而非声称）了哪些？每个在计算/内存/延迟上代价多少？要 accuracy-at-budget。

## 让它顿悟的类比

- **做梦 vs 行动（标题）。** 一个在行动前渲染整段电影般未来的白日梦者 = Render-and-Decode（生动、慢）。一个只感受"接下来发生什么"中刚够提交的部分的熟练运动员 = Latent-Only / Video-Generation-Free（稀疏、快）。论点"少做梦，多行动"是：*只渲染你下一步动作所依赖的那部分未来。*
- **JPEG vs 场景。** 像素级基底 = 保留整幅图像；几何/可供性 = 只保留重要的边/运动；特征 = 只保留一个嵌入。朝*控制相关性*的有损压缩，而非朝*感知保真度*。
- **编译器优化级别。** Φ 与 B 像选语言和编译器（一次设定，昂贵）。F 与 D 像 `-O` 标志和 JIT 决策（运行时调——如今的聪明所在）。

## 这篇论文纠正的常见误解

- ❌ "WAM 是带动作头的视频模型。" → 它是一个*耦合分布*；头只是三种耦合之一，且未来根本不必是视频。
- ❌ "视频越好 = 策略越好。" → 视觉保真度弱预测任务成功；*有用*的未来 > *好看*的未来。
- ❌ "按骨干分类。" → 决定性分裂是*动作在推理路径的何处解码*，它与骨干、与级联-vs-联合都正交。
- ❌ "属性是要最大化的清单。" → 它们是竞争压力；每个设计都是帕累托点。

## 半年后要记住什么

1. **定义**（未来在动作路径中）和**三种因式分解**。
2. **两个视角**：3 种哲学 + `(Φ, F, B, D)` 四元组。
3. **少做梦，多行动** = 抽象阶梯 + 按预期动作价值花费算力。
4. **五属性相互竞争**，且**评测是领域瓶颈**（需要 accuracy-at-budget）。
