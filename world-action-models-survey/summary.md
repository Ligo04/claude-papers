# 摘要总结 —— 世界动作模型综述

## 背景脉络

具身 AI 想要造出能在非结构化物理环境中感知、推理、行动的智能体。过去两年里，两条线索汇合了：

- **视觉-语言-动作（VLA）模型**（RT-2、OpenVLA、π₀）证明了互联网规模的视觉-语言预训练可以*被落地到机器人行为*，把观测 `o` 和指令 `l` 直接映射到动作 `a`。它们学习 `p(a | o, l)`——但**从不建模环境在自身干预下如何变化**。没有对物理、接触或视角变化的显式刻画。

- **世界模型**（PlaNet、DreamerV3、V-JEPA，尤其是 Wan、CogVideoX、Cosmos、Sora 等互联网规模的**视频生成器**）学习*预测未来* `p(o' | o, a, l)`，提供可迁移的视觉动力学先验——但它们不一定选择动作。

**世界动作模型（WAMs）** 把二者连起来：*一个预测的未来观测成为如何得到动作的一部分*。这个领域爆炸式增长——成果来自视频生成、机器人学习和语言模型三个社区，常常在不同名字下互相重新发明。这篇综述提供了缺失的**统一论述**。

## 问题陈述

> "World Action Model"这个标签传播的速度，超过了其背后的理解。

两个具体问题：

1. **没有统一定义。** 一个模型何时是 WAM，而不是普通 VLA、世界模型或视频世界模型？边界在哪？
2. **没有统一的比较轴。** 共用 WAM 标签的方法在几乎每个实现细节上都不同；密切相关的方法却用完全不同的术语。逐篇罗列无法比较它们。

统一一切的底层接口问题：**哪个被预测的未来被保留下来供动作使用，以及动作在推理路径的何处被解码？** 每个答案都以控制回路*内部*的计算、内存、延迟为代价换取预测的丰富性。

## 主要贡献

1. **精确的 WAM 定义**（图 1）。WAM 要求预测的未来留在*动作路径*中——去产生、打分、校验或训练动作——通过以下三种因式分解之一：
   - **预测后行动（级联）：** `p_Θ(o',a|o,l) = p_θ(o'|o,l) · q_ψ(a|o,o',l)`——如 UniPi、VLP、AVDC。
   - **对动作打分：** `p_Θ(o',a|o,l) = q_ψ(a|o,l) · p_θ(o'|o,a,l)`——提出一个动作，评估其预测后果。
   - **联合：** `p_θ(o',a|o,l)`——一个骨干同时预测未来与动作（GR-1/2、PAD、UWM、WorldVLA）。

2. **设计哲学分类法**（第 3 节）——互斥、且在普查集合上完备，依据是*每个方法在解码动作前必须生成什么*：
   - **Render-and-Decode（渲染再解码）**——把视频骨干一路跑到像素，再解码动作。
   - **Latent-Only（仅隐空间）**——保留视频派生的先验，但在像素解码前停下；动作来自隐变量、去噪特征、光流、掩码或价值图。
   - **Video-Generation-Free（无视频生成）**——移除视频骨干；在 LLM/VLM token 空间、JEPA 嵌入、冻结视觉特征或非视频扩散中预测。

3. **四轴组件解剖**（第 4 节）——把每个 WAM 表示为一个**四元组** `(Φ, F, B, D)`：
   - **Φ 预测基底**——*未来活在哪里*：像素级 / 特征 / 几何 / 可供性（affordance）。
   - **F 动作耦合**——*动作如何进出*：动作条件化 rollout / 联合生成 / 后置预测头。
   - **B 架构骨干**——*预测如何产生*：扩散 / 自回归 / 联合嵌入（JEPA）/ 混合 / LLM-VLM。
   - **D 部署机制**——*如何在回路中运行*：开环 / 分块闭环 / 单步闭环 / 交互式。

4. **属性审视**（第 5 节）——具身性所要求的五件事：**可交互性、因果性、持久性、物理合理性、泛化性**——以及每个方法如何满足或错失每一项，其解法的代价是什么。

5. **数据与评测的组织**（第 6 节）——五种数据来源，以及从视觉→模拟→真机的评测阶梯，揭示成本/有效性的权衡。

6. **开放挑战**（第 7 节）——按其在 WAM 栈中出现的位置定位。

## 关键结论（综述的"结果"即其组织性论断）

- **四元组能放置每一个 WAM。** 例：F1 =（像素可解码隐, 联合生成, 混合, 分块）；WorldVLA =（像素可解码隐, 联合生成, 自回归, 单步）；FLARE =（教师目标特征, 后置预测头, 联合嵌入, 分块）；UWM =（像素可解码隐, 联合生成, 混合, 分块）。
- **设计的不对称性：** 基底 Φ 与骨干 B 是*训练时*选择（昂贵、保守——集中在 4 种基底类别和扩散/混合骨干）。耦合 F 与机制 D 是*推理时*的，灵活得多——这正是近期大多数创新出现的地方（自适应 K 分块、事件触发调用、慢-快双频回路）。
- **昂贵的角落**——解码像素基底 + 联合生成 + 扩散骨干 + 单步闭环——在生产中几乎无法使用；看似占据它的方法实际上都换走了一个坐标（用模拟、离线 rollout 或推理时更小的模型）。
- **视觉指标弱预测任务成功。** Fast-WAM 与 GigaWorld-Policy 在推理时丢弃渲染的预测*而不损失控制*；MotuBrain 报告世界模型分数与下游成功之间仅有弱相关。
- **历史轨迹**（图 3）从 Render-and-Decode → Latent-Only → Video-Generation-Free：从生成完整视觉未来，到*生成更少的未来却保留控制所需的部分*。

## 论文提到的量化锚点

- **DreamZero**：用 **14B** 自回归视频扩散模型、借助 KV 缓存观测替换，维持 **7 Hz** 闭环控制。
- **UD-VLA**：通过同步联合离散去噪，推理比自回归对手快约 **4 倍**。
- **DexWM**：有界测试时内存使其能在 **900 小时**人类+机器人交互上训练/运行。
- **普查**：两张表（表 1 = Render-and-Decode + Latent-Only；表 2 = Video-Generation-Free），跨越 2023.02（UniPi）→ 2026（DAWN、RoboFlow4D 等），约 200 篇参考文献。
