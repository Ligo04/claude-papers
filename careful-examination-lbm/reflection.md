# Reflection — 延伸、开放问题与脆弱假设

## 如果我要扩展这篇论文

1. **计入训练随机性**：本文最大方法论缺口是 CI 只覆盖评估随机性，未积分掉 $p_\text{train}(w|dataset)$。→ 训多个种子的策略、把"训练-评估"两级随机性都纳入层次贝叶斯模型，才能严格比较**架构 A vs B**（而不仅是"这个 checkpoint vs 那个"）。

2. **把语言可操控性做成一等实验**：作者猜测零样本 LBM 不稳定是因 CLIP 小语言编码器。→ 固定视觉/动作，只换语言编码器容量（CLIP → T5 → LLM 级），在"视觉歧义、必须靠语言区分"的 Breakfast/Kitchen 场景做对照，直接测量"语言 steerability vs 语言编码器规模"的曲线。

3. **主动评估 / 更省的统计**：50 次 rollout 很贵。→ 引入序贯/自适应停止（已用了一部分）、重要性采样初始条件、或用仿真做**功效分析预算规划**（给定目标效应量，算需要多少真机 rollout）。

4. **归一化的系统性消融**：既然归一化能盖过架构，值得一篇专门工作：逐特征 vs 全局、逐时间步 vs 共享、百分位裁剪范围、按数据源分离——各自对 nominal / OOD 的独立影响。

5. **缩放规律外推**：本文说"无锐利拐点"，但数据规模有限。→ 把预训练数据推到 10×，看 TC 是否仍平滑增长、是否出现涌现，以及 OXE 异构数据的边际收益何时饱和。

## 仍然开放的问题（Open Problems）

- **零样本多任务为何不稳？** 是语言编码器容量、数据配比、还是 diffusion 策略本身对语言条件的利用不足？本文只给了假设。
- **sim 与 real 的定量对齐**：Kiwi/Mug 等任务出现"真机比仿真更成功"，说明仿真 timeout、动力学或视觉差异仍在系统性扭曲结论。如何让 sim 评估成为 real 的**无偏预测器**？
- **TC rubric 的可扩展性**：人工里程碑不可能覆盖成千上万任务。能否用 VLM 自动生成/评判 rubric，并保持 QA 级可靠性？
- **效应量本身在变大吗？** 作者警告"可能在测噪声"。随着模型变强、效应变大，严格统计的边际必要性会下降还是上升？
- **跨具身（embodiment）迁移的统计验证**：OXE 补零成双臂、随机换臂——这种粗暴对齐到底贡献了多少？值得单独审计。

## 哪些假设是脆弱的（Fragile Assumptions）

1. **"聚合任务 ≈ i.i.d."**：作者承认聚合破坏 i.i.d.（每任务试验数是固定而非随机抽），只是"经验上影响可忽略"。在任务数少、任务难度极不均衡时，这个近似可能失真。

2. **"50 次足够"**：对 ~10-20% 效应够用，但论文自己承认可能漏掉小效应——很多"统计不可区分"的结论其实是**功效不足**，不等于"真的没差别"。

3. **Welch's t-test 用在离散 TC 上**：明确违反正态假设，Type-I 误差不受控，仅靠大样本 + CLT 兜底。TC 分布若强烈多峰/偏斜，结论需谨慎。

4. **归一化 bug 的影响"很小"**：这个结论来自**小规模仿真**消融，未在真机主实验上验证。主结论建立在一个已知有 bug 的预训练之上——虽方向性结论大概率稳健，但绝对数字应打折扣。

5. **CLIP 编码器代表性**：所有关于"语言 steerability"的结论都绑定在小语言编码器上，作者自己说大 VLA 可能不同——因此**不要把零样本负面结论外推到 GR00T/π0 级模型**。

## 它可能在实践中哪里失效

- **超长程 / 强序列依赖任务**：TC 里程碑是线性累加的，对"前一步错则后续全错"的强耦合任务，TC 可能高估"部分完成"的价值。
- **高度动态 / 安全攸关场景**：整套协议假设准静态 tabletop、可复现初始条件；对移动操作、人机协作、动态物体，overlay 复现和 seed 确定性都会崩。
- **数据分布极端不均**：批平衡权重是"经验找到的"，换数据集需重新调，缺乏原则性。
- **他人复现**：没有开源 checkpoint/完整数据（TRI 内部数据），社区只能复现**协议**而非**结果**——这既是它的贡献（协议可迁移）也是它的局限（结论难独立验证）。

## 一个值得深思的元问题 🐾

> 这篇论文用严格统计证明了"预训练有用"，但它也顺手证明了"**我们过去很多关于机器人策略的信念，可能从未被严格验证过**"。
>
> 如果连"预训练有用"这种看似显然的命题都需要 1800 次真机 + 47000 次仿真 + 贝叶斯 + 假设检验才能站住——那整个领域里还有多少"人尽皆知"其实是"从未证实"？这才是本文最深远的余震。
