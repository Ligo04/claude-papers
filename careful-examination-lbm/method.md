# Method — 方法拆解

本文有**两条并行的"方法线"**：(A) LBM 模型本身；(B) 评估协议与统计分析（真正的原创贡献）。下面分别拆解。

---

## Part A：LBM 模型

### A.1 生成式策略：DDIM/DDPM 扩散

策略是一个**条件扩散模型**，把高斯噪声去噪成连续动作序列，条件是视觉 + 本体 + 语言观测。

**DDIM 去噪更新（式1）**：
$$A^{k-1}_t = \alpha\left(A^k_t - \gamma\cdot\epsilon_\theta(O_t, A^k_t, k)\right)$$

- $A^k_t$：第 $k$ 步去噪时刻 $t$ 的含噪动作；$O_t$：观测；$k$：扩散步。
- $\alpha, \gamma$：由噪声调度决定；$\epsilon_\theta$：噪声预测网络。

**训练损失（式2，标准 DDPM）**：
$$\mathcal{L}(\theta) = \left\|\epsilon_k - \epsilon_\theta(O_t, A^k_t, k)\right\|^2_2$$

采样 $A^0_t$ 与随机步 $k$，加噪 $A^k_t = A^0_t + \epsilon_k$，训网络从含噪动作预测噪声。

### A.2 策略架构（Diffusion Transformer）

```
                     ┌─────────────── 观测 O_t（历史 n_obs=2） ───────────────┐
   6× RGB ──► CLIP ViT-B/16 (CLS token, 微调) ─┐
   语言指令 ──► CLIP text enc (冻结) + 投影层 ──┤
   本体(EE位姿/夹爪宽度) ───────────────────────┼─► concat ─► 条件特征 (size 6732)
   扩散步 k ──► 正弦位置编码 + 2层MLP ──────────┘            │
                                                              ▼  (adaLN 注入)
                              ┌──────────────────────────────────────┐
   含噪动作 A^k_t ───────────►│   DiT × 8 层, embedding = 768         │──► 预测 ε
                              └──────────────────────────────────────┘
                                                              │
                              输出: 16 步 × 20 维 = 320 维动作 A_t
```

**关键规格**：
- **8 个 DiT block，嵌入维度 768**；扩散步 $k$ 经正弦编码 + 2 层 MLP，通过 **adaptive LayerNorm (adaLN)** 注入。
- 视觉：CLIP **ViT-B/16** 的 CLS token；**微调**视觉编码器（LR 为其余部分的 1/10），所有相机共享。
- 语言：CLIP 文本编码器**冻结**，只训顶部投影层（EOS pooled token）。
- 单任务/从零策略用**同一架构**，只是语言 prompt 固定为该任务。

### A.3 观测与动作空间

| 空间 | 内容 |
|------|------|
| **观测** | ① EE 位姿（相对工位基座系=桌心）② EE 相对另一臂位姿 ③ 连续夹爪宽度 ④ 6 路 RGB（缺失相机零填充）⑤ 1 条自然语言指令。历史 $n_{obs}=2$ |
| **动作** | EE 位姿（基座系）+ 夹爪宽度。旋转用 **6D 表示**（旋转矩阵前 2 行）。预测 horizon $n_{horizon}=15$，共 16 步 |

- 采用相对轨迹表示（类 UMI [48]）。
- OXE 单臂数据 → 补零成双臂，并随机交换左右臂。
- 每条 TRI-Ramen 含一组语言指令（1 条人写 + 5 条 ChatGPT 改写），推理时随机采样；OXE 缺语言标注填 "do something useful"。

### A.4 数据归一化（⚠️ 出过 bug 的地方）

**逐特征维度 + 逐时间步**归一化到 $[-1.5, 1.5]$：
$$y_i = \min\left(\max\left(-1.5,\ 2\frac{x_i - x_{0.02}}{x_{0.98}-x_{0.02}} - 1\right),\ 1.5\right)$$

- 用 **2nd/98th 百分位**缩放（把 2%~98% 映射到 [-1,1]），保留部分离群值但把分辨率集中在高密度中心。
- **逐时间步独立**计算：因为动作是相对当前观测的，越远的未来动作分布越宽；逐步归一化能为"近未来动作"（更重要）保留分辨率。
- 6D 旋转**不归一化**（本就在 [-1,1]，避免破坏旋转矩阵）。
- 归一化参数**按数据源分别**计算（OXE-Ramen、UMI 各自；Real+Sim 合并算 `lbm_robot` 参数）。测试时用 `lbm_robot` 反归一化。

> **🐛 Bug**：预训练时因代码错误，一个 batch 内**部分 datagram 用了错误数据源的归一化参数**。事后小规模仿真消融（Fig S21）：nominal 下差异小，**正确归一化在分布偏移下更好**。作者因真机评估太贵未重跑主实验，但诚实披露。**教训：归一化影响可能盖过架构。**

### A.5 数据过滤（起始低运动帧）

TRI-Ramen 开头常有静止帧（遥操作 UI 加载慢/操作员误触）。定义运动阈值（平移 >5cm 或旋转 >15°）裁掉起始静止段。
- 过滤后**单任务性能提升**；但**预训练 LBM 反而更爱"擅自执行别的任务"**。
- 折中：**预训练用未过滤数据，微调/单任务用过滤数据**（仿真任务）。

### A.6 训练与部署配方

| 超参 | 预训练 | 微调(真机) | 微调(仿真) | 单任务(真机) | 单任务(仿真) |
|------|--------|-----------|-----------|-------------|-------------|
| Learning Rate | 3e-4 | 2e-5 | 2e-5 | 2e-5 | 2e-5 |
| Batch Size | 2560 | 320 | 320 | 320 | 320 |
| Steps | 48k | 30k | 10k | 100k | 25k |
| LR schedule | Constant | Constant | Constant | Constant | Constant |

- 图像增广：resize 256×342 → random crop 224×224 + color jitter（部署时改 center crop）。
- 训练算 16 步动作损失，**部署只执行前 8 步**再重规划，**10 Hz** 闭环。
- 平台：双臂 **Franka FR3** + WSG50-110 夹爪 + finray 指；关节阻抗控制 + 差分逆运动学（含避碰）；9 个真机工位。

## Part B：评估协议与统计分析（核心贡献）

### B.1 公平对比协议

- **盲测**：评估者不知道当前是哪个策略。
- **随机化策略顺序**：抵消环境漂移（光照等）。
- **一致初始条件**：真机把评估拆成"bundle"（bundle 大小 = 被比策略数），同一初始条件下随机顺序跑完所有策略再换下一个初始条件；用**图像 overlay**（当前相机图 vs 目标场景）让操作员手动复现初始场景。仿真用同 seed 采样初始条件。

### B.2 指标：SR 与 TC

- **Success Rate (SR)**：二值成功/失败 → 估计 Bernoulli 参数 $p$。
- **Task Completion (TC)**：基于**里程碑**的部分分。
  - 真机：人工填 **rubric**（"抓住苹果了吗""掉了吗"等二值问题），完成里程碑 +1，除以里程碑总数。
  - 仿真：**predicate**（定义在仿真状态上，如"苹果中心距桶中心 < 阈值"）自动判定，成功 = 一组 predicate 全 True。

### B.3 Rubric QA（人为误差量化）

对 ~2700 真机 rollout 的 **27%** 做独立质检（QA 人员与评估者分离）：
- SR 差异 **2.31%**，问题级差异 **6.25%**；据此修正了 5 个 rollout。**Section III 结果是修正后的。**

### B.4 单策略不确定性（贝叶斯）

- **SR**：均匀 Beta 先验 → 后验画成小提琴图，反映真实 $p$ 的不确定性。
- **TC**：分类分布，均值不足以刻画分布（高阶矩不定），故直接画**原始数据分布**的小提琴图；仅在"分数微调效应""策略间比较"时才用均值（配均匀 Dirichlet 先验）。
- **为何不用 CI**：① 小提琴图信息更全；② CI 重叠 ≠ 无显著差异（易误判）。

### B.5 多策略比较（假设检验 + CLD）

对 $k$ 个策略做 $k(k-1)/2$ 次成对检验：
- **Bonferroni 校正**维持全局 95% 置信。
- **二值 SR**：序贯假设检验框架 [75] + [79] 的检验，小样本下功效好且严格控制 Type-I 误差（假阳 ≤ 5%）。
- **TC（分类）**：无法用 [79] → 用 **Welch's t-test** 比较均值（依赖大样本 ≥50 + 中心极限定理近似）。
- **Compact Letter Display (CLD)**：给每个策略贴字母（"a"/"ab"/"bc"…），**不共享字母 = 95% 置信下可区分**。
- 多任务聚合：不再逐对再校正（否则过严）；聚合产生可交换（exchangeable）Bernoulli 序列近似 i.i.d.，作者验证违反影响可忽略。

### B.6 分布偏移的系统化构造

**仿真（appearance 为主）**：
- 第二方向光源（强度/方向偏移）；环境贴图从 20 个未见选项抽；相机内外参随机；物体/桌面替换纹理与颜色；场景 B 加随机干扰物。

**真机（两类）**：
- **Station shift**：在**不在该任务微调集**里的工位上评估（跨工位迁移），初始条件同 nominal。
- **Object-centric shift**：每个关键 manipuland 至少 5 个新实例 + 不同杂乱度的干扰物（尽量选预训练数据里没有的新物体）。

## Part C：实验设计（回答三大假设）

| 任务类别 | 定义 | 用途 |
|---------|------|------|
| **Seen** | 在 TRI-Ramen 预训练集里的任务 | 验证"预训练 SR>0"、"微调 > 单任务" |
| **Unseen** | 不在预训练集（仿真新任务 + 全新长程真机任务，如 CutAppleInSlices） | 验证"新任务学得更快、更省数据" |

- 仿真评估：16 seen + 8 unseen 任务；4 个场景（DryingRack / Shelf / Breakfast / **Kitchen**，K 完全不在预训练里）。
- 真机评估：3 seen（有匹配仿真数据）+ 5 unseen 长程任务。
- **缩放规律实验**：用 25% / 50% / 100% TRI-Ramen + 全量(含OXE) 四档预训练，比较微调后 TC → 预训练数据越多、微调数据越少时收益越明显。

## 复现陷阱与风险（Reproduction Pitfalls）

1. **归一化参数按数据源分离**——搞错就是那个 bug，影响可能大于架构。**务必单独消融归一化。**
2. **逐时间步归一化**：别用全局单一归一化，会牺牲近未来动作分辨率。
3. **旋转不归一化**：6D 旋转过归一化会破坏旋转矩阵。
4. **过滤策略非对称**：预训练不过滤、微调过滤——反直觉但作者实测如此。
5. **部署 vs 训练裁剪**：训练 random crop，部署 center crop；训练算 16 步，部署执行 8 步。
6. **统计功效**：50 次真机 rollout 只够抓 ~10-20% 量级效应；想抓小效应必须加样本。
7. **GPU 策略非确定**：仿真同 seed 环境确定，但 GPU 策略推理不保证逐位复现。
8. **TC 依赖人工 rubric**：没有 QA 流程，人为误差会污染结论。
