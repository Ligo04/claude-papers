# A Careful Examination of Large Behavior Models for Multitask Dexterous Manipulation

> **TRI LBM Team（丰田研究院）· arXiv:2507.05331v1 · 2025-07-07**
> 项目主页：https://toyotaresearchinstitute.github.io/lbm1/

---

## 这篇论文在讲什么（一段话）

这是一篇**"打假 + 立标准"**性质的实证论文喵。当下机器人领域盲目跟风"大行为模型"（Large Behavior Models, LBM），但**几乎没人能拿出统计上站得住脚的证据**证明"多任务预训练到底有没有用、用在哪"。TRI 团队没有发明新架构，而是把已有的 **Diffusion Policy** 扩展成多任务 LBM，在 **~1700 小时、500+ 任务**的数据上预训练，然后设计了一套**极其严格的评估流水线**（盲测 A/B、随机化、贝叶斯后验、假设检验），用 **~1800 次真机 + 47000+ 次仿真** rollout 去回答一个朴素问题：**预训练到底带来了什么？** 结论：预训练让策略**更省数据（3-5×）、更强、更鲁棒**，且收益在**分布偏移下被放大**——但零样本（不微调）的 LBM 并不稳定胜过单任务基线。

## 关键 takeaways（先记住这 6 条）

1. **贡献是"评估方法学"，不是模型**：论文刻意固定架构，只研究"多任务预训练"这一个变量。
2. **微调后的 LBM 全面胜出**：同等数据下优于从零训练；达到同等性能只需 **1/3 ~ 1/5** 的任务数据。
3. **分布偏移放大收益**：nominal 下仿真 3/16 任务显著更优 → 分布偏移下变成 **10/16**。
4. **零样本 LBM 结果喜忧参半**：不微调时不稳定胜过单任务，作者归因于 **CLIP 小语言编码器的"语言可操控性"脆弱**。
5. **设计细节 > 架构**：一个**数据归一化 bug** 的影响，可能盖过架构/算法改动——比较方法时必须隔离这些变量。
6. **统计功效警告**：很多机器人论文的样本量太小，**可能在测量噪声**。这是对整个领域的方法论敲打。

## 关键数字速查

| 项目 | 数值 |
|------|------|
| 预训练数据 | **~1695 小时**（Ramen 混合集） |
| └─ TRI-Ramen | 545h / 532 任务 / 64,262 demos（Real 468h + Sim 45h + UMI 32h） |
| └─ OXE-Ramen | ~1150h（Open X-Embodiment 子集） |
| 真机试验 | **~1800** 次盲测 A/B rollout（每任务每策略每条件 50 次） |
| 仿真试验 | **>47,000** 次 rollout（每任务每策略每条件 200 次） |
| 省数据倍率 | **3-5×**（仿真 <30%，真机 SetBreakfastTable 仅 15% 即超越全量基线） |
| 架构 | Diffusion Transformer，8 层 / 768 维，CLIP ViT-B/16 |
| 动作空间 | 20 维 × 16 步 = 320 维输出，10 Hz，执行前 8 步后重规划 |
