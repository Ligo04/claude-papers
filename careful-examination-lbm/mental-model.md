# Mental Model — 把这篇工作装进研究地图

## 这是什么类型的问题？

**一篇"评估方法学 + 实证审计"论文**，而非算法/架构论文。它属于机器人学习里一个被长期忽视的子领域：**如何可信地测量一个机器人策略有多好**。

用三个坐标定位：
- **X 轴（贡献类型）**：不是"新模型"，而是"新评估协议 + 对现有假设的严格检验"。
- **Y 轴（对象）**：多任务预训练（Large Behavior Models）的因果价值。
- **Z 轴（手段）**：临床试验级别的对照实验（盲测、随机化、贝叶斯 + 假设检验）。

---

## 假设的先验知识（Prerequisites）

要读顺这篇，你需要：

1. **模仿学习 / 行为克隆基础**：知道"用遥操作 demo 监督训练策略"是什么。
2. **扩散模型**：DDPM 训练目标、DDIM 采样；Diffusion Policy 的思路（把动作生成当去噪）。
3. **VLA / 机器人基础模型**：了解 Octo、π0、GR00T 这条线在做什么。
4. **贝叶斯统计**：Beta-Bernoulli 共轭、后验、Dirichlet 先验。
5. **假设检验**：Type-I 误差、多重比较校正（Bonferroni）、t-test 的假设。
6. **Transformer / ViT / CLIP**：架构侧的常识。

如果 4-5 薄弱，重点读 `method.md` Part B 和 `code/` 里的贝叶斯/CLD demo。

## 如何在脑内归类这项工作

给它贴三个标签，方便日后检索：

1. **"机器人界的 RCT 宣言"** — 把随机双盲对照实验引入策略评估。
2. **"预训练价值的因果审计"** — 在变量隔离下量化多任务预训练的三重收益（省数据 / 更强 / 更鲁棒）。
3. **"细节 > 架构的警世钟"** — 归一化 bug 案例证明工程细节可盖过架构差异；统计功效不足使很多比较等于测噪声。

## 读这篇论文该带走的"思维工具"

1. **变量隔离**：想归因某个因素，先把其它全部锁死。
2. **相对 > 绝对**：可平移的绝对指标不可比，盯相对差异。
3. **先算功效再下结论**：小效应 + 大噪声 + 小样本 = 可能在测噪声。
4. **分布偏移是默认，不是加分项**：不测 OOD 就是在藏起最重要的信息。
5. **部分分 > 全或无**：长程任务用 TC 保留信息。
6. **诚实披露坑**：归一化 bug、过滤反直觉——负面结果同样是知识。
