# T-Rex：触觉反应式灵巧操作（Tactile-Reactive Dexterous Manipulation）

> Niu, Liu, Wang 等（UC Berkeley、NVIDIA、Stanford、Panasonic、罗马一大）— arXiv:2606.17055（2026）
> 项目主页：https://tactile-rex.github.io/

## 这篇论文讲什么（一段话）

人类的灵巧操作依赖**触觉**，而且反应速度远快于视觉控制回路——把卡片滑进窄缝、用钥匙开锁、把牙膏挤到牙刷上。今天的视觉-语言-动作（VLA）机器人基础模型本质上"对触觉是盲的"：触觉数据稀缺，即便用上也只是当作静态、低频的信号。**T-Rex** 端到端地解决了这个问题，做出三项贡献：(1) 一个 **100 小时、触觉同步的双臂遥操作数据集**，围绕 22 个**运动基元（motor primitives）**而非具体任务来组织；(2) **T-Rex 模型**——一个变速率的 **Mixture-of-Transformer-Experts (MoT)** 架构，把控制拆成慢速（约 5 Hz）的动作专家做视觉运动规划、与快速（约 20 Hz）的触觉专家做高频反应式**精修（refinement）**，并配一个**时空触觉 VQ-VAE** 编码器；(3) 一个 **12 个任务的真实世界基准**，在富接触灵巧任务上比最强基线高出 **30 个百分点以上的平均成功率**。

## 难度

**进阶（Advanced）。** 需要熟悉：流匹配 / 扩散策略（flow matching / diffusion policy）、Transformer / 专家混合架构、VQ-VAE，以及近期的 VLA 基础模型文献（π₀、GR00T、EgoScale）。核心*思想*（慢规划 + 快触觉微调）很直观；但其*机制*（共享速度目标的异步级联流匹配）值得仔细推敲。

## 核心要点（5 条）

1. **预训练阶段不需要触觉数据。** 触觉能力可以在专门的**中训练（mid-training）**阶段、在仅视觉的人类视频预训练（EgoScale 配方）之上注入。这样就绕开了大规模同步视触觉数据采集的高昂成本。
2. **真正的架构难题是频率不匹配。** 触觉反应式控制需要约 20 Hz 的闭环响应，而 VLM 主干慢得多。T-Rex 用**速率解耦**化解：重的视觉/规划专家每个 chunk 只跑一次，轻的触觉专家在同一个 chunk 内复用缓存上下文多跑几次。
3. **触觉是"残差精修"，不是"重新规划"。** 动作专家把流匹配轨迹从噪声去噪到中间时刻 τ_split=0.4；触觉专家用实时触觉把剩下的去噪（0.4 → 0）完成。两者回归**同一个**速度目标——所以触觉只是"轻推"，不会和规划"打架"。
4. **时间维度的触觉编码很重要。** 对一段 16 步的力历史做逐指 VQ-VAE，胜过静态 MLP——去掉它掉约 6%，完全去掉触觉掉约 23%。
5. **运动基元数据 > 任务专用数据。** 同样 100 小时预算下，围绕多样"动词-名词"基元采集的数据，其泛化与迁移远好于任务专用演示。
