# 洞见 — T-Rex（真正重要的部分）

## 用大白话讲核心思想

想象把一张信用卡插进一条很窄的缝里。你的眼睛搭好"接近动作"——把卡片*大致*带到缝口。但最后这几毫米是由你的**指尖**控制的：你感到卡片卡住、感到它顶到边缘，于是做出微小、快速的修正——这远比你"看一眼、再决定、再重新规划"要快得多。视觉负责规划；触觉负责闭合回路。

T-Rex 把这种分工直接做进了一个神经策略里：

- 一个**慢大脑**（*动作专家*）看相机和语言指令，铺出一条粗略动作规划——"把卡片往缝口移"。它大约**每秒跑 5 次**。这很重：它得跑那个大视觉主干。
- 一个**快反射**（*触觉专家*）拿过这条粗规划，用实时触觉来*精修*它——"我感到左边有阻力，往右挪一点"。它大约**每秒跑 20 次**。这很轻：它完全跳过视觉主干，复用慢大脑已经算好的东西。

巧妙之处在于**交接是怎么发生的**。两个专家共享同一条流匹配去噪轨迹：

> 动作生成 = 去噪。从纯噪声出发，沿一个学到的速度场积分到干净动作。**动作专家把 τ 从 1（噪声）去噪到 0.4**——产出一个*部分去噪的、中间态*动作。然后它**停下并缓存**自己的视觉上下文。**触觉专家从 τ=0.4 接手、把去噪一路完成到 τ=0**——但条件是*实时触觉*。最终完全去噪的动作就是机器人要执行的。

所以触觉信号是在去噪的**最后一段**进入的——在那里它只能对一个已经定下的规划做*精细调整*。它精修；它不重新规划。这就是全部窍门，也正是它让触觉成为*反应式残差*而非竞争性控制器的原因。

## 为什么有效

**1. 流匹配天然提供了一个可供"分裂"的"由粗到细"轴。**
在流匹配 / 扩散里，早期去噪步（接近 τ=1）决定动作的*粗*结构，后期步（接近 τ=0）决定*细*节。在 τ_split=0.4 处分裂轨迹，几乎完美对应"视觉决定粗运动、触觉决定细运动"。这很优雅：架构上的解耦（慢 vs 快）与去噪过程内部本就存在的*语义*解耦（粗 vs 细）对齐了。τ_split 的消融（图 4）证实存在一个甜点区——太早则规划太模糊、触觉无从精修；太晚则触觉无处发挥。

**2. 共享的速度目标让两个专家保持一致。**
两个专家都被训练去回归*同一个*流目标 v⋆ = ε − A_demo，只是覆盖 τ 的不相交子区间。它们不是两个分别训练、可能彼此冲突的控制器。它们是同一个去噪器的两半。这就是触觉为何*精修*而非*打架*：在边界 τ_split，触觉专家精确地接着动作专家正在积分的那条轨迹往下走。

**3. 异步执行在不引入第二个模型的前提下击败了频率不匹配。**
VLA 里昂贵的部分是视觉/语言主干。通过在 τ_split 处缓存它的键值上下文（`KV_τ_split`）、让触觉专家复用，快回路*从不碰那个重网络*。于是你在 5 Hz 规划器之上得到 20 Hz 的反射，却不必付 4 倍算力——重活在整个 chunk 上被摊销了。对长度 16 的 chunk，慢流只跑一次（6 个 Euler 步），快流在偏移 {0,4,8,12} 处触发（每次 4 个 Euler 步）。

**4. 中训练是注入触觉的正确位置。**
"触觉无需进入预训练"这一洞见在经济上意义巨大。预训练规模（22,889 小时人类视频）恰恰是*触觉数据不存在、也无法廉价采集*的区间。把触觉学习推迟到一个 100 小时的中训练阶段——大到足以学会接触动力学，小到真的采得起——他们就同时拿到了两样东西：互联网规模的视觉运动先验**和**接地的接触反应性。

**5. 时间维度的力编码捕捉了静态编码器丢掉的东西。**
触觉的有趣之处恰恰在其*动态*：滑动的起始、接触时的尖峰、抓握稳定后的衰减。对当前力向量做静态 MLP 只能看到单帧，错过了这一切。逐指 VQ-VAE 在 16 步力历史上把这些*时间模式*压成离散 token。消融显示这很重要（去掉掉 6–7%），直觉上这是"我正碰到某物"与"某物刚开始打滑"之间的区别。

## 它带来了什么概念转变

快/慢机器人控制此前的主流框架是**双系统架构**（System-1/System-2、fast-in-slow）：一个*独立*的快策略和一个*独立*的慢推理器，常被训练成、甚至搭建成两个不同网络并带一套交接协议。T-Rex 把快/慢分裂重新表述为**一个模型内、单条去噪轨迹的两个区段**。"系统边界"变成了一个*去噪时刻*，而不是一个网络边界。这是更干净的抽象：只有一个目标、一个速度场、一组共享的多模态注意力——而"快 vs 慢"只是*你在 τ 上处于何处、以及你以什么为条件*。

第二个转变：**触觉是一种精修模态，而非输入模态。** 以往工作问的是"我该如何编码触觉、并把它和视觉一起喂进去？"T-Rex 问的是"触觉该在动作生成的*哪个阶段*介入？"——答案是"最后一段，作为残差"。π₀.₅+tactile 的结果（17% → 6%）是旧框架的反面教材：把触觉当作又一个 token 塞进去，可能主动地伤害性能。

## 权衡

| 你得到 | 你付出 |
|---|---|
| 在慢 VLA 主干上得到 20 Hz 触觉反应性 | 一个固定的 τ_split——粗/细边界是超参数，而非按情境学习 |
| 触觉精修而不破坏规划的稳定性 | 触觉*无法*触发重新规划；若粗规划本身错了，反射救不回来 |
| 廉价的快回路（复用缓存 KV） | 缓存的视觉上下文在 chunk 内是*过时的*——对约 0.2 秒的 chunk 没问题，对快速场景变化不行 |
| 触觉能力来自 100 小时、而非预训练规模 | 仍需一个强的、仅视觉的预训练主干（EgoScale）来嫁接——并非从零训练的配方 |
| 离散 VQ-VAE 力 token 紧凑地捕捉动态 | VQ-VAE 增加训练复杂度（码本、commitment loss）和一个离散化瓶颈 |

## 与先前工作的对比

- **对比 π₀ / π₀.₅ / GR00T（视觉 VLA）：** 同属流匹配动作专家的脉络，但它们对触觉是盲的。论文展示了 T-Rex 的全部要点——π₀.₅ 得 17%，而*糟糕地*加触觉把它拉到 6%。
- **对比 EgoScale：** T-Rex *建立在* EgoScale 的人类第一视角预训练之上（核心作者相同）。EgoScale 是最强基线，35%——它有视觉运动先验，但没有触觉反应性。T-Rex = EgoScale + 触觉中训练 + 触觉专家 → 65%。
- **对比 RDP（Reactive Diffusion Policy）：** RDP 也用变速率扩散做慢-快视触觉精修——但它是面向*平行夹爪*的*任务专用模仿*策略、从零训练。它在此只得 6%，因为缺乏大规模预训练。T-Rex 把 RDP 的慢-快思想推广到*基础模型*设定，配统一 MoT 与灵巧双臂手。
- **对比 ViTacFormer / Tactile-VLA：** ViTacFormer（ACT 式交叉注意力融合 + 未来触觉预测）与 Tactile-VLA（触觉感知 VLA）都整合了触觉，但都是*静态*且无大规模预训练；分别为 13% 与 15%。

## 实践启示

1. **若你已有强视觉 VLA、想要富接触技能：** 你大概率无需重新预训练。加一个触觉中训练阶段和一个精修专家即可。这是一个*改造（retrofit）*配方。
2. **不要只是拼接触觉 token。** π₀.₅+tactile 的失败是直接警告。整合的*阶段与机制*比编码器更重要。
3. **围绕运动基元采集数据，而非任务。** 在固定预算下，以基元为中心的采集泛化与零样本迁移更好（图 6），且在下游任务间复用性高得多。
4. **在*时间维度*上编码触觉。** 想抓住滑动与瞬变，就用一段力历史窗口，而非只用当前帧。

## 值得内化的局限

- **反射无法覆盖规划。** 因为触觉只作用于 τ ∈ [0, 0.4]，一个根本错误的粗规划不会被触觉精修救回来。这把 T-Rex 能恢复的失败模式限定在*局部*接触修正上。
- **chunk 内的过时视觉上下文。** 快回路在整个 chunk 内复用 `KV_τ_split`。若视觉场景变化快于一个 chunk（约 0.2 秒），缓存上下文就是错的。对手内力动态没问题；但不能替代快速视觉反应。
- **硬件天花板。** 作者很坦诚：传感器畸变、标定漂移、缺乏手掌感知，限制了可达上限。方法在一定程度上被触觉硬件成熟度所制约，而不仅仅是建模问题。
- **固定 τ_split。** 原则上一个可学习的、依赖输入的分裂点能按任务自适应粗/细边界，但 T-Rex 用的是单一常数（0.4）。
