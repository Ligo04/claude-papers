# 摘要 — T-Rex：触觉反应式灵巧操作

## 背景脉络

视觉-语言-动作（VLA）模型——例如 RT-2、OpenVLA、π₀、GR00T、EgoScale——已成为通用机器人操作的主流范式。它们微调大型视觉-语言主干，通常配一个专门的*动作专家（action expert）*，用扩散或流匹配生成连续动作。这类模型在**视觉驱动、语义丰富**的任务上能力惊人。

但它们压倒性地是**视觉的**。预训练语料（互联网图像/视频、大型机器人数据集）里没有力、没有微滑（micro-slip）、没有局部形变信号。结果就是：VLA 恰恰在人类擅长的地方力不从心——**富接触、力敏感、触觉反应式**的操作：插卡、转钥匙开锁、挤管、剥、折、擦。

有两个障碍一直把触觉挡在 VLA 基础模型之外：

1. **数据稀缺。** 不存在互联网规模的触觉语料。在预训练规模上采集同步视触觉的灵巧遥操作，成本高得离谱。
2. **频率不匹配 + 静态编码器。** 触觉反应式行为需要*快*闭环响应（几十 Hz）。VLM 主干很重，只能跑几 Hz。以往触觉感知工作大多把触觉当作*静态、低频*的额外 token 注入，丢掉了真正有用的高频时间动态（力的瞬变、滑动起始）——而把触觉硬塞进 VLA 甚至会*损害*性能。

## 问题陈述

> 如何让大型预训练 VLA 基础模型获得真正的**高频、闭环触觉反应式**灵巧能力——既不在预训练规模上付触觉数据的代价，又不破坏主干已有的视觉运动能力？

## 主要贡献

论文同时攻击三个局限（数据、架构、编码器）：

1. **T-Rex 数据集** —— 100 小时、触觉同步的**双臂**遥操作数据集。
   - 200+ 日常物体，**22 个运动基元**（合拢、剥、折、裹、擦、挤、插、抽……），7700+ 条轨迹。
   - 围绕**多样的"动词-名词"运动基元**而非狭窄的任务演示来组织，以紧凑、可迁移地覆盖富接触行为。
   - 每段轨迹都有同步的 RGB（头部 + 两只手腕）、逐指**力向量** + **形变图（deformation map）**、机器人状态、动作、语言指令。已开源。

2. **T-Rex 模型** —— 一个变速率的 **Mixture-of-Transformer-Experts (MoT)**，含三个专家：
   - **潜表示专家（Latent expert）** —— 从视觉+语言预测未来视觉潜表示（辅助 grounding 目标）。
   - **动作专家（Action expert）** —— *低频*（约 5 Hz）流匹配去噪器，产出基线动作规划。
   - **触觉专家（Tactile expert）** —— *高频*（约 20 Hz）去噪器，用**时空触觉 VQ-VAE** 编码*精修*规划，复用缓存的视觉-语言上下文。
   - 两个动作类专家通过**级联流匹配（cascaded flow matching）**在固定去噪时刻 τ_split 处**异步**协作。

3. **真实世界基准** —— **12 个富接触触觉反应式任务**（插入、形变、力敏感、双臂协同）。T-Rex 树立了强基线，比最强先前方法高 **30 个百分点以上的平均成功率**。

## 关键方法思想（每条一句话）

- **触觉走中训练，而非预训练。** 三阶段配方：仅视觉的人类视频预训练 → 触觉接地的机器人中训练 → 任务专用后训练（约 100 条演示）。
- **异步级联流匹配。** 动作专家每个 chunk 把 τ: 1 → 0.4 去噪一次（缓存视觉/语言 KV）；触觉专家用实时触觉在 chunk 内多次完成 τ: 0.4 → 0——两者回归同一个流速度目标 v⋆ = ε − A_demo。
- **时间维度触觉 VQ-VAE。** 逐指 VQ-VAE 把 16 步力历史压成离散 token；瞬时力直接投影；卷积编码器嵌入形变图——三者拼接成触觉 token。

## 关键结果（定量）

**主基准（表 1，12 个任务的平均成功率，每任务 16 次试验）：**

| 方法 | 平均成功率 |
|--------|--------:|
| ViTacFormer | 13% |
| RDP（Reactive Diffusion Policy） | 6% |
| Tactile-VLA | 15% |
| π₀.₅ | 17% |
| π₀.₅ + tactile | 6% |
| EgoScale（最强基线） | 35% |
| **T-Rex（本文）** | **65%** |

→ 比最强基线（EgoScale）高 **30 个百分点**。注意：*天真地*给 π₀.₅ 加触觉反而把它从 17% **拉低到 6%**，凸显了触觉*怎么*整合才是决定性的。

**消融（表 2，6 个代表性任务的平均；完整模型 = 65%）：**

| 配置 | 平均 | Δ |
|---|--:|--:|
| 完整模型 | 65% | — |
| 去掉触觉 | 42% | **−23%** |
| MLP 力 + 形变（无 VQ-VAE） | 58% | −7% |
| 仅形变 | 54% | −11% |
| MLP 力 + VQ-VAE 力（无形变） | 59% | −6% |
| 去掉异步（同步） | 60% | −5% |

**训练配方（表 3，6 个任务的平均）：**

| 预训练 | 中训练 | 平均 |
|:--:|:--:|--:|
| ✗ | ✗ | 18% |
| ✓ | ✗ | 34% |
| ✗ | ✓ | 45% |
| ✓ | ✓ | **65%** |

→ 人类预训练与触觉中训练都贡献显著，且互补。

**其他发现：**
- **分裂步 τ_split：** 中间值（≈0.4）最佳；太小 → 动作专家给的视觉运动先验太弱；太大 → 触觉专家发挥空间太小（图 4）。
- **数据效率（图 5）：** 触觉接地的中训练在低数据区间（10–200 条后训练演示）大幅提升性能，降低下游数据需求。
- **数据集设计（图 6）：** 在相同预算下，100 小时的*运动基元*数据集比 100 小时的*任务专用*数据集泛化与零样本迁移更好。

## 硬件设置

固定底座的双臂 **Dexmate Vega-1**，配两只 **22 自由度 Sharpa Wave** 灵巧手；ZED 头部相机 + 两个单目手腕相机；逐指力向量 + 形变图。动作空间：手臂用**相对末端执行器增量（delta）**控制，手指用**绝对关节**控制。

## 局限（作者自述）

1. 对长时序、紧公差的接触任务，当遥操作本身就困难时，T-Rex 仍吃力——未来工作指向强化学习 / 基于在线交互的精修。
2. 触觉硬件是瓶颈：传感器畸变、跨设备标定漂移、缺乏用于全手操作的稠密**手掌**感知。需要跨异构触觉传感器的统一表示。
