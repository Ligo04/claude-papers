# 方法 — T-Rex 详解

## 0. 问题形式化

策略 π_θ 在时刻 t 接收：
- RGB 观测 `o_t`（头部 + 2 个手腕相机）
- 语言指令 `ℓ`
- 触觉**力历史** `f_{t−H_f : t}`
- 触觉**形变图** `d_t`

打包多模态上下文 `c_t = {o_t, ℓ, f_{t−H_f:t}, d_t}`。策略预测一个**未来动作 chunk** `A_{t:t+H}`，时域为 H。

动作生成用**条件流匹配（conditional flow matching）**。模型学习一个速度场 `v_θ(x_τ, τ | c_t)`，最小化

```
L_FM(θ) = E [ || v_θ(x_τ, τ | c_t) − (x_1 − x_0) ||² ]      (式 1)
```

其中 `x_0 = A_{t:t+H}`（干净动作 chunk）、`x_1 = ε ~ N(0, I)`（高斯噪声）。约定：**τ=1 是纯噪声，τ=0 是干净动作。** 去噪 = 把速度场从 τ=1 积分到 τ=0。

## 1. 架构 —— 共享 MoT 主干上的三个专家

```
                          ┌──────────────────── 多模态共享注意力 ────────────────────┐
   头部图 ──► ViT ───┐    │                                                                      │
  手腕图 ──► ViT ────┤    │   ┌─────────────┐    ┌──────────────┐    ┌────────────────────────┐  │
   语言 ──► Txt ─────┼──► │   │ 潜表示专家   │    │ 动作专家      │    │ 触觉专家               │  │
                     │    │   │ 预测未来     │    │ 低频去噪      │    │ 高频去噪               │  │
  力历史 ─┐          │    │   │ 视觉潜表示   │    │ τ: 1 → 0.4   │    │ τ: 0.4 → 0             │  │
  当前力  ─┼─►[ 时空  │    │   │             │    │ (~5 Hz)      │    │ 复用缓存 KV            │  │
  形变图  ─┘  触觉    │    │   │             │    │              │    │ + 实时触觉 token       │  │
              编码器 ]│    │   └─────────────┘    └──────┬───────┘    │ (~20 Hz)               │  │
                     │    │                             │ 缓存 KV_τsplit ──────────►          │  │
   含噪动作  ────────┘    └─────────────────────────────┼────────────────────────────┘─────────┘
                                                         ▼
                                                 中间动作  x̂_{τsplit}
                                                         │
                                                         ▼
                                                 最终动作 chunk A_{t:t+Ta}  ──► 机器人
```

**Mixture-of-Transformer-Experts (MoT) 主干。** 三个专门的专家在*共享*的多模态注意力上协作：

1. **潜表示专家** —— 处理视觉 + 语言以**预测未来视觉表示**。提供时间上接地的上下文；用辅助目标 `L_future` 训练。
2. **动作专家** —— 从纯噪声（τ=1）去噪到中间时刻 `τ_split`，生成低频动作规划。
3. **触觉专家** —— 复用缓存的视觉-语言上下文，**从 τ_split 继续去噪到 τ=0**，用高频触觉观测精修动作，产出最终可执行 chunk。

各专家是分开的 Transformer 参数集，但通过共享注意力通信——这是 "Mixture-of-Transformers" 设计（类似 GR00T / 统一多模态模型），区别于 token 级路由的 MoE。

## 2. 时空触觉编码

三个互补的触觉特征拼接成触觉 token `z_τ_t`：

```
z_τ_t = [  Emb_vq( E_f(f_{t−15:t}) )  ;  Proj_f(f_t)  ;  Proj_d( E_d(d_t) )  ]     (式 2)
           └── 时间维度力 ──┘            └─ 瞬时 ─┘    └──── 空间形变 ────┘
              (逐指 VQ-VAE)               力           (卷积编码器)
```

- **时间维度力** —— 逐指 **VQ-VAE** `E_f` 把最近 16 步力历史 `f_{t−15:t}` 压成紧凑的*离散*时间 token（捕捉动态：滑动起始、接触瞬变）。
- **瞬时力** —— 当前力向量 `f_t` 直接**投影**（`Proj_f`），使瞬时接触信息不被离散化丢失。
- **空间形变** —— **卷积编码器** `E_d` 从当前形变图 `d_t` 抽特征。

（VQ-VAE 与编码器实现细节见附录 C。）

## 3. 异步触觉反应式级联流匹配

这是论文的核心（4.2 节）。单条流匹配去噪轨迹在**固定时刻 τ_split 处分裂**；动作专家拥有上段，触觉专家拥有下段。

### 共享流目标
给定演示 chunk `A_demo` 和噪声 `ε ~ N(0,I)`：

```
x_τ = (1 − τ) A_demo + τ ε        (线性插值)
v⋆  = ε − A_demo                   (常速度目标)        (式 3)
```

**两个专家都回归同一个目标 v⋆**，覆盖 τ ∈ (0,1] 的*不相交*子区间：
- 动作专家：以全局多模态上下文为条件（上段）
- 触觉专家：以局部触觉观测为条件（下段）

这个共享目标正是触觉专家*精修*而非*打架*的原因——它是在接着同一条轨迹往下走。

### 推理时的级联去噪
总共 `N = 10` 个 Euler 步，在 `τ_split = 0.4` 处分裂。

**慢流（动作专家）** —— 每个 chunk **跑一次**，从噪声 `x_1 = ε` 起、用 `K_slow = 6` 步积分上段（Δτ = −0.1）：

```
x̂_{τsplit} = Euler( f_act_θ ; x_1, τ: 1 → 0.4, K_slow = 6 )       (式 4)
```

这次部分去噪后，边界状态被**缓存为静止视觉上下文 `KV_τsplit`**。

**快流（触觉专家）** —— 对长度 `T_a = 16` 的动作 chunk，在 chunk 内**偏移 {0, 4, 8, 12}** 处触发。它**跳过重的视觉网络**，把实时触觉 token `z_τ_t` 与 `KV_τsplit` 喂入触觉专家，解出剩余 `K_fast = 4` 步：

```
A_{t:t+Ta} = Euler( f_tac_θ ; x̂_{τsplit}, τ: 0.4 → 0, K_fast = 4 ) (式 5)
```

→ 慢流把昂贵的视觉前向摊销为一次；快流在 chunk 内于缓存上下文上重跑 4 次，每次响应新鲜触觉。**结果：约 5 Hz 规划 + 约 20 Hz 触觉反射。**

### 训练协议
从偏向噪声端的 Beta 分布采样去噪时刻：
- 动作专家：`τ_act ~ Beta(1.5, 1.0)`，定义域 (0, 1]   ← **全域**
- 触觉专家：`τ_tac = τ_split · τ̃`，其中 `τ̃ ~ Beta(1.5, 1.0)`，定义域 (0, τ_split]

两者都对共享目标做 MSE：

```
L_act = || f_act_θ(x_τact, τ_act) − v⋆ ||²
L_tac = || f_tac_θ(x_τtac, τ_tac ; KV_τsplit) − v⋆ ||²            (式 6)
```

其中 `KV_τsplit` 从一次**detach（停止梯度）**的慢流前向中提取——触觉损失不会反传进慢流的 KV。

> **关键设计要点：** 动作专家在**全域 (0,1]** 上训练，而非只在 [τ_split, 1]。这保证它仍是一个*独立胜任*的动作生成器（与预训练范式一致）——必要时它能自己一路去噪到干净动作。分裂只是推理期的分解，不是训练期的"截肢"。

### 总目标
```
L = L_act + λ_tac · L_tac + λ_future · L_future                   (式 7)
```
其中 `λ_tac = 1.0`、`λ_future = 0.5`。`L_future` 是潜表示专家的未来视觉预测损失。

## 4. 三阶段训练配方

```
阶段 1：大规模人类第一视角 预训练（PRE-TRAINING）   （无触觉专家）
  ├─ 22,889 小时第一视角人类视频（沿用 EgoScale）
  ├─ 潜表示专家：从头部视角学视觉+语言表示
  └─ 动作专家：在统一动作空间里学重定向（retarget）的人类手臂+手部动作
        → 广泛语义接地 + 视觉运动先验

阶段 2：触觉接地的机器人 中训练（MID-TRAINING）     （引入触觉专家）
  ├─ 100 小时含同步触觉的遥操作双臂操作
  ├─ 围绕 22 个运动基元 + 物体交互组织
  ├─ 动作专家适配到机器人多视角观测 + 可执行动作
  └─ 触觉专家学习作为精细精修的高频去噪
        → 把先验桥接到机器人可执行的接触动力学

阶段 3：技能专用 后训练（POST-TRAINING）
  └─ 在每任务约 100 条演示上微调
        → 适配具体任务，同时保留中训练学到的触觉反应行为
```

阶段 2 之后，T-Rex 已展现**零样本**富接触能力（图 6）。

## 5. 硬件与动作空间

- 机器人：固定底座双臂 **Dexmate Vega-1**，两只 **22 自由度 Sharpa Wave** 灵巧手。
- 相机：ZED 头部 + 2 个单目手腕相机。
- 触觉：逐指**力向量** + **形变图**。
- 动作空间：手臂用**相对末端执行器增量**控制 + 手指用**绝对关节**控制。

## 6. 实现陷阱与复现风险

| 陷阱 | 为什么会坑你 | 论文的处理 |
|---|---|---|
| 在分裂处 detach KV | 若把触觉损失反传进慢流 KV，慢流会被拉去"服务"快流而失去独立胜任能力 | `KV_τsplit` 来自 **detach（停止梯度）**的前向 |
| 触觉专家只在 (0, τ_split] 上训练 | 触觉专家必须学会它在推理时拥有的*下段*；动作专家保留全域 | 不相交的 τ 采样（式 6） |
| 选 τ_split | 太小 → 动作先验对精修太弱；太大 → 触觉专家无处发挥 | 甜点区 ≈ 0.4（图 4 消融） |
| 天真的触觉条件化 | 仅拼接触觉 token 可能*损害* VLA（π₀.₅+tactile：17%→6%） | 在精修阶段整合，而非输入拼接 |
| 静态触觉编码 | 丢失力动态 / 滑动起始 | 16 步历史上的时间维度 VQ-VAE（式 2） |
| 过时的缓存视觉上下文 | KV 在整个 chunk（约 0.2 秒）内复用；对手内动态可以，对场景快变会错 | 保持 chunk 短；触觉只处理*局部*修正 |
| 数据采集策略 | 任务专用演示过拟合、不迁移 | 围绕**运动基元**采集（图 6） |

## 7. 超参数速查表

| 符号 | 取值 | 含义 |
|---|---|---|
| `N` | 10 | Euler 去噪总步数 |
| `τ_split` | 0.4 | 动作/触觉专家之间的去噪分裂点 |
| `K_slow` | 6 | 慢流 Euler 步（τ: 1→0.4） |
| `K_fast` | 4 | 快流 Euler 步（τ: 0.4→0） |
| `T_a` | 16 | 动作 chunk 长度 |
| 快流触发偏移 | {0,4,8,12} | chunk 内触觉精修点 |
| 力历史 `H_f` | 16 步（t−15:t） | VQ-VAE 时间窗 |
| `λ_tac` | 1.0 | 触觉损失权重 |
| `λ_future` | 0.5 | 未来潜表示预测损失权重 |
| 慢速率 | ~5 Hz | 动作专家规划 |
| 快速率 | ~20 Hz | 触觉专家精修 |
| 预训练数据 | 22,889 小时 | 第一视角人类视频 |
| 中训练数据 | 100 小时 | 触觉同步双臂遥操作 |
| 后训练数据 | 约 100 条/任务 | 技能专门化 |
| `τ` 采样 | Beta(1.5, 1.0) | 偏向噪声端 |
