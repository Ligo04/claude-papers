# 反思 — 扩展、压力测试、开放问题

## 如果我来扩展这篇论文

1. **自适应 / 可学习的 τ_split。** 粗/细边界是单一常数（0.4）。一个自然扩展：让它依赖输入——用一个小头从多模态上下文按 chunk 预测 τ_split，给高接触不确定性的任务更大精修窗口。风险：它会让缓存 KV 的契约复杂化（缓存点变成动态的）。

2. **触觉触发的重规划。** 加一个事件门控：当触觉精修残差或力意外信号尖峰时，从更高的 τ 重新唤起慢流（直至完整重规划）。这直接解决最大的结构性局限——触觉无法覆盖错误的粗规划——代价是偶尔一次昂贵的视觉前向。要事件触发，而非每个 chunk。

3. **在模仿之上叠加 RL / 在线精修。** 作者自己为长时序、紧公差任务点出了这一点。级联结构是插入 RL 的干净位置：冻结预训练的慢流，*只*用在线交互微调触觉专家（下段 τ）。动作空间小、回路快、规划器冻结 → 一个可处理的 RL 问题。

4. **异构触觉传感器统一。** 在多种传感器类型（不同手指、不同厂商、不同模态）上训练触觉 VQ-VAE，趋向一个*共享*离散码本，使触觉专家跨硬件泛化——直接攻击标定漂移的局限。

5. **全手 / 手掌感知。** 当前设置缺乏稠密手掌感知。把形变图编码器扩展到更丰富的全手接触场，能解锁指尖感知做不到的手内操作（再抓握、滚动）。

6. **一个仿真基准。** 所有实验都在真实世界（12 任务、16 试验）。一个对接触动力学可控的匹配仿真基准，能让消融更快、复现更易，也让没有 Dexmate/Sharpa 硬件的人能在配方上继续做。

## 还有哪些开放问题

- **没有学习到的粗/细边界。** 为什么是 0.4？最优分裂点是否依赖任务？（图 4 暗示是的——不同任务曲线形状不同。）
- **超出训练基元的泛化。** 22 个运动基元很广但有限。对该集合之外的接触行为（如新颖的工具使用动作）T-Rex 如何处理？
- **触觉 sim-to-real 与跨本体。** 配方绑定到特定手与传感器。向其他灵巧手的迁移未经测试。
- **双臂协同的深度。** 基准含双臂任务，但架构除共享注意力外没有显式的手间协同机制。紧耦合双臂任务（如双手打结）可能需要更多。
- **为何中训练就够用的理论。** 实证上 100 小时触觉中训练迁移良好，但没有针对*触觉*轴的标度律刻画（如 EgoScale 对预训练的标度律）。性能如何随中训练小时数标度？

## 哪些假设是脆弱的

| 假设 | 为何可能崩 |
|---|---|
| 粗视觉规划大致正确；触觉只需精修 | 在高杂乱或视觉歧义场景中，粗规划可能定性错误——反射无法修复 |
| 视觉上下文在约 0.2 秒的 chunk 内稳定 | 快速移动物体、动态智能体、或快速场景变化都违反此假设；缓存 KV 会过时 |
| 16 步力历史捕捉了相关动态 | 极快瞬变（亚帧滑动）或极慢漂移可能落在此窗口之外 |
| 逐指 VQ-VAE 码本覆盖接触分布 | 分布外的材料/纹理可能产生码本难以表示的力模式（离散化失败） |
| 运动基元能重组覆盖下游任务 | 被一个*不在* 22 个之内的基元主导、或被紧密的基元间时序主导的任务，可能不迁移 |
| 遥操作能产出演示 | 作者指出紧公差任务难以*遥操作*——所以数据本身受人类遥操作技能限制 |

## 它在实践中可能在哪失败

1. **视觉驱动的快事件。** 杯子倾倒、物体滚走——触觉看不见，缓存视觉又过时。T-Rex 是*接触*反射，不是*视觉*反射。
2. **接触下需要重规划的任务。** 若接触揭示规划错了（抓错、接近角度错），精修无法恢复；你会看到自信却错误的执行。
3. **传感器退化。** 论文明说：跨设备的畸变与标定漂移。漂移的传感器会喂给触觉专家垃圾，而它会忠实地在其上"精修"。
4. **顺应性陌生的新物体。** 远离 200+ 训练物体的形变/力分布的材料，可能同时迷惑形变卷积编码器和力 VQ-VAE。
5. **长时序。** 误差在许多 chunk 上累积，每个 chunk 只有局部修正能力，又无全局重规划触发。

## 一个研究下注

这里最可复用的思想是 **"system-1/system-2 边界可以是一个去噪时刻，而非一个网络边界"**。这个抽象比触觉操作大得多。同样的级联流匹配分裂可以承载*任何*快残差模态——音频、本体振动、甚至一个快速学到的代价——在复用慢多模态规划的缓存上下文的同时精修它。可以说 T-Rex 是首个在 VLA 基础模型中干净展示该模式的工作；预期它会被远超触觉地复用。
