# SimDist 思维框架

## 这是什么类型的问题？

**模块化迁移学习 + 在线规划**

SimDist 解决的核心问题是：如何在数据稀缺的真实环境中，利用数据丰富的仿真环境来实现高效的机器人控制改进。

它不属于传统的任何单一范式：
- 不是纯 sim-to-real（不追求零样本迁移）
- 不是纯真实世界 RL（不从头学习）
- 不是纯模仿学习（能超越演示性能）

而是一种**结构化知识迁移 + 局部修正**的混合范式。

## 前置知识图谱

```
理解 SimDist 需要的知识层次：

Level 1 (基础):
├── MDP / POMDP 基本概念
├── 强化学习基础（策略、价值函数、奖励）
└── 神经网络基础（编码器、Transformer）

Level 2 (中级):
├── Model-Based RL（世界模型、Dreamer、TD-MPC）
├── Sim-to-Real Transfer（Domain Randomization、System ID）
├── 采样规划（MPC、MPPI、CEM）
└── 潜在空间动力学建模

Level 3 (高级):
├── 模块化世界模型设计（哪些组件可分离）
├── 信用分配问题的本质
├── 表征学习与下游任务的关系
└── 分布偏移下的鲁棒性分析
```

## 研究定位

### 在 Sim-to-Real 谱系中的位置

```
完全仿真 ←──────────────────────────────→ 完全真实
    │                                          │
    │  Domain        SimDist      Real-World   │
    │  Randomization    ↓         RL           │
    │      ↓           │          ↓            │
    │  零样本迁移    结构迁移+    从头学习      │
    │  (脆弱)      局部修正      (低效)        │
    │              (高效)                       │
```

### 在世界模型谱系中的位置

```
生成式世界模型（Genie, UniSim）
  └── 预测像素，需要大规模视频数据，动作条件弱

规划导向世界模型（TD-MPC, Dreamer）
  └── 在线学习，数据效率受限

SimDist（本文）
  └── 仿真预训练 + 真实微调，兼顾覆盖度和精确度
```

## 类比理解

### 类比 1：语言模型的预训练-微调

| 语言模型 | SimDist |
|---------|---------|
| 大规模语料预训练 | 仿真数据预训练世界模型 |
| 学到语法、语义结构 | 学到任务结构、奖励/价值排序 |
| 微调适应特定任务 | 微调动力学适应真实世界 |
| 冻结底层、调顶层 | 冻结编码器/奖励/价值、调动力学 |

### 类比 2：地图导航

想象你有一张城市地图（仿真预训练）：
- **街道名称和目的地位置**（奖励/价值模型）→ 在不同城市间大致通用
- **具体路况和交通规则**（动力学模型）→ 需要本地更新
- 你不需要重画整张地图，只需要更新"这条路单行"、"这里有施工"

### 类比 3：乐器演奏

- **乐理知识**（和弦进行、节奏感）= 价值/奖励模型 → 跨乐器通用
- **手指肌肉记忆**（具体按键力度）= 动力学模型 → 需要针对每把琴调整
- 换一把新吉他时，你不需要重新学乐理，只需要适应琴弦的手感

## 如何分类这项工作

**一级分类**：机器人学习 / Sim-to-Real Transfer
**二级分类**：Model-Based RL / 世界模型
**方法论标签**：模块化迁移、监督适应、在线规划
**核心创新类型**：架构分解 + 训练策略（非新算法）

## 与你已知工作的连接

如果你熟悉：
- **TD-MPC2**：SimDist 可以看作"TD-MPC 的仿真预训练版本"，解决了数据效率问题
- **DAgger/DreamER**：SimDist 不做在线策略蒸馏，而是直接规划
- **Isaac Lab/MuJoCo 训练**：SimDist 利用这些管线的产出（专家策略+价值函数）作为监督信号
- **Foundation Models for Robotics**：SimDist 是"小而精"的路线，不追求通用性，追求任务内的高效适应
