# SimDist 核心洞察

## 核心思想：一句话版本

世界模型的不同组件对 sim-to-real gap 的敏感度不同——奖励和价值模型只需正确排序状态（弱要求），而动力学模型需要精确预测（强要求）。利用这种不对称性，冻结前者、微调后者。

## 为什么这个方法有效

### 1. 排序 vs 校准的区别

传统 sim-to-real 试图让所有组件都精确匹配真实世界。SimDist 的关键洞察是：

- **价值函数**只需要正确排序状态（"插入孔中 > 对准 > 远离"），不需要精确的数值
- **奖励模型**同理，只需区分好坏轨迹
- **动力学模型**确实需要精确——但它可以通过简单的监督学习修正

这是一个比"完美仿真"弱得多的要求，因此更容易满足。

### 2. 将 RL 问题降维为监督学习

传统真实世界 RL 需要同时解决：
- 表征学习
- 动力学建模
- 信用分配（哪个动作导致了成功？）
- 探索

SimDist 将前三个问题移到仿真中解决，真实世界只剩下动力学修正——一个纯粹的监督回归问题。

### 3. 数据多样性 > 数据精确性

仿真数据不需要完美模拟真实世界，但需要覆盖足够广泛的状态-动作空间。通过注入次优策略和随机扰动，模型见过"失败→恢复"的模式，使规划器能在真实世界中评估反事实轨迹。

## 概念转变

| 传统思路 | SimDist 思路 |
|---------|-------------|
| 缩小 sim-to-real gap | 利用 gap 的结构化特性 |
| 端到端微调所有参数 | 只微调对 gap 敏感的组件 |
| 需要真实世界奖励信号 | 奖励从仿真迁移，无需真实标注 |
| 策略直接输出动作 | 世界模型 + 在线规划 |
| 数据质量至上 | 数据多样性至上 |

## 权衡与局限

1. **性能天花板**：冻结的价值函数可能在真实世界饱和，无法区分高水平轨迹间的差异
2. **仿真依赖**：需要足够好的仿真器来提供结构化先验（不是所有任务都有）
3. **计算开销**：在线 MPPI 规划需要实时推理，对硬件有要求（RTX 4090M）
4. **任务范围**：目前验证在接触丰富的操作和运动任务，未涉及更开放的场景

## 与先前工作的对比

- **TD-MPC2**：在线从头学习世界模型，数据效率低
- **Dreamer**：使用像素重建，在 sim-to-real 中编码无关视觉细节
- **SGFT-SAC**：只迁移价值函数，不利用完整世界模型结构
- **Diffusion Policy**：行为克隆，无法超越演示数据的性能
- **Domain Randomization**：试图让策略对 gap 鲁棒，而非修正 gap

## 实际意义

对于有仿真器的机器人任务，SimDist 提供了一条清晰的路径：
1. 在仿真中训练专家 → 生成多样数据 → 预训练世界模型
2. 部署到真实世界 → 收集 15-30 分钟数据 → 微调动力学
3. 迭代改进，无需人工奖励标注或大量演示
