# SimDist 扩展思考

## 如果我要扩展这篇论文

### 方向 1：渐进式解冻

当前方案冻结价值函数会设置性能天花板。可以设计一个课程式解冻策略：
1. 初始阶段：完全冻结，仅微调动力学（当前方案）
2. 中期：动力学收敛后，用小学习率 + 强正则化微调价值函数
3. 关键：需要检测"价值函数排序开始失效"的信号（如规划器选择的轨迹实际回报下降）

### 方向 2：主动数据收集

当前 SimDist 被动收集在线数据。可以设计信息增益驱动的探索：
- 识别动力学模型不确定性高的状态区域
- 主动引导机器人去这些区域收集数据
- 类似 PETS/MBPO 的不确定性引导探索，但在 SimDist 框架内

### 方向 3：跨具身迁移

如果编码器和价值函数编码的是"任务结构"而非"机器人结构"：
- 能否在一个机器人上预训练，迁移到另一个机器人？
- 动力学模型需要完全重新训练，但奖励/价值可能部分迁移
- 需要动作空间的对齐或抽象

### 方向 4：与基础模型结合

- 用视觉基础模型（如 DINOv2）替代从头训练的编码器
- 价值函数可以用 VLM 提供的语义奖励增强
- 动力学模型保持任务特定的轻量设计

## 哪些假设是脆弱的

1. **"排序迁移"假设**：在高度非线性的任务中（如流体操作），仿真中的状态排序可能与真实世界完全不同。一个在仿真中"接近成功"的状态，在真实世界可能因为流体行为不同而完全无法到达目标。

2. **编码器鲁棒性**：依赖视觉随机化来实现编码器迁移。但如果真实世界有仿真中从未见过的视觉模式（如透明物体、镜面反射），编码器可能产生无意义的潜在状态。

3. **动力学可分离性**：假设动力学差异可以通过仅更新 f_θ 来修正。但如果 sim-to-real gap 导致了状态空间本身的变化（如真实世界有额外的自由度），仅修正动力学可能不够。

4. **短时域规划足够**：MPPI 只规划 T=5 步（操作）或 T=25 步（四足）。对于需要更长时域推理的任务（如多步装配），这可能不够。

## 在实践中可能失败的场景

1. **高度随机的环境**：如果真实世界的随机性远超仿真（如风力干扰、人类交互），确定性动力学模型可能无法捕获这种不确定性。

2. **稀疏接触任务**：如果任务的关键时刻是短暂的接触事件（如抓取瞬间），5Hz 的控制频率可能错过关键信息。

3. **长尾分布**：仿真中的随机化可能无法覆盖真实世界的所有边缘情况。一个从未见过的初始条件可能导致编码器产生异常输出。

4. **硬件退化**：随着机器人使用，关节摩擦、传感器漂移等会改变动力学。SimDist 需要持续的在线适应，而非一次性微调。

## 开放问题

1. **最优冻结边界在哪里？** 是否存在比"冻结除动力学外的一切"更好的分割方式？例如，冻结编码器底层但微调顶层？

2. **数据多样性的理论下界是什么？** 需要多少种失败模式才能保证规划器的鲁棒性？能否形式化这个要求？

3. **价值函数饱和的检测与修复**：如何自动检测冻结的价值函数已经成为瓶颈？检测到后如何安全地更新它？

4. **与 diffusion policy 的结合**：能否用 diffusion model 替代 MPPI 作为规划器，同时保留 SimDist 的预训练-微调框架？

5. **规模化**：100k-100M 轨迹的预训练是否可以进一步扩展？是否存在类似 LLM 的 scaling law？
