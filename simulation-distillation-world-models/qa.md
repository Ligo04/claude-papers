# SimDist 自测题

## 基础题（概念理解）

### Q1: SimDist 在真实世界适应时，哪些组件被冻结，哪个被微调？为什么？

<details>
<summary>答案</summary>

**冻结**：编码器 E_θ、历史编码器 C_θ、奖励模型 R_θ、价值模型 V_θ、基础策略 π_θ

**微调**：仅潜在动力学模型 f_θ

**原因**：
- 编码器冻结是为了保持奖励/价值头的输入分布一致（否则它们收到分布外输入会失效）
- 奖励/价值模型只需正确排序状态，这个能力跨 sim-to-real gap 保持不变
- 动力学模型将动作映射到未来状态，对物理差异最敏感，必须修正
- 这样将适应问题简化为纯监督学习（预测下一个潜在状态）

</details>

### Q2: SimDist 的数据生成策略为什么要混合专家和次优策略？

<details>
<summary>答案</summary>

规划器（MPPI）在部署时会采样大量候选动作序列，其中很多偏离专家分布。如果世界模型只在专家数据上训练：
- 动力学模型无法预测非最优动作的后果
- 奖励/价值模型无法区分好坏轨迹（只见过好的）
- 规划器会利用模型在分布外的错误

混合策略提供了"失败→恢复"的覆盖，使模型能可靠地评估反事实轨迹。实验证实：仅用专家数据时，Peg Insertion 成功率从 0.90 降至 0.10。

</details>

---

### Q3: 为什么 SimDist 不使用像素重建损失？

<details>
<summary>答案</summary>

两个原因：

1. **视觉随机化冲突**：sim-to-real 需要大量视觉随机化（纹理、光照、渲染风格）。像素重建会迫使潜在状态编码这些刻意变化的、与任务无关的视觉细节，损害迁移性。

2. **数据多样性已足够**：SimDist 的多样化数据生成（覆盖各种状态-动作对）已经迫使编码器学到鲁棒表征，无需重建作为额外正则化。

实验验证：加入重建损失后，操作任务成功率从 0.90 降至 0.32。

</details>

### Q4: MPPI 规划的基本流程是什么？SimDist 如何加速它？

<details>
<summary>答案</summary>

**MPPI 流程**：
1. 采样 N 条候选动作序列
2. 用世界模型预测每条序列的未来轨迹
3. 计算每条轨迹的回报 R = γ^T·v̂_{t+T} + Σγ^{s-t}·r̂_s
4. 按回报进行重要性加权，得到最优动作

**SimDist 的加速设计**：
- **分块预测**：动力学模型一次前向传播预测 T 步（非自回归逐步展开），充分利用 GPU 并行
- **基础策略热启动**：用 π_θ 的输出（加噪）作为部分候选序列的种子，减少需要的采样数
- **最小历史表征**：历史只用本体感觉，避免处理多帧图像的开销

</details>

### Q5: "排序正确"和"数值精确"的区别是什么？为什么这对 sim-to-real 很重要？

<details>
<summary>答案</summary>

**排序正确**：V(state_A) > V(state_B) 当且仅当 state_A 确实比 state_B 更接近目标。不要求 V 的绝对数值准确。

**数值精确**：V(state_A) = 0.85（精确的期望回报值）。

**对 sim-to-real 的意义**：
- 规划器只需要比较不同轨迹的好坏（排序），不需要精确的回报数值
- 排序是一个比精确预测弱得多的要求——即使仿真和真实世界的物理参数不同，"更接近目标 = 更好"这个排序通常保持不变
- 这就是为什么价值函数可以直接从仿真迁移而不需要微调

</details>

## 中级题（方法理解）

### Q6: 解释预训练损失 L_sim 中 stop-gradient 的作用。如果去掉会怎样？

<details>
<summary>答案</summary>

在动力学损失项 ‖ẑ_{t+i+1} - sg(E_θ(o_{t+i+1}))‖² 中：

**sg 的作用**：阻止梯度从动力学损失回传到编码器 E_θ。编码器只通过奖励和价值损失更新。

**如果去掉**：
- 编码器会被动力学损失"拉扯"，可能学到让预测容易但对任务无用的表征
- 表征可能退化为常数（让所有预测都相同来最小化损失）
- 奖励/价值头的训练信号会被稀释

这是一种常见的"目标网络"思想——让编码器提供稳定的学习目标，类似于 BYOL/SimSiam 中的设计。

</details>

### Q7: 为什么 SimDist 选择 Transformer 而非 MLP 作为奖励/价值解码器？

<details>
<summary>答案</summary>

**MLP 方式**：独立地对每个时间步的潜在状态 ẑ_t 预测奖励/价值，无法看到轨迹上下文。

**Transformer 方式**：对整条预测轨迹 ẑ_{t:t+T} 做 attention，能聚合轨迹级信息。

**为什么重要**：
- 某些状态的价值取决于"怎么到达的"和"之后会去哪"——需要轨迹上下文
- 例如：机械臂正在对准孔的状态，其价值取决于对准的趋势（越来越准 vs 偏离）
- MLP 只看单帧，无法捕获这种动态信息

实验证实：MLP 解码器在 Table Leg 任务上成功率从 0.85 降至 0.60。

</details>

### Q8: SimDist 的迭代改进循环如何避免分布偏移问题？

<details>
<summary>答案</summary>

传统 MBRL 的分布偏移：模型在旧数据上训练 → 规划器利用模型错误 → 收集的新数据偏离训练分布 → 模型更不准确。

**SimDist 的规避策略**：

1. **广泛的仿真预训练**：模型已经见过大量失败和恢复轨迹，对分布外动作有基本的泛化能力
2. **冻结编码器**：潜在空间固定，不会漂移
3. **监督学习目标**：动力学微调是纯预测任务（预测下一个潜在状态），不涉及策略梯度或价值 bootstrapping
4. **Off-policy 兼容**：所有真实数据（包括失败的）都可以用于动力学训练，不需要丢弃旧数据
5. **短时域预测**：只预测 T 步，误差不会无限累积

</details>

### Q9: 对比 SimDist 和 SGFT-SAC。两者都从仿真迁移价值函数，为什么 SimDist 效果更好？

<details>
<summary>答案</summary>

**SGFT-SAC**：
- 迁移仿真训练的价值函数作为初始化
- 然后用 model-free RL（SAC）在真实世界端到端微调策略
- 问题：仍需解决长时域信用分配、仍面临灾难性遗忘风险

**SimDist 的优势**：
1. **不只迁移价值**：还迁移编码器、奖励模型、基础策略——完整的决策结构
2. **世界模型放大数据**：一条真实轨迹可以生成无数反事实预测，等效于大量虚拟经验
3. **无需信用分配**：适应是监督学习（预测下一状态），不需要回答"哪个动作导致了成功"
4. **单调改进**：动力学越准 → 规划越好 → 性能越高，没有策略梯度的高方差问题

</details>

### Q10: 动作扰动的"短时间窗口"设计有什么讲究？

<details>
<summary>答案</summary>

论文使用"contiguous action perturbations"——在连续的短时间窗口内注入随机动作。

**为什么是连续窗口而非逐步随机**：
- 连续扰动产生有意义的偏离轨迹（如：持续向左偏 → 需要恢复）
- 逐步随机只产生抖动，不会真正偏离专家流形
- 连续扰动模拟了真实世界中的系统性误差（如摩擦力不同导致持续偏移）

**为什么是短窗口而非全程随机**：
- 需要看到"偏离→恢复"的完整模式
- 全程随机会产生无法恢复的轨迹，对训练无用
- 短窗口后切回专家/次优策略，展示如何从错误中恢复

</details>

## 高级题（深度分析）

### Q11: 如果真实世界的奖励结构与仿真显著不同（如新增障碍物改变了最优路径），SimDist 会如何表现？如何修复？

<details>
<summary>答案</summary>

**问题分析**：
- 冻结的奖励/价值模型编码了仿真中的任务结构
- 如果真实世界引入了仿真中不存在的约束（如新障碍物），价值函数的排序可能不再正确
- 规划器会生成穿过障碍物的轨迹（因为价值模型不知道障碍物的存在）

**可能的修复方向**：
1. **扩展仿真覆盖**：在仿真中随机化障碍物配置，让价值函数学到通用的避障偏好
2. **选择性解冻**：用约束优化方法微调价值函数，但加强正则化防止遗忘
3. **残差奖励**：在冻结的奖励模型上叠加一个小型残差网络，用真实数据训练
4. **层次化规划**：高层用迁移的价值函数，低层加入局部避障约束

这是 SimDist 的核心局限之一——论文也承认冻结价值函数会设置性能天花板。

</details>

### Q12: 从信息论角度，为什么"仅微调动力学"是合理的？什么条件下这个假设会失效？

<details>
<summary>答案</summary>

**信息论视角**：

世界模型编码了关于环境的互信息 I(model; environment)，可以分解为：
- I(encoder; task-relevant features)：哪些视觉特征与任务相关
- I(dynamics; physics)：动作如何影响状态转移
- I(value; goal structure)：什么是好的/坏的状态序列

Sim-to-real gap 主要影响 I(dynamics; physics)，因为物理参数（摩擦、质量、刚度）不同。而 I(encoder; task-relevant features) 和 I(value; goal structure) 在合理的视觉随机化下应该保持不变。

**失效条件**：
1. **观测模态差异**：仿真用完美渲染，真实世界有运动模糊、遮挡——编码器可能失效
2. **任务语义变化**：真实世界的成功标准与仿真不同（如精度要求更高）
3. **状态空间不匹配**：真实世界存在仿真中完全没有的状态（如物体变形）
4. **奖励非单调**：某些中间状态在仿真中是好的但在真实中是危险的

</details>

### Q13: SimDist 能否扩展到多任务设置？主要挑战是什么？

<details>
<summary>答案</summary>

**理论上可行**，但面临几个关键挑战：

1. **价值函数冲突**：不同任务的价值排序可能矛盾（同一状态对任务 A 好、对任务 B 差）。需要条件化的价值函数 V(z, task_id)。

2. **编码器瓶颈**：64 维潜在空间可能不足以编码多任务所需的所有特征。不同任务关注不同的视觉线索。

3. **动力学共享 vs 分离**：
   - 如果任务共享相同的物理环境 → 可以共享动力学模型
   - 如果涉及不同物体/接触模式 → 可能需要任务条件化的动力学

4. **规划效率**：MPPI 需要为每个任务评估不同的回报函数，计算量线性增长

5. **数据生成复杂度**：每个任务需要独立的专家策略和多样化数据

**可能的方案**：类似 TD-MPC2 的多任务世界模型，但加入 SimDist 的仿真预训练和冻结-微调策略。

</details>

### Q14: 比较 SimDist 的"冻结+微调动力学"与 LoRA 风格的"低秩适应所有组件"。哪种更适合 sim-to-real？

<details>
<summary>答案</summary>

**SimDist 的硬冻结**：
- 优点：完全避免奖励/价值漂移，适应是纯监督学习
- 缺点：性能天花板，无法修正价值函数的系统性偏差

**LoRA 风格的低秩适应**：
- 优点：所有组件都能微调，理论上无性能天花板
- 缺点：重新引入了组件间的耦合和信用分配问题

**分析**：

对于 sim-to-real，SimDist 的硬冻结可能更优，原因：
1. 真实数据极少（15-30 分钟），不足以稳定地更新所有组件
2. 低秩更新仍可能导致奖励/价值头的输入分布偏移
3. 动力学 gap 是结构化的（物理参数差异），全秩更新 f_θ 比低秩更新所有组件更直接

**但如果数据更多**（如数小时），LoRA 可能更好——可以逐步解锁价值函数的适应能力。

一个折中方案：先用 SimDist 快速适应动力学，达到瓶颈后再用 LoRA 微调价值函数。

</details>

### Q15: 设计一个实验来验证"价值函数的排序在 sim-to-real 中保持不变"这一核心假设。

<details>
<summary>答案</summary>

**实验设计**：

**目标**：量化价值函数在真实世界中的排序保持度（rank preservation）。

**方法**：
1. 收集 N 对真实世界状态 (s_i, s_j)，其中 s_i 客观上比 s_j 更接近任务成功
2. 用冻结的价值函数计算 V(E_θ(o_i)) 和 V(E_θ(o_j))
3. 计算排序一致性：Concordance = P(V(s_i) > V(s_j) | s_i 确实更好)

**具体步骤**：
1. 在真实世界收集成功和失败轨迹各 50 条
2. 从每条轨迹中均匀采样状态，按任务进度标注（如：距离目标的距离）
3. 构造所有跨轨迹的状态对，计算 Kendall's τ 排序相关系数
4. 对比：(a) 预训练后直接迁移 (b) 不同程度的视觉 gap (c) 不同程度的动力学 gap

**预期结果**：
- 视觉随机化充分时，排序一致性 > 0.9
- 动力学 gap 对排序影响小（因为"更接近目标"与物理参数无关）
- 视觉 gap 过大时（如完全不同的相机角度），排序会崩溃

**控制变量**：
- 消融视觉随机化的程度
- 消融仿真-真实的物理参数差异程度
- 对比不同任务（操作 vs 运动）的排序鲁棒性

</details>
