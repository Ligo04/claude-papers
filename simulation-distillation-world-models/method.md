# SimDist 技术方法详解

## 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    World Model (θ)                        │
│                                                          │
│  ┌──────────┐   ┌──────────┐   ┌──────────────────┐    │
│  │ Encoder  │   │ History  │   │ Latent Dynamics  │    │
│  │   E_θ    │   │ Encoder  │   │      f_θ         │    │
│  │          │   │   C_θ    │   │                  │    │
│  └────┬─────┘   └────┬─────┘   └────────┬─────────┘    │
│       │z_t            │h_t               │ẑ_{t+1:t+T}   │
│       └───────┬───────┘                  │              │
│               │                          ▼              │
│         ┌─────┴─────┐          ┌──────────────────┐    │
│         │ Base Policy│          │ Reward & Value   │    │
│         │    π_θ     │          │   R_θ,  V_θ      │    │
│         └───────────┘          └──────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

## 组件详解

### 1. 潜在编码器 E_θ

- 输入：原始观测 o_t（RGB 图像 + 本体感觉）
- 输出：64 维潜在状态 z_t
- 操作任务：3 个 ResNet-18（腕部、俯视、侧视相机）+ 本体感觉融合
- 四足任务：CNN 处理地形高度图 + MLP 融合低维观测

### 2. 历史编码器 C_θ

- 输入：(o^p_{t-H:t-1}, a_{t-H:t-1}, o^e_t)
- 关键设计：只用本体感觉历史 + 最新的高维观测
- 原因：减少推理延迟，避免处理多帧图像

### 3. 潜在动力学模型 f_θ

- 输入：z_t, a_{t:t+T-1}, h_t
- 输出：ẑ_{t+1:t+T}（T 步未来潜在状态）
- 架构：Transformer + cross-attention
- 关键：**单次前向传播预测 T 步**（非自回归），充分利用 GPU 并行

### 4. 奖励/价值模型 R_θ, V_θ

- 输入：预测的潜在轨迹 ẑ_{t:t+T}
- 架构：Transformer（序列到序列），非逐步 MLP
- 优势：能聚合整条轨迹信息，产生更准确的回报估计

### 5. 基础策略 π_θ

- 用于 MPPI 规划的热启动
- 输出动作块 â_{t:t+H}，加噪后作为候选轨迹的种子

## 算法流程

### Phase 1: 仿真预训练

```
1. 训练专家策略 π_e（特权状态）→ 保存 V_e 和中间检查点 {π_k}
2. 生成多样数据集 D_sim：
   - 交替使用 π_e 和 {π_k}
   - 周期性注入随机动作扰动（短时间窗口）
   - 记录 (o_t, a_t, r_t, v_t)，其中 r_t 来自特权状态，v_t 来自 V_e
3. 预训练世界模型，最小化 L_sim：
```

### 预训练损失 L_sim

```
L_sim_t(θ) = Σ_{i=0}^{T} [
    ‖ẑ_{t+i+1} - sg(E_θ(o_{t+i+1}))‖²   (潜在动力学)
  + c₁·(r̂_{t+i} - r_{t+i})²              (奖励预测)
  + c₂·(v̂_{t+i+1} - v_{t+i+1})²          (价值预测)
  + c₃·𝟙_e(a_{t+i})·‖â_{t+i} - a_{t+i}‖² (行为克隆，仅专家动作)
]
```

- sg = stop-gradient，防止编码器通过动力学损失更新
- c₁, c₂, c₃ 通过目标范围归一化确定
- 𝟙_e 仅对专家动作施加行为克隆损失

### Phase 2: 真实世界适应

```
1. 冻结 E_θ, C_θ, R_θ, V_θ, π_θ
2. 循环 J 次：
   a. 用 MPPI + 当前世界模型收集 M 条真实轨迹
   b. 仅更新 f_θ，最小化：
      L_real_t(θ) = Σ_{i=0}^{T} ‖ẑ_{t+i+1} - sg(E_θ(o_{t+i+1}))‖²
```

### MPPI 规划

```
1. 采样 N 条候选动作序列（部分由 π_θ 热启动）
2. 用 f_θ 预测每条序列的未来潜在轨迹
3. 用 R_θ, V_θ 评估每条轨迹的回报：
   R(a_{t:t+T-1}) = γ^T · v̂_{t+T} + Σ_{s=t}^{t+T-1} γ^{s-t} · r̂_s
4. 按回报进行重要性加权，得到执行动作
```

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 不用像素重建 | 仅用奖励/价值监督 | 避免编码视觉随机化噪声 |
| 分块预测 vs 自回归 | 单次 T 步预测 | GPU 并行，降低规划延迟 |
| Transformer vs MLP 解码 | Transformer 奖励/价值头 | 捕获轨迹级结构 |
| 历史只用本体感觉 | 最新帧用高维观测 | 减少推理成本 |
| 冻结编码器 | 适应时不更新 | 保持奖励/价值头的输入分布一致 |

## 超参数

| 参数 | 操作任务 | 四足任务 |
|------|---------|---------|
| 潜在维度 | 64 | 64 |
| 历史长度 H | 5 | 25 |
| 预测长度 T | 5 | 25 |
| 控制频率 | 5 Hz | 50 Hz |
| 预训练数据量 | 100k 轨迹 | 100M 轨迹 |
| 微调间隔 | 每 20 episodes | 持续 |

## 实现陷阱

1. **编码器解冻会崩溃**：一旦编码器更新，奖励/价值头收到分布外的输入，性能归零
2. **价值函数解冻也会崩溃**：重新引入长时域信用分配问题，导致灾难性遗忘
3. **仅用专家数据不够**：规划器会探索专家分布外的动作，需要覆盖失败和恢复
4. **数据量很重要**：10% 数据时性能急剧下降（Peg: 0.90 → 0.06）
