# 反思与延伸

## 如果继续做这篇工作

1. **显式不确定性**：让高层子任务带置信度、候选集合或停止条件，减少“反复开关抽屉”的循环。
2. **记忆与跨房间上下文**：加入对象位置、已完成子任务和失败原因的显式 memory，针对论文指出的 partial observability。
3. **安全动作接口**：在 50 Hz PD 目标前加入碰撞、力矩、速度和可达性约束，测量安全层是否破坏泛化。
4. **数据贡献归因**：用固定算力和严格配比做 leave-one-source-out、source reweighting 和 curriculum，而不只做四种消融。
5. **更丰富的 prompt**：把偏好、顺序、例外和停止条件纳入高层标签，验证模型能否处理组合式自然语言。
6. **跨机器人离线适配**：研究动作语义 token、末端轨迹 token 或 diffusion/flow adapter，减少 zero-padding 对共享 trunk 的负担。

## 脆弱假设

- 家庭任务可以被有限的语义子任务词表覆盖。
- 其他 embodiment 的动作经验在归一化后仍与目标机器人有用地对齐。
- web 图像/文本中的物体知识能够迁移到真实家庭的可操作性判断。
- 高层子任务不会因遮挡、延迟或错误历史而长期漂移。
- 简单 PD tracking 足以把生成的 action chunk 可靠地执行出来。

## 可能失败的场景

- 需要跨房间记忆、隐含偏好或长上下文约束的任务。
- 抽屉、柜门、软物体或接触力明显不同于训练分布的场景。
- 视觉遮挡导致“看不到 spill 但仍需擦除”等部分可观测任务。
- 新物体类别同时伴随新抓取几何和新容器，而不是只改变外观。
- 高层文本看似合理但低层动作不可达，模型没有独立的可行性检查。

## 可检验的新假设

- **H1**：在相同移动机器人小时数下，增加语义子任务标注比增加 web caption 对长时程任务进度的边际收益更高。
- **H2**：把高层输出改为结构化 `(verb, object, destination, termination)` 比自由文本更能降低循环行为。
- **H3**：加入失败轨迹和恢复语言，能比单纯成功 episode 更快提升陌生开关/抽屉的成功率。
- **H4**：对动作 expert 做 embodiment-conditioned adapter，能减少 CE 数据的负迁移。

这些假设应通过固定测试家庭、固定 10-trial rubric、预注册数据混合比例和完整置信区间来检验。
