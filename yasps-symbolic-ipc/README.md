# YASPS:面向可扩展、高性能 IPC 仿真的符号化框架

> Xuan Tang、Kemeng Huang、Gilbert Bernstein、Minchen Li、Tzumao Li
> ACM Transactions on Graphics(SIGGRAPH 2026),第 45 卷第 4 期,文章 142 · [doi:10.1145/3811327](https://doi.org/10.1145/3811327)

## 这篇论文讲什么

基于 **增量势接触(Incremental Potential Contact,IPC)** 的物理仿真器很鲁棒,但很僵化:为了保持高性能,
最先进的系统(GIPC、PolyFEM、Stark)都手写 GPU kernel 和矩阵装配逻辑,把一组固定的能量、图元类型和
**参数化(parameterization)**——即一个点的位置是如何计算出来的:自由顶点、仿射体、笼形(cage)等——
硬编码进去。新增一种参数化就要重新推导梯度/Hessian,更糟的是会遇到 **组合爆炸**:一个涉及 4 个顶点、
3 种参数化的碰撞能量,需要 3⁴ = 81 套专门的导数/装配代码。YASPS 通过引入两个 **关系算子**——
`JOIN`(沿连接关系收集属性)与 `UNION`(把异构参数化合并成一个可微属性)——进入符号化中间表示(IR),
彻底消除了这个瓶颈。对这两个算子的符号微分规则让 YASPS 能从一份高层 Python 描述自动生成局部导数、
推断全局 Hessian 稀疏结构、并 JIT 编译出 CUDA kernel。新增一种材料/参数化只需约 130 行 Python、且
*无需* 改动后端,同时性能与 GIPC 级别相当。

## 难度

**高级。** 假定你对以下内容比较熟悉:变分物理/基于能量的仿真、IPC 的势垒(barrier)形式、带 PSD Hessian
投影的牛顿法、一阶和二阶自动/符号微分(张量上的链式法则)、稀疏线性代数(块稀疏、共轭梯度),以及一点
编译器/DSL 思维(IR、代码生成、公共子表达式消除)。即便没有全部背景,你也能掌握 *核心思想*
(JOIN/UNION + 避免组合爆炸)——可以从 `insights.md` 开始。

## 如何使用这些材料

建议阅读顺序:

1. **`summary.md`** —— 一次读完的总览:问题、贡献、关键数字。
2. **`insights.md`** —— *最重要的文件。* 为什么 JOIN/UNION 是对的抽象,它代表了什么概念性转变。即使其他都不读,也读这个。
3. **`mental-model.md`** —— 如何在脑中归类这项工作:它是面向 IPC 的 *关系型 DSL + 符号微分编译器*,而非新的物理模型。与 FEniCS/UFL、数据库、autodiff 的类比。
4. **`method.md`** —— 工程化细节:前端 API、JOIN/UNION 的形式定义、微分规则、两遍式方案、索引生成、模块化代码生成、求解器。
5. **`code/`** —— 一个可运行、零依赖的 Python 演示,复现 *组合爆炸的消除* 论证以及一个极简的 JOIN/UNION 符号微分器。**从这里入手把思想落到实处。**
6. **`qa.md`** —— 15 道自测题(5 基础 / 5 中级 / 5 高级),答案折叠隐藏。
7. **`reflection.md`** —— 扩展方向、脆弱假设、以及实际中可能失败的地方。
8. **`index.html`** —— 交互式浏览器:玩一玩参数化的组合数与 EVD 投影加速,直观感受"为什么结构很重要"。

## 关键要点

- 快速 IPC 中的 **可扩展性瓶颈** 来自:*结构信息*(谁参与、如何参数化、局部如何映射到全局)被
  *隐式地* 散落在手写 kernel 里。
- 通过 `JOIN`/`UNION` 把这些结构 **显式化且可微**,让同一份描述同时驱动微分、稀疏推断 *和* 装配——
  不再有重复的用户工作,也不再有代码爆炸。
- `UNION` 是关键诀窍:它把 *可选的* 参数化表示成单个符号节点,因此混合参数化的能量编译成 **一个** kernel,
  而不是每种组合一个。
- 性能不是来自更快的微分,而是来自 **缩小需要做 PSD 投影的矩阵**(那个 O(n³) 的特征分解)。块压缩 +
  降维投影在"自由+ABD 顶点的点-点势垒"上带来高达 **44×** 的加速。
- 结果:端到端时间 **与 GIPC 相当甚至更优**(如 40k–60k 顶点场景:130–300 秒,GIPC 为 199–586 秒,主要
  得益于快得多的 CG 求解器),而新增一种参数化仅约 130 行 Python。
