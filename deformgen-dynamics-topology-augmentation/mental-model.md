# 心智模型：DeformGen

## 这是什么类型的问题？

**机器人模仿学习中的数据增强（data augmentation for imitation learning）**，专门针对**可变形物体操作（deformable object manipulation）**。

更抽象地说，这是一个**"如何在受强物理约束的高维状态空间里采样合法样本，并把已有的解（轨迹）迁移到新样本上"**的问题。这个抽象框架在很多领域都成立——任何"状态空间巨大但合法子集很薄、且解依赖于具体状态"的场景。

## 假设的前置知识

- **模仿学习 / 行为克隆**：从 (观测, 动作) 对学策略。知道 ACT、Diffusion Policy、VLA（SmolVLA、π₀）大致是什么。
- **刚体位姿与变换群**：SE(3)（位姿）、SO(3)（旋转）、等距变换、等变性。
- **可变形物体仿真**：粒子表示、质点-弹簧/FEM/PBD/MPM，前向动力学。
- **几何/数值工具**：KNN、反距离加权插值、最小二乘、Moore-Penrose 伪逆、SVD、SLERP、Procrustes 对齐。
- **数据增强直觉**：为什么"增加数据多样性"能改善泛化。

## 一个统一的类比

把它想成**"给一道题生成更多练习题 + 同步生成答案"**：

- 旧方法（刚性增强）：把题目里的图**整体平移旋转**，再把答案同样平移旋转。对刚体题这没问题。但对"橡皮泥造型题"，整体搬动图根本没造出新形状，而且答案的"手怎么捏"完全没变——题变难了答案却没跟上。
- DeformGen：
  - **造新题**（状态增强）= 拿橡皮泥**真的去捏一下**（施加局部力 + 物理演化），捏出来的一定是个真实存在的形状（永远在 S_real 里），而不是 PS 一张物理上不可能的图。
  - **配新答案**（轨迹增强）= 看橡皮泥每个点从原形状到新形状是怎么移动的，据此**把"手的轨迹"也连续地扭过去**——手的位置和姿态都跟着局部形变调整。

## 在研究地图中的位置

```
机器人操作数据获取
├── 从头生成
│   ├── 运动规划器
│   ├── 生成模型 / 学习智能体
│   └── RoboTwin 等数字孪生
└── 数据增强（扩展已有数据集）
    ├── 外观增强（视觉扰动、图像/视频生成）
    └── 行为增强（改物体构型 + 重解轨迹）
        ├── 刚体路线：MimicGen, DemoGen, R2R2R, SkillMimicGen
        │              └── 依赖 SE(3) 等变性，可变形上失效
        └── 可变形路线
            ├── SoftMimicGen：解决了【轨迹迁移】，但状态仍刚性  ← 最近邻
            └── DeformGen（本文）：同时解决【状态增强】+【轨迹迁移】  ★
```

另一条相关脉络是**可变形物体操作**本身：早期基于模型的规划（质点弹簧/FEM/粒子动力学）→ 直接学视觉运动策略（打结、布料折叠、面团塑形）→ 大规模 VLA 扩展到可变形（但更吃数据）。DeformGen 正是为"VLA 吃数据"这个痛点供给廉价合成数据。

## 如何把这篇归类记忆

用三个关键词钉住它：

1. **"动力学采样保证合法"**（状态增强的灵魂）——不修复，靠演化。对应 Assumption 1 的不对称性。
2. **"连续形变场扭曲"**（轨迹迁移的灵魂）——逐粒子位移 → 空间连续映射 → 同时管位置（IDW+衰减）和姿态（雅可比+SO(3)+SLERP）。
3. **"解耦消融"**（实验方法论的灵魂）——SMG\*/DG\*/DG 三档精确隔离两个组件各自的贡献。

## 与读者已知方法的连接

- 如果你熟悉 **MimicGen**：DeformGen 就是它的"可变形版"，把 SE(3) 扰动换成动力学 rollout，把刚性轨迹搬运换成形变场扭曲。
- 如果你熟悉 **非刚性配准 / 光流 warping**：轨迹扭曲那部分本质就是用稀疏粒子位移驱动一个稠密形变场，再把"被 warp 的对象"从图像像素换成"末端执行器位姿"。
- 如果你熟悉 **流形学习**：S_real 是嵌在 R^{3N} 里的低维流形，刚性增强只动了流形上一个 6 维切片，逐粒子加噪是垂直跳出流形，动力学方法是**沿流形测地线游走**。

## 什么时候该想到这套方法

当你面对一个问题满足：
1. 状态空间高维且物理可行子集很薄；
2. 有一个可信的前向仿真器（或动力学模型）；
3. 已有少量"状态-解"配对，想扩展到更多状态；
4. 解依赖于状态的局部几何（不能整体平移搬运）。

——就可以套用"动力学采样合法状态 + 连续场迁移解"的范式，不限于机器人。
