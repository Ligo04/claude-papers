# 方法详解：DeformGen

整体目标：**从稀疏示教数据出发，为同一任务但不同物体初始状态合成大量合法的操作数据。**

管线三大组件：
1. **状态增强**（Sec 3.1）：Dynamic Topological Transformation
2. **轨迹增强**（Sec 3.2）：Deformation-Field Warping
3. **策略训练**（Sec 3.3）：在增强数据上做模仿学习

---

## 0. 物体表示与符号

可变形物体离散成 N 个粒子，构型空间 **S = R^{3N}**，一个状态 `s = (p₁, ..., p_N) ∈ S` 记录所有粒子位置。

- **S_real ⊂ S**：物理可行子空间（与现实物理约束一致的所有构型）。一般 S_real ⊊ S。
- **Φ_sim(s, f, Δt)**：物理仿真器，在外力 f 下把状态 s 演化时长 Δt。
- 软体建模与仿真用 **PhysTwin**，基准与渲染用 **Real2Sim-Eval**。

---

## 1. 状态增强：Dynamic Topological Transformation

### 1.1 核心假设（Assumption 1，合法流形的近似条件封闭性）

```
s ∈ S_real   ⟹  Φ_sim(s, f, Δt) ≈ S_real      (合理的 f, Δt 下)   ... (A1)
s ∉ S_real   ⇏  Φ_sim(s, f, Δt) ∈ S_real                           ... (A2)
```

含义：仿真器从合法状态出发能近似保持合法，但**无法**可靠地把非法状态修回合法。
**推论**：任何"先把状态扰动出 S_real、再靠仿真修复"的方法都没有可靠的回到合法的路径。

### 1.2 为什么三种现成策略不行

| 策略 | 问题 |
|------|------|
| (i) 全局刚性变换 T∈SE(3) | 保持所有粒子间关系 ⟹ 仍在 S_real，但只能在 6 维位姿子空间动，捕捉不到形状/拓扑变化（Fig.8 非刚性残差≈0）。 |
| (ii) 逐粒子独立扰动 | 覆盖-合理两难：噪声大破坏连接性，噪声小只有局部褶皱。跌出 S_real，事后修复不可靠。 |
| (iii) 运动学形变场 | 保持拓扑连贯但忽略材料约束，产生"连贯但动力学不可行"的状态。同样跌出 S_real。 |

### 1.3 本文方法（公式 1）

```
s_aug = Φ_sim(s₀, f, Δt),    s₀ ∈ S_real          ... (1)
```

其中 **f 是局部力场（localized force field）**。

- 因为状态通过仿真器自身动力学演化，**从不显式离开 S_real，无需事后修复**。
- 局部力能诱导多样非刚性形变（弯 bending、扭 twisting、折 folding、垂 draping），可达集 **R(s₀) ⊆ S_real** 不再被限制在低维子流形。
- 不声称覆盖全部 S_real，作为实用采样启发式，覆盖远大于刚性变换（Fig.8 验证）。

### 1.4 工程实现

- 夹爪在与物体**接触**时执行随机化的笛卡尔扰动（rope/toy 180 步，cloth 260 步），随后做**稳定化（stabilization）**让物体沉降到静止合法状态。
- 每个任务生成增强状态并尝试轨迹合成，最终得到 **1000 条成功轨迹用于训练 + 200 个成功状态用于测试**（每任务实际合成 >1200 个状态）。

```
算法：状态增强
输入：源合法状态 s0，仿真器 Φ_sim，目标数量 M
输出：增强状态集合 {s_aug}
1. for m = 1..M:
2.     选取与物体接触的局部作用点，采样随机化笛卡尔扰动 → 局部力场 f
3.     s_tmp = Φ_sim(s0, f, Δt)          # 前向推演 180/260 步
4.     s_aug = Stabilize(s_tmp)           # 撤力后继续仿真至静止
5.     收集 s_aug（始终 ∈ S_real）
```

## 2. 轨迹增强：Deformation-Field Warping

合成轨迹分三阶段：**approach（接近）→ grasp（抓取）→ manipulation（操作）**。
- grasp 位姿与 manipulation 轨迹用形变场扭曲合成；
- approach 轨迹由机器人 reset 位姿到 grasp 位姿插值生成。

核心思想（受 Schulman 非刚性配准启发）：由逐粒子位移构造一个**连续空间映射**（闭式、无迭代优化），而非像刚性迁移那样对整个物体施加统一变换。

### 2.1 位置扭曲（公式 2–3）

设源点云 `p_orig` 和形变后点云 `p_def ∈ R^{N×3}`，逐点位移 `δ_i = p_def,i − p_orig,i`。

对每个时刻 t 的末端位置 x_t，取它在 p_orig 中的 k 个最近邻，用**反距离加权（IDW）**插值：

```
w_{t,j}  = 1 / ( ‖ x_t − p_orig,nn_j(x_t) ‖ + ε )       # ε>0 数值稳定
w̃_{t,j} = w_{t,j} / Σ_j w_{t,j}                          # 归一化
d(x_t)   = Σ_j  w̃_{t,j} · δ_{nn_j(x_t)}                  # 聚合位移      ... (2)
```

加**时间衰减**得到扭曲后位置：

```
x_warp_t = x_t + α_t · d(x_t),    α_t = decay(t)          ... (3)
```

α_t 让轨迹**初期跟随局部形变、后期逐渐回归原路径**。

### 2.2 姿态适配（公式 4–7）

在 x_t 的 KNN 邻域内构造局部相对坐标：

```
ℓ_orig_{t,j} = p_orig,nn_j(x_t) − x_t
ℓ_def_{t,j}  = ℓ_orig_{t,j} + δ_{nn_j(x_t)}              ... (4)
```

用**最小二乘拟合局部雅可比 J_t**，把源局部向量映射到形变后局部向量：

```
J_t = argmin_J  Σ_j ‖ ℓ_def_{t,j} − J · ℓ_orig_{t,j} ‖²   ... (5)
```

闭式解（X_orig, X_def 为堆叠的局部向量矩阵，(·)⁺ 为 Moore-Penrose 伪逆）：

```
J_t = X_def · X_origᵀ · ( X_orig · X_origᵀ )⁺            ... (6)
```

把 J_t·R_t 投影到 SO(3) 流形（SVD）得诱导旋转 R'_t，最后用 **SLERP** 按 α_t 插值：

```
R_warp_t = SLERP( R_t, R'_t, α_t )                       ... (7)
```

### 2.3 关键超参与约束

- **K 的选取**：grasp 位姿与附近物体点关系更强 → **用小 K**（局部精确）；manipulation 阶段依赖整体物体状态 → **K = 物体全部点数**（捕捉全局形变）。
- **旋转约束**：桌面场景下，旋转被限制到**垂直桌面的 Z 轴**。

```
算法：形变场扭曲（对一条源轨迹 {(x_t, R_t)}）
输入：p_orig, p_def, 源轨迹, 衰减函数 decay
1. δ = p_def − p_orig
2. for 每个时刻 t:
3.     K = K_grasp (小) if 抓取阶段 else N (全部点)
4.     找 x_t 在 p_orig 中的 K 近邻，IDW 权重 w̃
5.     d(x_t) = Σ w̃ · δ_nn                       # 位置位移
6.     α_t = decay(t)
7.     x_warp_t = x_t + α_t · d(x_t)              # 公式 3
8.     用 KNN 局部向量最小二乘解 J_t              # 公式 5/6
9.     R'_t = ProjectSO3( J_t · R_t )  (SVD)
10.    R_warp_t = SLERP(R_t, R'_t, α_t)           # 公式 7（约束到 Z 轴）
11. approach 段：reset 位姿 → grasp 位姿 插值
12. 在仿真中执行，按任务成功判据筛选保留成功轨迹
```

## 3. 策略训练（Sec 3.3）

- 三个任务，每个采集 **1 条** 遥操作示教。
- 用状态增强合成 >1200 状态/任务，再用形变场扭曲（及"局部刚性迁移"消融）合成轨迹。
- 增强轨迹在仿真中执行验证成功（任务专属成功判据），记录第三人称 + 腕部 RGB 图像 + 对应动作。成功 episode 划分训练/留出测试集。
- 遵循 Real2Sim-Eval 协议，训练 **4 种策略架构**：ACT、Diffusion Policy、SmolVLA、π₀（LoRA 微调）。
- 在**未见**的物体状态上评估（包括扭曲合成失败的配置）。

## 实现陷阱与复现风险

1. **Assumption 1 是地基**：若仿真器保真度不够，从合法状态演化也可能漂出 S_real，整个合法性保证失效 → 必须用高保真仿真器（PhysTwin）。
2. **稳定化不可省**：施力后物体可能仍在动；不稳定化就采样会得到非静止/接触不稳的状态，污染训练。
3. **ε 与 K 敏感**：IDW 的 ε 太小数值不稳，太大过度平滑；grasp 用大 K 会让抓取位姿被远处点"拖偏"。
4. **SO(3) 投影必须做**：J_t 一般不是正交矩阵，直接当旋转用会引入剪切/缩放，必须 SVD 投影。
5. **衰减函数 decay(t) 形状**：论文只说"初期跟随、后期回归"，具体形式（线性/指数）需查附录或调参——这是复现敏感点。
6. **轨迹要执行验证**：扭曲出的轨迹不保证成功，必须在仿真里跑一遍筛选；硬样本（toy/cloth）合成失败率不低。
7. **架构交互不稳定**：DG 不是处处最优（DP 上略逊 DG\*），复现时不要期待单调超越所有 baseline。
