# DeformGen：基于动力学的拓扑数据增强

> Dynamics-Based Topology Augmentation for Deformable Manipulation Policy Learning
> arXiv:2606.25939 · 2026-06-24 · cs.RO

## 这篇论文讲什么（一段话）

机器人模仿学习极度依赖大量人工示教数据，而采集示教非常昂贵。对**刚体**操作，人们用"一个示教 → SE(3) 位姿扰动 → 大量训练轨迹"的数据增强范式（MimicGen / DemoGen 等），因为刚体满足**等变性**（任意两点间欧氏距离在运动下不变）。但**可变形物体**（绳、布、毛绒玩具）打破了这个前提：状态空间是高维的、受物理约束的粒子构型空间，单纯位姿扰动既不能覆盖形状/拓扑变化，又会产生物理上不可能的构型；同时材料点不再刚性同步运动，刚性轨迹迁移会让抓取位姿与局部几何错位。**DeformGen** 用两步解决：(1) **动力学拓扑变换**——对一个合法状态施加局部随机外力并用高保真物理仿真器前向推演，得到拓扑连贯、物理可行的新状态；(2) **形变场扭曲（Deformation-Field Warping）**——把源/目标点云的逐粒子位移通过 KNN 反距离插值升维成连续空间形变场，用它同时平移轨迹位置并旋转末端执行器姿态，使单条示教能复用到整族变形状态。在三个高保真任务（绳子穿夹、毛绒玩具装箱、叠布）上，相比无增强和刚性增强基线，策略成功率普遍提升。

## 难度

**中级偏高（Intermediate–Advanced）**。需要的前置知识：模仿学习/视觉运动策略（ACT、Diffusion Policy、VLA）、刚体位姿与 SE(3)/SO(3)、粒子法可变形仿真、最小二乘与 SVD。数学不深但概念跨度大（机器人 + 物理仿真 + 几何）。

## 关键要点（Key Takeaways）

- **核心矛盾**：物理可行状态只占整个 R^{3N} 粒子空间的一个低维"流形" S_real；刚性增强只能在 6 维子空间里动，逐粒子加噪/运动学形变场则会跌出 S_real 且无法可靠修复。
- **关键洞见（不对称性，Assumption 1）**：好的仿真器从**合法**状态出发能近似保持合法，但**无法**可靠地把非法状态拉回合法。所以正确做法是"永不离开流形"——施加外力 + 前向仿真 + 稳定化。
- **轨迹迁移**：用连续形变场 D(x) 同时做位置扭曲（反距离加权位移 + 时间衰减 α_t）和姿态适配（局部雅可比 → 投影到 SO(3) → SLERP 插值）。
- **解耦实验设计**：SMG\*（刚性状态增强 + 形变场扭曲）vs DG 隔离"状态增强"贡献；DG\*（拓扑状态增强 + 局部刚性迁移）vs DG 隔离"轨迹迁移"贡献。
- **结果**：DG 在 4 个策略架构中的 3 个上取得最高平均成功率；增强数据量从 N=100→750 单调提升（ACT 19.5%→61.5%）；即使在轨迹合成失败的"硬样本"上策略也有非平凡成功率，说明学到的是可迁移策略而非记忆。
