# 论文总结 — KPM-FR

## 背景脉络（Background）

流体仿真（CFD 与计算机图形学共同关心）几十年来被三个目标的张力塑造：
- **高保真度**：物理准确、视觉可信、低数值耗散/色散，能保住涡结构。
- **大计算吞吐**：能在可行时间内跑高分辨率。
- **小内存占用**：在消费级硬件上可行。

主流方法的三选二困境：

| 方法族 | 优势 | 代价 |
|--------|------|------|
| 传统不可压 NS 求解器（投影法/Stable Fluids） | 强制不可压 | 全局压力泊松解昂贵；平流耗散大 |
| **LBM**（格子玻尔兹曼，stream-and-collide） | 局部、守恒、极低耗散、GPU 友好、谱类特性 | 存完整分布函数（D3Q27 存 27 个），内存巨大；两套分布避写冲突 |
| **MR-LBM**（矩表示 LBM） | 只存宏观矩，省内存 | streaming 时需从矩**重构** `f_i`，重新引入耗散 + 共享内存瓶颈 |
| **GKS**（气体动理学格式，flux-based） | 从局部演化 Boltzmann 构造通量，**不存分布** → 省内存；统一无黏/黏性 | 解析式极复杂、算术强度高；二阶有限体积耗散大 |
| **高阶 FR/DG**（Huynh 2007） | 高阶多项式、低耗散、谱类 | 处理黏性（二阶导跨单元一致）需 BR1/BR2/LDG 等昂贵辅助；通信开销 |

**关键观察**：GKS 的通量哲学（解耦动理学演化与速度空间存储）能保证最小内存，但被其解析复杂性与二阶精度拖累；高阶 FR 能降耗散但黏性处理麻烦。二者的互补性正是本文切入点。

## 问题陈述（Problem Statement）

能否设计一个**低马赫数弱可压**流体求解器，在**单一框架**内同时做到高阶低耗散、极高吞吐、极小内存？现有 kinetic-FR 方案都做了取舍：保留原始 GKS → 低速下通量评估昂贵；用多级 RK → 墙钟时间增加；解耦黏性处理 → 重新引入辅助梯度的通信开销。三者尚未被协同优化。

## 主要贡献（Main Contributions）

1. **基于矩的空间高阶动理学框架**：把高阶 FR 的谱精度与 kinetic 格式的统一无黏-黏性处理结合，专为低马赫流设计。核心创新是一个**完全在矩空间运行的 encode-transmit-decode（编码-传输-解码）流水线**，最小化 GPU 内存流量，并把通量重构简化为一串高效代数运算。
2. **硬件感知的预测-校正架构**：用一对轻量 predictor-corrector 实现该框架，为张量积 FR 在现代 GPU 上定制，把核心操作**融合成两个 kernel**。利用片上内存层次执行单步显式更新，配合混合精度存储饱和 GPU 内存带宽。
3. **SOTA 性能与可扩展性**：在同等误差下相对最先进 LBM 有更优 time-to-solution；单消费级 GPU 上 >80 亿 solution-point 更新/秒，内存降到 **42 字节/点**；从百万到十亿点规模的应用（低耗散→高吞吐），单 GPU 上跑到 18 亿点。

## 方法要点（速览，详见 method.md）

- **控制方程**：连续 Boltzmann-BGK（式 4）`∂f/∂t + ξ·∇f = -(1/τ)(f-g)`；取矩得守恒律（式 6）`∂U/∂t + ∇·F = 0`，`U=⟨φf⟩, F_d=⟨ξ_d φ f⟩`，`φ=[1,ξ^T]^T`。恢复等温弱可压 NS。
- **空间离散（FR）**：每单元度 `P` 多项式、`K=P+1` 个 Gauss-Lobatto solution points、Lagrange 基。半离散系统（式 8）`∂U/∂t = -(2/L)(QF + CF*)`，`Q=D-CR`；D 微分矩阵、C 校正矩阵、R 外插矩阵，均全局常量、且对 Gauss-Lobatto 高度稀疏。
- **时间积分**：半时刻 `h=Δt/2` 处 `F, F*` 闭式可得 → 二阶精度**单步更新**（式 10）`U^(n+1) = U^(n) - (2Δt/L)(QF + CF*)`；公共通量只算一次。
- **动理学通量**：半时刻分布（式 11）`f(h) ≈ A f_s(h) + B g(h)`，`A=τ/h, B=1-τ/h`，`f_s(h)=g(0)-h ξ·∇g(0)`（沿 ξ 的一阶 Taylor 传播项）。相容条件给出 `U(h)=⟨φ[g(0)-h ξ·∇g(0)]⟩`。公共分布 `f*` 由两侧半程矩构造 + 迎风选择（式 14、15）。
- **预测矩**：`F*(h)` 本需邻居的 `∇g`（3D 下 16 个标量/点）。利用「平衡态 g（由 U 定）+ 非平衡 f_neq（携黏性信息）」的分解与**演化态恒等式**，把跨单元传输压缩成紧凑的**预测矩**标量，消除梯度流量。
- **双 kernel**：predictor（算导数→编码矩→写全局）+ corrector（读矩→闭式算通量→校正更新），FR 微分全在片上，避免梯度溢出 DRAM。

## 关键结果（Key Results）

- **吞吐**：> 80 亿 solution-point 更新/秒（完整时间步，单 RTX 4090），近 roofline 带宽利用。
- **内存**：42 字节/点；为标准图形 LBM 的 **18%**、高保真 in-place streaming CFD LBM 的 34%、MR-LBM 的 53%；比 LBM 每点内存少 5 倍以上。
- **保真度**：数值耗散**低于**最先进 cumulant LBM；基准测试验证高阶空间收敛与谱类耗散特性。
- **验证**：从涡基准（谱类保真）到高雷诺数气动流；相同保真度下用**显著更少的 solution points** 达成（复合优势）。
- **规模化 demo**：赛车空气动力学 2000×332×800 ≈ 5.3 亿点、仅 21 GiB、5.5m 车 @ 220km/h；最大 18 亿点，单工作站。

## 局限（见 reflection.md 展开）

- 面向**低马赫数弱可压等温**流；高马赫/强可压/非等温不在范围。
- 二阶时间精度（更高阶可得但成本增加）。
- 弱可压近似仍非严格不可压（有可压误差）。
- 复杂/非结构网格需 per-element Jacobian 映射（补充材料），规则网格上最优。
