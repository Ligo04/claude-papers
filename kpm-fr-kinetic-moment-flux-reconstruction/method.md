# 方法细节 — KPM-FR

## 总览：predictor-corrector 循环 → 两个融合 kernel

```
┌──────────────────────────── 一个时间步 ────────────────────────────┐
│                                                                     │
│  PREDICTOR kernel (左)                    CORRECTOR kernel (右)      │
│  ─────────────────────                    ──────────────────────    │
│  · 读 U(0) (K^d 个 solution point)         · 从全局内存读回预测矩    │
│  · 片上 FR 微分: ∇g(0) = f(D·g)            · 闭式算元内通量 F(h)      │
│  · 由平衡/非平衡分解, 把物理态             · 闭式算公共通量 F*(h)     │
│    编码成紧凑"预测矩"标量                  · 构建 correction (Q,C)    │
│  · 把矩 (+F(h)) 写入全局 DRAM ────传输────▶· 单步更新 U(0)→U(n+1)     │
│                                                                     │
│  仅"预测矩"这几个标量经过 off-chip DRAM; FR 微分/梯度全程留在片上。  │
└─────────────────────────────────────────────────────────────────────┘
```

对照论文 Fig. 2。整套算法把「梯度数据溢出 DRAM」这一传统瓶颈消除，逼近内存带宽 roofline。

## 3.2 从 Boltzmann 到 Navier-Stokes

**控制方程**——连续 Boltzmann-BGK（式 4）：

```
∂f/∂t + ξ·∇f = -(1/τ)(f - g)
```

- `f(x,ξ,t)`：粒子分布函数（位置 x、粒子速度 ξ、时间 t）。
- `g = g(ρ,u)`：局部 Maxwell 平衡态（等温下只依赖密度 ρ 和速度 u）。
- `τ = ν/(RT)`：松弛时间，与运动黏度 ν 相关；等温 `T=T_0`。

**矩关系**（式 5），`φ=[1, ξ^T]^T` 为矩向量：

```
U = ⟨φ f⟩,        F_d = ⟨ξ_d φ f⟩
```

`⟨·⟩` = 速度空间积分。`U=[ρ, ρu^T]^T`（守恒变量），`F_d` = 沿方向 d 的通量。

对式 (4) 乘 `φ` 并对 ξ 积分（BGK 局部守恒质量动量），得**守恒型控制方程**（式 6）：

```
∂U/∂t + ∇·F = 0
```

通量张量 F 在单一动理学表达式内**同时含无黏与黏性**贡献。式 (6) 恢复等温弱可压 NS（低马赫近似不可压）。

## 3.3 空间离散：Flux Reconstruction（FR）

**多项式表示**：1D 单元局部坐标 `r∈[-1,1]`，解用度 `P=K-1` 多项式表示，由 `K` 个 solution points（SP）插值：

```
U(r) = Σ_{j=1}^K U_j ℓ_j(r)
```

`ℓ_j` 为 Lagrange 基（`ℓ_j(r_i)=δ_ij`）。SP 取 **Gauss-Lobatto 点**（含端点 ±1）。通量同样插值 `F(r)=Σ_j F_j ℓ_j(r)`。

对 `F(r)` 在 SP 处求导代入式 (6)（式 7）：

```
∂U/∂t = -(2/L) D F,     D_ij = ∂ℓ_j(r_i)/∂r
```

`D` 是 `K×K` 微分矩阵，`L` 单元长度。**注意：式 (7) 只管单元内演化，不耦合邻居。**

**单元间耦合**：各单元独立成多项式 → 界面通量不连续。FR 用两个度 `K` 的**校正函数** `g_LB(r), g_RB(r)`，满足 `g_LB(-1)=g_RB(1)=1`, `g_LB(1)=g_RB(-1)=0`, 对称 `g_LB(r)=g_RB(-r)`。它们把**公共通量 `F*`** 混入单元内部，得全局连续通量：

```
F̃(r) = F(r) + g_LB(r)[F*_LB - F(-1)] + g_RB(r)[F*_RB - F(1)]
```

对 `F̃` 在 SP 求导得半离散系统（式 8）：

```
∂U/∂t = -(2/L)(Q F + C F*),    Q = D - C R,    F* = [F*_LB, F*_RB]^T
```

- `R`：2×K 外插矩阵（把多项式求值到边界）。
- `C`：K×2 校正矩阵（校正函数在 SP 的导数）。
- 本文取 `g_LB=g_2`（Huynh 2007 的 g_2），对 Gauss-Lobatto 使 C **高度稀疏**：`g'_LB(r_1)=-K(K-1)/2`，`g'_LB(r_i)=0 (i≥2)`。
- **D, R, C, Q 全局常量**（预计算）。

**多维扩展**：六面体(3D)/四边形(2D) SP 排成张量积网格，`K^2`(2D)/`K^3`(3D) 点。各坐标方向独立 → 多维更新分解为 1D FR 子问题（2D 下 `K^2` 点 = `2K` 条独立 `K` 点线），方向贡献在每个 SP 累加。非结构网格只需 per-element Jacobian 映射。

**无黏局限（传统 FR 的痛点）**：常规 F, F* 只从无黏公式算，扩展到黏性需昂贵辅助（Huynh 2009 的 BR1/BR2/LDG）。KPM-FR 用动理学演化**单一局部演化同时给出无黏+黏性**，消除此弊。

## 3.4 单步时间积分

`F` 和 `F*` 在半时刻 `h=Δt/2` 均闭式可得 → 二阶精度**单步全离散更新**（式 10）：

```
U^(n+1) = U^(n) - (2Δt/L)(Q F + C F*)
```

- 公共通量 `F*` **只算一次**（RK2 至少两次）。
- 中点选择 → 二阶时间精度；单元间数据交换/off-chip 流量减半。
- 后续下标 d 省略，用 `F(t), F*(t)` 表示沿单方向的 per-point 通量。

## 3.5 动理学通量评估

需要在 `h=Δt/2` 算元内通量 `F(h)` 与公共通量 `F*(h)`，二者都是对应分布函数的速度矩（式 5）。

**半时刻分布函数**（式 11）——把式 (4) 在 `[0,h]` 上有限差分积分：

```
f(h) ≈ A f_s(h) + B g(h),    A = τ/h,    B = 1 - τ/h
```

- `f_s(h) = g(0) - h ξ·∇g(0)`：**传播分布**，沿 ξ 对 `g` 的一阶 Taylor 展开。
- `g(h)=g(U(h))`：半时刻宏观态的平衡态。
- 唯一未知 `U(h)` 由**相容条件**确定：`U(h) = ⟨φ[g(0) - h ξ·∇g(0)]⟩`，其中 `g(0), ∇g(0)` 由 FR 离散直接提供。

**per-point 通量定义**：
```
F(h)  = ⟨ξ_d φ f(h)⟩                         (式 12, 元内)
F*(h) = ⟨ξ_d φ f*(h)⟩                        (式 13, 公共)
```

**构造 f\***（式 14, 15）：界面处两侧各自重构半时刻分布 `f_L(h), f_R(h)`，公共态由半程矩逼近：

```
U*(h) = ⟨φ f_L(h)⟩_+ + ⟨φ f_R(h)⟩_-          (式 14)

f*(h) ≈ B g(U*(h)) + A · { f_s_L(h)  if ξ·n>0
                           f_s_R(h)  if ξ·n<0 }  (式 15, 迎风)
```

`⟨·⟩_±` = 对半空间 `ξ·n≷0` 积分。

**两个实现障碍**：(i) 速度空间积分（尤其半程）→ 冗长解析式，直接算昂贵；(ii) 每侧半时刻分布依赖算它那个单元的 `∇g`（`∇U`），需跨单元通信 → 增加数据流量。§3.6 用矩编码同时解决。

## 3.6 基于矩的预测与校正（核心创新）

**问题定位**：元内通量 `F(h)` 自足（式 11 只需本地 `g(0), ∇g(0)`）。但公共通量 `F*(h)` 需邻居的 `∇g` —— **3D 下每 SP 16 个标量**，远超紧凑矩表示。这些值 predictor 写、corrector 读，必经全局 DRAM；每个标量都增内存与带宽。界面 = 带宽受限信道，实现关键是**最小化传输载荷**。

**演化态恒等式**：算 `F*(h)` 真正需要邻居的**传播分布 `f_s`**，而非原始梯度 `∇g` —— 这个区别是紧凑编码的门。

**平衡/非平衡分解**：任意分布 = 平衡态 `g`（完全由 `U` 决定，接收方可自建）+ 非平衡偏离 `f_neq`（携黏性信息）。半时刻分布同时有**演化形式**（依赖单元本地宏观梯度）和**编码形式**（用紧凑预测矩）。于是只需传输与 `f_neq` 相关的少数**预测矩**标量，`g` 部分由接收方从 `U` 重建 → 跨单元载荷压到物理必需的最小，消除梯度流量（配合 §4 融合 kernel）。

> 直觉：predictor 把「非平衡部分」预积分/编码成几个标量矩 → 写全局；corrector 读回，配合本地可重建的平衡部分，闭式组装 `F*(h)`。

## 单步算法（伪代码）

```python
# 全局常量（预计算）: D(K×K), R(2×K), C(K×2), Q=D-CR
# 每个单元持有 K^d 个 solution point 的 U

# ---------- PREDICTOR kernel ----------
def predictor(U_elem):                      # U_elem: (K^d, C)
    g0   = equilibrium(U_elem)              # g(0)=g(U): Maxwell 平衡态
    grad_g0 = fr_gradient(g0, D, R, C)      # ∇g(0): 片上 FR 微分(小密矩阵乘)
    U_h  = moment(g0 - h * xi_dot(grad_g0)) # 相容条件 → U(h)  (式 11 取矩)
    F_h  = moment_flux(A, B, g0, grad_g0, U_h)   # 元内 F(h) (式 12) 片上
    pmom = encode_predicted_moments(g0, grad_g0) # 编码非平衡→紧凑预测矩
    write_global(F_h, pmom)                 # 仅这些标量落 DRAM

# ---------- CORRECTOR kernel ----------
def corrector(U_elem, F_h, neigh_pmom):
    # 从邻居预测矩 + 本地可重建平衡部分, 闭式构造公共态与公共通量
    U_star = halfrange_moments(neigh_pmom, local_pmom)   # 式 14
    Fstar  = common_flux_closed_form(U_star, neigh_pmom) # 式 15→13, 迎风
    # 单步更新 (式 10): 各坐标方向贡献累加
    U_new = U_elem - (2*dt/L) * (Q @ F_h + C @ Fstar)
    return U_new
```

## 关键设计与参数

| 项 | 说明 |
|------|------|
| SP 选点 | Gauss-Lobatto（含端点，使 C 稀疏） |
| 校正函数 | `g_LB=g_2`（Huynh 2007）；其他选择退化为 nodal DG 等 |
| 空间精度 | 度 `P`，`K=P+1` 个 SP/方向 |
| 时间精度 | 二阶（半时刻中点单步） |
| 每步 kernel | 2（predictor + corrector，融合） |
| 常量矩阵 | D, R, C, Q 全局常量、Gauss-Lobatto 下高度稀疏 |
| 多维 | 张量积，`K^3`(3D)，分解为 1D 线独立处理 |
| 精度存储 | 混合精度（压带宽） |
| 内存 | 42 字节/点 |

## 实现坑点（Implementation Pitfalls）

1. **梯度必须留片上**：predictor 的 FR 微分 `∇g` 若溢出 DRAM，全部优势尽失。核心是把微分矩阵乘（D, C, Q 小而密）在寄存器/共享内存内做完。
2. **只传预测矩**：跨单元载荷必须是编码后的非平衡预测矩，而非原始 `∇g`（16 标量）。传错东西 = 退回 GKS 的带宽瓶颈。
3. **半程积分 / 迎风**：式 14、15 的半空间矩 `⟨·⟩_±` 与迎风选择（`ξ·n≷0`）要正确，否则界面通量错、格式不稳。
4. **相容条件**：`U(h)` 必须由 `⟨φ[g(0)-hξ·∇g(0)]⟩` 一致地确定，否则时间精度掉阶。
5. **A, B 与 τ/h**：`A=τ/h, B=1-τ/h`；低黏（小 τ）时 A 小 B 近 1，需注意数值行为与稳定性。
6. **correction function 选择**：`g_2` 给稀疏 C；换别的会改变稳定性/耗散/最大时间步（Vincent 2011）。
7. **张量积方向累加**：多维下各方向 1D FR 贡献要正确累加到每个 SP，方向解耦但需规整访存以保带宽。
8. **弱可压时间步**：低马赫弱可压对声速/时间步有约束，CFL 需匹配。

## 复现风险（Reproduction Risks）

- **无公开代码**（meta 中 githubLinks 为空）；补充材料含非结构网格 Jacobian 与多维细节。
- **性能强依赖 GPU 体系结构**：near-roofline、混合精度、kernel 融合对具体硬件（RTX 4090）和访存布局敏感，换硬件需重调。
- **动理学推导门槛高**：式 11/14/15 的半程矩预积分需要仔细的动理学代数，容易出错。
- **数值稳定性**：高阶 + 弱可压 + 单步，稳定域对 τ、CFL、correction function 组合敏感。
