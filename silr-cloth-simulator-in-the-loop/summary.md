# 速览(Summary)

## 背景脉络(Background)

- **可变形物体操作的根本难点**:无限维构型空间、局部几何持续演化、严重自遮挡、无处不在的摩擦接触。这些既让**状态估计**难,也让**动作推理**难。
- **模仿学习(IL)是主流范式**:绕过显式动力学建模,直接拟合专家演示/交互数据的策略分布;近期机器人基础模型(RT-2、OpenVLA、π₀ 等)进一步规模化并展现任务级泛化。
- **但 IL 策略在部署时缺乏自我纠错能力**:感知、抓取选择、时序、动作预测里的小偏差,会经由接触丰富的布料动力学**累积**,把系统推离目标状态。因此可靠的布料操作需要一个**推理时(inference-time)机制**来精修策略提议、从累积误差中恢复。

## 问题陈述(Problem)

**中心问题**:能否直接把可变形物体仿真器当作真实世界布料操作的"**推理时前向模型**"?

要回答它,必须打通完整的 **real-to-sim-to-real 闭环**,且三处都不能掉链子:
1. **仿真器**必须物理可信、且快到能在线 rollout;
2. **真实布料状态**必须恢复得足够准,以同步一个仿真"数字孪生";
3. **rollout 表示**必须在状态粒度、动力学保真度、并行候选多样性之间平衡(受限于在线控制预算)。
任何一环失败,优化出的动作就会与物理场景错位、或贵到无法在线计算。

## 主要贡献(Contributions)

围绕三个耦合的系统级问题,提出统一的 simulator-in-the-loop 框架(Fig. 1),含**离线**与**在线**两条流:

1. **(支柱 i)可扩展合成数据 + 推理时 rollout 管线**:基于 **FLASH** 可变形仿真器,系统研究"仿真保真度 / 数值稳定性 / rollout 效率"如何影响布料操作的推理时精修。
2. **(支柱 ii)RGB-native real-to-sim 模块**:**纯用合成数据训练**,把单张 RGB 观测提升为仿真兼容的稀疏布料状态——融合预训练视觉特征 + 可学习 canonical query tokens + 随机抓取点掩码。
3. **(支柱 iii)先验引导的 MPPI 在线规划**:把稀疏网格 rollout 后端与 prior-guided MPPI 耦合,**锚定**在离线蒸馏策略轨迹上,既保留操作相关的形变与接触,又能提供足够的并行 rollout 批量。

> **首创性**:据作者所知,这是**第一个**在实时机器人控制预算下,直接用可变形物体仿真器作为推理时前向模型来做布料操作的框架。

## 一句话总结

> 用 **FLASH 仿真器(快+稳)+ RGB-native 状态估计(canonical tokens)+ 先验引导 MPPI(锚定离线策略)** 组成 real-to-sim-to-real 闭环,把"仿真器在环"推理时精修首次落地到单 RGB 的真实布料操作,显著提升成功率与鲁棒性;三组件紧耦合,缺一不可。
