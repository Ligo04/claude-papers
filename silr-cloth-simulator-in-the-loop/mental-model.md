# 心智模型(Mental Model)

## 这是什么类型的问题?

**机器人可变形物体操作 + 推理时最优控制(MPC/采样式)的系统集成问题**。它不是提出新仿真器、新策略架构或新控制算法,而是回答:

> "如何把已有的物理仿真器、视觉编码器、采样式控制器**正确地拼成一个 real-to-sim-to-real 闭环**,让一个不完美的布料操作策略在部署时被物理推理在线纠错?"

类比:
- 像给一个**导航 App(策略)**加一个**实时路况重规划(仿真在环精修)**——App 给出大致路线(名义轨迹),但每个路口都用当前路况(RGB→仿真孪生)模拟几条微调路线,选最优的走。
- 像 **MPC 之于 PID**:策略是前馈,仿真在环 MPPI 是基于模型预测的反馈校正层。

## 假设的前置知识

| 概念 | 你需要知道 | 在论文里的角色 |
|------|-----------|----------------|
| **MPPI / CEM** | 采样动作序列、rollout 打分、softmax 加权(无需对动力学求导) | 支柱 iii 的控制器 |
| **MPC / 滚动时域** | 优化一段时域只执行首动作,然后重规划 | 闭环执行方式 |
| **布料/可变形仿真** | 三角网格顶点为自由度,摩擦接触(Signorini–Coulomb)、隐式/local-global 积分 | 支柱 i 的 FLASH |
| **DINOv2 / 自注意力** | 冻结视觉基础模型提 patch 特征;query token 聚合 | 支柱 ii 的骨干 |
| **sim-to-real** | 仿真训练→真机部署的分布差,靠域随机化/增广跨越 | real-to-sim 纯合成训练 |
| **模仿学习 / VLA** | 从演示拟合策略,部署不纠错 | 被精修的"基础策略" |
| **CD / EMD / MSE** | 点集间距离度量 | 状态估计与最终状态评测 |

## 如何归类这项工作(研究地图)

```
机器人可变形物体操作
├── 状态估计 / 感知
│   ├── 点云全状态重建:UniClothDiff(DPM)、garment completion
│   ├── 深度基:DeFM
│   └── 单 RGB + canonical tokens   ◄── 本文支柱 ii
├── 前向动力学模型
│   ├── 学习型:MeshGraphNets / DPI-Net / VCD-Cloth / AdaptiGraph / UniClothDiff
│   └── 物理仿真器直接当前向模型     ◄── 本文核心主张(支柱 i)
│       └── 仿真器选型:Isaac Sim / SAPIEN / Genesis / Newton / FLASH
├── 动作优化 / 控制
│   ├── 端到端策略:Diffusion Policy / 3D DP / VLA(RT-2, OpenVLA, π0)
│   └── 采样式 MPC:CEM / MPPI / Predictive Sampling
│       └── 先验引导 MPPI(锚定离线策略)  ◄── 本文支柱 iii
└── 范式:simulator-in-the-loop(刚体已验证)→ 首次落地真实布料  ◄── 本文整体贡献
```

**独特定位**:它横跨"感知 + 前向模型 + 控制"三块,用一个紧耦合闭环把三者缝起来;**不与任一组件竞争**(用现成 FLASH/DINOv2/MPPI),贡献在**集成 + 把刚体范式跨越到布料 + 单 RGB 实时预算**。

## 记住它的三句话钩子

1. **"仿真器即前向模型"** —— 不训练学习型动力学,直接用物理仿真器做推理时 rollout(去掉一层近似误差)。
2. **"canonical tokens"** —— 每个网格顶点一个可学习 token,从单 RGB 经自注意力回归 3D,处理布料自遮挡。
3. **"先验引导 MPPI"** —— 以离线策略轨迹为锚点局部采样,让高维布料动作空间下的有限预算采样高效。

## 把它放进你已知的东西

- 如果你懂 **MuJoCo MPC / Predictive Sampling [17]**:本文 = 把那套搬到布料,前向模型换成 FLASH,状态来自单 RGB 的 real-to-sim,采样锚定在学习型策略上。
- 如果你做 **Diffusion Policy / VLA**:本文给你的策略加一个推理时"物理校正层",不重训策略,把它当先验。
- 如果你做 **布料感知**:把状态估计从"点云全重建"换成"RGB + 顶点 token 回归",换取实时延迟(7–12ms)与更低误差。
