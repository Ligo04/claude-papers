## 1. 三大能力维度的形式化

### 1.1 认知与空间推理（Cognition & Spatial Reasoning）
4 个子维度：
1. **空间关系理解**：相对方位、支撑关系、包含关系、遮挡与可见性。
2. **度量空间推理**：物体间距离估计、尺寸判断、自由空间能否容纳目标。
3. **3D 场景感知**：单目深度估计、跨视图几何推理、视频帧间空间一致性。
4. **物体与场景认知**：机器人/第一人称视角理解，区分操作目标与障碍物。

### 1.2 规划与纠错（Planning & Correction）
覆盖任务执行全生命周期：
- **任务规划**：(1) 长程任务分解（指令 + 观测 → 结构化子任务序列）；(2) 下一步规划（基于当前进度滚动出下一原子动作，直接服务闭环控制）。
- **过程监控与纠错**：(3) 过程检测（当前子任务是否完成）；(4) 错误定位（从执行/规划两个视角找失败原因）；(5) 错误纠正（生成具体修复建议：重规划或回滚重试，直接喂给下一轮规划）。

### 1.3 指向与定位（Pointing & Location）
4 种类型：
1. **REG** 指代表达 grounding：自然语言 → 物体点坐标。
2. **RRG** 区域指代 grounding：处理区域而非物体（如"能放下盘子的空区域"）。
3. **OFG** 物体功能部件 grounding：定位功能部件（壶嘴、把手、按钮）。
4. **VTG** 视觉轨迹生成：有序点序列描述完整操作轨迹；同时支持**物体流**（目标物运动路径）与**末端执行器流**（机器人末端运动路径）；支持 2D 与 **3D** 轨迹。

## 2. 模型架构

### 2.1 主干 VLM
- **基座**：Qwen3-VL-8B-Instruct（8B 参数，平衡推理能力与部署成本）。
- **统一文本表示**：所有输出 = 纯文本 token 序列。
  - 坐标归一化到 **[0, 1000]**。
  - 轨迹 = 有序坐标序列。
  - 推理 = 自由文本。
  - 可自由交错推理链与规划步骤。
- **不用特殊 token**：直接生成数字坐标，比"专用坐标 token"更稳定、词表开销可忽略；坐标作为可被跨步引用的符号，维持视觉锚定。

### 2.2 VLA 扩展（Embodied-R1.5-VLA）
双系统架构（System 2 推理 + System 1 动作）：
- VLM 骨干产生维度 **2048** 的隐表示。
- **DiT-B 动作头**：用 VLM hidden states 作 cross-attention context，结合 **32 个可学习的 future query token**，通过**流匹配（flow matching）**生成 **7 维**连续动作轨迹。
- **动作分块（action chunking）**：一次预测一段动作。
- 推理时：从高斯噪声出发，**4 步 Euler 积分**生成动作。
- 框架：starVLA。

```
VLM 中间层特征 ──┐
                ├─► [cross-attention] ─► DiT-B ─► flow matching ─► 7-DoF 动作块
32 个 query token ┘         ▲
                    高斯噪声 → 4步Euler积分
```

## 3. 三条自动数据流水线（详解）

### 3.1 Pipeline 1 — 3D 场景标注（→ ER1.5-Spatial, ~20K）
输入单张 RGB，输出结构化 3D 语义场景图，再程序化生成桌面级空间 QA。
数据源：Open X-Embodiment 的真实机器人桌面图（BridgeData V2、DROID、Fractal）。

阶段流程（每阶段嵌入质量控制）：
1. **语义理解**：双后端——Qwen3-VL（长尾物体、功能描述）+ RAM++（更广类别、更快）；再经 VLM 语义归一化合并同义词（cup/mug）、去冗余、生成全局标签表与文本提示 𝒯。质量控制：多帧一致性检查，过滤 <2 个有效物体、语义歧义、机械臂被误认为可操作物体的图。
2. **几何估计**（与分割并行）：**MoGe-2 度量版**从单张 RGB 联合预测**绝对尺度（米）**深度图 D、逐像素法线图 N、相机内参 K。→ 因为是绝对尺度，3D 重建与距离计算无需额外尺度恢复（这是能程序化生成距离 QA 的前提）。作者发现 MoGe-2 在桌面场景上稳定优于 Depth Anything V3。
3. **2D 实例分割**：Grounded-SAM-2（GroundingDINO 出候选框 + SAM2 精修掩膜），按逐图标签 𝒯 条件化以减少误检。过滤：置信度 <0.3、掩膜面积 <0.5% 或 >50% 的实例。
4. **3D lifting**（逆透视投影）：

   ```
   p_c = D_i(u,v) · K_i^{-1} · [u, v, 1]^T          ... (式3)
   ```
   边界感知滤波（去除深度梯度 >局部均值3σ 的像素）+ 2mm 体素下采样 + 统计离群剔除（SOR）。
5. **水平面对齐**：RANSAC 在法线图上估主平面法向（dot >0.996 即 <5° 为内点，K=100 次迭代取最大内点；内点率 <30% 判定无桌面、丢弃）→ 投影直方图定桌高 d_peak → Gram-Schmidt 正交化构造相机到世界变换 T（z 轴沿重力、桌面 z=0）：

   ```
   T_{c→w} = [ R  t ;  0  1 ],  其中 R=[x_new,y_new,z_new]^T, t=[0,0,-d_peak]^T   ... (式4)
   ```
   sanity check：多数物体包围盒底部 z 坐标须在 z=0 的 7cm 内，否则丢弃。
6. **QA 生成**：聚合每场景元数据（标签表、2D 掩膜、3D 点云段、内参、3D 包围盒、变换矩阵）→ 程序化生成空间关系/距离度量/场景认知/外观顺序 QA。

### 3.2 Pipeline 2 — 失败感知标注（→ ER1.5-Correction, ~800K+）
**两个正交维度**组织失败：
- **按阶段**：规划失败（漏步、冗余、换序、物体错、动作/位置错）；执行失败（中断、抓错物、动作错、操作失败）。
- **按认知层级**：检测（二分类 yes/no）→ 定位（识别失败类型+哪个子任务）→ 纠正（生成恢复计划）。
- 组合 = **6 类 QA**。

构造方法：
- **规划失败**：给定正确计划 𝒫={s₁,…,sₙ}，应用 5 个扰动算子：步删除 𝒟_del、步复制 𝒟_dup、步交换 𝒟_swap、物体替换 𝒟_obj、动作/位置替换 𝒟_act。每个扰动同时生成 3 个认知层级 QA；保留原正确计划为正样本防过拟合。
- **执行失败**：3 策略——(1) 截断成功视频模拟中断；(2) 替换子任务描述制造与视频内容的不匹配；(3) ManiSkill 仿真注入物理扰动（如抓取时施加对抗力）产生真实失败视频。RoboFail/RoboFAC 原生失败记录直接重格式化。
- 数据源：真实（BridgeData V2 ~802K、RoboFail、RoboFAC）+ 仿真（ManiSkill ~3.5K、GEMBench）。
- 质量控制：人工抽样审核；验证扰动计划确实无法完成任务；截断点落在子任务边界；正负样本平衡；三层级大致均衡。

### 3.3 Pipeline 3 — 功能 affordance 与轨迹（→ ER1.5-Pointing, ~400K）
- **OFG（功能部件）**：(1) 仿真自动抽取——部件级语义标注在仿真里几乎免费（PRISM 渲染铰接物体、PartNet-Maniskill 抽 17 类铰接物体部件）；(2) 开源 affordance 数据集重组统一成 OFG 格式（HandAL、PACO-LVIS、InstructPart）；(3) 人手-物交互数据抽取抓取模式。
- **RegularRearrangement**：呈现规则排列（三角/方形）但缺 1-2 个元素，要模型推理在哪补点——结合空间推理与指向。
- **VTG（轨迹）**：有 3D 末端位姿的（DROID）直接投影到 2D；无元数据的训 Detectron2 夹爪检测器追踪；物体轨迹用 Co-Tracker3 跨帧追踪；RoboCasa 资产生成铰接物体的 3D 轨迹。
- **语义泛化**：轨迹数据不需高保真仿真，VTG 关注拓扑结构与方向语义而非渲染保真度。

- **正则化数据**：混入大量通用视觉认知、逻辑推理、指令遵循数据（LLaVA、HONEY、MM-IF、EUCLID）防灾难性遗忘。

## 4. 两阶段训练

### 4.1 Stage 1：SFT（监督微调）
- 从 Qwen3-VL-8B-Instruct 起，**全参微调**，标准因果语言建模目标。
- 所有异构能力输出（自然语言推理、点坐标、轨迹序列）统一为 token 序列，同一目标联合优化，**1 epoch**。
- 超参：AdamW，bfloat16，峰值学习率 **2×10⁻⁶**，余弦衰减 + 10% warmup，有效全局 batch **512**，最大上下文 **8192** token。
- **视觉编码器不冻结**、与 LLM 联合训练（具身场景视觉分布与通用预训练差异大，需深度适配）。
- 目标：建立覆盖所有能力维度的多任务基础，为 RFT 提供强初始化，确保不同任务的 rollout 有足够区分度以产生有效 RL 信号。

### 4.2 Stage 2：RFT（强化微调）—— 多任务平衡 RL 配方

**两种不平衡**（来自异构多任务）：
- **组内**：组级 std 归一化偏向低方差样本，欠优化中等难度样本。
- **组间**：跨能力奖励尺度差异巨大，高密度任务主导梯度。

**五个组件**：

1. **难度感知数据筛选**：用 SFT checkpoint 的 rollout 通过率筛出 ~**200K 中等难度**样本。
2. **动态过滤**：一组 rollout 奖励全相同 → 无有效梯度 → 自动检测并屏蔽这些退化组。
3. **全局批奖励归一化**（核心）：

   ```
   Â_i = (R_i − μ_group) / (σ_batch + ε)
   ```
   - μ_group：组内均值（保留组内相对排序）。
   - σ_batch：整个混合批的标准差（统一跨任务梯度量级）。
   - 不需任务标签、不需历史状态。对比 EMA-GRPO 的"每任务移动平均"在低资源任务上不稳定。
4. **五类奖励函数**（见 §5）。
5. **自适应思考**：只约束输出含 `<answer></answer>` 标签，不强制思维链。模型按需分配计算：简单指向≈零推理直接出坐标；复杂规划生成结构化思考。

**RFT 训练设置**：
- 从 SFT checkpoint 初始化；改进版 **EasyR1** 框架（扩展支持视频+图像混合输入与外部奖励模型打分）。
- clip 比下/上阈值 **0.2 / 0.28**（具身回复较短，实际裁剪率极低）。
- KL 正则用 **KL-in-reward** + K1 无偏 KL 估计作奖励惩罚项（**β = 0.01**），约束策略不偏离 SFT 分布太远。
- 每 prompt 采 **n = 8** 并行 rollout。
- AdamW，学习率 **3×10⁻⁶**，梯度裁剪 1.0；视觉编码器联合训练；训练 **2 epochs**。

## 5. 多任务奖励设计（5 个家族）

**统一分段线性衰减框架**（连续值奖励）：给定距离度量 d 和阈值对 (τ_p, τ_z)：

```
φ(d; τ_p, τ_z) = clip( (τ_z − d) / (τ_z − τ_p), 0, 1 )          ... (式1)
```
d < τ_p 给满分；d ≥ τ_z 给零分；中间线性衰减。提供稠密梯度信号，避免二元奖励的稀疏性。

| # | 奖励家族 | 适用任务 | 公式 / 设计 |
|---|---------|---------|------------|
| 1 | **精确匹配** | 确定答案（选择题、数值、数学） | R = 1[match(ŷ, y*)] ∈ {0,1}；选择题灵活匹配（接受"A""A.dog"）；数值四舍五入到 1 位小数；数学用符号等价验证 |
| 2 | **IoU** | 空间 grounding（bbox） | R_IoU = |b∩b*| / |b∪b*| ∈ [0,1] |
| 3 | **点距** | 点定位 | 预测/真值点集的平均最近邻距离 d_nn → R = φ(d_nn; **40, 150**)；真值是多边形/框时改为"点在区域内"比例；点数不匹配加计数惩罚 δ_c = **0.3** |
| 4 | **轨迹 RMSE** | 2D/3D 轨迹 | 先线性插值对齐到等点数，逐点 RMSE：R_2D = φ(RMSE_2D; **50, 120**)；3D 深度维独立用 MAE：R_depth = φ(MAE_d; **0.1, 0.4**)，R = 0.5·R_2D + 0.5·R_depth；长度不匹配惩罚 δ_l = **0.35**；单点输出给零分防 reward hacking |
| 5 | **语义相似度** | 开放文本（纠错建议、长程计划） | Skywork-Reward-V2-Qwen3-4B 打分 → sigmoid 温度归一化到 [0,1]；推理失败时回退 BLEU |

**格式奖励**（所有任务）：二元，验证 (1) 含 `<answer>...</answer>` 结构；(2) 标签内符合任务格式（点任务需 `point_2d` 两元素数值列表；轨迹任务需 `depth` 字段）。与准确率奖励加权求和：

```
R = (1 − λ)·R_acc + λ·R_fmt,    λ = 0.1          ... (式2)
```

## 6. PGC 闭环自主框架

**设计原则**：单个 Embodied-R1.5 作为统一推理服务，**异步**调用不同能力接口驱动整个自主栈；无需多模型级联或多智能体编排。

**执行流程**（以"做奶茶"为例）：
1. 系统接收：用户指令 + 当前图像观测 + 可选外部上下文（如任务 SOP 文档）。
2. **Planner（高层）**：先调用规划能力，把长程任务分解为结构化子任务序列；每个子任务完成后基于最新观测做下一步规划，动态调整后续安排。
3. **Grounder（低层）**：对每个子任务，自适应编排指向能力组合，自主决定调用哪些接口（如"按茶饮分配器开关"= 先 OFG 定位开关功能部件，再 VTG 规划按压轨迹），产出精确空间 grounding 命令给低层技能执行器。
4. **Corrector（异步）**：持续基于当前观测 + Memory 历史评估执行态：**SUCCESS / PROCESS（仍在执行，继续等）/ FAIL**。检测到失败时把错误信息写入 Memory，反馈给 Planner，触发重试或自适应重规划。
5. **Memory**：极简 FIFO 缓冲，固定速率采样图像，记录每个子任务状态标注。

**关键性质**：
- 三角色共享同一实例 → Corrector 直接复用 Planner 的推理上下文与 Grounder 的空间理解 → 避免级联信息丢失，错误归因更准。
- 框架是**轻量无状态外壳**，只管控制流调度与 Memory，**不含推理逻辑或启发式规则**；天花板只由模型能力决定 → 随模型 scaling。

伪代码：

```python
def PGC_loop(instruction, get_obs, executor, model, sop=None):
    memory = FIFO(maxlen=K)
    plan = model.plan(instruction, get_obs(), context=sop)   # Planner: 任务分解
    for subtask in plan:
        while True:
            obs = get_obs()
            grounding = model.ground(subtask, obs)           # Grounder: OFG/VTG 自适应编排
            executor.execute(grounding)                       # 低层技能执行
            status = model.correct(subtask, obs, memory)      # Corrector: SUCCESS/PROCESS/FAIL
            memory.push((subtask, status, obs))
            if status == "SUCCESS":
                break
            elif status == "FAIL":
                plan = model.replan(instruction, obs, memory) # 反馈触发重规划
                break        # 跳出，按新计划继续
            # PROCESS: 继续等待
    return "done"
```

## 7. EmbodiedEvalKit（评测框架）

四层模块化设计，统一支持 25+ 具身基准、20+ 模型：
1. **数据层**：把多样具身基准重组为标准 HuggingFace Parquet 格式，单一加载管线。
2. **推理层**：模型无关接口（vLLM / HF Transformers / API 后端），骨干抽象自动处理坐标系与提示模板差异。
3. **解析层**：检测并归一化异构 grounding 输出（点/框/轨迹）为统一结构表示（解决不同模型坐标格式：归一化到 1000、绝对像素等）。
4. **评测层**：计算各基准官方指标，按能力维度聚合。

加新基准只需定义"数据适配器 + 评测器"。释放所有基准的预处理评测数据以保证精确复现。

## 8. 实现陷阱与复现风险

| 风险点 | 说明 |
|--------|------|
| **数据流水线误差传导** | 3D 场景图强依赖 MoGe-2 深度与 Grounded-SAM-2 分割质量；非桌面/杂乱场景被直接丢弃 → 复现需保证上游模型版本一致 |
| **奖励模型依赖** | 开放文本奖励依赖 Skywork-Reward-V2，奖励模型不同会显著影响 Planning/Cognition 的 RFT 效果 |
| **批构成影响 σ_batch** | 全局批归一化下，batch 内任务组成会影响归一化分母 → 需谨慎设计混合批的采样策略 |
| **难度筛选依赖 SFT 质量** | 中等难度样本由 SFT checkpoint 的 rollout 通过率界定，SFT 不达标会污染 RFT 数据 |
| **视觉编码器不冻结** | 全参微调（含视觉编码器）显存与算力开销大（8×H20-96GB 量级），且有破坏通用视觉能力的风险——靠混入通用数据正则化缓解 |
| **VLA 4 步积分** | 推理时 4 步 Euler 是速度-精度折中，步数过少可能损失动作精度 |
| **single-point 防 hack** | 轨迹任务单点输出给零分，否则模型会退化到"只出一个点"骗奖励 |
