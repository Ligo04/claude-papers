# 论文总结 · Embodied-R1.5

## 背景脉络（Background）

大语言模型（LLM）在**数字世界**取得了巨大成功，但要让智能"扎根"到**物理世界**、实现通用物理智能，仍是核心挑战。**具身推理（embodied reasoning）**被视为弥合"看见 → 做到"（seeing-to-doing gap）鸿沟的关键路径：模型不仅要感知物理世界，还要推理其中的空间几何与任务安排。

作者主张：要实现通用物理智能，需要一个**具身基础模型（Embodied Foundation Model, EFM）**——它要求所有能力都**扎根于物理**，并在**单一架构**中统一感知、推理与执行。本文是作者前作 **Embodied-R1**（一个"指向专家"）的升级：从单一指向能力跃迁为统一三大能力维度的综合 EFM。

引言开篇引用王阳明（1509）："**知是行之始，行是知之成**"（Reasoning initiates the action; Action fulfills the reasoning）——点明推理与行动一体两面的哲学立意。

## 问题陈述（Problem）

现有工作在构建统一 EFM 时面临**三大根本瓶颈**：

1. **能力碎片化（Fragmented capabilities）**：现有具身模型各管一段——有的专注认知，有的专注规划纠错，有的专注 grounding；即便像 RynnBrain 试图跨多维度，也是用**不同规模的多个独立模型**拼接，而非真正统一进单一模型。

2. **多任务冲突（Multi-task conflict）**：长文本推理、轨迹预测、各类 grounding 任务的**输出格式差异巨大**，多任务联合学习收敛困难，不同能力**互相侵蚀**。

3. **缺乏长程闭环自主验证**：多数 EFM 停留在 Embodied QA（具身问答）层面，没有验证其推理能力在**长程复杂决策**下是否真正落地于物理。

## 核心贡献（Contributions）

1. **统一具身能力体系 + 闭环自主**：将全部能力维度统一进单一模型，并提出 **PGC（Planner-Grounder-Corrector）闭环执行框架**，使长程复杂任务能无人工干预地自主规划、执行、自纠错。

2. **完整的 EFM 配方**：提供端到端的 recipe——数据配比、训练策略，以及 **EmbodiedEvalKit**（支持 25+ 具身基准的统一评测框架）。

3. **全面 SOTA**：仅 8B 参数，在 24 个具身 VLM 基准的 **16 个**上达到 SOTA；轻量动作数据微调即可在 4 个机器人操作基准套件上反超 π₀.₅ 等强 VLA 基线；零样本真机实验覆盖多样场景。

4. **开源生态**：开源全部模型权重、训练数据、训练代码与评测框架，提供可完全复现的社区基础设施。

## 方法概览（Approach in brief）

> 详细拆解见 [`method.md`](./method.md)。

- **三大能力维度**
  - **认知与空间推理**：空间关系理解、度量空间推理、3D 场景感知、物体与场景认知。
  - **规划与纠错**：长程任务分解、下一步规划、过程检测、错误定位、错误纠正。
  - **指向与定位**：REG（指代表达 grounding）、RRG（区域指代 grounding）、OFG（物体功能部件 grounding）、VTG（视觉轨迹生成，支持 2D/3D、物体流/末端执行器流）。

- **架构**：基于 **Qwen3-VL-8B-Instruct**，全部输出统一为**纯文本 token 序列**，坐标归一化到 [0,1000]，轨迹为有序坐标序列——不引入特殊 token，坐标作为"可被反复引用的符号"贯穿多步推理。可进一步外挂轻量 **flow-matching（DiT）动作专家**变成 **Embodied-R1.5-VLA**，构成双系统架构（System 2 推理 + System 1 动作）。

- **三条自动数据流水线**（合计 34 个数据集、>15B token）
  1. **ER1.5-Spatial**（~20K）：从单张 RGB 自动重建 3D 语义场景图（MoGe-2 度量深度 + Grounded-SAM-2 分割 + RANSAC 水平面对齐），程序化生成桌面级空间推理 QA。
  2. **ER1.5-Correction**（~800K）：用 5 个结构化扰动算子 + 视频截断/描述替换/物理引擎扰动，批量生成"失败检测 / 定位 / 纠正"三层级 QA。
  3. **ER1.5-Pointing**（~400K）：仿真合成功能部件 grounding（OFG）+ 自动轨迹抽取（DROID 投影 / Detectron2 夹爪检测 / Co-Tracker3 物体追踪）。

- **两阶段训练**：SFT（全参微调，1 epoch）→ RFT（强化微调，2 epoch，基于 EasyR1）。

- **多任务平衡 RL 配方**：难度感知数据筛选（保留 ~200K 中等难度）+ 动态过滤（屏蔽零梯度组）+ **全局批奖励归一化** `Â_i = (R_i − μ_group)/(σ_batch + ε)` + 五类奖励函数 + 自适应思考。

## 关键结果（Key Results）

| 维度 | Embodied-R1.5 | 第二名 / 对比 | 优势 |
|------|:---:|:---:|:---:|
| 规划与纠错（4 基准平均） | **65.3** | Qwen3-VL-8B 54.2 / Mimo-Embodied 54.1 | RoboFAC 77.2%，超 Gemini-Robotics-ER-1.5 **+24.0pp** |
| 指向与定位（9 基准平均） | **72.8** | Embodied-R1 58.7 | **9 个全 SOTA**；Part-Afford 82.9%，RoboAfford 80.0% |
| 认知与空间推理（8 基准平均） | **70.2** | Gemini-2.5-Pro 68.8 | 维度平均第一，RoboSpatial 69.7% SOTA |
| **21 个主基准总平均** | **70.4%** | — | 超 Gemini-Robotics-ER-1.5 **+17.0%**、GPT-5.4 **+21.7%** |

- **视觉轨迹（3 基准）**：VABench-V RMSE 7.00（物体流）、ShareRobot-V RMSE 15.79（机器人流），均最优。
- **通用视觉能力保持**：7 个标准视觉基准（AI2D/SEED/POPE/MMMU/…）相对基座 Qwen3-VL-8B 几乎无退化，MMMU 与 ScienceQA 反而提升——证明具身训练**没有牺牲通用理解**。

### 零样本迁移与真机

- **ManiSkill-Affordance**（铰接物体）：seen 0.76 / unseen 0.66，超 ManipLLM（0.59/0.54）+17pp/+12pp。
- **RoboTwin2.0**（完全零样本，基线用 400 演示/任务微调）：65.0%，逼近微调版 π₀.₅（72.9%），远超 π₀（15.0%）；Click Bell 99% 甚至超过微调 π₀.₅。
- **真机 5 类任务**（Xarm6 / ARX Lift2s，零微调，PGC 闭环）：全类别最佳；Cup Disassembly 66.6%（所有基线 0%），Door Open 16.6%（涌现的 3D 轨迹能力）。
- **长程闭环 demo**：做奶茶（10 步）、叠杯（6 步）、循环扫垃圾、货架取货——全部零样本、全自主、无人工干预；并展示**人为干扰下的鲁棒纠错**（人反复移动盘子/物体，系统实时重定位重规划）。

### 消融分析（Analysis）

- **Q1 RFT vs SFT**：RFT 在三维度全面提升（指向 +3.8、规划 +2.7、认知 +1.3）；指向提升最大，因其有可验证的几何奖励。
- **Q2 更强的 VLM 骨干 → 更好的 VLA**：Embodied-R1.5 作骨干，早期（10K 步）就比 Qwen3-VL-8B 快 +10pp 收敛，且收敛后仍领先——证明是真正的能力迁移而非仅"热启动"，且在 GR00T 与 OFT 两种动作专家上都成立。
- **Q3 RL 配方**：完整配方（难度筛选 + 动态过滤 + 全局批归一化）在三维度均衡最优，优于 vanilla GRPO 与 EMA-GRPO；难度感知筛选贡献最稳定。
- **Q4 接触丰富操作**：Embodied-R1.5 + 力感知流匹配策略，构成"视觉→力"接力，完成擦花瓶、插充电器等亚毫米对齐任务（细节见 ForceFlow）。

## 一句话总结

**Embodied-R1.5 用"统一单模型 + 全自动数据流水线 + 多任务平衡 RL + PGC 闭环"四件套，证明了把具身推理'大脑'训强之后，下游动作学习可以极大省力，从而以 8B 参数在具身 VLM 与 VLA 两条战线同时刷新 SOTA。**
