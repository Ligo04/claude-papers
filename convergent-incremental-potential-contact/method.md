# 方法详解

## 0. 记号

| 记号 | 含义 |
|---|---|
| `d` | 两个材料点或网格原语之间的无符号距离 |
| `d̂` | 障碍激活距离；`d ≥ d̂` 时接触势为零 |
| `κ` | 障碍缩放参数，论文给出的单位为 `Pa·m` |
| `Δx` | 空间网格尺度 |
| `h` | 时间步 |
| `εv` | 静摩擦/动摩擦平滑速度阈值 |
| `V, E, T` | 边界顶点、边、三角形集合 |
| `M, U(x)` | 有限元质量矩阵、形变能 |

## 1. 连续接触模型

### 1.1 障碍密度

论文沿用 IPC 的局部障碍函数：

```math
b(d,\hat d)=
\begin{cases}
-\kappa\left(\frac{d}{\hat d}-1\right)^2\ln\left(\frac{d}{\hat d}\right), & 0<d<\hat d,\\
0, & d\ge \hat d.
\end{cases}
```

它有三项关键性质：

- `d → 0⁺` 时发散，形成不可穿越的能量墙；
- `d = d̂` 时函数及低阶导数平滑接到零；
- 在激活区内随距离增加而单调减小，因此最近点等价于最大障碍值。

### 1.2 从点—点到连续曲面

对一组曲面 `S(u)`，连续总接触势写成：

```math
P(S)=\frac12\int_{u\in\widetilde M}
\max_{v\in\widetilde M\setminus_r u}
b\!\left(d(S(u),S(v)),\hat d\right)\,du.
```

`\widetilde M\setminus_r u` 排除材料坐标中以 `u` 为中心的无穷小邻域，避免把同一局部表面当成自接触。连续极限还要求 `\hat d/r → 0`。

这里的 `1/2` 去掉接触对的双向重复；积分变量位于**材料空间**，因此形变后不会因为当前几何面积变化而随意改变接触材料的计量方式。

## 2. 连续摩擦模型

接触点对的相对速度投影到切平面：

```math
v_k=P(x_1,x_2)(\dot x_1-\dot x_2).
```

最大耗散原理与 Coulomb 上界给出 `||f|| ≤ μλ`。为获得 Newton 可处理的光滑势，论文使用：

```math
D_k(v_k)=\mu\lambda_k m_{\epsilon_v}(\|v_k\|),
```

其中

```math
m_{\epsilon_v}(s)=
\begin{cases}
-\frac{s^3}{3\epsilon_v^2}+\frac{s^2}{\epsilon_v}+\frac{\epsilon_v}{3}, & s<\epsilon_v,\\
s, & s\ge\epsilon_v.
\end{cases}
```

摩擦力为 `f_k=-∇D_k`。当 `s=εv` 时，函数、一阶和二阶导数分别与线性分支连续连接；`εv → 0` 时逼近不可微的粘—滑转变。

## 3. 空间离散化

### 3.1 节点求积

对 2D 边界曲线，顶点 `x` 的材料权重 `w_x` 是相邻两条材料边长度之和的一半；对 3D 曲面，是相邻材料三角形面积之和的三分之一。离散接触势具有统一形式：

```math
P_h=\sum_{x\in V} w_x\,\Psi(x).
```

权重使离散求和成为连续边界积分的求积，而不是“每个网格点投一票”。

### 3.2 近似最近原语的 `max`

直接 `max` 不光滑；`p`-norm 或 LogSumExp 会扩大 stencil、降低 Hessian 稀疏性，并在高精度参数下加重病态。论文改用网格邻接结构。

对曲线：

```math
\Psi_c(x)=
\sum_{e\in E\setminus x} b(d(x,e),\hat d)
-\sum_{x_2\in V_{int}\setminus x} b(d(x,x_2),\hat d).
```

对三角曲面：

```math
\Psi_s(x)=
\sum_{t\in T\setminus x} b(d(x,t),\hat d)
-\sum_{e\in E_{int}\setminus x} b(d(x,e),\hat d)
+\sum_{x_2\in V_{int}\setminus x} b(d(x,x_2),\hat d).
```

这组 `面 − 边 + 点` 的交替项去掉共享低维原语造成的重复贡献。

### 3.3 边求积和联合势

点—三角形势在细化极限能消除边—边交叉，但中等分辨率下若要求每一步都没有边—边相交，可加入基于边—边距离的线框势 `P_w(E)`。其重复项按共享顶点的边价数 `ρ(x)` 修正。

联合势为：

```math
P_{combined}=\alpha P_s(V)+(1-\alpha)P_w(E),\qquad \alpha\in(0,1].
```

论文指出 `α=1/2` 足以做平均。若允许把小规模边—边交叉视作离散建模误差，可只用节点势 `P_s`。

### 3.4 正性条件

论文定义可接受的 `d̂`：以任一点为中心、半径 `d̂` 的球与边界相交后，每个连通分量至多包含一个顶点。在该条件下，作者分别证明 `Ψc ≥ 0`、`Ψs ≥ 0`、`Ψw ≥ 0`。

证明的共同结构是：

1. 枚举激活球内可能出现的局部原语组合；
2. 使用“到父原语的距离不大于到子原语的距离”；
3. 利用 `b` 单调递减，把每个被减项配对到更大或相等的正项；
4. 剩余项非负。

## 4. 时间离散化

所有动态、准静态和静态问题都转化成增量势最小化：

```math
x^{t+1}=\arg\min_x E(x,h).
```

论文以 `β=1/4, γ=1/2` 的隐式 Newmark 为例：

```math
E(x,h)=\frac12\|x-\tilde x\|_M^2+\frac{h^2}{4}W(x),
```

其中 `W` 包含形变、接触障碍和摩擦势，`\tilde x` 由前一步位置、速度、外力和当前内力预测得到。实验还使用隐式 Euler 与 BDF-2。

## 5. 离散摩擦

摩擦势使用与接触势相同的节点权重和交替重计数结构，只是每个局部项改为切向速度、法向压力与摩擦系数组成的耗散势。最近点位置和速度由边/三角形上的重心插值获得。

实现中法向力 `λ` 和切向投影依赖未知位置。论文沿用 lagged friction：在一次外迭代内固定上一轮的法向力和投影，解完整 Newton 问题，再更新它们，直到与当前接触状态一致。

## 6. 数值求解器

### 6.1 Projected Newton

每个局部形变、障碍和摩擦 stencil 的 Hessian 在装配前投影到对称半正定锥，得到稳定的下降方向。该投影改变的是数值搜索模型，不改变最终要求满足的增量势一阶平衡。

### 6.2 CCD 过滤线搜索

障碍在 `d=0` 发散，但标准回溯线搜索仍可能沿一条穿透路径跳到另一侧的低能量点。论文在每个 Newton 步：

1. 用连续碰撞检测求一个保守、严格可行的最大步长；
2. 从这个上界开始回溯，直到增量势下降；
3. 若弹性能本身也含防翻转障碍，再叠加 inversion-aware 步长过滤。

因此每个内部迭代点都保持不相交；需要时也保持单元不翻转。

### 6.3 终止准则

论文使用按时间步缩放的 Newton 方向无穷范数：

```math
\frac1h\|H^{-1}\nabla E(x)\|_\infty < \epsilon_d.
```

`εd` 具有速度单位，使不同时间步和场景尺度的精度阈值更可比较。

## 7. 算法流程

```text
输入：xᵗ, vᵗ, 网格, 材料参数, Δx, h, d̂, κ, μ, εv

为当前时间步构造预测位置 x̃
初始化 x ← xᵗ，初始化滞后法向力和切向投影

重复（摩擦外迭代）：
    重复（Projected Newton）：
        检测 d < d̂ 的局部 stencil
        按材料权重装配形变能
        装配节点接触势；需要时加入边求积势
        用固定的法向力/投影装配平滑摩擦势
        将每个局部 Hessian 投影到 PSD 后装配 H
        求解 p = -H⁻¹∇E
        若 ||p||∞ / h < εd：退出 Newton
        αmax ← CCD 给出的可行步长上界
        α ← 从 αmax 开始回溯到 E(x+αp) < E(x)
        x ← x + αp
    更新法向力和切向投影
直到摩擦状态与当前 x 收敛

更新 vᵗ⁺¹，进入下一时间步
```

## 8. 参数敏感性

| 参数 | 减小时的收益 | 主要代价/风险 |
|---|---|---|
| `d̂` | 更小接触间隙、更好互补精度 | 势更尖，压力更易振荡；可能需要更小 `h` |
| `κ` | 障碍更软、条件数可能改善 | 接触层内位移/压力曲线改变；不能替代 CCD |
| `Δx` | 更高几何与场精度 | stencil 数量和求解成本增加；必须同步缩放 `d̂,h` |
| `h` | 更好解析高频接触响应 | 时间步数增加；积分器耗散/稳定性仍不同 |
| `εv` | 更准确逼近静—动摩擦切换 | 摩擦势更尖，外迭代和 Newton 更困难 |
| `α` | 调节点求积与边求积贡献 | 太依赖边求积可能放大 3D 过积分误差 |

一维细化实验采用：

```math
\hat d=c_B\Delta x,\qquad
h=\nu_C\frac{\Delta x}{\sqrt{E/\rho}}.
```

冲击实验的主要收敛图使用 `cB=4`。论文还显示 `cB=1` 时势的平滑性不足，Newmark 与 BDF-2 的收敛率都会明显变差。

## 9. 实现陷阱

- 把 `max` 直接换成所有活跃原语障碍之和，却忽略共享顶点/边的重计数。
- 在当前形变空间而不是材料空间构造求积权重。
- 只细化 `Δx`，固定 `d̂` 和 `h`，然后把曲线不重合归因于“方法不收敛”。
- 把势发散误当成线搜索自动安全，省略 CCD 步长上界。
- `d̂` 大于局部高频几何尺度，使激活球包含多个边界连通分量。
- 3D 同时启用点—三角形和边—边势，却未分析平面接触的过积分。
- 用很小 `εv`，但不给摩擦 lagging 足够外迭代精度。
- 把 PSD 投影后的搜索 Hessian 与真实能量 Hessian混为一谈。

## 10. 复现风险

- arXiv v1 没有给出专属 EIPC 代码仓库链接；完整复现需要自行实现或确认后续代码来源。
- 教学脚本不包含 FEM 形变能、宽/窄相碰撞检测、距离梯度/Hessian、CCD、稀疏线性求解或摩擦外迭代。
- 图中收敛阶依赖论文的联合细化、初始条件、积分器和参考解定义；只抄某个 `d̂` 或 `κ` 不构成复现。
- BDF-2 宽时间 stencil 需要一致的历史初始化；论文在一维基准中用解析解初始化 `t=-h` 状态。
- 2D/3D 无解析解的实验以最细网格或解析平面为参考；复现时必须区分“逼近参考离散解”和“逼近解析解”。
