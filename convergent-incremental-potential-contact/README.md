# Convergent Incremental Potential Contact 学习包

> 论文版本：arXiv `2307.15908v1`，提交于 2023-07-29。本文常把新模型简称为 **EIPC**。

这篇论文研究摩擦接触弹性动力学中的一个基础一致性问题：原始 IPC 能可靠地阻止网格穿透，却直接在离散网格上定义接触约束，因此网格细化时接触能量和力不一定收敛。作者先在连续曲线/曲面上定义接触与摩擦势，再给出带材料空间积分权重、几何重计数修正和联合参数细化规则的离散化，从而同时追求“不穿透”和“随离散细化收敛”。

## 难度评估

- 难度：**高级（Advanced）**
- 论文性质：连续变分建模 + 有限元离散 + 非线性优化 + 数值实验
- 方法复杂度：数学推导较重；实现还依赖距离导数、CCD、PSD Hessian 投影和摩擦外迭代
- 建议前置知识：有限元、隐式时间积分、Newton 法、接触/摩擦、连续碰撞检测

## 建议学习路线

1. 用 15 分钟读 [summary.md](summary.md)，先掌握问题、贡献和定量结果。
2. 用 30–45 分钟读 [mental-model.md](mental-model.md) 与 [insights.md](insights.md)，建立“连续模型 → 一致离散 → 可行优化”的三层框架。
3. 用 60–90 分钟精读 [method.md](method.md)，对照原论文第 2–7 节理解公式和求解器。
4. 运行 [eipc_barrier_demo.py](code/eipc_barrier_demo.py)，观察障碍势、摩擦平滑和重复计数修正。
5. 打开 [index.html](index.html)，交互查看真实收敛阶与参数耦合。
6. 用 [qa.md](qa.md) 的 15 道题检查理解，再读 [reflection.md](reflection.md) 形成研究问题。

## 五个关键结论

1. **可靠不穿透不等于网格收敛。** 原始 IPC 的鲁棒性不能自动推出离散一致性。
2. **先定义连续接触能，再离散。** 接触势必须按材料边界测度积分；离散顶点/边要带长度或面积权重。
3. **直接求和会重复计算。** 邻近网格原语共享顶点或边时，原始求和会把同一连续接触区域计算多次；EIPC 用类似包含—排除的交替加减修正。
4. **空间与时间参数必须联合细化。** `Δx`、接触激活距离 `d̂` 和时间步 `h` 只细化其中一项，通常不能得到论文展示的收敛行为。
5. **障碍势本身不足以保证求解路径可行。** 每个 Newton 步仍需 CCD 限制步长，再做回溯线搜索。
