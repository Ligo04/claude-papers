# 论文总结

## 背景

Incremental Potential Contact（IPC）把非穿透接触写成随距离趋零而发散的障碍势，并用优化式时间积分、连续碰撞检测和可行线搜索求解。它对复杂、大形变、多物体接触非常稳健：只要求解路径保持在可行域内，几何就不会穿透。

但原始 IPC 是“先有网格，再在网格原语对上放障碍势”。当网格细化时，参与求和的点—边、点—三角形和边—边对数量与重叠方式发生变化。即便每个离散问题都不穿透，这串离散问题也未必逼近同一个连续接触模型。

## 问题陈述

论文要回答：能否构造一个接触与摩擦模型，使它同时具备以下性质？

- 粗网格和细网格都保持非穿透；
- 接触能量和物理量随空间/时间细化收敛；
- 保留 IPC 的优化式时间积分与 Newton 型求解框架；
- 能处理 2D/3D、自接触、摩擦和尖锐/贴合几何。

## 主要贡献

### 1. 从连续边界定义接触势

作者把最近点障碍能密度沿连续曲线或曲面材料域积分，而不是从离散碰撞对求和出发。连续模型明确了“接触能按边界测度累积”这一物理对象。

### 2. 一致的空间积分与几何重计数修正

离散化使用材料空间中的边长/三角形面积作为求积权重。对最近原语的 `max` 障碍，作者不用会破坏稀疏性或造成病态的高阶 `p`-norm / LogSumExp，而是利用网格邻接做交替修正：

- 2D 曲线：点—边项求和，减去内部点—点重复项；
- 3D 曲面：点—三角形项求和，减去内部点—边项，再加回内部点—点项；
- 需要中等分辨率下严格避免边—边穿越时，再加入边求积势。

### 3. 连续摩擦势及对应离散化

论文从最大耗散原理和 Coulomb 上界出发，用速度阈值 `εv` 平滑静摩擦/动摩擦转变，并采用与接触势相同的积分和重计数结构。摩擦法向力与滑动投影在外层迭代中滞后更新，直至与当前解一致。

### 4. 可行的二阶优化求解

每个时间步最小化增量势。局部能量 Hessian 投影到半正定锥后装配；Newton 方向先经 CCD 得到不相交的步长上界，再做回溯线搜索。障碍势负责“接近零距离时代价发散”，CCD 负责“迭代路径不跨过零距离”。

### 5. 系统的收敛验证

论文先用带解析解的一维弹性杆冲击/反弹基准，再扩展到 2D/3D 滑动、摩擦临界角、三块立方体堆叠、高速球碰撞和 gyroid 压缩。

## 关键定量结果

下表只记录 v1 正文/图注中明确报告的数值；“收敛阶”是误差关于相应细化尺度的拟合斜率。

| 实验 | 量 | 报告值 |
|---|---|---:|
| 1D 冲击，Newmark | 位移 / 接触压力收敛阶 | 1.0389 / 0.4709 |
| 1D 冲击，BDF-2 | 位移 / 接触压力收敛阶 | 1.0669 / 0.4402 |
| 1D 反弹，Newmark | 能量 / 位移收敛阶 | 0.9877 / 1.0092 |
| 1D 反弹，BDF-2 | 能量 / 位移收敛阶 | 0.9384 / 0.9661 |
| 原始 IPC，自适应刚度 | 冲击位移 / 压力收敛阶 | 0.2334 / 0.0823 |
| 原始 IPC，固定刚度 | 冲击位移 / 压力收敛阶 | 0.6997 / 0.2745 |
| 2D 静态方块落地 | 能量 / 位移 / 压力 | 1.5688 / 1.3850 / 1.1952 |
| 2D 动态方块落地 | 能量 / 位移 / 压力 | 1.0718 / 1.1527 / 0.5065 |
| 2D 网格平面滑动 | EIPC 横向轨迹收敛阶 | 1.0761；原始直接求和不收敛 |
| 3D 网格平面滑动 | 同时细化 `Δx` 与 `d̂` | 0.8879 |
| 3D 临界斜面摩擦 | 速度 / 加速度误差关于 `εv` | 0.9959 / 0.9926 |
| 三立方体堆叠 | 质心高度 / 弹性能 / 压力 | 约 1.230 / 1.137 / 1.962 |

其他可核对结果：

- 1D 冲击中，BDF-2 的解比隐式 Euler 距解析解近两倍以上，同时数值耗散更小。
- 两个高速碰撞球各含约 29K 节点，时间步 `h = 2×10⁻⁵ s`；论文报告 BDF-2 造成约 10% 总能量耗散，而总动量在图示精度下保持守恒。
- gyroid 压缩中，Dirichlet 边界的“有/无接触”曲线约在 26% 压缩后明显分离；自由边界接触模型约在 15% 压缩时就与 Dirichlet 接触模型分离。

## 如何读这些结果

- 接触压力通常只呈约半阶收敛，而位移和能量多接近一阶；不能把“所有量都一阶”当作结论。
- 论文展示的是**一致性与精度**，不是性能论文：没有系统报告 wall-clock、每步 Newton 次数、内存、GPU 加速或相对运行时间。
- “不穿透”是每个离散问题的可行性性质；“收敛”是离散序列逼近连续解的性质，两者必须分开判断。

## 总结

EIPC 的核心贡献不是一个新的碰撞检测器，而是把接触势从“碰撞对的离散惩罚和”提升为“连续边界上的积分对象”，再用保持稀疏性的几何修正进行一致离散。论文同时说明：接触模型、空间求积、时间积分和可行优化不可割裂；只有它们的参数与数值误差共同缩小时，鲁棒接触模拟才可能得到可信的网格收敛结果。
