# 心智模型

## 这是什么类型的问题？

这是一个**接触模型的一致离散化问题**，不是单纯的碰撞检测、线性求解或时间积分问题。输入是连续的摩擦接触弹性动力学；目标是构造一族有限维优化问题，使每个问题都可行、且解随网格和时间步细化逼近同一连续对象。

## 三层框架

```text
连续物理层
  接触障碍密度 + 最大耗散摩擦 + 边界材料积分
                         │
                         ▼
一致离散层
  FEM + 材料权重求积 + 面/边/点交替修正 + 联合参数细化
                         │
                         ▼
可行求解层
  增量势 + Projected Newton + CCD 过滤线搜索 + lagged friction
```

三层分别回答不同问题：

- 连续层：究竟要逼近什么物理/变分对象？
- 离散层：网格变化时能量和力是否保持正确尺度？
- 求解层：在有限精度 Newton 迭代中是否始终不穿透并达到足够精度？

缺少任一层都不能得到论文主张的结果。

## 最直观类比：给边界“按长度收费”

想象接触能是沿边界收取的费用。连续模型规定每一小段材料边界按长度/面积付费。网格化后，顶点只是收费采样点：它必须带上代表的边长/面积权重。

共享顶点附近若两条边都对同一接触区域收费，直接求和就重复收费。EIPC 的减去顶点项相当于退款一次；3D 中“面减边加点”是同样的多层修正。

## 与几个相邻概念的关系

| 概念 | 与本文的关系 | 不应混淆之处 |
|---|---|---|
| Penalty contact | 也用平滑能量近似接触 | 固定 penalty 刚度通常允许穿透；EIPC 势在零距离发散 |
| 原始 IPC | 提供障碍、CCD、优化时间积分基础 | 原始接触势从离散 constraint/stencil 出发，不保证细化一致性 |
| Mortar / Nitsche 接触 | 也是 FEM 接触一致性路线 | 本文保留 IPC 的无符号距离障碍与可行优化结构 |
| CCD | 认证一段运动轨迹是否相交 | CCD 不定义接触力，也不保证网格收敛 |
| Newton/PSD 投影 | 求解非凸增量势 | 优化器再稳也修复不了错误的离散物理模型 |
| Coulomb friction | 规定摩擦力上界和方向 | 本文还需平滑、积分与 lagging 才能数值求解 |

## 需要掌握的前置知识

### 必需

- 有限元中质量矩阵、形变能、材料/当前构形；
- 无符号点—边、点—三角形、边—边距离；
- 隐式 Euler、Newmark 或 BDF-2 的基本性质；
- Newton 法、Hessian、线搜索；
- Coulomb 摩擦与静/动摩擦转变。

### 有帮助

- Γ-convergence / 一致性—稳定性—收敛性的基本观念；
- 数值求积与网格细化误差；
- 连续碰撞检测和单元防翻转；
- 稀疏矩阵 stencil 结构。

## 阅读论文时始终问四个问题

1. 这个量属于连续模型，还是只在离散网格上定义？
2. 求和项有没有材料长度/面积权重？
3. 共享原语是否导致同一接触区域重复计数？
4. 当前结论依赖哪个极限：`Δx→0`、`d̂→0`、`h→0`、`εv→0`，还是它们的联合极限？

## 一句话分类

EIPC 可以记成：**“把 IPC 的鲁棒可行优化，放回一个有连续极限的接触/摩擦变分模型中。”**
