# 反思与扩展

## 如果我要扩展这篇论文

1. **单边约束 SPD**（论文自己点名的头号方向）
   把 SPD 适配到脚-地接触、碰撞等只能推不能拉的约束。思路：对 SPD 预测的约束力做投影/裁剪（如 $\max(0, \tau)$ 沿法向），或与 LCP/互补性求解结合。回报巨大——接触处也能用大步长，绕开仿真中最大的步长瓶颈。

2. **自动增益优化**
   利用 SPD 平滑的稳定区域，用梯度/贝叶斯优化自动调增益以匹配目标风格（柔顺度、反应速度）。可与可微仿真结合，让增益对最终运动可微。

3. **二阶 / 自适应泰勒展开**
   当前用一阶泰勒，大步长下预测位置 $q+\dot q\Delta t$ 误差变大（虽稳定但跟踪精度降）。引入二阶项或根据局部曲率自适应，可在更大步长下保持精度。

4. **与学习型控制深度融合**
   现代 DeepMimic 已把 SPD 当执行器。可进一步让网络同时输出**目标姿态 + 增益**，或把 SPD 的 $(M+K_d\Delta t)^{-1}$ 做成可微层，端到端训练。

5. **GPU / 批量化 SPD**
   $(M+K_d\Delta t)^{-1}$ 求解可批量并行（大量角色 / RL 并行环境）。与你库里的 FLASH GPU 形变仿真思路相通——把稀疏/块对角结构利用起来。

## 仍然开放的问题

- **多维严格稳定性证明**：论文只有"近似对角"的启发式。小增益、强耦合、病态质量矩阵下的稳定性边界仍无理论刻画。
- **任意积分器的兼容性证明**：实测兼容显式欧拉/中点/RK4/隐式，但无数学证明。哪些积分器一定有效、一定无效？
- **跟踪延迟的精确刻画**：SPD + 参考速度时误差线性下降，但"跟踪延迟"只是假说，缺乏严格分析。
- **大步长下的精度-稳定权衡曲线**：稳定不等于准确。一阶泰勒在多大步长开始显著损失精度，缺乏系统研究。

## 哪些假设是脆弱的？

| 假设 | 脆弱点 |
|------|--------|
| 一阶泰勒展开足够 | 大步长 / 高曲率轨迹下预测位置误差大，跟踪精度下降 |
| $K_d\ge K_p\Delta t$ 保证稳定 | 只在 1D 严格成立；多维仅"近似对角"启发式 |
| 质量矩阵被 $K_d$ 主导 | 小增益时不成立；病态 $M$（轻长链）时退化 |
| 约束方向 $d$ 与控制力方向一致 | 仅当曲线平滑时成立；尖角处会震荡（虽快速衰减） |
| 弹簧式双向力可接受 | 单边约束（接触）下产生非物理拉力，直接失效 |

## 它在实践中可能在哪里失败？

1. **脚-地接触 / 抓取**：单边约束被吸住，角色像被磁铁粘在地上。
2. **极轻、极长的连杆链**（如细绳、长尾巴）：质量矩阵病态，即便 SPD 也可能精度差或需更小步长（论文 toy mouse 提到尾巴 ill-conditioned 让 PD 更糟，SPD 缓解但不根除）。
3. **需要大幅偏离参考动作的任务**：SPD 是跟踪器，不做规划/平衡，无法凭空生成与参考差异大的运动。
4. **控制与仿真分离的黑盒场景**：需额外回代算控制力，失去"零额外成本"优势。
5. **非常大的步长**：稳定但跟踪明显滞后/失真，一阶预测不再准确。

## 给读者的研究启示

SPD 是"**最小改动撬动最大杠杆**"的典范：它没发明新框架，只把一个用了几十年的工具改了一处状态引用（当前→下一帧），就解决了困扰整个领域的稳定性-效率耦合。

启示：当你遇到"参数 X 太大就不稳定"的问题时，先别急着加正则或缩步长——**问问是不是某个量用了"过时的状态信息"**，能否用预测的未来状态 + 泰勒展开把它半隐式化。这个模式在数值方法、控制、优化里反复出现，值得放进工具箱。
