# 如何理解这项工作

把衣架和衣服放在一起。衣架应该有详细的接触表面，但它的运动通常接近整体平移和旋转；衣服则必须保留局部褶皱。设计任务只改衣架肩部的两个参数，评价标准却是衣服能否挂住。

这件事同时涉及三套变量。设计变量 `z` 描述怎样修改衣架；物理参数 `θ=φ(z)` 包括修改后的静止表面与质量；运动变量 `y_t` 描述每一步衣架与衣服的位置。设计变量少，不代表软体的运动维度少；表面顶点多，也不要求衣架有同样多的运动变量。

DiffGIPC 在这三套变量之间建立导数。详细表面提供接触几何，紧凑的 affine 坐标描述近刚体运动，FEM 坐标保留软体局部变形。损失可以测量衣服，而梯度仍能回到衣架形状。

| 前置知识 | 需要掌握的程度 |
| --- | --- |
| FEM 与增量势能 | 知道一次隐式步可写成能量最小化 |
| IPC | 知道 barrier 与 CCD 如何从可行初始状态维持不相交 |
| ABD | 知道 `x=p+A x̄`，以及 12 维 affine 状态与 6 维精确刚体的区别 |
| 隐函数定理 | 能从 `g(y,θ)=0` 得到 `H dy/dθ=-G` |
| 伴随法 | 理解标量损失下，用一次转置线性求解避免显式构造完整状态灵敏度 |
| GPU 迭代求解 | 区分数值计算量、kernel launch 和 CPU–GPU 同步成本 |

阅读顺序可以围绕一个问题展开：改衣架后，为什么衣服的损失会变？先看世界坐标中的接触导数如何映射到混合运动坐标，再看这个影响如何倒序穿过整条轨迹，最后补上形状本身对质量、接触和损失的直接影响。

研究位置可概括为：StiffGIPC 提供前向仿真基础，DiffIPC 提供可微 IPC 的重要比较对象，DiffGIPC 增加耦合 FEM–affine 轨迹伴随、affine 形状与控制导数及 GPU 反向实现。关于前作的比较限于本文的相关工作和实验，未在本资料中逐篇复现。
