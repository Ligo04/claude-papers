# 从步方程推到轨迹梯度

## 1. 明确三类变量

优化器变量为 `z`，物理参数为 `θ=φ(z)`，每帧求解状态为 `y_t`。物理参数可以包含静止形状、材料、摩擦、初始状态和控制序列。一次前向轨迹中参数固定，控制序列仍可为不同帧指定不同数值。

运动状态按 affine 与 FEM 排列：

\[
y_t=[q_{t,1}^T,\ldots,q_{t,N_A}^T,x_{t,1}^T,\ldots,x_{t,N_F}^T]^T,
\qquad n=12N_A+3N_F.
\]

每个 affine body 有 `q=[p, row₁(A), row₂(A), row₃(A)]`。表面点通过 `x_i=J_i q_b=p+A x̄_i` 得到。接触点组对应的映射为 `K_c=∂x_c/∂y`。FEM 点使用单位块，affine 点使用 `J_i`，固定点对应零块。[式 1–5，PDF 第 4 页](https://arxiv.org/html/2610.19091v1#S3.SS1)

## 2. 前向求解的是隐式步方程

论文写为增量势能最小化：

\[
\Phi_t(y_t)=\tfrac12(y_t-\widehat y_t)^TM(y_t-\widehat y_t)
+\sum_e w_e(h,\theta)\Psi_{t,e}(y_t,y_{t-1};\theta).
\]

第二项包括 FEM 弹性、affine 近刚性、碰撞 barrier、摩擦与关节能量。收敛状态满足 `g_t=∇_{y_t}Φ_t=0`。

动态 BDF1，也就是 backward Euler，在消去速度后给出 `ŷ_t=2y_{t-1}-y_{t-2}+h²a_t`。它虽然出现两帧位置，仍是 BDF1。第一步用 `ŷ₁=y₀+hẏ₀+h²a₁`。速度重置的准静态近似使用 `ŷ_t=y_{t-1}+h²a_t`，仍有前帧依赖。[式 6–8、§4.4，PDF 第 5、8 页](https://arxiv.org/html/2610.19091v1#S3.SS2)

## 3. 单步隐式微分

定义 `H=∂g/∂y`、`G=∂g/∂θ`，在其它输入固定时有 `H dy/dθ=-G`。若直接构造状态灵敏度，会得到 `n×n_θ` 矩阵。

对标量损失 `L`，用 `Hᵀλ=ℓ_y` 得到 `dL/dθ=ℓ_θ-Gᵀλ`。`ℓ_θ` 是固定求解状态时损失对参数的直接偏导。这里对收敛步方程求导，未逐次展开 Newton 或 PCG 的迭代。[式 9–13，PDF 第 5–6 页](https://arxiv.org/html/2610.19091v1#S3.SS3)

在静止形状固定时，点坐标到运动坐标的映射是线性的，所以局部能量可映射为 `g_y=Kᵀg_x`、`H_y=KᵀH_xK`。累加后得到包含 `H_AF` 与 `H_FA` 的完整耦合系统。多个点属于同一 affine body 时，需要把各项加到同一物体块；不能漏掉映射到该块的有序交叉项。[式 14–18](https://arxiv.org/html/2610.19091v1#S3.SS4)

## 4. 轨迹伴随如何递推

令 `C_{t,s}=∂g_t/∂y_s` 表示历史依赖。整条轨迹满足：

\[
H_tS_t+\sum_{s\in D(t)}C_{t,s}S_s+G_t=0,
\qquad S_t=dy_t/d\theta.
\]

完整轨迹 Jacobian 是块下三角。其转置为块上三角，因此伴随从 `T` 倒序求解：

\[
H_t^T\lambda_t=\ell_t-\sum_{\tau>t,\,t\in D(\tau)}C_{\tau,t}^T\lambda_\tau,
\qquad
\nabla_\theta L=\ell_\theta-\sum_tG_t^T\lambda_t.
\]

每帧求解后，把 `-C_{t,s}ᵀλ_t` 累加到更早帧右端项。对动态惯性，`C_{t,t-1}=-2M`、`C_{t,t-2}=M`，因此分别传播 `+2Mλ_t` 与 `-Mλ_t`。初始位置和速度是参数输入，相关项进入 `G_t`，而不是构造额外的第零帧伴随系统。[式 19–35，PDF 第 6–8 页](https://arxiv.org/html/2610.19091v1#S4)

```text
z → 参数映射 φ → θ → 前向隐式轨迹 → 输出 O → 标量损失 L
                    保存状态和接触记录          │
                    T, T-1, …, 1 倒序          │
                    装配 H_t ←─────────────────┘
                    解 H_tᵀ λ_t = b_t
                    累加参数项 -G_tᵀ λ_t
                    向早帧传播 -C_t,sᵀ λ_t
                    经 φ 的链式法则返回 z 的梯度
```

只在终点观测不意味着只对终点求导。未被观测的中间帧可以有 `ℓ_t=0`，仍会收到后续帧传播的右端项。

## 5. 摩擦历史不能在反向中全部冻结

前向求当前帧时，摩擦切平面、最近点插值权重和法向力由前帧几何给出并保持固定。反向对前帧求导时，却必须包含这些量对前帧位置的依赖，同时计算相对滑移的变化。

摩擦历史项为 `C_{t,t-1}^{fr}`。实现可直接计算转置导数乘积，按接触累加到顶点，再映射到前帧运动坐标，避免组装完整历史矩阵。前向 lagging 与反向省略依赖是两种不同做法。[§4.5、附录 A.1，PDF 第 8–9、23–26 页](https://arxiv.org/html/2610.19091v1#S4.SS5)

## 6. affine 形状导数的检查清单

| 依赖 | 固定运动状态下的变化 | 漏项后果 |
| --- | --- | --- |
| 质量与惯性 | `δM`，以及 predictor 的形状依赖 | 设计后惯性响应的梯度错误 |
| 近刚性能量 | 体积变化改变能量权重 | 缺少体积对形状能的作用 |
| 接触几何 | `δx=A δx̄` | 无法反映接触距离变化 |
| 接触点映射 | `(δK)ᵀg_x` | 力映射到 affine 方程的变化缺失 |
| 摩擦 | 当前点、前帧点及前帧接触量 | 滑移和历史导数不完整 |
| 输出与损失 | 固定 `y` 下表面位置仍变化 | 缺少直接损失项 `ℓ_θ` |

质量可直观写为 `M_b=∫ρ J(x̄)ᵀJ(x̄)dV`，论文用闭合表面的体积积分形式计算质量相关量。形状变化既会改变 `J`，也会改变积分区域和体积分布。输入形状须保持闭合、定向一致、非退化，非法候选在更新前被拒绝。

接触项的完整形状变化为：

\[
\delta g_c^y=(\delta K_c)^Tg_c^x+K_c^TH_c^x\delta x_c.
\]

摩擦还包含前帧点移动的项。直接表面损失另有 `∂L/∂x · A δx̄`，不能由上述方程梯度自动替代。[§5.1–§5.2、式 43–48、§6.3](https://arxiv.org/html/2610.19091v1#S5)

## 7. 初始状态与控制

初始 affine 状态 `q₀`、速度 `q̇₀` 通过 predictor 和初始摩擦几何影响轨迹。对物理参数求偏导时，已解出的运动状态保持固定，随后由伴随补上状态变化。

关节支持 prismatic 与 revolute 的目标和力。prismatic 位移能可理解为 `h²[k(ξ-a)²/2-fξ]`，于是对目标 `a` 的方程导数为 `-h²k∇ξ`，对力 `f` 为 `-h²∇ξ`。转动关节使用两物体 affine 方向构成的正弦、余弦量表达控制，保留跨物体导数；完整 Hessian 还包含残差加权的坐标二阶导数。[§5.3–§5.4、附录 A.3](https://arxiv.org/html/2610.19091v1#S5.SS3)

## 8. GPU 执行做了什么

每个倒序帧恢复轨迹记录、装配耦合 Hessian、解 PCG，再并行累加局部参数和历史导数。局部任务按 FEM 单元、接触、关节或 affine 表面三角形划分。多个任务写同一梯度项时使用原子加法。

Conditional CUDA Graph 管理 PCG 的初始化、循环与收敛检查。CPU 一次发起，GPU 控制何时继续。矩阵、预条件器和右端项在帧之间更新，在一次求解中固定。接触集合改变后仍可复用图，前提是存储和 kernel 配置兼容。图没有覆盖整个反向过程，帧恢复、Hessian 装配和梯度累加仍在该 PCG 图之外。

论文默认反向 `η_cg=1e-14`、最大迭代 `3e4`。比较的是预条件残差量 `χ=rᵀP⁻¹r` 与其初值之比，不能把它直接称为二范数相对残差 `1e-14`。达到迭代上限但未满足残差目标的伴随不被接受。前向 PCG 相对残差容差为 `1e-4`。[§6.1、算法 2、附录 B，PDF 第 12、30 页](https://arxiv.org/html/2610.19091v1#S6.SS1)

## 9. 实现与复现时优先检查的事实

先确认前向真正达到被求导的步方程收敛要求，再检查 backward 所用 Hessian 与该方程导数是否一致。若实现采用正定化、阻尼或近似 Hessian，需要核对其对梯度的影响。此处是复现检查建议，未据此认定论文代码存在问题。

有限差分要同时改变参数并重跑前向，固定观察窗口，扫描扰动尺度，检查接触分支是否变化。论文只沿解析梯度方向核对，工程实现还应增加随机方向或选定坐标方向，避免某些梯度误差被单一方向掩盖。

复现实验时记录运动表示、表面网格、接触参数、`h`、轨迹步数、精度、Newton/PCG 停止条件、硬件，以及前向和反向 evaluation 次数。仿真时长 `T h` 与实际运行秒数必须分别报告。只测 PCG 不能代表完整梯度成本，只测一次前向加一次反向也不能代表整个优化过程。
