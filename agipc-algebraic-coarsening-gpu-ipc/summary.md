# AGIPC 摘要与贡献

## 背景

隐式时间积分（Implicit Time Integration）是模拟刚性材料和大变形的关键技术。IPC（Incremental Potential Contact）方法通过最小化增量势能来鲁棒地处理复杂摩擦接触，但每个时间步需要求解大规模稀疏非线性系统，计算成本随自由度 n 呈 O(n²) 增长。

### 现有方法的问题

| 方法 | 问题 |
|------|------|
| **自适应重网格化** | 显式拓扑修改破坏 IPC barrier 的 C² 连续性；不规则内存访问不利于 GPU |
| **子空间方法** | 基构造和更新代价高；基向量通常稠密，导致粗化 Hessian 构建内存密集 |
| **多重网格** | GMG 缺乏自适应性；AMG 建立成本高；对 IPC 的极端非线性适应性差 |

## 问题陈述

**核心问题：** 如何在 GPU IPC 框架下高效地自适应减少自由度，同时保持 IPC barrier 能量的 C² 连续性和 GPU 友好的内存访问模式？

## 主要贡献

### 1. 代数自适应粗化框架
- 将自适应性重新定义为选择性的代数边坍缩过程
- 不修改网格拓扑，仅改变精细→粗的映射关系
- 每个 Newton 迭代动态更新粗化策略

### 2. Green 应变增量自适应准则 + 仿射嵌入
- 用 Green 应变增量 ΔG 的 Frobenius 范数判断边是否需要保护
- 对大聚合体（>32 个精细节点）使用 12-DoF 仿射嵌入，保持旋转运动
- 阈值 5×10⁻⁵ 在效率与精度间取得良好平衡

### 3. 首个全 GPU 优化的自适应 IPC 求解器
- Warp 级哈希映射方案并行聚合精细节点
- 利用矩阵对称性优化 Hessian 组装
- 无栈 BVH 遍历优化碰撞检测

## 关键结果

| 场景 | 加速比 | 备注 |
|------|--------|------|
| 弹性球（E=10⁷） | **3.30×** | 刚性材料获益最大 |
| 三个弹性球（混合刚度） | **3.15×** | 复杂多体场景 |
| 扭转垫（E=10⁷） | **2.87×** | 极端变形 |
| 布料可扩展性（174K） | **2.70×** | 高分辨率 |
| 多米诺（172K 顶点） | **2.00×** | 大规模场景 |
| 海豚穿漏斗 | **1.41×** | 碰撞密集，粗化受限 |

### 定量指标
- 所有场景视觉结果与全分辨率模拟不可区分
- 粗化映射开销 < 10ms
- 后粗化 CG 迭代 ≤ 10 次
- Newton 收敛容差 εd = 10⁻³·l（l 为场景包围盒对角线长度）
