# AGIPC 反思与展望

## 如果要扩展这篇论文

### 1. 自适应阈值
当前 τ = 5×10⁻⁵ 是固定全局值。可以：
- **空间自适应**：不同区域的阈值根据局部刚度/密度调整
- **时间自适应**：根据 Newton 迭代的收敛速率动态调整——收敛快时更激进，收敛慢时更保守
- **学习阈值**：用强化学习或 Bayesian 优化在线调整阈值，目标是最小化总求解时间

### 2. 消除细网格瓶颈
当前仍需要在细网格上计算梯度和 Hessian。可以探索：
- **逐步粗化**：细网格→中间网格→粗网格的多级结构，中间网格已可减少计算量
- **稀疏 Hessian 近似**：对粗化区域只计算 Hessian 的稀疏近似（如对角块），细节区域保持完整
- **增量更新**：如果上一迭代的 Hessian 已知，只更新变化大的部分

### 3. 跨对象聚合
论文限制在同一对象内粗化。对于大量小物体的场景（如颗粒模拟、破碎）：
- 将相邻且运动一致的对象合并为 supernode
- 需要定义跨对象的"虚拟边"和相应的 Green 应变
- 潜在巨大加速（N 个几乎静止的小物体 → 1 个 supernode）

### 4. 神经加速
- **学习粗化策略**：用 GNN 预测哪些边可坍缩，避免 Green 应变计算
- **学习延拓算子**：用小型网络学习比线性延拓更好的 fine→coarse 映射
- **学习初始猜测**：用前几步的解预测当前步的粗解初始值

## 开放问题

1. **最优粗化比例是多少？** 论文未给出理论分析。粗化比例与加速的关系是非线性的（组装和精炼有固定开销）。存在一个最优平衡点吗？

2. **与其他加速方法的组合？** AGIPC 与子空间方法或多重网格方法能否叠加使用？例如在粗网格上再做一次 AMG。

3. **非弹性材料？** 论文只测试了弹性体和布料。粘弹性、塑性材料的应变增量模式可能不同，标记准则是否需要修改？

4. **拓扑变化场景？** 断裂、切割等拓扑变化如何与代数粗化交互？新生成的边没有历史应变。

5. **精度保证？** 论文展示了"视觉上无差异"的结果，但缺乏严格的误差界。是否能证明粗化引入的位移误差上界？

## 脆弱假设

| 假设 | 为什么脆弱 | 可能的后果 |
|------|-----------|-----------|
| Green 应变增量小 = 可安全粗化 | 应变增量小不代表下一步也小（突然碰撞） | 粗化后下一迭代可能需要更多精炼 |
| τ = 5×10⁻⁵ 全局适用 | 不同材料和场景可能需要不同阈值 | 某些场景过度粗化或粗化不足 |
| 32 节点仿射切换阈值 | 经验值，无理论依据 | 边界情况（33 节点）的行为可能不稳定 |
| 接触边 always protected | 可能过于保守——远离活跃接触的 barrier 边也被保护 | 接触密集场景加速受限 |
| 后精炼 ≤10 CG 够用 | 对高度非线性区域可能不够 | 极端情况下精度下降 |

## 实践中可能失败的场景

1. **全网格均匀高频振动**：所有边的 Green 应变增量都大于阈值，无法粗化，退化为标准求解器（但也不会更差）

2. **大量小物体场景**：每个物体内部边很少，粗化收益有限；跨对象无法合并

3. **接触主导的场景**：大面积接触→大面积 protected→可粗化区域很小

4. **材料刚度跨度极大**：非常软的区域和非常硬的区域相邻，应变增量阈值对两者适用性不同

5. **拓扑退化**：极端粗化可能导致某些 supernode 形状过于细长，仿射嵌入的几何条件退化
