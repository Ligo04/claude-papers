# AGIPC 思维模型

## 这是什么类型的问题？

**线性系统求解加速** — 具体来说，是物理仿真中隐式时间积分内层 Newton 求解的加速。

分类路径：
```
数值仿真
└── 隐式时间积分
    └── Newton 迭代
        └── 线性系统求解 ← 瓶颈在此
            └── 通过自适应粗化降维来加速
```

## 如何归类这项工作

**不是：**
- 不是传统 AMG（不构建层次结构，每次 Newton 迭代独立粗化）
- 不是自适应重网格化（不修改拓扑）
- 不是子空间方法（不预计算基底）
- 不是纯粹的预条件器（直接在粗空间求解）

**是：**
- 一种 **in-solve adaptivity**（在求解过程中动态调整自由度）
- 介于全精度求解和多重网格之间的中间地带
- 将"哪里需要精度"的决策从空间域转移到应变增量域

## 与相关工作的关系

```
精度 ◀─────────────────────────────────────▶ 速度

  全精度        AGIPC          子空间       粗网格
  细网格      自适应粗化       降维法       直接求解
  PCG        (本文)          (预计算)
  │            │               │            │
  最精确       动态精度         受限于基底    最快但粗糙
  最慢        1.4-3.3×加速     需离线训练    不适合接触
```

## 跨领域类比

### 交响乐团类比

想象一个管弦乐团在排练：

- **细网格** = 每个乐手独立演奏每个音符
- **边标记** = 指挥观察：这段旋律哪些声部变化不大？
- **粗化** = 变化小的声部合并为"声部组"，由首席代表
- **代数组装** = 声部组的音量和音色由成员加权混合
- **仿射嵌入** = 大声部组需要更细腻的表达（不只是齐奏）
- **后精炼** = 合奏后微调个别乐手的细节
- **每次排练重新分组** = 每次 Newton 迭代重新标记（因为音乐在变化）

### 图像压缩类比

- JPEG 对平坦区域用大 block，纹理区域用小 block
- AGIPC 对应变变化小的区域合并节点，变化大的区域保持细节
- 两者都是自适应地在"需要精度的地方保持精度"

## 关键洞察

1. **Newton 迭代是渐进收敛的** — 早期迭代大部分网格变化不大，可以安全粗化
2. **应变增量比位移更好** — 旋转不变性避免误判
3. **代数操作比拓扑操作更 GPU 友好** — 映射+归约 vs 网格修改
4. **粗化比例与加速比不是线性关系** — 粗化后的组装和精炼也有开销
5. **接触区域是粗化的天然边界** — barrier 能量需要精确的几何信息
