# AGIPC 核心洞察

## 核心思想（一句话）

**不改网格拓扑，只改线性系统大小** — 把"哪些自由度可以合并"的决策从几何操作降级为代数操作，每个 Newton 迭代都可以重新决定。

## 为什么这个方法有效

### 关键观察：大多数 DoF 在大部分时间是"无聊"的

物理仿真中，弹性波和变形在时空上是局部的。一个多米诺骨牌场景中，任意时刻只有少数骨牌在运动，其余处于近刚体状态。传统求解器对所有 DoF 一视同仁——这是巨大的计算浪费。

AGIPC 的洞察：**对于那些局部运动高度一致（kinematically coherent）的区域，可以把多个节点合并为一个"超级节点"，只求解少量粗化的 DoF，然后再映射回去。**

### 为什么不直接重网格化？

IPC 的 barrier 能量 B(x) 要求 C² 连续性才能可靠收敛。显式重网格化（增删顶点/边）会：
1. 破坏 barrier 能量的连续性
2. 改变变量顺序，破坏内存局部性
3. 可能引入局部几何交叉

AGIPC 的巧妙之处：**精细网格始终不变，只是每次 Newton 迭代时用不同的"视图"（restriction operator U）来看它。** 这保证了：
- Barrier 能量始终在精细网格上计算 → C² 连续性不受影响
- 网格连通性不变 → 内存布局可预测 → GPU 友好
- 边-单元邻接关系可预计算 → 标记步骤高效

## 概念转变

### 从"改变几何"到"改变代数"

传统自适应方法的思路：
```
精细网格 → 几何操作（边分裂/坍缩）→ 新网格 → 重建系统
```

AGIPC 的思路：
```
精细网格（固定）→ 代数映射 U → 粗系统 Hc = UHfU^T → 求解 → 延拓 U^T dc
```

**类比：** 这就像你有一本字典大小的书（精细网格），但你只想读其中几章（活跃区域）。传统方法是把书拆了重新装订一本小册子；AGIPC 是给你一个目录（映射 U），告诉你直接翻到那几页就行。

### 从"全局均匀"到"局部自适应"

StiffGIPC 对所有 DoF 用同样的 PCG 迭代次数。AGIPC 把 DoF 分为：
- **活跃 DoF**（Green 应变增量大）→ 保持精细分辨率
- **惰性 DoF**（Green 应变增量小）→ 聚合为超级节点

这个分界线每个 Newton 迭代都在变化，完美追踪弹性波传播。

## 与多重网格的关系

AGIPC 不是多重网格，但借鉴了其思想：
- **高频误差**（大 Green 应变增量的边）→ 保留在精细层 → 类似 smoother
- **低频误差**（小 Green 应变增量的边）→ 坍缩到粗层 → 类似 coarse grid correction
- **后粗化 CG**（≤10 次）→ 修正局部误差 → 类似 post-smoothing

关键区别：多重网格是线性求解器/预条件器，AGIPC 是降阶模型构建器。AGIPC 完全绕过全空间求解。

## 权衡与局限性

### 优势
- GPU 端到端并行，无需 CPU-GPU 数据传输
- 对刚性材料效果最好（变形小 → 粗化率高 → 加速比大）
- 与 IPC barrier 无缝集成

### 局限性
1. **Hessian 组装和碰撞检测仍在精细网格上进行** — 在碰撞密集场景中（如海豚穿漏斗），这些阶段成为瓶颈
2. **固定阈值** — Green 应变增量阈值 5×10⁻⁵ 不是所有场景最优的
3. **跨对象边界不能聚合** — 粗化限制在单个物体内部
4. **软材料加速有限** — 变形范围广、持续时间长，可粗化区域少

### 与先前工作的对比

| 特性 | AGIPC | 自适应重网格化 | 自适应子空间 | AMG |
|------|-------|---------------|-------------|-----|
| GPU 友好 | ✅ 端到端 | ❌ 不规则访问 | ❌ 稠密基 | ⚠️ 建立成本高 |
| IPC 兼容 | ✅ barrier 连续 | ❌ 破坏 C² | ✅ | N/A |
| 自适应粒度 | 每 Newton 迭代 | 每时间步 | 每时间步 | 固定层次 |
| 旋转保持 | ✅ 仿射嵌入 | ✅ 几何精确 | 取决于基 | N/A |

## 实际意义

对于 GPU IPC 求解器的使用者（如 Newton 项目中的 UIPC 后端）：
- 刚性物体场景（机器人、刚体）获益最大
- 大规模场景（多物体、高分辨率布料）中线性系统求解是瓶颈时最有价值
- 可以作为现有 PCG 求解器的前置缩减步骤集成
