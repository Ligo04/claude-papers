# 论文摘要式笔记

## 背景

UV mapping 需要一个全局二维参数化。对复杂拓扑或高曲率网格，展开会产生接缝和面积畸变；空白 UV 区域、接缝处顶点复制和每顶点 UV 坐标还会增加存储。神经纹理减少了手工展开，却常常需要较大的 MLP/编码器；点云和普通 3D Gaussian 又是在环境欧氏空间中优化，容易离开曲面。

## 问题定义

给定三角网格流形 `M=(X,F)`，学习一个不需要 UV 坐标的连续颜色场 `C(p)`。它需要：

- 在任意曲面点（而非仅顶点）评价颜色；
- 让表示基元始终贴在网格曲面上；
- 能从已有 UV 纹理压缩，也能从多视图图像直接逆渲染；
- 在相近存储预算下保留纹理细节。

## HKTex 表示

每个核为

`κ_s = (p*_s, θ_s, η_s, τ_s, ς_s, c_s)`，

分别表示曲面位置、方向、各向异性、尺度阈值、边界锐度和 RGB 颜色。热核由 ALBO 的特征值/特征函数构成：

`h_t(p,p*) = Σ_k exp(-t λ_k^(η,θ)) φ_k^(η,θ)(p) φ_k^(η,θ)(p*) m*`。

先按源点温度归一化，再用双调和距离高斯衰减远处的谱振铃，最后通过 sigmoid soft-step 产生可控尺度与边界的权重 `α_s(p)`。颜色采用 top-`K_c` 核的 alpha 加权分区统一，并加一个可学习全局底色：

`C(p)=c_base + Σ α_s(p)c_s / Σ α_s(p)`。

## 方法贡献

1. **内禀纹理表示**：各向异性热核定义在流形上，不需要 UV 展开。
2. **Riemannian 优化**：位置梯度投影到切平面，用指数映射与平行移动更新核和动量。
3. **流形密度控制**：依据命中率、核能量和颜色误差进行剪枝、克隆与拆分，拆分位移仍沿测地线。
4. **可微 PBR 集成**：在 Mitsuba3/Dr.Jit 中，射线与网格交点直接查询核颜色，支持从图像反向传播。

## 关键工程设计

- 预计算各向同性 LBO 的 64 维谱，用于双调和距离；对 7 个角度 × 7 个各向异性节点各预计算 256 维 ALBO 谱。
- ALBO 特征基存在排列、旋转和符号歧义。作者依次用 Hungarian assignment、质量加权 Procrustes/SVD 和符号校正对齐谱基，再做双线性插值。
- 顶点谱量通过重心插值扩展到连续曲面点；源点质量可用 KDE 估计，但实验发现统一设为 `m*=1` 更快且不损失效果。
- GPU FAISS 做双调和空间 KNN，PyTorch Triton 生成核，位置使用 GPU straightest-geodesic 实现的 Riemannian-SGD。

## 实验设置

从 Objaverse 过滤出约 3,000 个高质量模型：最多 60,000 顶点、单连通、流形、无复杂内部结构，并能成功分解 LBO。主要报告五个图像指标和存储/渲染开销：MSE、PSNR、SSIM、MS-SSIM、LPIPS、Render、Storage。

## 一句话结论

HKTex 把“纹理是二维图像”改成“纹理是曲面上的局部扩散场”：它用几何内禀性换取了无接缝和高存储效率，但需要昂贵的谱预计算、流形几何运算和更慢的在线核评价。
