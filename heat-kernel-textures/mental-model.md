# 心智模型

## 它属于哪类问题

这是一个**表面信号表示**问题，而不是重新估计几何的问题。输入网格 `M` 固定，待学习对象是曲面上的颜色函数 `C:M→RGB`。因此最关键的设计选择是：基元的坐标、支持域、混合规则和优化路径是否尊重 `M` 的内在几何。

## 三层类比

1. **UV 纹理**：把曲面撕开、摊平，再在平面上画；优点是成熟快速，缺点是撕口与畸变。
2. **3D Gaussian**：在环境空间放椭球；优点是局部显式基元，缺点是椭球会穿出或脱离曲面。
3. **HKTex**：在曲面上点燃一处热源，热量沿网格扩散；扩散方向和速度定义了“曲面上的椭圆”，颜色只是每个热源携带的属性。

## 研究地图

`UV / vertex color → neural texture → Gaussian splatting → surface-aligned Gaussian → intrinsic heat kernel`

HKTex 不是把 UV 纹理换成更复杂的 UV 网络，而是改变坐标系：从全局参数化坐标转到 LBO 谱和测地距离。它与 Intrinsic Neural Fields 共享“在流形上评价函数”的目标，但以显式局部核替代 MLP；与 3DGS 共享“少量可优化基元”的工程路线，但不在三维空气中 splat。

## 读公式时的最小背景

- **LBO**：网格上的拉普拉斯算子，描述信号在曲面上的平滑/扩散。
- **热核**：`exp(-tL)` 的点源响应；谱域中每个频率乘 `exp(-tλ_k)`，高频衰减更快。
- **ALBO**：把局部度量改成方向相关的 shear matrix `H_{η,θ}`，于是扩散在一个切向方向更快或更慢。
- **重心插值**：把顶点谱量评价到三角形内部，让核源和射线交点连续化。
- **指数映射**：把切平面速度变成曲面上的新点；是“沿表面走一步”的几何版本。

## 关键张力

论文的主张不是“所有指标都最快”，而是“在相似或更小存储下，显式内禀核保留更好的感知与结构细节”。HKTex 的存储优势来自局部核和不存 UV 拓扑开销；速度劣势来自每个交点要做 KNN、谱评价和 top-k 混合。

## 看到结果时要问

- 表格是否把 UV 坐标、网络权重和拓扑开销一起计入？论文明确计入并统一压缩。
- PSNR 高是否来自直接存储更多像素？因此还要看 LPIPS、SSIM、MS-SSIM 和 Storage。
- 单连通、流形和 LBO 可分解的过滤是否限制了外推范围？是，论文把它作为当前方法的适用边界。
