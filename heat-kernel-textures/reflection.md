# 进一步思考

## 可以如何扩展

1. **多通道材质核**：把 `c_s` 从 RGB 扩展为 albedo、roughness、metallic、normal residual 和 visibility，并加入物理范围约束。
2. **层次化运行时**：先用粗热核做低频底图，再用局部高频核细化；KNN 查询可按半径/尺度建立多级缓存。
3. **拓扑分块**：对非流形或多连通资产先按组件/局部 chart 分块，在组件边界共享或约束底色，扩大可用数据范围。
4. **可学习谱参数网格**：根据曲率和纹理方向自适应加密 `(θ,η)` 网格，减少全局 7×7 预计算。
5. **误差感知核预算**：把存储字节作为训练正则项，直接优化质量–存储–查询时间的 Pareto 前沿。

## 脆弱假设

- 表面可由一个良好的离散 LBO 表示；低质量三角化会污染谱基和双调和邻域。
- 颜色在测地邻域内局部平滑，少量核足以表达高频纹理；极细线条、文字和周期图案可能需要大量核。
- top-k 选择的局部性不会造成明显的梯度断点或闪烁；动画/形变网格上的核索引稳定性尚未说明。
- 多视图像素足以确定颜色；遮挡、反射和光照误差仍会进入 albedo 优化。

## 可验证的后续实验

- 固定网格和核预算，只改变 ALBO 网格分辨率，画出谱插值误差与渲染指标曲线。
- 比较 `m*=1`、KDE 质量和真实离散质量对不同网格采样密度的影响。
- 在同一 GPU 上拆分报告 KNN、谱评价、top-k 混合和光线追踪时间，定位表 1 的 784.7 ms 开销。
- 对非流形、多个组件和动态形变资产分别做失败率统计，而不是只报告过滤后的平均指标。
