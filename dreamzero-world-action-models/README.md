# World Action Models are Zero-shot Policies（DreamZero）

> Ye, Ge, Zheng 等 · NVIDIA · arXiv:2602.15922（2026 年 2 月 17 日）
> 项目主页：https://dreamzero0.github.io · 代码：https://github.com/dreamzero0/dreamzero

## 这篇论文讲什么（一段话）

当前最强的视觉-语言-动作（VLA）机器人模型擅长*语义*泛化（"把可乐罐移到泰勒·斯威夫特那里"），但一旦遇到训练数据里没有的**新动作/新技能**（比如"解开鞋带"）就会失败——因为它们的先验只编码了"该做什么"，却没有"该如何精确执行"的时空表示。本文提出 **DreamZero**，一个 14B 的**世界动作模型（World Action Model, WAM）**：它不在视觉-语言模型（VLM）上微调，而是在一个预训练的**视频扩散模型**（Wan2.1-I2V-14B）之上，**联合预测未来视频帧与动作**。视频充当"未来如何演化"的稠密表示，于是动作学习从"稠密的状态-动作模仿"转变为"逆动力学（IDM）"——把电机指令与*预测出来的视觉未来*对齐。这带来三大新能力：(1) 能从**多样、非重复**的真实数据里高效学习；(2) **零样本**泛化到新任务/新环境（真机上比最强 VLA 提升 **2 倍以上**）；(3) 极其高效的**跨本体迁移**（仅 10–20 分钟纯视频数据相对提升 42%+，30 分钟示教即可适配全新机器人）。配合模型与系统优化，14B 模型实现 **38× 推理加速、7Hz 实时闭环控制**。

## 难度

**进阶（Advanced）。** 需要熟悉：扩散模型 / 流匹配（flow matching）、视频扩散、DiT（Diffusion Transformer）、自回归生成与 KV 缓存、VLA 机器人基础模型（π₀、GR00T）、逆动力学模型（IDM）的概念。核心思想（"会预测视频 → 就会做动作"）很直观；但其工程深度（异步执行 + 三层优化 + Flash 解耦噪声调度）值得细读。

## 核心要点（5 条）

1. **"会预测视频，就会做动作。"** 联合分布 π(视频, 动作) 可分解为"自回归视频预测 × 逆动力学（从视觉未来抽动作）"。把机器人能力提升问题，转化为视频生成质量问题——大多数失败源于*视频预测错误*，而非动作抽取。
2. **多样数据 > 重复示教。** WAM 因为视频预测能力主要来自预训练，真正要学的是 IDM；而稳健 IDM 需要*多样*的状态-动作对应。500 小时多样数据（33% → 50%）显著优于同等时长的重复数据。这打破了"通用策略需要每任务大量重复示教"的惯例。
3. **自回归 + KV 缓存闭环，根治误差累积。** 每执行完一个动作 chunk，就用*真实观测*替换 KV 缓存里的预测帧——这是 WAM 独有的优势，消除了自回归视频生成的复合误差，同时保留原生帧率以保证视频-动作精确对齐。
4. **38× 加速让 14B 视频扩散模型能实时控制。** 三层优化叠加：系统级（CFG 并行、DiT 缓存 16→4 步）+ 实现级（torch.compile、NVFP4 量化、kernel）+ 模型级（DreamZero-Flash），把 5.7 秒/chunk 降到 150ms，达 7Hz。
5. **跨本体迁移只需视频、无需动作标签。** 别的机器人或人类的纯视频示范即可强化世界模型；这开启了用海量人类视频（比机器人数据大几个数量级）扩展技能的路径。
