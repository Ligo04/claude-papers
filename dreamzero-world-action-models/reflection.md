# 反思 — 扩展、压力测试、开放问题

## 如果我来扩展这篇论文

1. **WAM 标度律。** 作者明说缺这块。系统性地刻画"模型规模 × 数据规模 × 训练算力 → 下游动作性能"的标度律，并验证作者的猜想——WAM 对*动作*有比 VLA 更直接的标度律（因为视频质量直接转化为动作质量）。

2. **把预测模态从视频换成/扩展到触觉、力、潜表示。** WAM 之名就在暗示这点。一个"多预测目标"的 WAM：视频负责粗的视觉规划，触觉/力负责接触阶段——这与你库里的 **T-Rex**（触觉精修）天然互补。可以想象 DreamZero × T-Rex：视频世界模型给粗轨迹，触觉专家做高频精修。

3. **大规模人类视频预训练。** 论文只在 12 分钟实验室人类视频上验证了人到机器人迁移。把它推到互联网规模人类第一视角视频（EgoDex/Ego4D 级），只用视频目标，看能否在无动作标注下习得长尾技能——这是该范式最大的可扩展性赌注。

4. **长程 / 记忆任务。** 当前未评估需要记忆的任务、上下文长度受限。引入长时程视频世界模型的连贯生成技术（或外部记忆/检索）来扩展 WAM 上下文，解锁多阶段长程任务。

5. **高精度任务的专门化。** 多样性预训练侧重广度，欠采样亚厘米精度任务。可在 WAM 上叠加一个高精度后训练阶段，或引入更高分辨率/局部放大的视频表示来刻画精细接触——作者引用的近期工作暗示 WAM 在毫米级任务上反而可能有优势，值得验证。

6. **量化隐式 IDM 的精度。** 作者指出"IDM 精度难以量化"是高自由度本体迁移的核心难点。提出一个度量隐式 IDM 准确度的指标，会让"需要多少 play 数据"变得可预测，对本体设计有直接指导。

## 还有哪些开放问题

- **视频质量与动作质量的定量关系**：是否线性？是否存在"够用就好"的饱和点？哪些视频误差对动作*致命*、哪些无害？
- **多本体联合训练**：本文为每个本体单独预训练，多本体联合训练留作未来工作——联合训练会增益还是互相干扰？
- **跨本体迁移机制为何有效**：目前只有"视觉相似 + IDM 省样本"的假设，缺机制性证据。形态差距多大就失效？
- **Flash 的极限**：单步已达成；能否零步（直接回归）？解耦噪声比例如何最优配置以匹配不同推理工况？
- **闭环 KV 替换的失败边界**：当真实观测本身噪声大、或视角突变时，替换是否反而注入分布外信号？

## 哪些假设是脆弱的

| 假设 | 为何可能崩 |
|---|---|
| 视频预测足够准，IDM 只需反解 | 在视觉歧义、遮挡、罕见物理（流体、可变形、透明物）下，视频可能定性错误，IDM 再准也救不回 |
| 闭环能定期拿到可靠真实观测 | 高速任务、相机抖动/遮挡、或观测延迟会让 KV 替换注入坏信号 |
| 多样数据能覆盖 IDM 所需对应 | 长尾或高自由度本体的状态-动作空间组合爆炸，500 小时未必够 |
| 跨本体靠视觉相似即可迁移 | 形态差距大（人手 vs 平行夹爪、灵巧手）时，纯视频迁移可能失效 |
| "机器人=视频"会随视频研究水涨船高 | 若视频模型在精细接触/精度上长期停滞，WAM 的天花板也会停滞 |
| 自回归视频不会因长上下文退化 | 极长程任务上，即便有 KV 替换，骨干的长程一致性仍可能漂 |

## 它在实践中可能在哪失败

1. **亚厘米精度任务**：插钥匙、精细装配——视频骨干刻画不出毫米级差异，行为克隆固有局限叠加。
2. **视觉不可见的物理**：力、摩擦、内部状态（瓶内液面、布料内层）——视频里看不全，IDM 缺条件。
3. **罕见/分布外动态**：训练视频未充分覆盖的物理现象，视频会"幻觉"，动作随之出错（5B 模型尤甚）。
4. **长程记忆任务**：需要记住早先事件才能成功的任务，当前上下文与评估都未覆盖。
5. **高自由度本体（灵巧手/人形）**：隐式 IDM 的映射随运动学复杂度组合爆炸，少样本适配可能不够。
6. **实时性在弱硬件上**：38× 加速里相当一部分依赖 GB200/Blackwell 的 NVFP4 等特性，H100 仅约 9–16×，更弱硬件可能达不到 7Hz。

## 一个研究下注

最具杠杆的思想是 **"机器人策略 = 世界模型 + 逆动力学，且世界建模目标可插拔"**。如果这成立，机器人领域的"基础模型竞赛"就会与"视频/世界模型竞赛"合流——谁的世界模型更强、更通用、更省步，谁的机器人就更强。而 WAM 之名预留的"可换预测模态"接口（视频→触觉/力/潜表示），意味着不同感知模态的世界模型可以模块化组合。DreamZero 是这条路线上第一个工业级、实时化、系统性验证数据多样性的代表作；预期它会成为后续 WAM 工作的基准与起点。
