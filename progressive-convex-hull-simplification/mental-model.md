# 思维模型:如何在脑中归档这篇论文

## 这是什么类型的问题?

**带约束的组合优化 + 计算几何**:从 m 个半空间中选 n 个,最小化交集体积增长——NP-hard 子集选择问题的贪心反向消除(backward elimination)解法。工程上属于**包围体(bounding volume)构造**这一经典图形学基础设施问题。

一句话归档:**"QEM 网格简化在对偶空间的孪生兄弟,输出保守凸包代理。"**

## 需要的前置知识

| 知识点 | 用在哪 | 不熟怎么办 |
|---|---|---|
| 凸包 H-表示 / V-表示 | 全文的概念地基 | 记住:H = 半空间交集(面视角),V = 顶点凸组合(点视角) |
| 凸多面体对偶(polar dual) | §2,面↔点互换 | 看 code/ 里的 2D 演示直观感受 |
| QEM 贪心网格简化 [GH97] | 算法骨架(优先队列+局部代价) | 任何网格简化教程 |
| 精确几何谓词 orient3D [She97] | 凸性判断、无穷体积检测 | 知道"谓词精确、构造近似"的 CGAL 哲学即可 |
| 低维线性规划(Seidel) | Chebyshev 中心、可行性测试 | 当黑盒用 |
| 积分几何(Cauchy 公式类) | §6 面积↔线假阳率、平均宽度↔平面 | 只影响"为什么选这个代价函数"的动机 |

## 在研究地图上的位置

```
包围体谱系(松→紧):
AABB ── k-DOP ── OBB ── 【本文:n 面简化凸包,n 可调】── 精确凸包
                                    ▲
                        把"离散的两端"变成"连续的谱"

方法谱系(凸包简化):
  V-表示删顶点(内近似):GH97 直跑 / TLG17     → 不安全或不紧
  V-简化后 offset 补救:Blo11 / MCK13(正向选择)→ 安全但次紧
  法向聚类:STL*25(Sphere carving 后处理)      → 方向≠体积,病态
  【本文】H-表示(对偶)贪心删除,直接最小化体积 → 安全且最紧
  理论根基:LR00 / LR02 / RSW01(删除界),KRB21(NP-hard)
```

与近邻领域的关系:
- **近似凸分解**(CoACD [WLLS22]、VHACD [Mam16]):本文是它们的即插即用后处理,修复"decimation 留缝隙"问题。
- **BVH / 射线追踪**:面积最小化版 = SAH 语义的凸节点。
- **物理仿真碰撞代理**(与我此前研读的 ABD/IPC/FLASH 系工作相邻):broadphase 紧代理直接减少窄相候选对。
- **网格简化**(Hoppe96/GH97):算法模板来源,本文证明该模板搬到对偶空间 + 换体积代价即成新工具。

## 心智图像(记这三幅画)

1. **拆玻璃罩**:每次拆掉鼓包最小的那块玻璃,邻面延伸补洞 → 贪心删半空间。
2. **面变星星**:每个面在对偶天空中是一颗星(φᵢ = −nᵢ/(nᵢ·c+bᵢ)),拆面 = 摘星 + 一环补网;星越靠近原点,对应面离中心越远。
3. **凸帽/非凸对偶帽**:原始空间鼓出的帽永远是凸的(好算体积),但它在对偶空间的影子是非凸的(所以别在对偶空间量体积)——附录 A 的警告。

## 判断"我真的懂了"的标准

- 能解释为什么删半空间是外近似、删顶点是内近似;
- 能说出为什么 Chebyshev 中心比随便一个内点好;
- 能推出"删除代价为什么只依赖一环邻域"(凸性 → 不可见面不受影响);
- 能解释二十面体→正四面体为什么贪心几乎必败(对称代价并列 + 菱面体死路);
- 能说出体积/面积/平均宽度三种代价分别对应哪类查询的假阳率。
