# Progressive Convex Hull Simplification(渐进式凸包简化)

> Alec Jacobson · University of Toronto · arXiv 2604.14468v2 [cs.GR] · 2026

## 这篇论文讲什么

凸包是最紧的凸包围体,但它的面数随输入网格线性增长(几千个三角形的网格,凸包动辄 2000+ 个面),作为碰撞检测/射线求交的加速代理反而变慢。本文解决的问题是:**把凸包保守地简化到用户指定的 n 个半空间,同时让增加的体积(或表面积)尽可能小**。核心做法是把凸包转到对偶表示(面 ↔ 对偶顶点),在对偶网格上做类似 QEM 网格简化的**贪心顶点删除 + 优先队列**,每次删掉"删除后新增原始体积最小"的那个半空间。整个算法 O(n log n),每一步都严格保证简化结果包含原凸包(外近似、无缝隙),在 133 个真实扫描模型上全部取得比现有方法更小的体积增长(中位数 1.02×,次优方法 1.09×)。

## 难度评估

**中级**。需要的背景:凸包与 H-表示/V-表示、凸多面体对偶性、贪心网格简化(QEM [GH97])的基本套路。数学不重(线性规划求 Chebyshev 中心 + 高斯公式算体积),但对偶变换的几何直觉需要花一点时间建立。

## 关键要点(TL;DR)

1. **外近似要在 H-表示做,内近似才在 V-表示做**:删半空间必然让凸包变大(保守),删顶点必然变小(会漏碰撞)。这是全文最基础的一条分界线。
2. **对偶变换把"删面"变成"删点"**:半空间 → 关于 Chebyshev 中心的对偶顶点,删除半空间 = 删除对偶顶点 + 局部重三角化,只需局部信息,不需要任何显式多面体求交。
3. **删除代价可以只用局部对偶网格算**:一环邻域重三角化 T_i 反向 + 原一环三角形拼成封闭"局部对偶网格",转回原始空间得到凸"帽",高斯公式直接算新增体积。
4. **代价函数可换**:最小化体积(点包含查询)、表面积(射线求交假阳率 = 1 − area(A)/area(B))、平均宽度(平面/大物体剔除),还能给指定面设无穷代价来锁定它们。
5. **实战价值**:直接可作为 CoACD / VHACD 近似凸分解的后处理替代品——默认的丢顶点简化会产生缝隙(假阴性)或泄漏,本文方法同样面数预算下"又紧又安全"。
