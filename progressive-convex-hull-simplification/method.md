# 方法详解:对偶空间贪心半空间删除

## 0. 总览:算法即"对偶版 QEM 简化"

```
输入点集 P ⊂ R³
   │  CGAL convex_hull_3
   ▼
原始凸包(V-表示,~O(n) 个面)
   │  每个面 → 平面方程 (nᵢ, bᵢ)   [H-表示]
   │  LP 求 Chebyshev 中心 c        [Eq.4-5, O(n)]
   │  φᵢ = −nᵢ/(nᵢ·c + bᵢ)          [Eq.2, 对偶化]
   ▼
对偶包(三角化,半边结构维护)
   │  对每个对偶顶点 i:
   │    预计算删除后的一环重三角化 Tᵢ(拓扑)
   │    预计算新增原始体积 cost(i)(几何)
   │    push 进惰性最小堆
   ▼
循环:pop 最小代价顶点 i
   ├─ 从对偶包删除 i,按 Tᵢ 重三角化一环
   ├─ 对每个邻居 j ∈ Nᵢ 重算 Tⱼ、cost(j),更新堆
   └─ 直到剩余对偶顶点数 == 目标 n
   ▼
输出:幸存对偶顶点 → 反解回半空间(H-表示)
      (需要网格时:对偶面 → 原始顶点 vⱼ = c − ηⱼ/βⱼ [Eq.3])
```

## 1. 对偶变换(Background,Eq. 2–5)

**原始 → 对偶(面变点)**:半空间 x·nᵢ + bᵢ ≤ 0 关于内部中心点 c 的对偶顶点

φᵢ = −nᵢ / (nᵢ·c + bᵢ)

**对偶 → 原始(对偶面变原始顶点)**:第 j 个对偶面平面 (ηⱼ, βⱼ) 对应原始顶点

vⱼ = c − ηⱼ/βⱼ

**中心点 c 的选择**:理论上任何内部点都行,但 c 靠近某个半空间边界时 Eq.2/3 数值敏感。稳妥选择是最大内切球心(Chebyshev 中心):

maximize r  s.t.  nᵢ·c + ‖nᵢ‖r ≤ −bᵢ ∀i

固定维数 LP,Seidel 算法 O(n)(实现用 SDLP)。这个 LP 同时能检测半空间交集为空或无界。

**连接关系对偶**:原始顶点↔对偶面、原始面↔对偶顶点、边↔面邻接互换。一般位置下对偶包是三角网格(对应原始顶点价数为 3);非三角对偶面任意三角化即可,不影响算法行为。

## 2. 拓扑变化(§4.1):删除对偶顶点后如何补洞

删除对偶顶点 i 前,记录其一环三角形;一环边界是一个拓扑多边形 Nᵢ(几何上未必共面)。目标:找到 Nᵢ 的一个**保持外凸**的三角化 Tᵢ。

由对偶包的凸性,一环之外的面不受影响(它们"看不到"顶点 i),所以只需局部处理。两种策略:

- **通用策略**:对 Nᵢ 求凸包,只保留"外侧包络"——保留满足 orient3D(φₐ, φᵦ, φ꜀, φᵢ) 为正(顶点 i 在正侧)的面。最坏 O(k log k),k = |Nᵢ|。
- **小邻域快路径**(绝大多数情况 k≈6):先扇形三角化,再对非边界边做**翻边直到全部凸**,最坏 O(k²) 但小 k 下更快。

实现里 k ≥ 100 才调用 CGAL convex_hull_3,否则走翻边路径。Tᵢ 的边界按顺序与 Nᵢ 吻合——这是下一步能拼出封闭网格的前提。

## 3. 几何变化(§4.2):删除代价 = 凸"帽"的体积

删除半空间 i 后,邻居半空间自然延伸相交,鼓出一个"帽"(cap)。帽 = (∩_{j∈Nᵢ} 半空间 j) ∩ (半空间 i 取反),**按定义是凸的**。

无需显式求交的构造法:
1. 取 Tᵢ 的**反向**(翻转朝向),拼上原来 incident 于 i 的一环三角形 → 得到一个**封闭、genus-0 的"局部对偶网格"**(因为 Tᵢ 边界与 Nᵢ 逐序吻合)。
2. 把这个局部对偶网格的每个面(作为对偶平面)用 Eq.3 类似的公式转回原始顶点,并取对偶-对偶(即原始)连接关系 → 得到帽的原始网格。
3. **高斯公式**求体积:Σ_faces (面积法向 · 面质心)/3。

表面积代价类似:新面(对应 Nᵢ)的原始面积总和 − 被删面 i 的原始面积。注意**面积含开方,不能用有理数精确算**;体积可以。

平均宽度代价(§6):多面体平均宽度 w = (1/4π) Σₑ ℓₑθₑ(边长 × 二面角),同样可局部增量计算,同样不兼容有理数。

**附录 A 的反直觉点**:原始帽是凸的,但它对应的"对偶帽"(丢失的对偶体积)一般**非凸**——因为对偶中心 c 固定在原凸包深处,不在帽里。这就是为什么代价计算要"转回原始空间再算",而不是直接在对偶空间量体积。

## 4. 无穷体积检测(§4.3)

删掉某些半空间会让交集变成无界(2D 直觉:去掉"封口"的那条边)。判据:**对偶空间原点落在新三角化 Tᵢ 之外**。鲁棒检测:对每个 {a,b,c} ∈ Tᵢ 测 orient3D(φₐ, φᵦ, φ꜀, 0)。

浮点实现的边角:原点"几乎"在外面时对偶→原始转换数值敏感,表现为代价要么极大正(自然被队列忽略)要么极大负(如 −10²⁰,显式识别为无穷并剔除)。**约束面功能就搭在这上面:把指定面的删除代价设为 +∞,它就永远留在输出里**(Fig. 16 的锤面/锤底)。

## 5. 贪心消除(§4.4)与数据结构

- **惰性最小堆**(lazy min-heap):代价更新不删旧堆项,pop 时校验是否过期——网格简化的标准做法。
- **半边结构**(CGAL Polyhedron)维护对偶包拓扑:局部改动输出敏感,且方便最后取拓扑对偶(原始包)做输出/可视化。
- 弹出 i → 删除 + 按 Tᵢ 重三角化 → 只有 j ∈ Nᵢ 的代价失效,重算并更新堆。
- 到达目标数后:多数应用只要 H-表示(对偶顶点反解 Eq.2);要网格就再做一次对偶(Eq.3 + 对偶连接,面一般是多边形)。

复杂度:n 次删除 × O(log n) 堆操作 × O(1) 期望邻域大小 = **O(n log n)**,Fig. 7 实测紧贴线性(log-log)。

## 6. 数值与实现细节(§5)

| 细节 | 选择 | 原因 |
|---|---|---|
| 数值内核 | 默认 CGAL::Epick(精确谓词+浮点构造);全程兼容 Epeck/GMP 有理数 | 谓词(orient3D)必须精确,构造可以近似 |
| 退化面过滤(浮点) | 面积 < 1e-8 或对偶空间法向距离 < 1e-14 视为退化 | 有理数下退化 = 恰好零面积,浮点需容差 |
| 对偶面非三角 | 一律三角化;多余内部顶点会在后续局部重三角化中被无害地重排,代价摊销 | 不需要严格一般位置假设 |
| 初始凸包 / 大价数一环 | CGAL convex_hull_3 | 现成、鲁棒 |
| LP(Chebyshev 中心) | SDLP(Seidel) | 固定低维,O(n) |
| 原型 | MATLAB 动态邻接矩阵(不需要严格流形性) | 验证算法本身很简单 |

## 7. 复现要点与坑

1. **Tᵢ 边界必须逐序吻合 Nᵢ**,否则局部对偶网格不封闭,高斯公式体积就是错的——这是实现里最隐蔽的正确性 bug 来源。
2. **无穷体积的浮点哨兵**:遇到巨大负体积(−10²⁰ 量级)必须当作 +∞ 处理,否则贪心会优先选它,输出直接爆炸。
3. **翻边终止条件**是"所有非边界边外凸",用 orient3D 判断;写错方向(内凸)会让对偶包失去凸性,后续所有代价计算失效。
4. **惰性堆的过期校验**要绑定"顶点当前版本号"或等价机制,否则会按陈旧代价删错顶点。
5. 极限简化(< 8 面)时留意**菱面体式死路**:剩余每个候选都是无穷代价,算法会在目标数之上停住——这是正确行为,不是 bug(Fig. 17)。
6. 需要严格鲁棒性(如退化/共面密集输入)时切 Epeck + 体积代价(面积/平均宽度代价与有理数不兼容)。

## 8. 超参数敏感性

本方法几乎没有超参数(这是它工程上讨喜的原因):
- 目标面数 n:唯一的用户参数,直接控制紧度-成本谱(Fig. 1:18 面 <5% 体积增长;6 面 1.61×)。
- 退化容差(1e-8 / 1e-14):仅浮点路径需要,论文给的值在 133 模型上工作良好。
- 价数切换阈值(k=100):纯性能开关,不影响结果。
