# 来源与阅读边界

## 已核验来源

- DOI 元数据与摘要：<https://doi.org/10.1145/3811386>、Crossref API。
- 作者维护的实现入口：<https://github.com/MeshFEM/MeshFEM>。
- 稀疏结构、装配和直接求解器包装：<https://github.com/MeshFEM/MeshFEMSparse>。
- BlockCatamari 求解器：<https://github.com/MeshFEM/BlockCatamari>。

## 限制

本次请求的 ACM 页面及其 PDF/EPDF 下载在当前网络环境均返回 HTTP 403，因此没有伪造 PDF 解析结果，也没有把二手网页中的性能数字当作论文事实。下面的“论文事实”来自公开摘要和 DOI 元数据；涉及数据结构、缓存策略、默认选项的内容则明确标记为“官方仓库实现观察”。

## 如何补全全文学习

如果后续提供可读取的 PDF，本目录可以在不改动现有材料结构的情况下补充：逐节引用、图表/定量结果、完整消融表，以及 `images/` 中的论文原图。
