                                                                                    A BSTRACT

                                                  World action models (WAMs) aim to answer a coupled physical question: given
                                                  a task instruction, what motion should the robot execute, and how will that mo-
                                                  tion change the surrounding world? Most existing WAMs build on pretrained
                                                  video generators and represent world evolution through images or visual latents.
                                                  Robotic interaction, however, takes place in metric three-dimensional space, while
                                                  images are view-dependent projections whose pixel distances do not directly en-
                                                  code physical distances. We introduce U NITAS, to our knowledge the first 3D-
                                                  native world action model that unifies observations, actions, and scene dynamics
                                                  in a shared metric 3D frame within each interaction, using a common represen-
                                                  tation across robot embodiments and human hands. Action flow represents hu-
                                                  man hands and robot grippers as 3D point trajectories, while scene flow describes
                                                  scene-point displacements conditioned on these trajectories. World-aligned 3D
                                                  positional embeddings ground visual tokens with or without depth input, and a
                                                  physical-time trajectory tokenizer encodes each point trajectory as one token an-
                                                  chored at its current 3D position. This interface supports both direct action ex-
                                                  ecution and action-conditioned scene prediction. With 1.7B parameters, U NI -
                                                  TAS achieves the best action-conditioned scene prediction on RoboTwin among
                                                  the compared methods, with up to 49% lower displacement errors than Point-
                                                  World, and state-of-the-art manipulation success, including 99.8% on LIBERO
                                                  and an average of 85% across real-world tasks. The code is available at https:
                                                  //github.com/DexForce/UNITAS.


                                        1     I NTRODUCTION
                                        World Action Models (WAMs) aim to answer a coupled physical question: given a task instruction,
                                        what motion should the robot execute, and how will that motion change the surrounding world?
                                        Most existing WAMs couple action learning with prediction of future images or visual latents, in-
                                        creasingly building on pretrained video models (Yang et al., 2023; Li et al., 2025b; Zhu et al., 2025;
                                        Cen et al., 2025; Bi et al., 2025; Ye et al., 2026; Yuan et al., 2026b; Zhou et al., 2026b). Robotic
                                        interaction, however, takes place in metric three-dimensional space, and an image is only a view-
                                        dependent projection of that space.
                                        The same robot motion, object displacement, or contact event can produce different pixel changes
                                        across views, and equal pixel displacements need not correspond to equal physical distances (Ze
                                        et al., 2024; Qu et al., 2025). Differences in camera intrinsics and camera-to-robot poses further
                                        make this mapping vary across embodiments. Evaluations of video-based WAMs report sensitivity
                                        to viewpoint and robot-state changes (Zhang et al., 2026b), and a photorealistic prediction may still
                                        misrepresent object displacement, deform rigid geometry, or allow static regions to drift (Huang
                                        et al., 2026). Such visual representations leave metric motion and contact relationships implicit for
                                        spatial reasoning, prediction, and control.

Recent methods incorporate depth, optical flow, scene flow, or reconstructed 4D geometry into pre-
diction (Zhen et al., 2025; Guo et al., 2026; Zhao et al., 2026; Wang et al., 2026b) or ground action
generation in explicit 3D structure (Shridhar et al., 2023; Ze et al., 2024; Zhen et al., 2024; Qu
et al., 2025). Yet geometry often serves as an input cue or auxiliary prediction target, rather than a
shared interface for action generation and scene dynamics. PointWorld (Huang et al., 2026) directly
predicts metric point flows conditioned on externally supplied robot motion, rather than generating
that motion from a task instruction. A 3D-native WAM should place observations, actions, and re-
sulting scene changes in a shared metric frame, enabling task-conditioned behavior, consequence
prediction, and executable control.
We introduce U NITAS, UNIfied Trajectories for Action and Scene flow. To our knowledge, it is
the first 3D-native world action model that aligns observations, actions, and scene dynamics in a
shared metric frame within each prediction window, using a common representation across robot
embodiments and human hands, as illustrated in Fig. 1.
Realizing this 3D-native world action model presents three challenges. First, visual observations
must be grounded in metric space even when depth is unavailable. We propose world-aligned 3D
position embeddings derived from observed depth or learned weights over candidate positions along
calibrated camera rays. Second, human hands and robot grippers have different morphologies and
control interfaces. We propose action flow, which represents their motion as trajectories of corre-
sponding 3D points in the shared frame. Third, trajectories differ in frame rate and duration across
data sources. Representing each timestep as a token allocates backbone capacity across unequal
physical-time intervals. We propose a physical-time trajectory tokenizer, which aligns each trajec-
tory to elapsed time and encodes the whole trajectory as one token before the backbone. Scene flow
describes scene-point displacements decoded from trajectory tokens conditioned on action flow.
In the backbone, observation tokens are grounded in world coordinates, while action-flow tokens
across embodiments and scene-flow tokens are anchored at each point’s current 3D position, allow-
ing the network to model motion through features associated with fixed spatial anchors. Given the
instruction and current observations, a layer-coupled Mixture-of-Transformers jointly models point
trajectories and executable commands. This supports two modes: policy mode directly generates
executable actions, while simulator mode predicts scene changes conditioned on externally supplied
action flow. A causal attention mask enables key–value caching of shared context across denoising
steps, reducing repeated computation and accelerating inference.
We evaluate U NITAS on action-conditioned scene prediction and robotic manipulation. In simulator
mode, it leads the compared methods across all four RoboTwin scene-prediction metrics, reducing

         tions, actions, and scene dynamics in a shared metric frame, using a common representation
         across robot embodiments and human hands.
       • Action flow represents human hands and robot grippers through point trajectories, while

       • With 1.7B parameters, U NITAS achieves leading action-conditioned scene prediction and

2   R ELATED W ORK
Video world–action modeling. Video-based policies use future prediction for control (Hu et al.,
2024), with early WAMs coupling prediction and action learning through shared representations and
generative objectives (Li et al., 2025b; Zhu et al., 2025; Cen et al., 2025; Xu et al., 2025a). Video-
generation priors subsequently support joint video–action learning and future-conditioned policies
(Liao et al., 2025; Shen et al., 2025; Bi et al., 2025; Kim et al., 2026; Li et al., 2026; Wang et al.,
2026a), while heterogeneous robot and video-only data support cross-task and cross-embodiment
transfer (Ye et al., 2026; Zhang et al., 2026a). Efficient variants omit future generation at deployment
or replace it with latent subgoals (Yuan et al., 2026b; Chen et al., 2026a). These models primarily
represent world evolution in images or visual latents. Reported sensitivity to viewpoint and robot
initial-state changes (Zhang et al., 2026b; Hong et al., 2026) highlights the importance of grounding
perception, world evolution, and executable actions in a shared physical space.
Policy learning in 3D space. Explicit 3D representations improve spatial understanding for ma-
nipulation (Shridhar et al., 2023; Ze et al., 2024; Zhen et al., 2024; Qu et al., 2025). Geometry-
aware world models augment visual prediction with image-aligned geometric signals (Zhen et al.,
2025; Guo et al., 2026; Zhao et al., 2026). In policy learning, LaMP (Wang et al., 2026b) and Ge-
omVLA (Xiong et al., 2026) use intermediate motion features from trajectory denoising to condition
action generation. PointWorld (Huang et al., 2026) follows the complementary direction, predicting
scene flow conditioned on robot motion for planning. U NITAS jointly models agent motion and its
conditional scene response through point flows, while supporting direct command execution without
generating scene flows.
Unified action representations for manipulation. Cross-embodiment learning must reconcile dif-
ferent morphologies and control interfaces (Chi et al., 2024). Generalist policies use embodiment-
specific prompts, canonical state–action formats, and aligned end-effector conventions (Liu et al.,
2024; Zheng et al., 2025; Yuan et al., 2026a; Xiaomi Robotics Team et al., 2026). Point flows pro-
vide transferable motion targets across embodiments (Yuan et al., 2024; Bharadhwaj et al., 2024; Xu
et al., 2025b), connecting object-motion prediction to control (Zhi et al., 2025; Dharmarajan et al.,
2025) and representing robot and object trajectories (Huang et al., 2026; Lin et al., 2026). U NITAS
unifies human-hand, robot-gripper, and scene trajectories with a shared physical-time tokenizer.

models that condition actions on predicted futures, the action distribution can be written as

3.4   P HYSICAL -T IME P OINT-F LOW R EPRESENTATION
Action flow and scene flow. In the same world frame, action and scene flows describe displacement
from each query point’s current position. For query n at xt,n , the target is {∆xn,k }H k=1 , with
∆xn,k = xt+τk ,n − xt,n . The elapsed time is τk , and point identity is preserved throughout the
trajectory.
For robots, we sample Ng = 20 points from the URDF-defined gripper geometry of each arm
and retain their link-local coordinates. Forward kinematics maps these points into the world frame
at each recorded joint configuration, preserving correspondence through arm and finger motion.
Human demonstrations use 21 MANO-derived keypoints (Romero et al., 2017) per observed hand.
Following PointWorld (Huang et al., 2026), we mask robot pixels using the URDF and current joint
state, back-project the remaining RGB-D pixels, and sample Ns scene query points. Simulator
states supply ground-truth correspondences where available and scene-flow loss is applied only to
valid trajectories. At inference, scene prediction requires current 3D query coordinates from depth
or supplied geometry.

features; history uses negative offsets. An input MLP maps each displacement to hn,k , and temporal
MLPs map ϕtime (τk ) to FiLM parameters (ak , bk ) for the encoder and the decoder. The encoder

3.5 M ODEL A RCHITECTURE
Coupled experts. U NITAS uses a Mixture-of-Transformers (Liang et al., 2024) with two diffusion
transformers (Peebles & Xie, 2023): a point dynamics expert for action and scene flows, and an
action expert for the end-effector action chunk u. The point dynamics expert processes spatially
grounded primary-view VLM tokens, auxiliary-view features from the shared vision tower, and
historical and future flow latents. At each layer, the smaller action expert reads the dynamics expert’s
observation/language keys and values (KV), together with its own current-state and noisy command
tokens. It predicts relative end-effector translation, rotation, and gripper openness at each future
timestep.
Attention structure. Let O and HA be the observation/language and history tokens, and let Aγ ,
Aclean , and Sγs be the noisy action-flow, clean action-flow, and noisy scene latents. The context
[O, HA ] is bidirectional. Each action-flow group attends to this context and to itself. Scene tokens
attend to the context, to Aclean , and to one another, but not to Aγ , so scene prediction conditions on
action flow without entering action-flow denoising. Action chunk tokens attend to the observation
KV, the current end-effector state, and one another. They do not attend to future action-flow or
scene-flow tokens, so policy-only inference can skip both future-flow branches, as shown in Fig. 2.
Training. We first train the trajectory tokenizer to reconstruct historical and future action flow and
available scene trajectories, then freeze it. Both experts learn through rectified flow (Liu et al.,
2022). For a clean target y, either a normalized trajectory latent or an action chunk, and noise
ϵ ∼ N (0, I), we form yγ = (1 − γ)ϵ + γy and regress y − ϵ. Action flow and action chunk
share γ but use independent noise, while scene flow draws γs independently. During training, scene
prediction conditions on clean action-flow latents from demonstrations. The objective is
                               L = λA LA + λs Lscene + λctrl Lctrl + λPE LPE .                               (9)
The first three terms use mean squared error (MSE) losses to supervise action flow, scene flow, and
the action chunk, with λA = λs = λctrl = 1. LPE is Eq. 7, with λPE = 0.1. Each loss uses only
available annotations, with missing targets and absent arm slots masked.
Inference. Action flow and action chunk are denoised in parallel on one Euler schedule. Generated
action flow, or an externally supplied trajectory in simulator mode, then conditions scene denoising.
The context and clean action-flow keys and values are cached and reused across scene-denoising
steps. Policy-only execution keeps the observation and history context and denoises only u, skipping
both point dynamics branches. Appendix A.3 gives the schedule, widths, and optimization.

4     P OLICY E VALUATION
Our policy evaluation tests whether representing interaction in a shared metric space supports ef-
fective robot control. We examine task completion across simulation benchmarks, robustness when
observations and initial states change, and execution on real-world robots.
4.1    E XPERIMENTAL S ETUP
Training settings. We initialize the vision-language backbone from Florence-2 (Xiao et al., 2023)
and randomly initialize all remaining components. We consider two training settings: (1) with pre-
training, U NITAS is pretrained on a mixture of real-robot, simulation, and human hand demonstra-
tions, then fine-tuned on each downstream benchmark or dataset; (2) without pretraining, U NITAS
(w/o Pretrain) is fine-tuned directly on each target benchmark or dataset without the mixed-dataset
pretraining stage. More detailed training configurations are provided in the appendix.
Baselines. We compare against VLA policies (Zheng et al., 2025; Sun et al., 2026; Black et al.,
2024; Physical Intelligence et al., 2025; Yang et al., 2026), video-based WAMs (Kim et al., 2026;
Liao et al., 2025; Bi et al., 2025; Li et al., 2026; Yuan et al., 2026b), and 3D-aware policies (Qu
et al., 2025; Wang et al., 2026b; Guo et al., 2026; Zhou et al., 2026a).
4.2    S IMULATION B ENCHMARKS
We evaluate U NITAS on single-arm and bimanual manipulation benchmarks. LIBERO (Liu et al.,
2023) includes Spatial, Object, Goal, and long-horizon LIBERO-10 suites; RoboTwin 2.0 (Chen
et al., 2025) covers 50 bimanual tasks under Clean and Randomized conditions. VLABench (Zhang
et al., 2024) tests object and instruction generalization across five tracks, measured by success rate
(SR), progress score (PS), and intention score (IS). LIBERO-Plus (Fei et al., 2025) evaluates robust-
ness to seven types of observation, instruction, and initial-state perturbations. Detailed protocols
and per-task results are provided in the appendix.
Manipulation performance. Tab. 1 reports policy performance across the evaluated simulation
benchmarks. On LIBERO, U NITAS achieves a state-of-the-art average success rate of 99.8%, with
strong results on spatial and long-horizon tasks. Without mixed-dataset pretraining, it achieves
99.5%, also exceeding all baselines. On RoboTwin 2.0, U NITAS achieves 92.94% and 93.04%
under Clean and Randomized conditions, respectively. Its 1.7B model outperforms the compared
methods while using fewer parameters than Fast-WAM (6B) and Motus (8B). On VLABench, it
achieves 56.2% SR compared with 48.1% for π0.5 , alongside a higher progress score.
Robustness to distribution shifts. As shown in Tab. 1, U NITAS achieves the highest overall success

5   ACTION -C ONDITIONED W ORLD M ODELING
Evaluation setup. We evaluate action-conditioned scene prediction on held-out RoboTwin roll-
outs using matched initial observations and robot-motion conditions, with simulator states providing
ground-truth point trajectories. We compare against PointWorld (Huang et al., 2026), which directly
predicts 3D trajectories, and video-based Ctrl-World (Guo et al., 2025) and X-WAM (Guo et al.,
2026). Video predictions are lifted to 3D using SpatialTrackerV2 (Xiao et al., 2025), with Depth
Anything 3 (Lin et al., 2025) for Ctrl-World and native depth predictions for X-WAM. Both are cal-
ibrated using only initial-frame ground-truth depth. We report Moving ADE and FDE for trajectory
and endpoint accuracy, Static ADE for background drift, and Moving Acc@1cm for the fraction of
moving-point predictions within 1 cm of ground truth. Detailed evaluation protocols are provided in
Appendix F.1.

6   C ONCLUSION
U NITAS advances a physical-space formulation of world action modeling: what the robot observes,
how it moves, and how the scene responds are expressed within a common metric reference. Making

interaction geometry an explicit prediction target connects world modeling with action learning and

More broadly, this work positions physical interaction as a unifying basis for embodied learning,
with robot behavior and environmental change represented as complementary parts of the same
process. Extending this foundation to reliable prediction over longer interactions and broader real-

with latent dimension dz = 256. Future trajectories use positive offsets; history uses negative offsets
and displacements from past positions toward the current anchor. An input MLP produces hn,k from
∆xn,k , and separate temporal MLPs produce the encoder and decoder FiLM parameters.

Reconstruction training. We minimize squared Euclidean error over valid point–time pairs, av-
eraging the future and historical action losses and adding available scene reconstruction loss. The
trained tokenizer is frozen, and its latents are standardized with fixed channelwise training statistics
before world-action model training.

Spatial anchoring and query sets. The spatial anchor is separate from the displacement latent.
Pointwise Fourier features of xt,n are projected to the point dynamics expert’s hidden dimension and
added to the trajectory token throughout denoising. Shared token processing and order-independent
attention masks make prediction permutation equivariant within each query type: reordering query
points and their noise tokens together reorders the outputs. Variable query counts support sparse
object-level prediction or denser scene coverage.

Held-out trajectory reconstruction. We evaluate the frozen tokenizer on 600 held-out trajectory
windows per source and trajectory type, none used for tokenizer training. Each point trajectory is
encoded into one token and decoded at its original physical timestamps. Tab. 6 reports ADE, the
mean Euclidean error across future timesteps, and FDE, the error at the final timestep, averaged
over point trajectories. The millimeter-scale errors indicate that the tokenizer preserves motion

Token structure and attention. The mask is specified in Sec. 3.5. The action expert has the same
depth as the dynamics expert and a smaller hidden dimension, with one noisy command token per
future timestep. Physical execution time τk enters command tokens through FiLM, separately from
the denoising time.

Flow matching and inference. The interpolation and the loss weights are given in Sec. 3.5. At
inference, action flow and commands use the same Euler schedule for 10 steps. Scene denoising
starts from independent noise.

Training configuration. We pretrain for 200K steps with a total batch size of 1,024 using AdamW.
The learning rates are 10−4 for the point dynamics and action experts and 10−5 for the VLM, with
weight decay 10−8 . We use constant learning rates after 1,000 steps of linear warmup. Training
uses 64 BW1000 H DCUs (64 GiB each) with FSDP.

Queries and objectives. Robot grippers use 20 query points sampled from URDF-defined gripper
geometry per arm; human hands use 21 MANO-derived keypoints per observed hand. Scene points
are voxelized and capped at 12,000 before random subsampling. The mixed-dataset run retains
1% (approximately 120 scene queries at the cap), with 5-mm voxels for the simulation datasets.
RGB inputs are resized to 224 × 224. The flow-matching weights are set in Sec. 3.5; unavailable
supervision is masked. This run uses a frustum-routing substitution probability of 0.1. Action
position coordinates are scaled by 10; rotation and gripper coordinates retain unit scale. Inference
uses 10 Euler steps for each active expert.

Evaluation protocol. Tab. 4 evaluates 550 test clips from 50 RoboTwin tasks, with one Clean
and ten Randomized episodes per task. Each episode contributes a fixed window near its midpoint,
containing the current frame and 20 future recorded frames. Initial scene points are sampled with
a 1.5 cm voxel grid. All methods share initial queries, point identities, ground-truth trajectories,
and robot-motion conditions. For video methods, queries are projected into the initial image us-

ing camera calibration, accounting for resizing and cropping; only in-frame projections are tracked
by SpatialTrackerV2. Ctrl-World uses Depth Anything 3 depth, whereas X-WAM uses its native
depth predictions. Depth scale for Ctrl-World and inverse-depth affine calibration for X-WAM are
estimated from initial observed depth and fixed throughout the video. Tracked trajectories are trans-
formed into world coordinates, and their predicted displacements are anchored at the shared initial
queries. No future ground-truth depth or trajectories are used for alignment.

Scoring. In our evaluation, we label a point as moving when its maximum ground-truth displace-
ment from its initial position over the 20 future frames exceeds 1 cm, and as static otherwise. These
labels are fixed per clip and shared across methods. We score future frames 4, 8, 12, 16, 20: ADE av-
erages Euclidean errors over valid point–frame pairs in each group, Moving FDE measures moving-
point error at frame 20, and Moving Acc@1cm is the fraction of valid moving-point–frame pairs
with prediction error at most 1 cm. Metrics are first computed per clip, averaged within each task–
condition group, and then averaged equally across groups. Clips without valid moving points are
excluded only from the corresponding moving metrics.

F.2   C LOSED -L OOP ACTION –S CENE C ONSISTENCY

We evaluate three RoboTwin tasks, Adjust Bottle, Beat Block Hammer, and Blocks Ranking RGB,
under Clean and Randomized conditions, yielding six settings. Each method is evaluated over 10 tri-
als per setting, for 60 trials in total. We compare with X-WAM (Guo et al., 2026), Fast-WAM (Yuan
et al., 2026b), LingBot-VA (Li et al., 2026), and Motus (Bi et al., 2025). Each generated action
chunk is executed in the simulator, and the resulting observation conditions the next prediction.
Models retain their native prediction horizons and are scored at completed action boundaries until
termination. Fast-WAM executes all 32 actions rather than replanning after 24.
For U NITAS, the point dynamics expert generates an action flow, while the action expert separately
generates an executable command chunk from the same observation and instruction. The dynamics
expert then predicts scene-flow trajectories conditioned on its generated action flow. We compare
these predictions with the ground-truth scene trajectories resulting from executing the action expert’s
command chunk in the simulator.

Trajectory extraction and scoring. Ground-truth query points follow their simulator objects or
links. SpatialTrackerV2 lifts video predictions using X-WAM’s native depth or Depth Anything
3 estimates for RGB-only models, with initial-frame depth calibration and query anchoring. We
apply the 1 cm displacement threshold to label moving points within each scored chunk. Metrics are
averaged within rounds, then within episodes, across trials within each setting, and finally equally
across the six settings. Rounds without valid moving points are excluded only from moving-point
metrics; all episodes are retained regardless of task outcome.
