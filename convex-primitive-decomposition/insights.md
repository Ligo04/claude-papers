# 核心洞察

## 核心思想

**用网格简化的思路做碰撞体生成** — 不是把网格切成凸块（top-down），而是从每个面开始，逐步合并成更大的基元（bottom-up）。

类比：QEM 把顶点合并成更少的顶点来简化网格；本方法把面合并成更少的基元来简化碰撞体。

## 为什么这行得通

### 1. 线性算子的优雅性

每个面的信息用一个 3×3 矩阵 Q = nn^T（法线外积）编码。这个矩阵：
- 可以直接相加合并 Q_merged = Q_a + Q_b
- 特征分解给出最优方向（最大特征向量 = 主法线方向）
- 只需 9 个浮点数，内存极小

这比 QEM 还简单 — QEM 需要 4×4 矩阵（含位置信息），本方法丢弃位置项，直接用顶点集计算位置。

### 2. 超量体积作为代价函数

C(p₀, p₁) = V(merge(p₀, p₁)) - (V(p₀) + V(p₁))

这个代价函数：
- 含义直观：合并引入多少额外空间
- 计算便宜：只需参数化基元的体积公式
- 不需要水密输入：只用基元自身体积，不需网格体积
- 负值表示合并消除重叠，是"免费"操作

### 3. 统一接口约束

任何满足以下接口的基元都可加入框架：
1. 高效计算体积
2. 从给定方向和位置构造零体积元素
3. 支持单调递增参数以封闭点集

这使得扩展新基元非常容易 — 只需实现 3 个操作。

## 概念转变

**从 "切割" 到 "生长"**：
- 传统方法（CoACD）：找切割平面 → 分割成凸块 → 可能切错
- 本方法：从最小单元开始 → 贪心合并 → 自然尊重几何结构

**从 "精确形状" 到 "参数化近似"**：
- 凸包：任意形状，精确但昂贵
- 基元：固定参数，紧凑且物理引擎原生支持

## 权衡分析

| 优势 | 劣势 |
|------|------|
| 输出可编辑（参数化） | 不如凸包贴合凹区域 |
| 物理引擎原生支持 | 需要手动选择基元数量 |
| 复杂度可控（固定字节/基元） | 特征分解非全局最优 |
| 不需水密输入 | 梯形棱柱等非标准基元需凸包化 |
| 算法简单高效 | 贪心策略无法回溯 |

## 局限性

1. **贪心不可逆**：早期错误合并无法撤销
2. **基元数量需人工指定**（虽然有体积阈值辅助）
3. **凹区域处理有限**：基元必然填充凹区域
4. **不处理动画**：仅针对静态刚体
5. **交叉体积忽略**：Eq.4 不考虑基元重叠体积

## 与先前工作的对比

| | 本方法 | CoACD | V-HACD |
|--|--------|-------|--------|
| 方向 | 自底向上 | 自顶向下 | 自顶向下 |
| 输出 | 参数化基元 | 凸包 | 凸包 |
| 切割 | 无（合并） | 平面切割 | 体素化+切割 |
| 输入要求 | 任意 | 流形 | 流形 |
| 可编辑性 | 高 | 低 | 低 |

## 实践意义

1. **游戏开发**：自动生成高性能碰撞体，节省美术时间
2. **物理模拟**：更快的帧时间 = 更多预算给其他系统
3. **工具链集成**：输出可直接在 Blender/UE 中编辑
4. **LOD 碰撞**：可按需调整基元数量实现不同精度级别
