# 思维模型

## 这是什么类型的问题？

**几何近似 + 优化** — 用少量简单形状逼近复杂形状，同时优化下游任务（碰撞检测）的性能。

本质上是一个 **多目标离散优化**：
- 目标 1：最小化几何误差（近似精度）
- 目标 2：最小化碰撞检测成本（运行效率）
- 约束：基元必须封闭（包含）输入表面

## 需要的前置知识

### 必须掌握
- **线性代数**：矩阵特征分解、外积、正交基
- **基本几何**：法线、包围盒、体积计算
- **贪心算法**：优先队列、局部最优选择

### 有帮助
- **QEM（Quadric Error Metrics）**：理解类比的来源
- **物理引擎**：GJK 碰撞检测、broad/narrow phase
- **游戏开发**：碰撞体在实际项目中的使用

### 不需要
- 深度学习
- 微分几何的高深理论
- 具体物理引擎实现细节

## 如何归类这项工作

**一句话**：把 QEM "网格→简化网格" 的范式迁移到 "网格→碰撞基元"。

**关键洞察**：法线外积矩阵是一个足够好的方向估计器，而方向是拟合所有基元类型的共同瓶颈。

**方法论创新**：不是设计每种基元的专用拟合算法，而是用一个统一的线性算子提供方向，然后各基元类型独立拟合参数。

## 类比理解

| 概念 | 类比 |
|------|------|
| 线性算子 Q | 指南针 — 告诉你基元该朝哪个方向 |
| 贪心合并 | 拼图 — 把相似的小块拼成大块 |
| 超量体积 | 包装浪费 — 箱子比内容物大多少 |
| 基元类型权重 | 邮费等级 — 越贵的包装越不想用 |
| 面邻接拓扑 | 社交网络 — 只有邻居才能合并 |

## 举一反三

这个框架可以迁移到：
1. **LOD 系统**：不同距离用不同数量的基元
2. **光线追踪加速**：用基元做 BVH 的叶节点
3. **机器人碰撞**：实时路径规划中的快速碰撞检测
4. **3D 打印**：简化模型用于碰撞/支撑分析
