# Convex Primitive Decomposition for Collision Detection

## 论文概述

本文提出了一种自底向上的凸基元分解方法，将输入网格自动分解为参数化凸基元（包围盒、球体、胶囊体、圆柱体、棱台、梯形棱柱）用于刚体碰撞检测。该方法受 Quadric Mesh Simplification 启发，通过贪心合并策略生成紧密贴合输入表面的碰撞体，保证封闭输入网格的同时实现高效的物理仿真性能。

## 难度等级

**中高级** — 需要线性代数（特征分解）、计算几何和物理引擎基础知识。

## 关键收获

1. 用参数化基元（盒子、球、胶囊等）代替凸包分解，在游戏物理引擎中性能更优
2. 受 QEM 启发的 3×3 线性算子可统一处理多种基元的方向估计
3. 超量体积（excess volume）作为代价函数既简单又有效
4. 在 60+ 模型上验证：比 V-HACD 和 CoACD 更贴合输入、更低复杂度、更快仿真
