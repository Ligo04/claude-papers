Convex Primitive Decomposition for Collision Detection

Julian Knodt, Xifeng Gao — EUROGRAPHICS 2026 | Lightspeed Studios

算法流程

1. 输入网格 M = (V, F)
2. 每面计算 Q = area·(nnT + ε·ttT)
3. 特征分解 Q → 方向轴 (w₀, w₁, w₂)
4. 拟合初始基元 (每面一个)
5. 计算相邻对的合并代价
6. 贪心合并 (最小超量体积优先)
7. 重复直到 |P| ≤ N
8. 后处理：移除冗余基元

线性算子 Q 的特征分解

蓝色箭头=法线方向(w₂), 绿色=w₁, 红色=w₀(圆柱轴向). 合并更多面时观察方向变化。
