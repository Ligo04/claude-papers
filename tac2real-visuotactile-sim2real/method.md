```

   RL Agent ──action──▶ 物理引擎走一步 ──▶ 抽取"传感器↔被抓物体"的相对位姿/速度 ──┐         │

      │                                                          PNCG-IPC 在 Ray 多GPU 并行 │
      │                                                                          │         │
      └──── 组合观测(基线观测 + 标记点位移场)◀── 标记点位移场 ◀── KNN 插值 ◀────┘         │

                          ┌───────────── TacAlign 离线/部署前完成 ──────────────┐           │
                          │ ①控制对齐 ②基线IPC标定(CMA-ES) ③任务级标定 ④域随机化 │──────────┘
                          └────────────────────────────────────────────────────┘
```

**两个刻意的解耦:**
- 触觉仿真在物理引擎 **外部**,只吃相对量、吐位移场 → 跨引擎兼容。
- 物理求解(PNCG-IPC)与观测读取(标记点)分离:物理在网格上算,观测从网格节点插值到标记点。

## 1. PNCG-IPC 方法(第 3.1 节)

### IPC 的变分表述
IPC 把弹性动力学接触仿真表述为变分优化问题。用隐式欧拉积分,每个时间步的位置 `x_{t+1}` 通过最小化下式得到:

```
E(x) = ½ (x − x̂)ᵀ M (x − x̂)  +  h² Ψ(x)  +  B(x)  +  D(x)            (式 1)
```

四项分别是:
- **惯性势** `½(x−x̂)ᵀM(x−x̂)`:`x̂` 是无内力时的预测位置,`M` 是质量矩阵,`h` 是时间步长。
- **超弹性能** `h²Ψ(x)`:弹性体的形变能。
- **对数势垒接触势** `B(x)`:当物体逼近时能量 →∞,保证不互穿(IPC 的核心)。
- **摩擦势** `D(x)`:摩擦能。

### 为什么用 PNCG 而非牛顿
标准 IPC 用 **牛顿法 + 基于 CCD(连续碰撞检测)的线搜索**:每次迭代精度高,但要 **组装并分解 Hessian 矩阵**,
昂贵且难在 GPU 上并行。

**PNCG-IPC 用非线性共轭梯度替代牛顿法**,直接求解非线性优化,**不组装、不分解 Hessian**。它只需要:
- 梯度求值,
- **对角** Hessian 项,
- 向量-向量点积,

——全是高度 GPU 可并行的操作。再加一个 **无 CCD 的线搜索**:推导出 **解析的步长上界**,免去每次迭代昂贵的
碰撞检测。

### 设计哲学:用每步精度换吞吐
单步共轭梯度不如牛顿步精确,但 GPU 上极低的单步成本让 PNCG-IPC 在 **几十次迭代** 内收敛到足够精度。对触觉
仿真——"视觉合理 + 物理一致的形变" 比 "机器精度收敛" 更重要——这个权衡非常划算。

> **实现要点。** PNCG-IPC 基于 **Taichi** 实现:从简洁 Python 编译出高性能 GPU kernel,因此容易作为插件模块
> 嵌入各种仿真管线。
>
> **复现风险。** 迭代次数、步长上界推导、对角 Hessian 近似的质量直接影响收敛与稳定;论文把 PNCG-IPC 细节放在
> 补充材料(本文引用 [31])。

## 2. 触觉表征:标记点位移场(第 3.2 节)

**传感器:** GelSight Mini,可输出 RGB 触觉图像(320×240)或标记点位移场(9×7),取决于 gel 类型。

**为什么选位移场:** 一个简单碰撞测试——把传感器装在 Franka Panda 夹爪上抓 peg,与 socket 做静止/下压/前移/
后移四种接触。记录 RGB 和 2D 标记点位移场。结果(图 2):**标记点位移场在不同接触状态间变化显著,而 RGB 只有
细微差别**。位移场对接触模式更敏感 + 维度更低 → 利于大规模 RL(提升规律性与效率)。

**标记点 ↔ 网格的映射(关键机制):**
1. 用 **k 近邻(KNN)** 在 *初始* 状态下,为每个标记点建立到附近 IPC 网格节点的映射(及权重)。
2. 仿真推进后,网格节点位置改变;标记点的位移 **从形变后的网格节点位置加权插值** 得到。

也就是说:物理在网格上算,观测在标记点上读——固定的低维输出,与高保真物理解耦。

```python
# 伪代码:标记点位移场的构建
mapping = knn(marker_init_positions, mesh_init_nodes, k)   # 初始建映射 + 权重
# ... PNCG-IPC 仿真若干步,得到形变后的 mesh_nodes_deformed ...
for m in markers:
    nbrs, w = mapping[m]                                    # 该标记点的 k 个邻居与权重
    pos_deformed = sum(w[j] * mesh_nodes_deformed[nbrs[j]] for j in range(k))
    marker_disp[m] = pos_deformed - marker_init_positions[m]
```

## 3. 集成到物理引擎(第 3.3 节)

**插件式架构(图 3)。** 一个 RL 步的数据流:
1. RL agent 发出 action,触发物理引擎走一步。
2. 在这一步里,抽取被抓物体与触觉传感器之间的 **相对位置和朝向**,并算出对应的 **线速度和角速度**。
3. 把这些相对量喂给触觉仿真(Tac2Real),仿真输出 **标记点位移场**。
4. 位移场 + 引擎里的基线观测 → 拼成 **组合观测**,回传给 RL agent 继续训练。

**三个特性:**
- **跨引擎兼容:** 触觉仿真只需"传感器弹性体 ↔ 交互物体"之间的相对物理量,所以接口可以嵌进引擎之上的环境
  文件(如 Isaac Lab 的 `_get_observations()`)。支持 Isaac Lab / Isaac Gym / MuJoCo / PyBullet。
- **多 GPU 并行(Ray 集群):** 构建包含多节点、每节点多 GPU 的 **Ray** 集群。每个 GPU 实例化一个 Ray 包装的
  触觉仿真类,管理一组环境的触觉任务。在线 RL rollout 时迭代调用该类的仿真函数:输入相对位姿量,返回位移场;
  最后用 Ray 跨节点分布式通信汇集所有 GPU 的结果。

> **陷阱。** "只传相对量"是一个近似——它假设触觉响应只取决于局部相对运动,忽略某些全局耦合;对大多数夹持
> 接触成立,但极端情形需留意。

## 4. TacAlign:缩小 sim2real 差距(第 4 节)

**核心思想:** 把 sim-to-real 差距拆成 **结构化**(可建模的系统偏差:控制器动力学、材料参数、接触模型)和
**随机**(噪声、未建模不确定性)两类,用不同武器、按顺序对齐。四个阶段:

### 4.1 控制对齐(等级 1)
仿真和真机的 Franka 都用 **笛卡尔阻抗控制**,末端目标力:

```
F_targ = kp * (p_targ(a) − p_ee) − kd * v_ee ,   kd = 2·√kp  (临界阻尼)
```

直觉是"让 kp_sim 接近 kp_real 就能减小轨迹差距",但论文 **经验性地证伪** 了:由于未建模动力学、作动器延迟、
摩擦、接触非线性,轨迹差距与 |kp_sim − kp_real| **无显著线性相关**(随机取 20 对 sim-real kp 可视化,差距不随
参数接近而单调下降)。

所以改为 **轨迹级对齐**——最小化轨迹差距:

```
D(kp_sim, kp_real) = (1/T) Σ_t ‖ x_t^sim − x_t^real ‖²     (在 6 个标准末端运动上:三轴平移 + 三轴旋转)
```

并用 **交替最小化(alternating minimization)** *双向* 标定(不把任一域当真值):

```
kp_sim^(k+1)  = argmin_{kp_sim}  D(kp_sim,      kp_real^(k))
kp_real^(k+1) = argmin_{kp_real} D(kp_sim^(k+1), kp_real)         (式 4)
```

迭代降低轨迹散度。**结果**:11.11mm → 2.521mm(平移)、2.635°→0.454°(旋转);kp_sim=(600,50)、kp_real=(400,20),
之后固定。

### 4.2 基线 IPC 标定(等级 2)
标定 PNCG-IPC 的材料参数 **θ = [E, ν, ρ, μ]**(杨氏模量、泊松比、密度、摩擦系数)。用一个含 6-DOF 定位平台 +
GelSight Mini + 若干 3D 打印压头的装置,在不同压头和形变模式下记录 *真实* 标记点位移场序列;在 IPC 仿真里复刻
同样的形变模式。定义 MSE 损失:

```
L(θ) = (1 / (K·N)) Σ_{k=1}^K Σ_{i=1}^N ‖ u_{k,i}^sim(θ) − u_{k,i}^real ‖²        (式 5)
θ* = argmin_θ L(θ)                                                              (式 6)
```

(K = 帧数,N = 压头数。)这是 **无梯度** 非线性优化,用 **CMA-ES(协方差矩阵自适应进化策略)** 求解。
**结果**:用 cube/cylinder/moon/triangle 四个压头,各做按压(1mm,步进0.1)、滑动(1mm,0.1)、旋转(2°,0.5°)
三种形变;仿真弹性体力学行为与真实高度吻合。

### 4.3 任务级标定(等级 3)—— *消融显示最关键*
基线标定不足以覆盖真实富接触任务的全部形变,所以进一步对 **Isaac Lab 的仿真参数** 做任务感知微调,主要是
**摩擦系数 μ_isaac 和接触刚度 s_isaac**(并启用 Isaac Lab 的 *compliant contact*)。在四种代表性接触状态(静止
抓取、下压、前向碰撞、后向碰撞)下,记录 sim 与 real 的位移场序列(real 为真值),微调 μ_isaac、s_isaac 直到
最匹配帧之间的位移场 MSE 低于预定阈值。

### 4.4 域随机化(等级 4)
把 sim-to-real 差距建模为 **参数性 + 观测性** 不确定性,随机化:
- **物理参数**(控制器增益、摩擦),
- **几何配置**(物体与 socket 位姿),
- **感知通道**(末端位姿噪声、IPC 扰动)。

这种随机正则化鼓励策略对底层动力学失配和接触变化 *不变*,作为结构化对齐的补充,压下确定性标定难以解决的
随机差距。

## 5. 强化学习设置(第 5.3 节)

**任务(两个,均随机初始朝向 [-35°,35°]):**
- **随机朝向插销 Peg Insertion:** Franka 把夹爪里的圆柱 peg 完全插入固定圆柱 socket;**不靠重力**,全靠主动控制。
  peg 与孔直径均 8mm(比 TacSL 用的更小更难)。
- **随机朝向拧螺母 Nut Threading:** 把随机朝向的螺母放到固定螺栓上并旋拧;成功定义为拧入 1.5 个螺距深度。

**MDP 表述(强调对触觉的依赖):** 策略只观测——
- 末端位姿 `p_ee ∈ R⁷`,
- **单指标记点位移场** `u ∈ R^{7×9×2}`,
- 上一动作 `a_{t-1}`,
- **显式排除** 物体位姿和视觉数据(近乎"盲操作")。

**动作:** 增量笛卡尔更新,经阻抗控制器执行。
**奖励:** 关键点对齐 + 接合/插入的稀疏奖励,同时惩罚过大接触力以防碰撞。

**训练规模:** 512 环境,均匀分布在 **4 节点 × 16 GPU**;用 Isaac Lab 里 **rl-games 的现成 PPO**,共享 actor-critic;
3 个随机种子取平均。为公平对比,把 Tacchi、TacSL 用类似方案集成进 Isaac Lab。

## 6. 真机部署细节(第 5.4 节)

- 在 Franka 夹爪上装 **两个** GelSight Mini 维持力平衡,但 **仅用右指** 的标记点位移场做推理。
- **gel 保护机制:** 当相邻标记点位移场的 MSE 差超过预定阈值,暂停推理、末端回退一步、从调整后的位置恢复推理
  (防止 gel pad 损坏)。
- peg 初始朝向设 0° 和 ±15°,共 60 次试验(每朝向 20 次)。结果 55 次成功 → **91.7%** 零样本迁移成功率。

## 实现陷阱与复现风险(汇总)

- **"控制器参数接近 ≠ 轨迹接近"**:必须做轨迹级对齐,且双向交替最小化(别把任一域当真值)。
- **任务级标定是命门**:消融显示去掉它成功率 0.917→0.250。换新任务很可能要重做这一步。
- **标记点-网格映射在初始状态建好后固定**:KNN 的 k 和权重影响位移场质量。
- **PNCG 迭代次数/步长上界**:决定收敛与稳定;触觉场景追求"视觉合理"而非机器精度,别过度迭代。
- **"只传相对量"是近似**:忽略全局耦合;极端接触需验证。
- **CMA-ES 标定成本**:无梯度优化 + 真机采样,工程量大;θ 的搜索范围和损失阈值需调。
- **Ray 多 GPU 通信开销**:跨节点汇集位移场是吞吐瓶颈之一;FPS 随网格类型(伪结构 4465 vs 非结构 1665)差异大。
- **真机 gel 易损**:保护机制的 MSE 阈值要调,过敏则频繁回退、过钝则伤传感器。
