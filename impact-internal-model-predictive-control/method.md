# 方法 — IMPACT（完整技术管线）

## 0. 系统总览

IMPACT 是一个**双频率、双层**控制架构：

```
        ┌──────────────────────────────────────────────────────────────┐
        │  高层 — 任务规划            （学习的扩散策略，30 Hz）            │
        │  Diffusion Policy  π_θ(O) → X_d[t : t+H_p]  期望末端位姿        │
        └───────────────────────────────┬──────────────────────────────┘
                                         │ 期望位姿 x_d（插值得到）
        ┌───────────────────────────────▼──────────────────────────────┐
        │  底层 — 基于内模型的力预测控制              （1000 Hz）          │
        │                                                                │
        │  (1) 阻抗反馈         w_imp = K e − D ẋ                        │
        │  (2) 力旋量估计        ŵ_ext = (JJᵀ+λ²I)⁻¹ J τ_res            │
        │  (3) 低通 → w_slow     （慢/快分解）                            │
        │  (4) 内模型           w_pred = M_ϕ(z_{t−L:t})                 │
        │      + 惊讶门控的在线梯度更新 ϕ                                 │
        │  (5) 前馈             w_ff = w_pred,  τ_ff = Jᵀ w_ff           │
        │  (6) τ = τ_imp + τ_ff + τ_null  →  施加                       │
        └───────────────────────────────────────────────────────────────┘
```

两个时钟：**策略**以 **30 Hz** 更新期望轨迹；**控制器**以 **1000 Hz** 运行整个估计 + 补偿环，在策略更新之间插值期望位姿 `x_d = S(X_d, t)`。

---

## 1. 高层 — 模仿策略与阻抗背景（§2.1）

### 策略
扩散策略 `π_θ` 用标准模仿学习在遥操作演示上训练。它把观测历史 `O_{t−H_o+1:t}` 映射到一段期望末端执行器位姿序列 `X_d[t:t+H_p]`，以滚动时域方式执行。（`H_p = 32`，`H_o = 2`。）

> **关键点：** 策略*只*输出位姿。它从不被告知物体质量，也从不输出力。所有力的处理都在下游。

### 位姿与误差
末端位姿 `x = (p, R) ∈ SE(3)`，位置 `p ∈ ℝ³`，姿态 `R ∈ SO(3)`。任务空间误差：
```
e = [ p_d − p ;  Log(R_d Rᵀ) ]      # 6 维向量；Log 把 SO(3)→轴角
```

### 阻抗控制
```
w_imp = K e − D ẋ          # 反馈产生的期望交互力旋量
τ_imp = Jᵀ w_imp           # 映射到关节力矩
```
`K = diag(400,400,400, 30,30,30)`，`D = diag(40,40,40, 10.95,10.95,10.95)`（平移 / 旋转）。

### 机器人动力学（机械臂方程）
```
M(q) q̈ + C(q,q̇) q̇ + g(q) = τ + τ_ext ,    τ_ext = Jᵀ w_ext
```
`M` 惯性、`C` 科氏/离心、`g` 重力、`τ_ext` 来自外部力旋量 `w_ext` 的关节力矩。

---

## 2. 从力矩残差估计外部力旋量（§2.2）

这是"虚拟力传感器"。无需腕部力/力矩硬件。

**第 1 步 — 基于模型的力矩预测：**
```
τ_model = M(q) q̈̂ + C(q,q̇) q̇ + g(q) + τ_fric(q̇)
```
`q̈̂` 由编码器测量估计；`τ_fric` 为摩擦模型。

**第 2 步 — 残差 = 未建模的交互：**
```
τ_res = τ_meas − τ_model        # ≈ τ_ext = Jᵀ w_ext
```

**第 3 步 — 恢复 6 维力旋量（正则化最小二乘）：**
```
ŵ_ext = arg min_w  ‖Jᵀ w − τ_res‖² + λ² ‖w‖²
      = (J Jᵀ + λ² I)⁻¹ J τ_res      # 闭式解    (式 1)
```
`λ = 0.02` 对接近奇异的位形和噪声做正则化。（注意这是从关节空间反求回 6 维力旋量的阻尼右伪逆形式。）

**第 4 步 — 慢/快分解（一阶低通，式 2）：**
```
w_slow(t+Δt) = w_slow(t) + η · clip( ŵ_ext(t) − w_slow(t) )
```
- `η` = 适应速率：**力 2.0 s⁻¹，力矩 1.0 s⁻¹**（滤波时间常数 ≈ 0.0495 s）。
- `clip(·)` = 逐轴饱和，界限 **10 N / 1 Nm**，防止瞬态尖峰污染估计。
- 结果：`w_slow` 跟踪*持续*力旋量（负载重力、稳态接触）并抑制高频扰动。**`w_slow` 是内模型的监督信号。**

> **为何故意做慢？** 快滤波器会跟踪噪声。慢滤波器干净但在负载变化后滞后——而这正是内模型要填补的缺口。

## 3. 内模型学习与前馈补偿（§2.3）

### 预测器
```
w_pred = M_ϕ( z_{t−L:t} )
```
`z_{t−L:t}` = 关节状态与末端测量的短历史（长度 `L = 32`）。`M_ϕ` 是一个小的在线训练模型（学习率 0.01）。

### 在线、惊讶门控的更新
`M_ϕ` 在执行**过程中**用梯度下降训练以回归 `w_slow`：
```
loss ≈ ‖ M_ϕ(z) − w_slow ‖²
```
但更新是**门控**的：
- **仅当**预测"被惊讶"时更新：
  - `surprise = ‖w_pred − (估计的交互力)‖ ≥ 5 N`，**且**
  - 慢力旋量在稳定下来：`slow-wrench rate ≤ 0.2`。
- 当预测误差低于阈值 → **冻结**学习；把 `M_ϕ` 输出当作可靠预测。

这就是**稳定性-可塑性调速器**：惊讶时快速适应，否则保持冻结（抗噪）。

### 前馈补偿
学会后，在识别出已知条件时，预测被*立即*施加，无需等待 `w_slow` 收敛：
```
w_ff = w_pred ,    τ_ff = J(q)ᵀ w_ff
```

### 闭环力矩（式 3）
```
M(q) q̈ + C q̇ + g(q) = τ_imp + τ_ff + τ_null + τ_ext
```
`τ_null` = 用于次要目标（如姿态）的零空间力矩；`τ_ext` = 系统在对抗的真实外部关节力矩。

## 4. 算法 1 — 完整控制环

```
要求: 策略 π_θ ; 阻抗增益 (K, D) ; 观测历史 O_t
1:  for 每个策略更新时刻 t_k  (30 Hz) do
2:      X_d[t_k : t_k+H_p] ← π_θ(O_{t_k})                 # 规划轨迹
3:      for 每个控制步 t ∈ [t_k, t_{k+1})  (1000 Hz) do
4:          x_d ← S(X_d, t)                               # 插值期望位姿
5:          计算位姿误差 e 与雅可比 J
6:          w_imp ← K e − D J q̇                          # 阻抗反馈
7:          τ_imp ← Jᵀ w_imp
            # --- 外部力旋量估计 ---
9:          r ← τ_meas − τ_model
10:         ŵ_ext ← (J Jᵀ + λ² I)⁻¹ J r
11:         w_slow ← LowPass(ŵ_ext)
            # --- 内模型预测（+ 门控更新，§2.3）---
13:         w_pred ← M_ϕ(z_{t−L:t})
            # --- 预测补偿 ---
15:         w_ff ← w_pred
16:         τ_ff ← Jᵀ w_ff
            # --- 力矩指令 ---
18:         τ ← τ_imp + τ_ff + τ_null
19:         施加 τ
20:     end for
21: end for
```

（对 `ϕ` 的惊讶门控梯度步发生在第 13 行附近，见 §2.3；打印的算法概括的是推理过程。）

## 6. 实验设置回顾

- **真实：** 7-DOF **Franka FR3**，桌面，2 个固定 RGB-D 相机，8 维动作（末端笛卡尔位姿 + 夹爪），数据 **30 Hz**，用 **Nintendo Switch Joy-Con** 遥操作。任务：抓取放置 **2.5 kg / 5 kg** 哑铃。演示在 2.5 kg 采集。
- **仿真：** **MuJoCo** Franka FR3，锤子 + 篮子位置随机，专家演示由运动规划生成，锤子质量扫描 0.1–10 kg。
- **基线：** **Vanilla DP**（单一标称质量训练）与 **Augmented DP**（域随机化质量，200 个 episode）。

## 7. 实现陷阱与复现风险

1. **准确的动力学模型是必需的。** `τ_model` 需要好的 `M, C, g`，尤其是**摩擦** `τ_fric`。摩擦出了名地难；坏模型会漏进 `τ_res` 并被误读为外力。要为真正的标定工作留预算。
2. **雅可比奇异。** 在接近奇异的位形附近 `(JJᵀ + λ²I)⁻¹` 由 λ 主导；力旋量估计退化。保持机械臂位形良好，且不要把 λ 设得太小。
3. **1000 Hz 的力矩控制基础设施。** 你需要实时力矩指令接口（FR3 libfranka / FCI）。纯位置臂无法运行 IMPACT。
4. **滤波/门控调参是耦合的。** η（滤波速度）、clip 界限、惊讶/速率阈值相互作用。η 太快或惊讶阈值太低 → 模型追噪声/抖动；太慢/太高 → 适应滞后。论文的取值（η_力=2.0，surprise≥5 N）是起点，因机器人而异。
5. **前馈一个错误的预测会失稳。** 若 `M_ϕ` 自信地错了，`τ_ff` 会*增加*扰动。门控是防护；在信任补偿前要验证它确实在负载变化时重新触发。
6. **`q̈̂` 估计。** 由编码器求加速度有噪（二次差分）。这里的滤波选择会影响 `τ_model`，进而影响残差。
7. **双频率同步。** 30 Hz 策略输出之间的位姿插值 `S(X_d,t)` 必须平滑；不连续会产生伪跟踪误差，可能被力旋量估计器误判为外力。

## 8. 超参数敏感性（定性）

- **`K`（刚度）：** K 越高 → 偏移越小但接触时力越大/柔顺性越差；IMPACT 的前馈让你能保持适中的 K 同时仍抵消负载。
- **`η` / 时间常数：** 决定 `w_slow`（*监督信号*）多快稳定——直接限制变化后模型多快能被正确训练。
- **惊讶阈值（5 N）：** 可塑性旋钮。越低 → 适应更小的负载变化但有追噪声风险；越高 → 忽略小的负载差异。
- **`L = 32` 历史：** 必须足够长以区分驱动力旋量的动态状态，足够短以满足实时推理。
