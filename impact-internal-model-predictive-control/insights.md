# 洞见 — IMPACT（概念内核）

这是最重要的文件。方法细节见 `method.md`；这里聚焦于这个思想*为何*有效，以及它代表了怎样的思维转变。

---

## 1. 核心思想，用大白话讲

机械臂在每个关节上本就有一个**力矩传感器或力矩估计**（Franka FR3 就有）。当机械臂握着重物时，关节会感到额外的拉力——一个机械臂自身模型无法解释的力矩。IMPACT 的洞见是：

> **你不需要在腕部装力传感器。关节感受到的那部分"多出来的"力矩——也就是你的机器人模型没有预测到的部分——*就是*外力，只不过被机械臂的几何投影到了关节空间。把几何反过来求逆，你就恢复出了力。**

然后，IMPACT 不是在外力已经把机械臂推偏之后才*反应*，而是**学会预测**它并*提前*顶住。第一次举 2.5 kg 哑铃时它会短暂"惊讶"并适应；之后每一次都以零延迟预补偿——正如你在第一次拎起后，就不再被牛奶盒的重量骗到。

---

## 2. 思维转变：*物体动力学应该住在哪里？*

最深刻的贡献是对操作技术栈中**职责划分的重新分配**。

```
                 隐式 / 显式（既有工作）                IMPACT
                 ───────────────────────────────         ──────────────────────
   策略          规划运动 + 编码力/动力学                  仅规划运动
   （学习）       （物体特有的过冲，或来自
                  力/力矩传感器的力目标）
                          │                                       │
   控制器        笨跟踪器（阻抗）                          智能：估计力、
   （固定）                                                在线学习物体动力学、
                                                          并前馈出去
```

既有工作把物体动力学塞进**学习到的策略里**。这是原罪：策略现在必须*为每个物体质量学习不同的行为*，因为举 5 kg 所需的过冲不同于 2.5 kg。物体质量是一个*连续的干扰变量*，它让数据需求爆炸，且永远无法泛化到训练分布之外。

IMPACT 则把物体动力学**移出策略，放进一个在线自适应的控制器里**。策略学习任务中*不变*的部分（"抓起哑铃放进篮子"这一几何），它在 2.5 kg 和 5 kg 时确实一样。质量相关的部分交给一个*专门为适应质量而设计*的机制。**让每个子问题各得其所。**

这正是为何在 0.2 kg 上训练的 IMPACT 击败了在 0.1–8 kg 上训练的 Augmented DP：当问题本身有可利用的*结构*（牛顿动力学）时，数据多样性是对抗它的*钝器*。

## 3. 为何有效——三个相互配合的机制

### (a) 力矩残差求力——把机械臂方程当作传感器

机械臂方程 `M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + τ_ext` 被重排：算出你的*模型*预测的力矩（`τ_model = Mq̈̂ + Cq̇ + g + τ_fric`），从测得力矩中减去，残差 `τ_res = τ_meas − τ_model = τ_ext` 就是外部力旋量在关节空间的影子。对 `Jᵀ` 做正则化最小二乘逆即可恢复 6 维力旋量：
`ŵ_ext = (JJᵀ + λ²I)⁻¹ J τ_res`。
**机器人自身的动力学模型变成了一个虚拟力传感器。** `λ²` 正则化处理雅可比接近奇异、逆会爆炸的位形。

### (b) 慢/快分解——把"要学什么"和"噪声"分开

原始力旋量估计是带噪的（模型误差、传感器噪声、瞬态接触）。一个一阶**低通滤波器**把它拆开：**慢分量** `w_slow` = 值得建模的持续效应（重力、稳态接触）；快瞬态 = 忽略。只有慢分量去监督内模型。这是让在线学习*稳定*而非追逐噪声的关键设计选择。

### (c) 内模型 + 惊讶门控——预测，而不只是滤波

这里有一个许多读者会忽略的微妙之处：**如果 `w_slow` 已经捕捉到了负载，为何还要学一个模型？** 因为低通滤波器是*故意做得慢*的（为了杀噪声）——所以在负载变化后它会严重滞后。内模型 `M_ϕ(z_{t−L:t})` 学习把*近期状态历史 → 慢力旋量*的映射，于是一旦学会，它在识别出已知条件时能**立即**输出正确补偿，**无需等待**滤波器重新收敛。

**惊讶门控**是优雅的调速器：仅当预测误差很大（surprise ≥ 5 N）且力旋量在稳定下来（slow-wrench rate ≤ 0.2）时，才用梯度下降更新 `M_ϕ`；否则冻结。这同时买到两个通常对立的性质：
- **可塑性** —— 新负载（5 kg）→ 大惊讶 → 快速重新学习。
- **稳定性** —— 已知负载 → 无惊讶 → 权重冻结 → 不漂移、不追噪声。

这是对稳定性-可塑性困境的极简回答，且在精神上直接对应小脑（小脑根据感觉预测误差来更新）。

## 4. 小脑类比是承重墙，不是装饰

人类**没有腕部力传感器**，却能以同样平滑的控制举起羽毛和砖头。神经科学（Wolpert、Kawato、Imamizu）认为**小脑构建身体和被操作物体的内部前向/逆模型**，并用它们对重力等可预测扰动做**前馈**（预判式）补偿。IMPACT 是这一思想几乎逐字的工程转写：

| 小脑假说 | IMPACT 组件 |
|----------|-------------|
| 无专用力传感器；从本体感觉推断负载 | 从关节力矩残差估计力旋量 |
| 物体动力学的内模型，经练习精炼 | `M_ϕ` 在线梯度下降训练 |
| 根据*感觉预测误差*更新 | 惊讶门控（仅当预测误差大时更新） |
| 前馈以抵消*可预测*扰动 | `τ_ff = Jᵀ w_pred` 预判式施加 |
| 反馈处理不可预测的剩余部分 | 阻抗控制器 `τ_imp` 仍在底层运行 |

该架构是前馈预测*叠加在*反馈柔顺之上——与生物学使用的分层结构相同。

## 5. 权衡（你付出的代价）

- **需要关节力矩感知/良好的力矩估计。** Franka FR3 有；廉价的纯位置臂没有。所以 IMPACT 是用*腕部*传感器换*关节*力矩感知——协作/力矩控制臂上往往已具备，但不是免费的。
- **需要一个合理的动力学模型**（`M, C, g, τ_fric`）来计算残差。模型误差会直接污染力旋量估计（被 λ 和低通滤波部分吸收，但无法消除）。
- **两个时间尺度要调。** 低通速率 η 与惊讶/门控阈值相互作用；门控太激进会抖动，太保守会滞后。论文取固定值（η ≈ 2 s⁻¹ 力，surprise ≥ 5 N）。
- **前馈一个*错误*的预测是危险的。** 一个自信而错误的内模型会注入*增加*扰动的力矩。门控缓解了这一点，但它是主要的安全相关失败模式。
- **高控制频率。** 内环以 **1000 Hz** 运行（对比策略 30 Hz）——需要实时力矩控制基础设施。

## 6. 局限与诚实的适用范围

- **仅限刚体 + 准静态负载。** 内模型捕捉重力、接触刚度、摩擦——这些量在*给定位形下*大致*恒定*。它**无法**建模可变形物体、流体或颗粒介质，它们的力依赖于关节力矩无法区分的内部状态（变形场、流动）。
- **"慢变"假设。** 整个慢/快拆分假设待补偿的力相对控制环变化缓慢。快速动态力（冲击、快速晃动）会被*设计性地滤掉*——它们被当作反馈处理的扰动，而非要预测的对象。
- **内模型是回归器，不是物理模型。** 它记忆一个状态→力旋量的映射；它不会向真正新颖的动力学*外推*，只能（经门控）在亲身经历后重新适应。

## 7. 与既有工作的对比

| 方法 | 力硬件 | 动力学在哪里学 | 能泛化到新质量？ |
|------|--------|---------------|------------------|
| Vanilla / 隐式 DP | 无 | 策略内（过冲） | 差（记忆式） |
| 显式力/力矩传感器策略 | 腕部力/力矩传感器 | 策略内（力目标） | 较好，但受硬件约束 |
| 数据增强（Augmented DP） | 无 | 策略内，更多数据 | 仅在训练范围内 |
| 经典阻抗控制 | 无 | 无（无补偿） | 否——稳态误差 |
| 自适应控制 / HIM（足式运动） | 关节力矩 | 在线估计器 | 是（最近亲） |
| **IMPACT** | **仅关节力矩** | **控制器内的在线内模型** | **是，且超出训练范围** |

最近的亲戚是**经典自适应控制**和足式运动中的**混合内模型（Hybrid Internal Model）**思想（参考 [59,60]，部分作者重合）。IMPACT 的新意在于把在线内模型补偿带入*基于学习的操作*技术栈，并将其与扩散策略干净地解耦，外加面向操作尺度力的惊讶门控更新规则。

## 8. 实践意义

- **从轻负载演示做重负载操作。** 用轻工具采集演示；部署到重工具上。巨大的数据效率收益。
- **无需力传感器即可做工具使用/富接触任务**——在具备力矩能力的臂上可行。
- **安全与能量：** 前馈补偿让机械臂贴近规划轨迹，而非累积大的阻抗力，减少偏移和能量浪费——对人机协作场景很重要。
- **可复用的控制器模块：** 内模型控制器与策略无关。它可以放在*任何*产生轨迹的策略（扩散、VLA、脚本）之下，成为力交互任务的即插即用升级。

> **要记住的一个思想：** *不要让学习到的策略去记忆它无法泛化的物理。用你已测得的力矩恢复力，用惊讶门控更新在线学习预测其持续部分，并前馈出去——这就是小脑的配方，写成代码。*
