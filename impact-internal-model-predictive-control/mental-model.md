# 心智模型 — 如何思考 IMPACT

## 这是*哪一类*问题？

本质上，它是一个穿着现代机器人学习外衣的**扰动抑制 / 自适应控制**问题：

> *一个学习到的策略规划运动。一个未知的、物体相关的力（负载、接触）扰动执行。我们如何在 (a) 不用力传感器、(b) 不把扰动烤进策略里 的前提下抵消这个扰动？*

认清这一点会重新框定这篇论文："学习"这个标题是真的，但**承重的机器是经典控制**——基于模型的力估计、低通滤波、前馈补偿、在线适应。神经网络（`M_ϕ`）是一个小的自适应回归器，不是主角。

## 假定的先验知识

要顺畅读懂方法，你应该熟悉：

| 领域 | 具体概念 |
|------|----------|
| **机械臂动力学** | `M(q)q̈ + Cq̇ + g = τ + τ_ext`、雅可比 `J`、`τ = Jᵀw` 对偶 |
| **阻抗/柔顺控制** | 刚度 `K`、阻尼 `D`、`w = Ke − Dẋ`、稳态误差 `F = Ke` |
| **SE(3) / SO(3)** | 位姿误差、`Log` 映射到轴角 |
| **最小二乘与正则化** | 伪逆、Tikhonov/`λ²I` 阻尼 |
| **信号处理** | 一阶低通滤波器、时间常数、慢/快分解 |
| **模仿学习（概念）** | 扩散策略、滚动时域轨迹输出——你*不*需要扩散的数学 |
| **在线学习** | 执行中的梯度下降、稳定性-可塑性 |

如果你缺控制理论那一半，先读 `insights.md` §3——它不靠方程传达*为何*。

IMPACT 是一篇**桥梁论文**。它正好坐落于三个传统的交汇处，并从每一处取一个思想：*策略*来自机器人学习，*估计器/前馈*来自控制理论，*惊讶门控的在线内模型*来自小脑神经科学。

## 如何归类这项工作（分类槽位）

- **子领域：** 基于学习的力交互/富接触操作。
- **贡献类型：** *架构/框架*（一种新的分解），而非新的策略类别或新数据集。
- **力处理类别：** 在该领域"隐式 vs 显式"二分法之外的**第三种选择**——称之为**"估计 + 预测"**（无传感器估计 + 学习的前馈预测）。
- **最近的亲戚：** 足式运动的混合内模型 [59,60]（同源血统）、经典自适应控制、基于残差力矩的外力估计（动量观测器）。
- **它*不是*什么：** 不是新的扩散策略，不是触觉感知论文，不是 RL 论文。策略是现成组件。

## 锁定理解的三个类比

1. **拎牛奶盒。** 第一次拎你会估错并猛地一抖（惊讶门控触发，模型适应）。之后你会恰好预先发力（冻结模型，前馈）。倒掉一半再拎——你又会短暂被骗（门控重新触发）。那*就是* IMPACT 的三阶段协议。

2. **把机器人自己的肌肉当秤。** 你不在物体下面放秤；你读*关节*工作得多吃力（力矩残差）来推断重量。机械臂用自己的力气称物体。

3. **定速巡航 vs 好司机。** 纯阻抗控制是定速巡航，在坡道让你减速*之后*才反应（爬坡时的稳态误差）。IMPACT 是一个*看到坡道将至*的司机，提前踩油门（前馈）——并且在开过一次后*学会*每个坡的陡度。

## *这个*心智模型的阅读顺序

1. 牛奶盒类比（上文）——直觉。
2. `summary.md` —— 问题与结果。
3. `insights.md` §2–§4 —— 解耦转变 + 小脑映射。
4. `method.md` —— 图景建立后再看方程。
5. 运行 `code/internal_model_demo.py` —— *亲眼看见*门控触发。

## 什么会改变你的心智模型

- 如果你以为内模型 `M_ϕ` 又大又强（它不是——它是个小的在线回归器），你会把这重新归为学习论文。它是刻意极简的。
- 如果没有力矩感知，整个"虚拟力传感器"就崩塌，你又会退回到显式硬件。该方法的全部立足点是**关节力矩可观测性**。
