# 反思 — IMPACT

自动生成的批判性反思：扩展、脆弱假设、失败模式、开放问题。

---

## 如果我来扩展这篇论文

1. **让内模型*感知位形*且具物理结构。** 目前 `M_ϕ` 是对近期状态的黑箱回归器。换成一个结构化估计器（例如把物体质量 + 质心 + 惯量估计为隐参数并代入机械臂方程）会带来真正的*外推*——预测从未访问过的位形下的力旋量，而不只是经历后才重新适应。

2. **不确定性感知的前馈。** 让 `M_ϕ` 输出置信度/方差，并按它缩放 `w_ff`（`w_ff = α·w_pred`，`α∈[0,1]` 来自置信度）。这直接攻击"自信而错误的前馈使系统失稳"的失败模式，并能用一个软的、有原则的门控替代硬的惊讶阈值。

3. **把内模型反馈回策略/规划器。** 估计的负载是丰富的任务信息。一个*以*当前内模型状态*为条件*的策略，可以对重物 vs 轻物选择质的不同策略（如重新抓取、支撑、双臂），而不仅仅是更好地跟踪。

4. **多接触 / 全臂。** 把力旋量估计从单一末端力旋量扩展到分布式接触（残差本就是全臂的）。对接触中的机动、倚靠、支撑很有用。

5. **跨本体的内模型迁移。** 既然内模型小且有物理依据，在一只臂上学到的模型能否启动另一只？一个按物体索引的内模型"库"会把一次性适应变成零次识别。

6. **触觉/视觉融合以突破刚体限制。** 加一个以视觉/触觉特征为条件的学习残差来处理可变形物——视觉预测*是什么类型*的物体，触觉/力矩精炼力。

## 脆弱的假设

| 假设 | 为何脆弱 | 一旦失效 |
|------|---------|----------|
| **准确的动力学模型** `M, C, g, τ_fric` | 摩擦和未建模动力学很难；`q̈̂` 来自编码器二次差分，有噪 | 建模误差漏进 `τ_res` 并被误读为外力 → 错误补偿 |
| **关节力矩可观测性** | 廉价/纯位置臂没有 | "虚拟力传感器"崩塌；方法不适用 |
| **待补偿的力缓慢变化** | 经低通设计性地保证；冲击、晃动、快速接触切换是快的 | 快速力被滤掉且未补偿；依赖反馈吸收 |
| **良态雅可比** | 接近奇异时 `(JJᵀ+λ²I)⁻¹` 由 λ 主导 | 恰恰在几何尴尬时力旋量估计退化 |
| **物体动力学 ≈ 刚体** | 可变形/流体/颗粒违反它 | 内模型没有可学的有效目标 |
| **惊讶门控可靠地重新触发** | 阈值调参因机器人而异 | 漏检负载变化 → 陈旧前馈 → 误差增长；过敏 → 抖动 |

## 实践中的失败模式

- ***未被检测到的*负载变化后的陈旧预测** —— 若质量变化产生的力旋量增量低于 5 N 惊讶阈值（如小工具），模型永不更新，前馈微妙地错。
- **前馈对抗扰动** —— 错误符号或过大幅值的预测会注入能量；在负载变化时刻、门控赶上之前最糟。
- **低速时的摩擦/静摩擦** —— `τ_fric` 模型在零速附近最弱；静摩擦任务（缓慢精确按压）可能见到有偏估计。
- **门控抖动** —— 若阈值相对噪声太紧，门控会开关跳变，产生间歇前馈和顿挫运动。
- **接触切换** —— 建立/断开接触是个*快*事件，慢滤波器会抹掉它；接触起始时短暂误补偿。
- **策略/控制器频率不匹配的伪影** —— 不平滑的插值 `S(X_d,t)` 注入位姿误差瞬态，估计器可能误归因为外力。

## 这引出的开放问题

1. **用无传感器力预测做软体/可变形操作** —— 论文明确的"未来工作"。需要某种物体内部状态的概念。
2. 耦合（在线学习 + 前馈 + 阻抗）环的**理论稳定性保证**。在实时控制环内做在线适应是已知的稳定性雷区；论文经验性地验证但未给出 Lyapunov 式保证。
3. **有原则的、自调谐的门控** —— 用自适应/不确定性驱动的准则替代手设阈值（5 N、0.2）。
4. **"结构胜过数据"能走多远？** IMPACT 展示了对*质量*而言物理结构胜过数据增强。还有哪些干扰变量（摩擦系数、表面柔顺性）适用同样处理，结构化方法在哪里不再划算？
5. **动力学模型的 sim-to-real** —— 残差方法的精度取决于模型与现实的匹配；量化并缩小那个差距本身就是一条研究线。

## 它在真实世界可能在哪里失败（部署视角）

- **动态/高速任务**（投掷、带冲击的锤击）—— 快速力恰恰是滤波器移除的。
- **高度可变的摩擦表面**（湿、油、颗粒）—— 摩擦模型误差主导。
- **低成本机器人** —— 无关节力矩感知 → 无从谈起。
- ***规划本身*必须随质量改变的任务** —— IMPACT 保持策略固定；若 5 kg 确实需要不同的*运动*（而非只是更大的力），纯力补偿不够。

## 一段怀疑者的批评

"学习"的框架略微高估了它的本质——其核心其实是**经典的基于模型的外力估计 + 自适应前馈**——动量观测器式的力估计和前馈重力补偿已有数十年历史。真正新颖的部分是 (1) 针对操作尺度力调谐的*惊讶门控在线回归器*，以及 (2) 与现代扩散策略的干净*解耦*并具强经验泛化。这些是真实且有用的贡献，但论文若能加一个消融来隔离"仅估计 + 慢力旋量前馈"（无内模型）vs "完整内模型"，将更有力，从而量化学习预测器相对于直接前馈 `w_slow` 究竟增加了多少。三阶段分析暗示模型重要（零延迟重新补偿），但缺一个正面对比的数字。
