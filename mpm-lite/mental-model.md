# 心智模型：如何在脑中安放 MPM Lite

## 1. 这是什么类型的问题

**连续介质弹塑性仿真**，采用**混合 Lagrangian-Eulerian 离散**。具体落点：

- 物理对象：可变形固体（弹性、弹塑性、断裂）+ 部分流体（无黏水），覆盖大变形、自接触、拓扑变化。
- 数学骨架：动量守恒方程的弱形式（Galerkin），用时间离散（显式前向 Euler / 隐式后向 Euler 增量势优化）+ 空间离散（粒子载体 + 背景网格 + 胞心求积）求解。
- 工程定位：一个**仿真器/求解器架构**论文，不是新材料模型、不是新渲染。贡献在"如何切分计算"，而非"算什么"。

把它归类为：**"对 MPM 离散结构的重构"**，目标是把"求积"从"状态载体"中解耦出来。

## 3. 一句话心智图

> **"把 MPM 改造成体素网格上的单点六面体 FEM，让粒子退回 FLIP/PIC 流体里那种'纯标记物'的角色。"**

如果你熟悉 FLIP/APIC 流体：那里粒子只携带速度、辅助平流，真正的求解（投影、Poisson）在网格上做。MPM Lite 把固体也拉进这个范式——只是网格上的"求解"从 Poisson 换成了**六面体 FEM 弹性增量势**。固体比流体多记的东西（应变、应力、材料历史）由粒子在 Unload 时**忠实重采样**到胞心，于是网格求解期间不再需要粒子。

## 4. 它在研究地图中的位置

```
                      连续介质仿真
                          │
        ┌─────────────────┼──────────────────┐
        │                 │                  │
   纯 Lagrangian      混合 L/E            纯 Eulerian
     (FEM 网格)            │              (网格流体)
        │          ┌───────┴───────┐           │
        │          │               │           │
     标准 FEM     MPM            FLIP/APIC 流体
   (固定 Gauss   (粒子=求积       (粒子=标记物,
    求积, 节点    + 状态载体,       网格=求解)
    形函数,        宽 B-spline)        │
    干净边界)         │                │
        │            │                │
        └────────────┴────► MPM Lite ◄┘
              "MPM↔FEM 收敛点"
        粒子=状态载体(像 FLIP),
        求积=固定胞心+紧致线性核+网格 FEM(像 FEM)
```

**两条收敛线**：
1. **MPM → FEM**：MPM Lite 承袭"网格求积谱系"（Sulsky & Gong 2016、Al-Kafaji 2013），把积分搬到固定网格点，最终样子就是单点六面体 FEM。它补全了"MPM 是伪装的 FEM"这句话——现在它**真的**有了 FEM 的稀疏性、边界语义和求解器生态。
2. **固体 ↔ FLIP/PIC 流体类比**：粒子降级为标记物，这正是流体侧早已采用的设计。MPM Lite 把这个设计扩展到需要记忆应变/应力的固体上，关键创新是"如何让标记物忠实重采样应力"——答案是重采样广延 $V\tau$ + 旋转无关拉伸重建。

## 5. 如何归类这项工作

- **不是**："又一个 MPM 变体调了核函数"。CK-MPM、B-spline、IGA-MPM 都在"传输核"层面做文章，仍保留粒子求积。MPM Lite 在**计算架构**层面动刀：去掉粒子求积本身。
- **是**：一次"关注点分离"（separation of concerns）——把"运动学状态追踪"（粒子的职责）与"力积分/时间推进"（网格 FEM 的职责）解耦。这种解耦带来的最大红利是**求解复杂度与 PPC 无关**。
- **类比其他领域**：像把"数据存储"与"计算引擎"分层——粒子是存储层（带历史），网格 FEM 是计算层（无状态、可换求解器）。胞心是两层之间的**序列化/反序列化接口**（Unload/Load）。

## 6. 读论文时该带的问题

1. 重采样什么量才能既守恒又不被旋转污染？（答：广延 $V\tau$）
2. 隐式需要 $F$，但我们没存胞心 $F$，怎么办？（答：从 $\tau_c$ 旋转无关地重建拉伸 $S_c$）
3. 丢弃旋转会引入多大误差？（答：$O(\Delta t^2)$/步，对各向同性客观）
4. 为什么线性核不再导致穿胞不稳定？（答：求积不在粒子上，力对高频粒子运动不敏感）
5. 为什么不用速率形式隐式应力？（答：Jaumann 项使 Jacobian 非对称，不源于势能，不适合优化求解器）
