# 批判性反思与延伸：MPM Lite

## 1. 如果让我延伸这篇工作

### 1.1 突破各向同性限制
旋转无关拉伸重建的整条逻辑链依赖**各向同性**（能量只通过奇异值起作用 → 旋转无关 → 可从 $\tau$ 反演拉伸）。一个自然的延伸方向是：

- **各向异性 / 纤维增强材料**：能量依赖纤维方向，旋转不再无关。能否引入"重采样纤维取向 + 应力"的联合方案？广延量分析仍适用，但反演不再闭式。需要研究：丢弃哪部分旋转、保留哪部分（沿纤维的旋转必须保留）。
- **正交各向异性壳/布**：薄结构 MPM（Guo 2018）能否纳入这一框架？

### 1.2 更广的本构闭式反演
论文只给了 StVK-Hencky 与 split Neo-Hookean 的闭式 $\tau\to\sigma_i$。延伸：

- 建立**通用的谱反演求解器**（牛顿迭代解 $\tau_i=\sigma_i\partial\hat\psi/\partial\sigma_i$），让任意各向同性 $\psi$ 即插即用，代价是每胞一次小规模标量牛顿。
- 研究反演的**适定性边界**：哪些能量的 $e\mapsto\tau$ 映射非单调（非严格凸于对数拉伸），导致多解或无解？

### 1.3 高阶求积
当前是体素胞心**单点求积**。能否在胞内放多点求积（如 2×2×2 Gauss）提升精度阶，同时保持"求解成本与 PPC 无关"？这会把 MPM Lite 进一步推向标准高阶 FEM。

### 1.4 自适应/八叉树网格
胞心求积天然适配自适应细化。延伸到八叉树/稀疏网格，配合 multigrid 预条件，可能在大场景下进一步放大隐式优势。

### 1.5 可微分与逆向设计
to-element 装配与可微流水线对齐。一个具体延伸：把 MPM Lite 作为可微仿真器骨架，研究"粒子 Unload/Load 是否引入额外梯度噪声"，对比可微 MLS-MPM（Hu 2020）。

## 2. 开放问题

1. **旋转丢弃的长时累积**：单步误差 $O(\Delta t^2)$ 是局部的。在持续高速旋转、长时积分的场景（如高速旋转刚体附近的软体），这些误差是否会系统性累积、漂移？论文未给长时误差界。
2. **多材料界面的应力重采样**：colocated 求积 $(V_{c,k},\tau_{c,k})$ 共享速度。在强对比材料界面（如 Wheel 中 $E=10^8$ 与软体接触），单值速度 + 分材料应力是否会在界面引入伪应力或锁定？
3. **数值断裂的真正来源**：论文用高 PPC 抑制数值断裂，并指出 MPM Lite 求解成本与 PPC 无关。但断裂抑制是否仍要求高 PPC 在 **Unload 传输**阶段付出线性成本？也就是说，是否只是把成本从"每次迭代"挪到了"每步一次的传输"？（净赚明确，但传输本身仍 $\propto$ PPC。）
4. **塑性 return mapping 与拉伸重建的相互作用**：塑性在粒子上做（更新 $F_p$），但隐式弹性预测在胞心用重建的 $S_c$。塑性与弹性预测分处不同位置/表示，二者一致性如何严格保证？
5. **water 的 $J_{\text{base}}$ 反演分支**：公式 38 取了 $+$ 根（$J>0$）。在强负压（拉伸开裂）下 $1+4\pi_c/\kappa$ 可能为负，此时如何处理？

## 3. 脆弱的假设

| 假设 | 脆弱点 | 影响 |
|------|--------|------|
| **各向同性** | 拉伸重建的命门；各向异性直接失效 | 限制材料范围 |
| **能量严格凸于对数拉伸**（StVK-Hencky 特例） | 一般能量 $e\mapsto\tau$ 可能非一一对应 | 反演可能多解/无解 |
| **$F_{\text{base}}$ 重建是近似** | 只重建拉伸、丢旋转；$O(\Delta t^2)$ 但非精确 | 旋转主导场景累积误差 |
| **小弹性变形假设**（论文承认弹塑性材料塑性前弹性变形极小） | 选 $\psi$ 主要为闭式 return mapping，非匹配真实非线性弹性 | 大弹性变形纯弹性体精度存疑 |
| **mass lumping** | 集中质量矩阵 | 引入一致质量该有的部分精度损失 |
| **单点求积** | 体素单元单点 | 可能 hourglass 模式 / 精度阶受限（论文未深入讨论沙漏控制） |
| **线性核 $O(\Delta x^2)$ 一致** | 依赖局部速度场 Lipschitz 光滑（附录 A） | 强不连续/冲击界面处假设可能破坏 |

## 4. 实践中可能失效的场景

1. **强各向异性材料**（肌肉纤维、编织布、木材）：拉伸重建无闭式，需重新推导甚至不可行。
2. **高速旋转 + 长时积分**：丢弃旋转的误差累积可能可见（虽然单步 $O(\Delta t^2)$）。
3. **大弹性变形的纯弹性橡胶**：论文的 $\psi$ 选择偏向"塑性主导"，纯弹性大变形下的精度未充分验证。
4. **极端材料对比的多材料界面**：colocated 单值速度可能锁定或产生界面伪影。
5. **强拉伸开裂的流体**（$J\ll1$ 或负压）：water 的 $J_{\text{base}}$ 反演判别式可能为负。
6. **沙漏（hourglass）不稳定**：单点六面体单元的经典病，论文未明确给出沙漏控制方案——在低约束、纯弹性、细长结构上可能出现伪零能模式。
7. **非常低 PPC**（<8）：虽然求解成本与 PPC 无关，但 Unload 重采样在极低 PPC 下统计不足，$\tau_c$ 估计噪声大，可能影响重建质量。

## 5. 我会做的第一个验证实验

复现 Fig. 5 的 PPC 曲线之前，先做两个微型单元测试（见 code/）：
1. **守恒检验**：随机生成胞内多粒子，验证 $\sum_c V_c\tau_c=\sum_p V_p\tau_p$ 到机器精度，并对照"平均 $F$"方案显示其破坏守恒/产生伪应力。
2. **往返检验**：给定 $F$ → 算 $\tau$ → 重建 $S$ → 验证 $P(S)S^\top=\tau$，并验证 $S$ 与 $F$ 的极分解拉伸一致（差异仅来自旋转丢弃）。

这两个测试若不过，后续任何性能数字都无意义——它们是整套方法正确性的地基。
