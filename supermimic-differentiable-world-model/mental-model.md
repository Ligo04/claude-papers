# 用什么思路理解这篇工作

## 它是一种控制训练方法

SuperMimic 的世界模型服务于训练控制器。训练数据是机器人状态转移，不是视频帧；任务是闭环执行参考动作，而不是生成看起来像真的影片。部署示例运行策略，不需要实时展开一个 32 步世界模型再做在线规划。

学习它时始终分清四个对象：仿真器产生数据，模型预测动作后果，策略选择动作，critic 估计短期窗口之外的价值。

## 把原来昂贵的部分分别看

PPO 的采样成本包含物理步进，也包含需要很多动作试探才能得到有效更新的成本。SuperMimic 对这两项分别处理：学习模型加速轨迹生成，模型导数改进策略更新的数据效率。跨动作共享物理进一步摊薄模型训练的代价。

它并没有让 MuJoCo Warp 本身加速，也没有免掉仿真数据采集。把学习模型的速度写成原始物理引擎速度，会误解实验。

## 先修知识

| 概念 | 需要理解到什么程度 |
| --- | --- |
| MDP/POMDP | 真实状态与策略可见观测可能不同 |
| 目标条件策略 | 同一观测搭配不同参考目标可以产生不同动作 |
| replay buffer | 旧策略数据仍可监督不随策略改变的动力学 |
| 自动微分和 BPTT | 梯度能穿过多个时间步，参数冻结不等于截断输入梯度 |
| actor-critic | actor 改动作；critic 近似长期回报 |
| 域随机化 | 训练覆盖一组物理参数，缓解部分 sim-to-real 偏差 |

## 研究位置

可以把它放在“学习动力学 + 短期可微 actor-critic + 多动作全身控制”的交集。它沿用了 Dyna 式从 replay 状态开始 imagination 的组织方式，与 SHAC 式短时域反传接近；世界模型不由物理求解器提供，而从标准仿真日志学习。

和直接对接触求解器求导相比，这样更容易复用现有仿真后端，却引入预测和 Jacobian 偏差。和 PPO-WM 相比，差别主要是用模型导数还是在模型内继续做采样式策略梯度。和专家蒸馏相比，模型直接共享物理，下游接口也能根据自己的奖励优化。

## 读懂论文的自检

能够解释这几个问题，就掌握了方法：为什么目标不同却能共享动力学；为什么模型每次只拟合 8 步而策略展开 32 步；critic 如何影响窗口之后的后果；为什么 0 失败仍然不等于未见动作泛化；为什么卡时、rollout 吞吐和策略样本效率不能当成同一个数字。
