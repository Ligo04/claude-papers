04证据支持到哪里

§4–6 · 附录 G

论文已报告

  • 平地动作库的低资源训练与覆盖率提升。
  • 常用批量下世界模型 rollout 吞吐超过仿真器 10 倍。
  • 特定子集上，解析更新约少用 64 倍想象步。
  • 一个跟踪策略在 G1 真机上展示跳跃、侧滚和翻转。

还不能据此推出

  • 未见动作、不同机器人或复杂地形上的同等扩展规律。
  • 全部 129,514 条动作都在真机零失败。
  • 模型继承物理求解器的接触与不相交保证。
  • 约 7200 倍同硬件吞吐、推理速度或能耗收益。
为什么小预测误差不保证梯度可靠？

模型也可能含有幅度很小、频率很高的误差。以教学反例 f̂(a) = f(a) + ε sin(Ka) 为例，数值误差至多 ε，导数误差却能达到 εK。论文的 0.007–0.011 是在线归一化状态预测误差，不是 Jacobian 精度保证。

官网与 PDF 的分组为什么不同？

固定版本 PDF 表 A.8 单列 20 条 fire-in-the-hole turns，失败为 3 / 3 / 0。官网把这组并入“其他”，所以官网“其他”为 129,307 条、失败 53 / 14 / 0，PDF 为 129,287 条、失败 50 / 11 / 0。本页完全使用 PDF 分组；合计一致。

这份学习包验证了什么？

原文版本、页码与表格已经核对。独立 CPU 演示检查模型冻结、BPTT 与有限差分，并观察教学系统的控制误差。未运行作者训练、H100 benchmark 或 G1 真机实验。官方网页 demo 的专有许可不能当作公开训练源码。
