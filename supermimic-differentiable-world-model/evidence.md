## 官网分组与 PDF 分组

PDF 表 A.8 单列 `fire-in-the-hole turns`，20 条，失败数为 3/3/0。官网把这一组并入其他动作，因此官网“其他”为 129,307 条、失败 53/14/0，PDF 为 129,287 条、失败 50/11/0。总量和总失败数一致。这是展示分组的差别，不是总结果相互矛盾。

本学习包 `data.json`、交互图与表格统一采用 PDF 分组。没有把官网分组与 PDF 行混合相加。组总数与每列总失败数由本地验证程序计算检查。

## 本地验证做了什么

- `pdfinfo`、PyMuPDF 与 SHA-256 核对文件，保存完整文本。
- 检查 15 道问答、全部必需文件、恰好两个标签、所有数据分组的合计和文档内部链接。
- 运行 CPU 教学程序，检查有限差分、模型冻结、梯度传递以及教学真实环境的控制误差变化。
- 初次教学程序在模型拟合精度检查失败。诊断发现拟合已接近浮点精度后，模型 Adam 学习率 0.02 引发震荡；仅把该教学学习率改为 0.002，保留原精度门槛和物理系统后通过。这个参数不对应论文超参数。
- 检查单文件 HTML 的内嵌数据、脚本语法和外部依赖；浏览器结果另存验证记录。
- 用锁保护并原子追加学习库索引，保留已有条目并保存原索引备份。

具体运行版本、误差和 UI 检查见 `sources/demo-results.json`、`sources/validation.json` 和 `sources/browser-checks.json`。若其中缺少某项结果，应视为尚未完成该项，而不是自动通过。
