论文 IV-D

三个指标分别回答什么？

仿真成功率 = (TP + FP) / n，只看模拟器有多少成功。Agreement = (TP + TN) / n，检查是否预测同一案例。BA = ½[TP/(TP+FN) + TN/(TN+FP)]，给予真实成功和失败同等权重。恒定预测在两个类别都存在时 BA 为 50%。

TP：两域都成功；TN：两域都失败；FP：仿真成功、真实失败；FN：真实成功、仿真失败。两种 Wrap 阈值使用同一批 55 个案例，不能当成 110 个独立案例。
