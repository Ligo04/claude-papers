# 怎样在脑中组织 TapeSim

这篇论文属于接触丰富的物理仿真，主要问题是如何分配运动自由度。胶带的大量材料仍卷在一起，真正需要独立变形的位置集中在释放前沿和自由带上。分区跟着材料释放过程更新。

可以沿胶带材料坐标想象三段相连的区域：

```text
卷内 cluster      collar              已放出的薄壳
共享 6 DOF        可以弯曲并解除黏附    可以贴到新目标
            随剥离推进而缩小   →   自由区单调增长
```

## 必要知识

| 概念 | 在这里的作用 |
| --- | --- |
| 薄壳膜能量与弯曲能量 | 表达胶带背材拉伸和弯曲；平坦材料形状是 rest state |
| 隐式积分 | 每步通过一个增量势能优化求状态 |
| IPC barrier 与 CCD | 分别提供接近接触时的斥力和避免求解更新穿越的限制 |
| Newton、PCG 与停止准则 | 决定实际算到多精确，影响成本与运动 |
| 刚体运动学及链式法则 | 将外部接触力与曲率映射到 cluster 的 6 个坐标 |
| 状态机与图距离 | 在步边界更新 bond、释放前沿和 collar |
| 混淆矩阵 | 判断模拟器是否预测了同一批成功和失败案例 |

## 与相关方向的关系

IPC 提供薄壳接触优化基础；黏附 IPC 在其上添加黏附历史；adaptive rigidification 根据材料状态减少独立变形；TapeSim 把分区规则具体绑定到放带前沿。它保留细碰撞几何，同时改变部分几何的运动参数化。

它借用了 ABD-type bond 能量，但 cluster 使用刚体坐标。它可以参与机器人策略评估，但主体贡献不是策略学习或可微训练。论文引用的 RealSimLoop 会在线适配材料，TapeSim 的配对评估则固定胶带模型，检验冻结策略的预测结果。

## 三个自检

1. 把 cluster 整体旋转，卷内相对形状不变，内部项为何还要逐对求解？这解释减少内部项的动机。
2. 只刚化而不恢复自由度，材料怎样离卷？这解释 collar 和前沿更新的必要性。
3. 仿真和真实各有 4 次成功，共同成功却只有 1 次，这是否算准确预测？这解释配对指标的必要性。
