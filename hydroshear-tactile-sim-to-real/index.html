递归力追踪器 F 的五步（每个压头表面点 j，每个时间步）

1️⃣ 接触内位移截取（式 6–7）
α = [ReLU(−φ_E(o_t)) − ReLU(−φ_E(o_{t−1}))] / [φ_E(o_{t−1}) − φ_E(o_t)]
d = α·(o_t − o_{t−1})
两帧膜内 α=1；膜外 α=0；跨界 0<α<1。把"接触开/关"离散事件连续化，无分支，GPU 友好。
2️⃣ 法向/切向分解
dⁿ = ⟨d, n̂⟩；d^xy = d − dⁿ·n̂   (n̂ = 压头表面法向)
3️⃣ 弹性累积（式 8–9）→ stick 阶段剪切 build-up
fⁿ ← f̃ⁿ + E·A·dⁿ；  f^xy ← f̃^xy + K·A·d^xy
4️⃣ 单边约束 + 库仑摩擦锥截断（式 10–11）→ slip
f̄ⁿ = ReLU(fⁿ)；  f̄^xy = min{1, μ·f̄ⁿ/‖f^xy‖}·f^xy
切向力触顶 μf̄ⁿ 即滑移：力停止增长（增量 return mapping，塑性力学经典结构）。
5️⃣ 脱离重置（式 12）
f̃ = H(−φ_E(o))·(f̄ⁿ·n̂ + f̄^xy)   (H = Heaviside)
离开膜即清零——下一次接触重新累积。
⚠️ 复现提示：论文式 6 分母按原文为 φ_E(o_t)−φ_E(o_{t−1})，验算"两帧均在膜内"得 α=−1，与其自述 α=1 矛盾；正确符号应为 φ_E(o_{t−1})−φ_E(o_t)（本页 JS 与配套 Python demo 均已按正确符号实现并验证）。

一器两用（式 13–15）

f̂ = F(...; 1,1,1,μ̂) → 投影点 ô = o + f̂（滑移时在膜面漂移）
若 E=K, μ=μ̂, A 均匀 ⟹ f̃ = K·A·f̂（力与投影位移只差常数）
剪切场以投影点 ô 为中心汇聚（式 16–17）：粘着时中心不动，滑移时中心漂移——stick-slip 在空间分布上的体现。
M^s = Σ −φ_E(o)·(−f̃^xy)·exp{−λ_s‖(x,y)−ô^xy‖²}

Sim-to-Real RL 三阶段（AACD）

Stage 1 Teacher actor-critic（特权信息）+ 接触惩罚课程：先无惩罚训到成功，再加惩罚微调——否则策略要么"躲接触"塌缩，要么暴力到撕坏 GelSight 膜。
Stage 2 Student actor 从零训练（观测：EE 位姿 + 相对目标位姿 + 左右剪切场 7×9×2），critic 继承 teacher；同任务各仿真框架共用同一 teacher checkpoint。
Stage 3 真机零样本部署，无微调。PPO：teacher 1024 env / student 256 env，CNN+soft-argmax → LSTM(256)×2 → MLP[512,128,64]。
