# HydroShear：面向触觉 Sim-to-Real 强化学习的水弹性剪切仿真

> arXiv 2603.00446 · cs.RO / cs.AI · 2026-02-28
> An Dang*, Jayjun Lee*, Mustafa Mukadam, X. Alice Wu, Bernadette Bucher, Manikantan Nambi, Nima Fazeli（密歇根大学 & Meta 团队背景）

## 这篇论文讲什么

接触密集型操作（插孔、装箱、上架、抽屉拉取）的 sim-to-real 一直卡在**触觉仿真**上：现有视触觉仿真重"图像渲染逼真"、轻"力与剪切建模"，导致策略迁移到真机时大量失败。HydroShear 提出一个**非完整（non-holonomic）水弹性触觉剪切仿真器**：用 SDF 表示任意水密几何体，递归追踪压头（indenter）表面点在传感器弹性膜上的**路径依赖**位移与接触力，显式建模 stick-slip 转换、剪切累积/耗散和完整 SE(3) 交互。配合 GelSight Mini 标定后，用它训练的 RL 策略可**零样本**迁移到真机，4 个任务平均成功率 93%（112/120），远超触觉图像策略（34%）和其他剪切仿真方法（58%–61%）。

## 难度评估

**中高级（Intermediate–Advanced）**。核心是接触力学建模（SDF、库仑摩擦、粘弹性）+ RL 训练管线（teacher-student 蒸馏、PPO）。公式不深但符号密集；需要一点机器人学（SE(3) 位姿）和接触仿真背景。有 FLASH/ABD/IPC 阅读经历的话，接触模型部分会非常顺畅。

## 关键要点（Key Takeaways）

1. **剪切 ≠ 瞬时量**：真实弹性膜的剪切是路径依赖的（历史累积 + 摩擦锥截断 + 脱离重置），惩罚式"穿透×速度"模型天生学不到 stick-slip。
2. **一个递归力追踪器 F 干两件事**：同一个函数 F 既算接触力（物理参数 E,K,A,μ），又算滑移投影点（参数全设 1，摩擦 μ̂），并证明在 E=K、μ=μ̂、A 均匀时二者只差常数 KA。
3. **只有 4 个标定参数** (λ_d, λ_s, K, μ)，逐个用真实 GelSight 数据单变量最小二乘标定，避开高度非线性的联合优化。
4. **对物理引擎不可知**：只需要引擎给出压头相对弹性膜的位姿序列（允许穿透接触），剪切场在引擎外部计算，GPU 并行。
5. **保真度直接换成功率**：剪切仿真越接近真实（RMSE/余弦相似度最优），零样本迁移成功率越高——93% vs 基线 34–61%。
