# 批判性反思与扩展 — HydroShear

## 如果我来扩展这篇论文

1. **双向耦合**：把 f̃ 反馈回刚体动力学（作为额外接触力项），检验精细在手操作（in-hand reorientation）任务上是否显著改善。挑战：稳定性——递归观测模型变成动力学组件后需要考虑时间积分稳定性（联想 SPD 把增益移进质量矩阵的做法）。
2. **曲面弹性膜**：逐查询点切空间 + 测地衰减替代全局 xy 平面（见 qa.md 第 15 题的完整分析），推向灵巧手指尖。
3. **非线性/率相关本构**：E、K 升级为形变相关（超弹性）或加入真正的粘性项（Kelvin-Voigt 观测层版本），标定参数从 4 涨到 6–8，检验保真-可标定性 trade-off。
4. **批量 SDF 加速**：作者自己指出 1024 env 时 SDF 查询是瓶颈（103.7ms）。可试 hash-grid SDF、稀疏体素或低秩近似——与我关注的稀疏矩阵/GPU 仿真方向（FLASH、fill-reducing permutation）有直接交集。
5. **与 real-to-sim 修正结合**：残余 gap（非线性弹性、膜老化）用 SCORE 式支持约束或在线残差学习修正，把"4 参数标定"升级为"4 参数 + 轻量残差网络"。
6. **信息量消融**：论文对比的是不同仿真器，但没有消融"剪切场的哪个成分（幅值/方向/历史）贡献多少成功率"。可设计人为破坏实验（随机化幅值/冻结历史）定量归因。

## 遗留的开放问题

- 剪切观测只有 7×9×2/指，这么低维为什么够？任务的内在维度是多少？更高分辨率（真实 GelSight 可达数千 marker）会更好还是引入更多 sim-to-real 噪声？
- teacher critic 跨仿真框架共享（所有 student 用同一 teacher checkpoint）——这是否系统性偏向与 teacher 特权信息分布更一致的表征？
- 40 个标定测试样本、单一球形压头标定，泛化到任意几何依赖 SDF 形式的外推——复杂几何（Fig.11 的牛/圆环）只有定性展示，没有定量误差。
- 时间-成功步数表（Tab. IX）显示 HydroShear 并不总是最快完成（Book Shelving 180 步 vs TacSL Shear 99 步）——保真度换来的是成功率而非效率，为什么？

## 脆弱的假设

| 假设 | 脆弱点 |
|---|---|
| 引擎允许穿透接触 | 换零穿透求解器（IPC 类）模型直接失效；穿透深度本身是引擎接触刚度的函数，标定参数隐式绑定引擎设置 |
| 线弹性 E,K 常数 | 大形变、高速、温度/老化下真实胶体非线性显著 |
| 摩擦系数 μ 常数 | 真实 μ 依赖法向压力、速度（Stribeck 效应）、表面状态 |
| 平面膜 | 曲面指尖不可用 |
| 位姿历史来自引擎真值 | 引擎接触求解的位姿误差会被递归**累积**进剪切状态（误差传播未分析） |
| 重力增强不写回递归 | 增广是一次性的近似，长时间抓握下重力剪切的蠕变累积没有建模 |

## 实际部署中可能翻车的场景

1. **长 episode 漂移**：递归状态无泄漏项（除了脱离重置），长时间连续接触中数值误差和模型误差单调累积。
2. **高速接触**：帧间位移大时 α 线性插值和"逐帧直线路径"假设失真（掠过式接触可能整帧被漏检）。
3. **胶面磨损/污染**：真机 μ 随使用变化，4 参数是离线一次性标定的。
4. **多物体同时接触同一指**：M 个表面点属于单一压头 SDF；两个物体同时压膜需要多 SDF 合并的扩展。
5. **策略对剪切幅值敏感**：K 标定偏差直接缩放观测幅值，student 编码器对幅值分布偏移的鲁棒性未测。

## 对我自己研究方向的启示

- **"局部本构摘出来当观测模型"**是个可复用的架构模式：全耦合求解器太贵时，把策略/控制器需要的那部分物理（这里是摩擦 return mapping）单独轻量实现，比"整体降保真"更聪明。
- 与 FLASH/SILR-Cloth 的路线拼起来看：**布料/软体操作的触觉版**是明显空白——布料在指间滑动的剪切信号（HydroShear 假设刚体压头，布料是反例）可能是好题目。
- 标定哲学（每参数配一个隔离运动模式）值得在任何 system identification 场景复刻。
