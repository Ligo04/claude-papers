# 方法详解 — HydroShear

## 0. 符号与设定

| 符号 | 含义 |
|---|---|
| {p_i}_{i=1..N} | 弹性膜上的触觉网格查询点（marker 位置），p_i ∈ ℝ³ |
| s_i = (dx,dy) ∈ ℝ² | 每个查询点的 2D 剪切向量（marker 位移） |
| ᴱXᴵ_t ∈ SE(3) | t 时刻压头（indenter）在弹性膜（elastomer）坐标系下的位姿 |
| φ_I, φ_E | 压头 / 弹性膜的符号距离函数（SDF），内部为负 |
| {ō_j}_{j=1..M} | 压头局部坐标系下的表面采样点；o_{j,t} = ᴱXᴵ_t · ō_j |
| E, K | 法向 / 切向刚度；A_j 表面点关联面积；μ 摩擦系数 |
| λ_d, λ_s | dilation / shear 场的高斯衰减系数（触觉阴影） |

**总位移场分解（式 2）**：

```
M_t((x,y), X_{0:t}) = M_t^d((x,y)) + M_t^s((x,y), X_{0:t})
```

- M^d（dilation）：法向压入引起，**无记忆**（只看当前帧）；
- M^s（shear）：切向平移/SO(3) 旋转引起，**依赖整条位姿历史**。

## 1. Dilation 场（式 3–4，沿用 FOTS 形式）

对所有落入压头内部的膜网格点 c_i（φ_I(p_{c_i}) < 0）：

```
M_t^d = Σ_i  −φ_I(p_{c_i}) · v_{c_i} · exp{−λ_d ‖v_{c_i}‖²}
v_{c_i} = (x,y) − p_{c_i}^{xy}
```

直觉：每个接触点像一个"源"，把周围 marker 沿径向推开；推力正比穿透深度 −φ_I，随距离高斯衰减。**exp 衰减项就是触觉阴影（tactile shadowing）的建模**——真实弹性体形变会向外扩散并衰减，TacSL 缺这一项所以 dilation 的 CS 只有 0.323。

## 2. Shear 场 —— 递归力追踪器 F（核心贡献）

### 2.1 状态与递归（式 5）

对每个压头表面点 j 维护累积接触力 f̃_{j,t} ∈ ℝ³：

```
f̃_{j,t} = F(f̃_{j,t−1}, ᴱXᴵ_t, ᴱXᴵ_{t−1}, ō_j; E, K, A_j, μ),   f̃_{j,0} = 0
```

### 2.2 F 的内部五步

**Step 1 — 接触内位移截取（式 6–7）**：

```
α_{j,t} = [ReLU(−φ_E(o_{j,t})) − ReLU(−φ_E(o_{j,t−1}))] / [φ_E(o_{j,t}) − φ_E(o_{j,t−1})]
d_{j,t} = α_{j,t} · (o_{j,t} − o_{j,t−1})
```

α 的三种情形：全程膜内 α=1；全程膜外 α=0；跨界 0<α<1（按 SDF 线性比例截取）。无分支、可微、GPU 友好。

**Step 2 — 法向/切向分解**：d^n = ⟨d, n̂_j⟩（n̂_j 为压头表面法向），d^{xy} = d − d^n n̂_j。

**Step 3 — 位移→力累积（式 8–9）**：

```
f^n_{j,t}   = f̃^n_{j,t−1}   + E·A_j·d^n_{j,t}
f^{xy}_{j,t} = f̃^{xy}_{j,t−1} + K·A_j·d^{xy}_{j,t}
```

这是增量式弹簧：力随位移历史线性累积（stick 阶段的剪切 build-up）。

**Step 4 — 单边约束 + 库仑摩擦锥截断（式 10–11）**：

```
f̄^n = ReLU(f^n)                            # 法向力非负（不能"拉"）
f̄^{xy} = min{1, μ·f̄^n / ‖f^{xy}‖} · f^{xy}  # 切向力钳位在摩擦锥内
```

切向累积力触顶 μf̄ⁿ 即进入 slip：这一步就是**增量 return mapping**，产生 stick-slip 转换与滞回。

**Step 5 — 脱离重置（式 12）**：

```
f̃_{j,t} = H(−φ_E(o_{j,t})) · (f̄^n n̂_j + f̄^{xy})    # H 为 Heaviside
```

点离开膜（φ_E ≥ 0）→ 力清零。三件套（累积/截断/重置）合起来就是路径依赖性的全部来源。

### 2.3 投影点追踪器与"一器两用"（式 13–15）

滑移时，力的**作用位置**在膜面上漂移。定义投影点 ô_{j,t} = o_{j,t} + f̂_{j,t}，其中 f̂ 用**同一个 F**计算，只是参数全设 1：

```
f̂_{j,t} = F(f̂_{j,t−1}, ᴱXᴵ_t, ᴱXᴵ_{t−1}, ō_j; 1, 1, 1, μ̂)
```

**定理（式 15）**：若 E=K、μ=μ̂、A_j=A（均匀面积），则 f̃_{j,t} = KA · f̂_{j,t}。
直觉：F 的累积步对 (E,K,A) 齐次；摩擦截断 min{1, μf̄ⁿ/‖fˣʸ‖} 只依赖比值，KA 分子分母约掉。于是只跑一个追踪器，力 = KA × 位移。

### 2.4 汇聚成剪切场（式 16–17）

对所有在接触中的压头表面点 k_i（φ_E(o_{k_i,t}) < 0）：

```
M_t^s = Σ_i  −φ_E(o_{k_i,t}) · (−f̃^{xy}_{k_i,t}) · exp{−λ_s ‖v_{k_i}‖²}
v_{k_i} = (x,y) − ô^{xy}_{k_i,t}     # 注意：以投影点 ô 为中心！
```

权重 = 穿透深度；衰减中心 = **投影点**（不是当前压头点）；方向 = 切向力的反方向（marker 被往回拖）。

## 3. 管线总览（ASCII）

```
物理引擎(Isaac Gym, 允许穿透)              HydroShear (引擎外, GPU 并行)
┌──────────────────────────┐   位姿序列    ┌─────────────────────────────────┐
│ 刚体动力学 + Kelvin-Voigt │ ─ ᴱXᴵ_t ──→ │ ① o_{j,t} = ᴱXᴵ_t·ō_j          │
│ 柔顺接触(TacSL)           │              │ ② α 截取接触内位移 (φ_E)        │
└──────────────────────────┘              │ ③ 递归累积力 f̃ (E,K,A)          │
                                          │ ④ 摩擦锥截断 (μ) → stick/slip   │
        ┌─────────────┐                   │ ⑤ 脱离重置 (Heaviside)          │
        │ RL 策略      │ ←─ M_t^d + M_t^s │ ⑥ 投影点 ô = o + f̂             │
        │ (7×9×2/指)   │    (剪切观测)     │ ⑦ 高斯衰减汇聚成场 (λ_d, λ_s)   │
        └─────────────┘                   └─────────────────────────────────┘
```

注意：剪切场**只进观测，不反馈回动力学**（单向耦合）。

## 4. 标定（Sec. III-C）

参数仅 4 个：(λ_d, λ_s, K, μ)。逐个隔离标定（每步单变量最小二乘，各 10 组真实 GelSight Mini 数据）：

| 步骤 | 数据 | 固定 | 求解 | 技巧 |
|---|---|---|---|---|
| 1 | 纯竖直压入 | — | λ_d | 只有 dilation 场起作用 |
| 2 | 压入+切向平移 | λ_d*；K=1, μ=1e5 | λ_s | 真值重缩放到模型幅值范围；μ=1e5 关滑移 |
| 3 | 同上数据 | λ_d*, λ_s*；μ=1e5 | K | 不重缩放（K 定幅值） |
| 4 | 受控滑移 | λ_d*, λ_s*, K* | μ | 滑移数据里摩擦锥激活 |

像素换算：GelSight Mini 相机 1000/0.065 px/m。

## 5. Sim-to-Real RL（Sec. III-D + 附录 A/B）

### 5.1 三阶段 teacher-student（AACD，沿用 TacSL）

1. **Teacher actor-critic**（特权信息：物体位姿、接触力、物理参数）：
   - **接触惩罚课程**：先**无**接触惩罚训到初次任务成功 → 再加接触惩罚微调。直接带惩罚训会塌缩成"躲接触"策略；无惩罚到底则策略过于暴力、真机会撕坏 GelSight 膜。
2. **Student actor**（真机可得观测：EE 位姿、EE-目标相对位姿、左右剪切场）从零训练，critic 用 teacher 的（带惩罚课程的）critic 初始化；同一任务所有仿真框架的 student 共用同一 teacher critic checkpoint（公平比较）。
3. 真机零样本部署，无微调。

### 5.2 网络与超参数

- 编码器：剪切场 → 3 层 CNN（filters [32,64,64], kernel 3, stride 1）+ spatial soft-argmax；图像 → CNN（kernel [8,4,3], 首层 stride 2）+ soft-argmax。
- 主干：2 层 LSTM(256) → MLP [512,128,64]，ELU。
- PPO：γ=0.99，GAE 0.95，clip 0.2，lr 1e-4 自适应（teacher KL target 2e-3 / student 8e-3）；teacher 1024 env，student 256 env，episode 256 步。
- 动作：ΔEE 位姿(ℝ⁷) + 笛卡尔阻抗 K_p/K_d 增益(ℝ⁶+ℝ⁶)；抽屉任务额外输出连续夹爪位置(ℝ¹)。
- 剪切观测网格 [2×7×9]/指，匹配真实点阵胶。

### 5.3 重力增强（附录 B-E）

Isaac Gym 中在抓物体不因重力产生指间微位移。补偿法：额外用增广位姿 ᴳXᴱ·ᴱXᴵ_t 调一次 F 得 g_{j,t} 作为观测，但**不**写回递归状态。对 FOTS 与 HydroShear 都启用。

## 6. 复现要点与坑

1. **压头表面点密度 M 与 SDF 分辨率**是精度/速度旋钮；1024 env 时 SDF 批量查询已是瓶颈（103.7ms）。
2. **递归状态需要随环境 reset 清零**（f̃, f̂, 以及重力增广缓存），否则跨 episode 泄漏历史。
3. α 式分母在两帧 SDF 值相等时为 0/0，实现要加 eps 或特判（论文未提，工程上必踩）。
   **⚠️ 论文式 6 疑似符号笔误**：按原文分母 φ_E(o_t) − φ_E(o_{t−1}) 验算，"两帧均在膜内"时 α = −1，与论文自述的 α = 1 矛盾；按语义（截取接触内位移比例，α∈[0,1]）分母应为 **φ_E(o_{t−1}) − φ_E(o_t)**。本目录 code demo 已用正确符号实现并数值验证（错误符号会导致纯压入阶段法向力被 ReLU 清零、切向力方向反转）。
4. 摩擦锥截断的 ‖f^{xy}‖=0 时同样要防除零。
5. **物理引擎必须允许穿透**（penalty/compliant 接触）；换成硬约束求解器（如 IPC 类零穿透）时 φ_E(o) < 0 永不成立，模型直接失效——这是"引擎不可知"的边界条件。
6. 标定顺序不能换：λ_s 标定时 μ=1e5（关滑移）+ 幅值重缩放，是为了把 λ_s（空间衰减形状）与 K（幅值）解耦。
7. 真实剪切从 GelSight 点阵胶的光流提取；图像策略用无点胶，剪切策略用点阵胶（附录 -B）。
