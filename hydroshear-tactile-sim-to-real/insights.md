# 核心洞察 — HydroShear

## 一、用大白话讲核心思想

想象你用手指按住一块软橡皮，然后拖动手指：

- **一开始橡皮跟着手指走**（stick，粘着）：橡皮内部的剪切形变随拖动距离**线性累积**；
- **拖到某个程度橡皮"绷不住"了**（slip，滑移）：接触面开始打滑，剪切形变不再增长，被"钳位"在摩擦极限上；
- **手指抬起来**：形变（大部分）消失，重置归零。

GelSight 这类视触觉传感器的 marker 位移场记录的正是这个过程。关键观察：**同一个"当前位姿"，经由不同路径到达，会产生完全不同的剪切场**。先压后拖 vs 直接斜着压到同一位置，marker 位移完全不同——这就是"路径依赖 / 非完整（non-holonomic）"。

现有惩罚式仿真只看"此刻穿透多深、相对速度多大"，等于假设橡皮没有记忆——所以永远学不出 stick-slip 和剪切累积。HydroShear 的答案很朴素：**给每个压头表面点维护一个递归状态（累积接触力），每一步做三件事：累加位移×刚度、按库仑摩擦锥截断、脱离接触就清零。**

## 二、方法骨架（三行版）

1. **Dilation 场**（无记忆）：弹性膜网格点落入压头 SDF 内部（φ_I < 0）→ 按穿透深度加权、按距离高斯衰减（exp{−λ_d‖v‖²}，这就是"触觉阴影"）叠加成径向位移场。
2. **Shear 场**（有记忆）：压头表面点 o_{j,t} 的帧间位移，用弹性膜 SDF 的 ReLU 差商 α（式 6）截取"接触内部分"，乘刚度累积成力 f̃，摩擦锥截断（式 11）+ 脱离重置（式 12）；再以穿透深度加权、距离高斯衰减叠加到查询网格。
3. **投影点**：滑移时接触点在膜面上"漂移"，用同一个追踪器 F（参数全设 1）算出投影位移 f̂，得到力的作用位置 ô = o + f̂。

## 三、为什么这套设计有效

### 1. 记忆放在"压头表面点"上，而不是"弹性膜网格"上

这是一个容易被忽略但很聪明的选择。弹性膜网格点是欧拉视角（固定查询点），压头表面点是拉格朗日视角（跟随物体）。剪切的本质是**物体表面材料点相对膜的历史轨迹**，所以状态必须挂在拉格朗日点上。FOTS 把运动挂在"物体坐标系原点"上，只用一个刚体参考点概括整个接触——这正是它在物体中心远离接触斑（原版插孔 1/30 惨败）以及 SE(3) 滚动/倾斜时失效的根源：滚动时物体中心几乎不动，但接触斑内的材料点在剧烈交换。

### 2. ReLU 差商 α（式 6）——一行公式统一三种接触状态

α = [ReLU(−φ_E(o_t)) − ReLU(−φ_E(o_{t−1}))] / [φ_E(o_t) − φ_E(o_{t−1})]

- 两帧都在膜内 → α=1（位移全算）；
- 两帧都在膜外 → α=0（不算）；
- 跨越表面 → 0<α<1（线性插值出接触内的比例）。

这让"进入/离开接触"的瞬间不产生位移跳变，数值上光滑且完全可批量化（GPU 友好，无分支）。这个技巧和 IPC/FLASH 里处理接触边界的 clamp 思路一脉相承——把离散事件（接触开/关）连续化。

### 3. 库仑摩擦锥截断 = stick-slip 的最小充分实现

f̄ˣʸ = min{1, μf̄ⁿ/‖fˣʸ‖}·fˣʸ（式 11）。切向累积力没顶到 μ·法向力就原样保留（stick），顶到了就投影回锥面（slip）。这本质上是**增量式 return mapping**（塑性力学里最经典的算法），用在触觉剪切上恰好同时给出：剪切饱和、滑移方向、滞回（hysteresis）。不需要任何学习组件。

### 4. "一个追踪器两用"的自洽性

力追踪器（物理单位）和投影点追踪器（几何单位）本来要各跑一套递归。作者证明当 E=K、μ=μ̂、A_j=A 时 f̃ = KA·f̂（式 15）——因为递归 F 对参数是齐次的，摩擦截断又只依赖切向/法向**比值**（KA 约掉）。工程收益：状态内存和计算减半；概念收益：说明"滑移后的接触点位置"和"累积弹性力"其实是同一个量的两种读法。

### 5. 标定策略：把非线性联合优化拆成 4 个单变量问题

(λ_d, λ_s, K, μ) 按"影响可隔离"的顺序逐个标定：纯压入定 λ_d → 压入+平移（重缩放幅值、μ 设 1e5 关掉滑移）定 λ_s → 不重缩放定 K → 滑移数据定 μ。每步只有一个自由度，10 个样本就够。这和 SPD/ABD 论文里"把病态问题重构成良态子问题"的味道一致：**结构先行，优化其次**。

### 6. 保真度 → 成功率的因果链在实验中被"失败模式"证实

这篇论文实验设计最漂亮的地方是四个任务各自"卡"一种表征缺陷：

| 任务 | 卡什么 | 谁死在这 |
|---|---|---|
| Peg Insertion | 在手内位姿不确定性 + 力密集插入 | 原版 FOTS（物体中心远离接触斑，1/30） |
| Bin Packing | 大剪切/扭转 + 全局膜形变 | TacSL Shear（归一化丢幅值与空间结构，4/30） |
| Book Shelving | 满指尖接触 + 横向插入（重力不沿插入轴） | TacSL Gray（图像无剪切方向线索，6/30） |
| Drawer Pulling | 频繁接触切换 + 间歇滑移 + 外部扰动 | FOTS 重实现（单一参考接触斑假设崩溃，3/30）；TacSL Gray（无滑移线索，3/30） |

HydroShear 25/29/28/30——没有一个任务暴露短板。这说明它不是"平均更好"，而是**每一种被基线丢掉的信息（幅值、方向、历史、滑移事件）它都保留了**。

## 四、概念转变（Conceptual Shift）

**从"渲染触觉图像"到"仿真触觉力学状态"。** 之前的主流是把触觉仿真当图形学问题（渲染出逼真 RGB/深度），HydroShear 把它拉回力学问题：策略需要的不是逼真的像素，而是正确的**力的时空结构**（大小、方向、累积、滑移）。7×9×2 的低维剪切场胜过 320×240×3 的高保真图像（93% vs 34%），是对"视觉保真 ≠ 动力学保真"最直接的实证。

另一个转变：**触觉仿真器作为物理引擎的"外挂"而非"内嵌"**。HydroShear 只消费位姿序列，不参与动力学求解（剪切力不反馈回刚体动力学）。这是解耦的工程妙手，也是它最深的理论妥协（见下）。

## 五、权衡与局限（批判视角）

1. **单向耦合**：剪切场不反作用于物体动力学——物体的实际运动仍由引擎的（较粗糙的）Kelvin-Voigt 接触决定。真实世界里弹性膜的剪切力会影响物体在指间的微运动。这个 gap 被"策略对触觉输入的鲁棒性"吸收了，但在更精细的在手操作（in-hand manipulation）中可能暴露。
2. **线弹性 + 定常刚度**：E、K 是常数，真实弹性体是非线性、率相关（viscoelastic 提到但式 8-9 实为准静态弹簧+重置，没有真正的阻尼项/松弛项）。"viscoelastic"一词用得偏宽松。
3. **平面膜假设**：dilation/shear 分解和 2D 投影都依赖膜是平面。曲面指尖（灵巧手）需要重做投影几何。
4. **速度随规模退化**：SDF 批量查询让 1024 env 时耗时 103ms，比重实现 FOTS 慢 8.6 倍。大规模训练里保真-速度 trade-off 依然存在。
5. **重力效应靠增广补丁**：Isaac Gym 里在抓物体不因重力位移，靠额外施加位姿增广跑一遍 F 来补偿（附录 B-E）——这是对"单向耦合"缺陷的一个手工补丁，侧面印证了第 1 条。
6. **标定依赖精确位姿地面真值**（KUKA + 已知球形压头），换传感器/换胶要重标 4 参数；好在只有 4 个。

## 六、与我读过的工作的连接

- **与 FLASH/ABD/IPC 谱系**：HydroShear 的 α 截断、摩擦锥 return mapping 都是仿真界标准件的"轻量化转用"；它不解全局系统，只做逐点递归——可以看成把接触求解器的**局部摩擦模型**单独摘出来当传感器模型用。
- **与 SILR-Cloth（simulator-in-the-loop）**：同样是"仿真器为策略服务"，SILR 用高保真仿真做在线 MPPI，HydroShear 用中保真剪切仿真做离线 RL 训练——两条路线都绕开了"仿真器必须端到端可微/全耦合"的执念。
- **与 SCORE（real-to-sim-to-real）**：HydroShear 是纯 sim-to-real 零样本；SCORE 用真实数据修正流形。若 HydroShear 的残余 gap（如非线性弹性）用 SCORE 式支持约束修正，可能是自然的后续。

## 七、实践启示

- 如果你在做触觉 RL：**优先用低维、物理正确的剪切场做观测**，而不是高维触觉图像；归一化剪切只在接触斑小且稳定的任务上是安全的。
- 接触惩罚课程（先无惩罚训成功 → 再加惩罚微调）是保护真实传感器硬件的实用技巧，值得直接抄。
- "把递归物理状态挂在拉格朗日点上 + 摩擦锥截断"这个模式，可推广到任何需要路径依赖接触信号的仿真场景（例如指尖滚动检测、布料-手指交互信号）。
