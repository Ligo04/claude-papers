# 怎样给这项工作定位

这是一种为刚体动力学准备接触约束的窄相检测方法。输入是两个可查询的隐式体、刚体变换以及上一帧候选；输出是少量有位置、法向和深度的候选。动力学求解器负责施加冲量或更新约束。

需要掌握的前置知识：

- SDF 负值表示内部，零水平集表示表面。
- 局部优化从种子出发，通常只能找到附近吸引域的极小值。
- 一个接触法向主要约束一个相对速度方向，多个不同力臂有助于支撑旋转。
- Warm start 用历史状态减少重新求解的工作。
- DCD 检查给定时刻；CCD 搜索一段运动中的首次接触。

它在研究中的位置可以按职责排列：

| 职责 | 本文做了什么 | 本文没有证明或评估什么 |
| --- | --- | --- |
| 几何表示 | 查询解析或体素 SDF | 任意神经 SDF 的实测成本 |
| 碰撞候选筛选 | AABB 重叠 | 最优 broad phase |
| 窄相搜索 | 多种子局部优化 | 任意非凸几何的全局完备性 |
| 接触管理 | 缓存、曲率采样、排斥、去重 | 所有几何与运动下的稳定接触保证 |
| 动力学响应 | 用 CPU 顺序冲量或 GPU AVBD 验证 | 跨所有接触模型的同等收益 |
| 时间连续性 | 用速度预测下一帧搜索种子 | TOI 或严格防止 tunneling |

可以用五个问题检查是否真正理解：优化变量是什么？历史信息保存在什么地方？新接触靠什么发现？候选何时激活？耗时统计包含哪些模块？

对应答案是世界坐标位置、物体对的候选缓存、曲率引导的新种子、两个原始场均为负，以及论文报告的碰撞检测阶段。公开 demo 加入 margin 后，激活条件有所扩展。
