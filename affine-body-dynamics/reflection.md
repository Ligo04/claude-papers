# Affine Body Dynamics(ABD)研究者视角反思

> 基于 Lan, Kaufman, Li, Jiang, Yang, *Affine Body Dynamics*, SIGGRAPH 2022(arXiv:2201.10022)。本文档从"如果我来做后续工作"的角度进行批判性思考,而非复述论文内容。

---

## 一、如果我来扩展这篇论文

### 1.1 可微仿真(Differentiable Simulation)

论文结论部分明确提到 ABD "is also differentiable",并将其列为面向计算设计、机器学习、机器人的前景方向,但**全文没有给出任何可微化的具体实现或实验**——这本身就是一个清晰的延伸空间。

ABD 在可微化上有结构性优势:广义质量矩阵 $M$ 是常数(不随 $q$ 变化),正交惩罚势 $V_\perp$ 是纯多项式(公式 7、8 已经给出解析梯度和 Hessian),Jacobian $J(\bar x)$ 恒定——这意味着整条前向仿真链路(从 $\tilde q$ 到 IP 极小化解)理论上可以用隐函数定理(implicit function theorem)在 Newton 收敛点上直接求解 $\partial q^{t+1}/\partial q^t$、$\partial q^{t+1}/\partial(\text{材料参数}, \kappa, \mu)$,而不需要展开 unroll 整个迭代过程。相比刚体的 $SE(3)$ 微分几何(需要在李群/李代数上做微分,处理起来远比欧氏空间复杂),ABD 的仿射坐标是平坦欧氏空间中的向量,微分结构简单得多。

真正的难点在于**接触项**:接触势 $V_C$ 中的距离函数 $d_i(q)$ 在活跃集(active set,即哪些图元对处于接触状态)发生切换的时刻是不可微的(barrier 的支撑集边界),而 CCD 引入的 time-of-impact 是一个隐式的、依赖离散事件的量。要做端到端可微 ABD,需要处理:(a) 活跃集切换处的次梯度/近似平滑;(b) 摩擦项里 $\lambda_j$(接触力)对参数的依赖是通过另一层隐函数定义的,需要做二阶隐式微分或专门设计伴随(adjoint)方法;(c) CCD 步长 $\alpha$ 本身作为求根问题,其对参数的导数需要单独处理(而非简单地把它当作固定的离散决策)。这条工作线路的价值在于:一旦做通,就能把 ABD 的鲁棒接触保证和高性能优势,直接用于基于梯度的系统辨识(system identification,例如从真实抛掷/碰撞视频中反推物体的 $\kappa$、$\mu$、质量分布)和策略学习(在接触丰富的操作任务中用真实物理梯度取代无梯度强化学习)。

### 1.2 机器人抓取与接触丰富操作(Contact-Rich Manipulation)

ABD 提供无穿插保证 + 精确摩擦 + 高性能,这恰好是抓取仿真最缺的组合(传统刚体引擎要么快但会穿插,要么精确但慢)。延伸方向包括:

- **执行器/控制回路的引入**:论文目前只处理被动动力学(外力 $f$)和运动学约束(关节),没有讨论主动执行器(电机扭矩、PD 控制器驱动关节)。要用于机器人抓取仿真,需要在 IP 框架里加入执行器力矩项,并且要处理执行器目标(期望角度/速度)与仿射坐标系下关节参数化之间的映射——目前论文的关节线性化(§5.3)是"事后验证式"的(选定虚拟四面体后验证约束是线性的),尚未给出一套系统化的方法将任意执行器指令转化为该框架下的等式/不等式约束或额外势能项。
- **手指-物体的持续、密集接触**:抓取中手指与物体之间常有大面积贴合接触(而非论文benchmark里瞬时碰撞),这对 i-AABB 假设(见下文局部性假设)、barrier 参数 $\hat d$ 的选取、摩擦锥的精度都提出更高要求,需要专门评测。
- **与可微仿真结合**用于抓取姿态优化或基于梯度的抓取策略学习,是自然的下一步。

### 1.3 铰接系统(Articulated Systems)的系统化

论文 §5.3 的关节处理本质上是"手工技巧"——通过巧妙选取虚拟四面体 $\bar P$ 的形状与朝向(比如让某条边平行于旋转轴),把特定类型的关节约束(旋转轴)转化为线性等式约束,但这依赖人工针对每种关节类型单独设计。一个值得做的扩展是**建立通用的关节类型库**(旋转副、移动副、球铰、万向节等),给出每种类型下 $\bar P$ 的系统化选取规则和对应约束矩阵的自动生成方法,而不是像论文那样逐例手动构造。此外,论文没有比较 ABD 关节线性化方法与经典的 reduced-coordinate 铰接体算法(如 Featherstone 的 Articulated Body Algorithm)在大型链式/树状机构(如高自由度机器人手臂、人形骨骼)上的效率和精度差异——这也是一个自然的、可直接量化的对比研究方向。

### 1.4 GPU 大规模场景

论文已经报告了 GPU FPS 数据,并声称 i-AABB、affine CCD、Hessian 装配都是"parallelization-ready",但混合仿真例子(图 11)的 GPU FPS 只有 0.4,且 Table 2 显示其瓶颈在**线性系统求解(Sol. 4.6s,占总 16.4s 的大头)**,而非碰撞处理。这说明当前 GPU 实现的短板可能在稀疏线性求解器而非碰撞检测/Hessian装配本身。值得深入的方向是:matrix-free Newton-CG/PCG 配合专为块状 $12\times12$ 结构设计的 GPU 预条件子(preconditioner),或者探索区域分解/多重网格式的并行求解策略以支持数万乃至数十万物体规模(论文最大的 huge chain net 例子有 27,645 个物体,但 CPU 上仍需约 5 分钟每帧,尚未在 GPU 上跑通这一规模)。

## 二、遗留的开放问题

### 2.1 自碰撞(Self-Collision)完全未处理

这是论文明确承认的设计取舍("体内高刚度 ⇒ 无需自碰撞"),而不是技术局限,但它是一个真实的开放问题:一旦物体形状是细长、薄壁或高度非凸(例如镊子、钳子、可折叠工具、薄金属片),即便材料刚度极高,只要外部载荷足够大或者 $\kappa$ 因数值稳定性被迫调低,物体自身两个不相邻部位仍有可能在几何上"贴近甚至穿透"而不被检测——因为算法从设计上就完全没有为这种情况留出检测通道。这类物体在机器人抓取工具、机械装配场景中并不罕见。

### 2.2 需要"严格刚性"的场景

ABD 本质上是"极高但有限刚度"的柔性体,而非数学意义上的严格刚体。对绝大多数图形学/游戏应用这没有影响,但在一些对精度要求极高的领域(比如精密装配公差验证、计量学仿真、需要保证"零穿透且零虚假柔顺"的机械设计验证),即使是极小的、由 $\kappa$ 有限带来的柔顺形变,也可能是不可接受的建模误差来源。论文没有讨论 ABD 与"真正刚体"在长期(比如成百上千步)仿真中累积误差的定量差异,这本身是一个有意义但缺失的实验。

### 2.3 $\kappa$ 的数值条件问题

论文承认"$\kappa$ 极大带来数值刚性",并且在混合仿真中因 $V_\perp$ 的 Hessian 远大于弹性 Hessian 而导致正定性数值受损、LLT 求解偶尔失败需回退 LDLT(§5.4)。但论文**没有给出任何系统化的 $\kappa$ 选取准则**——比如 $\kappa$ 应如何随物体尺度、材料密度、期望的仿真步长联合缩放;是否存在一个与场景无关、可以自动标定的经验公式;当仿真中同时存在差异巨大的物体尺寸时(大炮塔与螺丝钉共存的机械装置),单一全局 $\kappa$ 是否会在不同尺度物体间引入不均衡的数值刚性。这是一个直接影响 ABD 在无人工调参场景下"开箱即用"承诺的开放问题(论文强调 ABD "无需逐场景调参",但 $\kappa$ 本质上仍是一个需要合理设置的敏感参数)。

### 2.4 恢复系数(Restitution)的可控性

论文提到 $V_\perp$"内在地处理了 restitution"(intrinsically handling restitution),但通篇没有给出任何机制让用户**独立、显式地控制恢复系数**——经典刚体仿真里,恢复系数 $e$ 是一个用户可调的物理参数($e=0$ 完全非弹性碰撞,$e=1$ 完全弹性碰撞)。在 ABD 里,碰撞后的回弹行为是由正交惩罚势的刚度、barrier 函数形状、隐式积分本身带来的数值耗散共同、隐式地决定的,缺乏一个类似"旋钮"式的直接控制通道。这对需要精确匹配特定材料回弹行为的应用(动画中特定材质道具的弹跳效果、体育器械仿真等)是明显缺口。

## 三、哪些假设脆弱

### 3.1 i-AABB 的"接触局部性"假设

i-AABB 剔除策略整体建立在一个经验观察上:"近刚体网格间的接触密集区域通常是局部的,只占各自表面的一小部分"。这个假设在论文所有 benchmark(链网、齿轮、纸牌屋、wrecking ball)中都成立,但存在明显的反例场景:

- **颗粒/散装物料仿真**(granular media,如沙堆、碎石堆、大量骨牌状物体紧密堆叠):此时几乎每个物体都与周围多个物体存在广泛贴合接触,粗 AABB 重叠区域可能覆盖物体表面的绝大部分,i-AABB 相对全身 BVH 的剔除收益会大幅萎缩,甚至退化到与传统 BVH 相近的开销。
- **细长/扁平物体**:AABB 对细长斜置物体(如一根倾斜的杆)是很松的包围盒,重叠区域会显著大于实际接触区域,削弱剔除效果。
- 论文给出的三级层级 i-AABB 是为"高度纠缠"场景(如齿轮组)设计的补救方案,但对上述真正的全局密集接触场景(而非局部纠缠),这个补救本身也未必有效,因为问题不在于需要更深的层级,而在于重叠区域本身就占主导。

### 3.2 "体内无自碰撞"假设的边界条件

如前所述,这个假设依赖于 $\kappa$ 足够大以至于形变可忽略。但这是一个**没有安全网的假设**:算法层面完全不做检测,一旦假设的前提(形变足够小)因为数值稳定性妥协(比如为了避免病态被迫降低 $\kappa$)或物体几何本身(细长、易自遮挡形状)而不成立,系统不会报错或降级,而是静默地产生物理上错误的自穿插结果。这种"failure mode 无提示"的特性在生产环境中是有风险的。

### 3.3 虚拟四面体选取对约束 Jacobian 条件数的影响

关节约束线性化(公式 13、14)依赖于选取一个非退化虚拟四面体 $\bar P$,论文强调这个四面体"可以自由选取"(甚至不必贴合物体真实几何),但没有讨论**四面体形状退化程度(如接近共面、体积接近零)对 Jacobian 条件数的影响**。理论上,病态(接近退化)的 $\bar P$ 会导致 $(\bar P \bar P^T)^{-1}$ 病态放大数值误差,进而影响约束求解的稳定性。论文所有例子选取的四面体似乎都形态良好,但这暗示了一个未被讨论的隐藏假设:虚拟四面体的选取需要满足一定的几何质量,而这一质量标准论文并未给出。

## 四、实践中可能失效的场景

1. **大规模颗粒/散体仿真**:如前述 §3.1,i-AABB 剔除收益消失,论文报告的"90% 加速来自更少迭代 + 更快 CCD"这一结论在广泛接触场景下也会被削弱(因为广泛接触意味着仍然需要大量的接触对处理,不像论文 benchmark 中接触总体上是稀疏、局部的)。
2. **需要精确恢复系数控制的动画/工程场景**(见 §2.4):台球、弹球机、体育器械等对回弹高度/角度有精确要求的应用,直接使用 ABD 默认的"隐式回弹"可能无法匹配期望行为,需要额外的参数标定工作(而论文恰恰以"无需逐场景调参"作为卖点之一,这里存在张力)。
3. **长时间、高刚度混合仿真**的病态求解:论文自己在混合仿真中就遇到了 LLT 失败、需要切换 LDLT 的问题;可以预见,在更极端的刚度对比(比如同一场景里既有极刚性金属件又有极软的橡胶/织物部件)或更长的仿真时长下,数值病态问题会更频繁地出现,可能拖慢求解效率甚至导致 Newton 不收敛,而论文给出的应对(切换分解方式)只是权宜之计。
4. **细长/薄壁物体受到强冲击**:如镰刀状工具、金属薄片,在强烈碰撞下即使高 $\kappa$,局部瞬时形变仍可能显著,而自碰撞检测的完全缺失意味着这类物体在受到挤压/弯折时可能出现看不见的自我穿透伪影,而不会被算法察觉或阻止。
5. **需要绝对严格刚性保证的工业验证场景**(见 §2.2):如果下游应用要求"零柔顺",ABD 的软约束本质意味着它不能直接替代传统刚体运动学求解器用于最终的公差/干涉验证,只能作为动力学仿真的加速手段。

## 五、已知的后续发展方向(审慎表述)

论文发表于 2022 年的 SIGGRAPH,其"面向计算设计、机器学习、机器人"的展望本身已经预示了后续工作的几个方向:GPU 化/大规模并行的 ABD 变体是一个活跃的研究领域,后续工作大概率会围绕提升 GPU 求解器效率(解决论文中已经暴露的 Sol. 阶段瓶颈)、扩展到更大规模场景(超过论文中 27,645 体的 huge chain net)、以及把可微化真正落地(论文本身只是提出可能性,未给出实现)这几条主线展开。由于这些内容超出了本文全文所覆盖的范围,此处不去编造具体的后续论文引用或数据,仅指出这是一个可以合理预期、值得持续关注的方向。
