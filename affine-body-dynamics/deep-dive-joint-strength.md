# 深挖:关节的 strength 参数

> 触发问题:joint 的 strength 的作用是?(2026-07-03)

## 论文 vs 实现的区别

- **论文 §5.3(原文)**:关节是**硬的线性等式约束**。利用"非退化四面体唯一确定仿射变换",把 $q$ 映射为虚拟四面体的 4 个顶点,旋转轴约束 = 固定四面体一条边的两个顶点(线性等式,直接消元或拉格朗日乘子)。论文中**没有 strength 参数**。
- **工程实现(如 libuipc 等 affine-body + IPC 库)**:通常不做硬约束,而是把关节写成**软惩罚能量**:

$$E_{joint} = \text{strength}\cdot\sum_k \|J(\bar{x}_k)q_a - J(\bar{x}_k)q_b\|^2$$

同一锚点(铰链则是轴上两点)分别用两个体的仿射坐标算世界位置,罚它们的分离距离。因 $x=J(\bar{x})q$ 线性,该能量是 $q$ 的二次型:Hessian 常数、凸,进 Newton 系统零负担。

## strength 的三重作用

1. **约束满足精度**:平衡时关节分离残差 ≈ 外载荷 / strength。太小 → 受扭矩的轴漂移、关节被拉开缝;越大 → 越接近硬等式约束。
2. **数值条件数**:strength 越大系统越 stiff。与正交势 κ 是同一哲学("用刚硬软势替代硬约束")与同一代价;论文的辩护同样适用——接触 barrier 已主导系统刚度,关节 penalty 的边际代价小。
3. **物理意义 = 关节柔度**:1/strength 即 compliance。真实关节本有间隙与弹性,软关节比严格硬约束更接近现实(呼应论文"stiff compliance 使紧密咬合零件可装配,严格刚性反而失败")。

## 调参直觉

- 与质量/惯性尺度匹配(许多实现默认按质量缩放),否则重物挂轻关节会下垂。
- 关节抖动/分离 → 调大;Newton 迭代暴涨或 LLT 失败 → strength 已远超 barrier 刚度量级,调小。
- 两个独立旋钮:**κ 管体自身多刚,strength 管关节多紧**。

## 与论文硬约束路线的取舍

| | 硬等式约束(论文) | 软 penalty + strength(实现) |
|---|---|---|
| 精度 | 精确满足 | 残差 ∝ 载荷/strength |
| 实现 | 需消元/乘子,改动求解器结构 | 加一项二次能量即可,求解器不变 |
| 数值 | KKT 鞍点系统或降维 | SPD 保持,但条件数随 strength 上升 |
| GPU 友好度 | 差(耦合结构) | 好(与接触/正交势同一装配管线) |

# 续:strength 与 target_kp / target_kd 的关系(2026-07-03)

## 分工:作用在关节的两组正交方向上

- **strength → 被约束方向**(轴不分离、不歪):被动、结构性,罚锚点分离距离,不产生驱动力。
- **target_kp/kd → 自由方向**(如铰链转角 θ):PD 伺服,τ = kp(θ_target − θ) − kd·θ̇。kp 是"拉向目标的刚度",kd 是角速度阻尼(抑制过冲、耗散能量)。

## 耦合:串联弹簧模型

驱动力矩经关节传递,伺服刚度 kp 与关节柔度 1/strength **串联**:

$$1/k_{eff} = 1/k_p + c/\text{strength}$$

实用准则:**strength ≫ kp(高 1–2 个数量级)**,否则:
- 命令刚度大半耗在关节形变上(电机拧软轴);
- 跟踪误差分裂为角度误差 + 关节被拉开的缝,大 kp 反而撕关节;
- kp 出现收益封顶,瓶颈变成 strength。

## 与 Stable PD(Tan/Liu/Turk 2011)的呼应

SPD 解决显式 PD 大 kp 爆炸问题(k_d Δt 隐式并入质量矩阵)。在 ABD/IPC 优化式积分器中把 PD 写成增量势能量项:

$$E_{drive} = \tfrac{1}{2}k_p\|\theta(q)-\theta_{target}\|^2 + \tfrac{k_d}{2\Delta t}\|\theta(q)-\theta^t\|^2$$

θ 的求解全隐式 ⇒ 免费获得 SPD 级稳定性,kp 可开很大不炸。kd 项即 IP 中除以 Δt 的"上一步位置差"二次项(Rayleigh 型耗散)。这与正交势 κ、接触 barrier、joint strength 进同一个 Newton 求解是同一哲学。

## 三旋钮速查

| 参数 | 作用方向 | 物理意义 | 太小 | 太大 |
|---|---|---|---|---|
| strength | 被约束 DOF | 关节结构刚度 | 轴分离/漂移 | 条件数恶化 |
| target_kp | 自由 DOF | 伺服比例刚度 | 跟踪松软滞后 | 撕关节(strength 不够)/振荡(kd 不够) |
| target_kd | 自由 DOF | 伺服阻尼 | 过冲振荡 | 响应迟钝、过度耗能 |

# 续:strength_ratio 应该只与什么有关(由论文推断,2026-07-03)

**结论:只与约束的时间尺度要求有关(Δt 与期望残差容差),与物体的质量/体积/密度/网格分辨率无关。**

1. **模板来自 V⊥ = κ·ν·‖AAᵀ−I‖²**:体积 ν 显式拆出,κ 只表达"多刚"的材料级意图,跨物体通用。strength = ratio × mass 同构:质量被拆出,ratio 只表达意图。
2. **IP 天平上质量消掉**:惯性项 ∝ M,penalty 写成 ratio×mass 后,两项之比 = Δt²·ratio,与质量无关;ω² = k/m = ratio,量纲 1/s²,纯时间尺度量 ⇒ 同一 ratio 在轻/重物体上产生相同的动力学与相对残差。
3. **锚定无量纲容差**:论文场景归一化 1×1×1、d̂=1/1000 ⇒ 精度目标是相对量。ratio 只需 Δt²·ratio ≫ 1(残差 ∝ 1/(Δt²·ratio) 压到容差下);且接触 barrier 已主导刚度,ratio "够大即可",确切值不敏感。

一句话:mass 吸收"物体是什么",ratio 只表达"约束相对惯性要多刚(以 1/Δt² 为标尺)"——这正是配置能跨场景复用、免逐场景调参的原因。

# 续:默认 strength_ratio=100 够吗?(libuipc 源码验证,2026-07-03)

**够,绝大多数场景。** 源码证据(~/Project/uipc/libuipc/src/backends/cuda/affine_body/):

- `ortho_potential.cu`:E = κ·volume·**dt²**·‖AAᵀ−I‖²(物理势,含 Δt²,对应论文 Δt²V⊥)
- `affine_body_revolute_joint.cu`:κ_J = strength_ratio × (m_i+m_j),E = ½κ_J(‖d₀‖²+‖d₁‖²),**不含 dt**

关节能量与惯性项 ½‖q−q̃‖²_M 同尺度直接相加 ⇒ ratio 是离散系统的无量纲权重,**连 Δt 都不依赖**(比"只与 Δt 和容差有关"的推断更干净):

- 每步跟踪权重 ratio/(1+ratio) ≈ 99%
- 重力稳态残差 r ≈ Δt²g/ratio ≈ 1e-5 m(Δt=1/100)≪ d̂=1e-3
- 等效物理刚度 k_phys = ratio·m/Δt²,ω = √ratio/Δt ≈ 1000 rad/s,随步长自动缩放

**需调大的情况**:① 强驱动伺服须被被动关节压住(串联弹簧规则);② 长运动链上 1%/节柔量累积;③ 关节传递远超 (m_i+m_j)·g 的重载/冲击。判断:看关节锚点分离是否 < d̂,超了乘 10。
