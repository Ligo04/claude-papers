## 1. 数值预备(§III)— 投影动力学 local-global

**隐式欧拉积分**(式1):给定 t 时刻位置 q_h、速度 v_h,求 t+h 的 q:
```
q = argmin_q'  1/(2h²) ||M^½(q' - q̃)||²_F  +  Σ_i ψ_i(q')
```
其中 M 是质量矩阵,`q̃ = q_h + h·v_h + h²·M⁻¹·f_ext` 是预测态,ψ_i 是第 i 个有限元的弹性能。

**接触约束动力学**(式2):用 Lagrange 乘子 λ 引入接触力作为约束乘子,对式(1)微分得:
```
M(q-q̃) - h²·f_int(q) - h²·Σ_j Hⱼᵀλ = 0        (2a)
∀j∈L, φ_j(q,λ) = 0                            (2b)
```
H 是接触 Jacobian(广义坐标→接触空间),φ_j 编码双边条件或 **Signorini–Coulomb 接触律**。

**投影内力**(式3,projective dynamics):对每个局部弹性约束解一个近端问题得投影变量 p_i,
```
p_i = argmin_p'  (w_i/2)||p' - G_i q||²_F + ζ_i(p', ξ_i)        (3a)
f_int(q) = Σ_i w_i G_iᵀ (p_i - G_i q)                          (3b)
```
w_i 是刚度权重,G_i 是状态→投影态的线性映射,ζ_i 定义本构流形。

**组装**(式4):代入后整个可变形多体系统写为
```
A q - b - h² Hᵀλ = 0,    φ(q,λ) = 0
A = M + h²·Σ_i w_i G_iᵀ G_i,    b = M q̃ + h²·Σ_i w_i G_iᵀ p_i
```
> **local-global 结构**:local 步=并行解各 p_i(式3a),global 步=解线性系统更新 q。这是 PD 高效的根源。

## 2. 非光滑 Newton(§III-C)

解式(4)用非光滑 Newton。令 J=∂φ/∂q,E=∂φ/∂λ,每次迭代解鞍点系统(式6):
```
[ A   -Jᵀ ] [   q   ]   [ g ]
[ J    E  ] [ h²Δλ  ] = [ h ]
```
三阶段:
1. 组装 J,E,g,h,形成 **Schur 补**:`Z = J A⁻¹ Jᵀ + E`(式7)
2. 解约束增量:`Δλ = (1/h²) Z⁻¹ (J A⁻¹ g - h)`(式8)
3. 位置修正:`q = A⁻¹ (b + h² Jᵀ(λ_{k-1} + Δλ))`(式9)

**关键稀疏分解**:`A⁻¹ = SᵀS`,其中 `S = L⁻¹` 是 A 的 Cholesky 因子的**显式逆**。这让全局线性解与 Schur 补评估都表达为**稀疏矩阵乘法** → 高度 GPU 友好。

## 3. ★ FLASH 的核心改进:惯性主导近似(§IV-B-1)

**问题**:接触密集时 `A⁻¹` 稠密 → `Z=JA⁻¹Jᵀ+E` 稠密 → 构建式(7)、解式(8)成为瓶颈;多环境并行下随"环境数 × 活跃约束数"恶化。

**解法**(式10):
```
Z = J A⁻¹ Jᵀ + E  ≈  J M⁻¹ Jᵀ + E
```
把全隐式接触度量放松为**惯性主导逆**(M⁻¹ 块对角稀疏),降低全局接触耦合,同时通过投影动力学**仍保留弹性内力的隐式处理**。

**为何合理**:软材料中弹性耦合主导系统行为,接触响应主要由惯性 + 局部几何决定。**稀疏性在整个非光滑 Newton 迭代中保持**。对"接触少、需强全局接触耦合"的任务,可保留原全隐式公式 —— **度量按任务灵活选择**。

## 4. ★ 多环境块对角并行(§IV-B-2/3,Algorithm 1)

定义块对角系统矩阵与堆叠变量(式11):
```
Ā = blkdiag(A₁,...,Aₙ),   q̄ = col(q₁,...,qₙ)
J̄ = blkdiag(J₁,...,Jₙ),   λ̄ = col(λ₁,...,λₙ)
```
鞍点系统(式12)与单环境同构,只是标量替换为块对角/堆叠版本。**无额外耦合**:每个环境在统一系统内独立处理,计算量随环境数线性增长,扩展性由数值库自动获得。

### Algorithm 1:多环境 GPU 管线
```
1  组装块对角算子 Ā
2  L̄ = Cholesky(Ā),  S̄ = L̄⁻¹
3  while 仿真:
4     碰撞检测(跨环境并行)
5     q̄̃ = q̄_t + h·v̄_t + h²·M̄⁻¹·f̄_ext           # 预测态
6     for k in 1..k_max:                          # local-global 迭代
7        p̄ = project(Ḡ_i q̄_{k-1})                 # local 投影,批量跨环境
8        由 q̄_{k-1}, λ̄_{k-1}, p̄ 构建 J̄,Ē,ḡ,h̄
9        Z̄ = J̄ M̄⁻¹ J̄ᵀ + Ē                        # ★ 惯性近似,稀疏
10       Δλ̄ = (1/h²) Z̄⁻¹ (h̄ - J̄ S̄ᵀ S̄ ḡ)
11       λ̄_k = λ̄_{k-1} + Δλ̄
12       q̄_k = S̄ᵀ S̄ (b̄ + h² J̄ᵀ λ̄_k)              # global 解,稀疏矩阵乘
13    q̄_{t+h} = q̄_{k_max},  v̄_{t+h} = (1/h)(q̄_{t+h} - q̄_t)
```

## 5. 学习与 sim-to-real(§IV-C/D)

**Teacher-Student 蒸馏**:
- **Teacher**:用特权状态信息 + 启发式规则,命令末端抓取并搬运特定关键点到目标;含**反应式恢复行为**处理抓取失败;复杂任务(衣物折叠)用**多阶段有限状态机**组织原语。
- **Student**:蒸馏成可部署策略,以**本体感知 + 视觉观测的堆叠历史**为条件;蒸馏时加**大量域随机化**保证 sim-to-real 鲁棒。

**Sim-to-Real(零样本,无微调)**:
- **感知**:YOLOv8 + SAM 从原始深度流分割目标,隔离物体、滤背景,使真机视觉输入匹配仿真的干净观测。
- **控制**:策略每臂输出 `aₜ=(Δp, w)`,Δp∈R³ 位置增量;连续夹爪参数 w 经 sigmoid 二值化为开/合;积分位置增量得笛卡尔目标 → 数值 IK → 关节位置 → 高频底层控制器。双臂输出 8 维。

**Real-to-Sim 数字孪生**:几何(简单物体程序化、复杂衣物 3D 扫描/合成数据集)、物理标定(泊松比、杨氏模量对齐真实形变)、视觉渲染(含机器人自遮挡的深度图、手眼标定空间对齐)+ 物理与视觉域随机化。

## 6. 实现要点与复现风险(Pitfalls)

- **度量选择**:多接触任务用惯性近似(式10),少接触强耦合任务用全隐式 —— 选错会精度或速度二选一受损。
- **Cholesky 显式逆 S=L⁻¹**:显式求逆只在稀疏性被保持时才划算;若 A 的稀疏模式因约束变化而退化,S 可能变稠密。
- **local-global 迭代数 k_max**:Fig.4(b) 显示把 local-global 与线性求解迭代都设为 2 会显著削弱长程弹性耦合(肩部折不动),但**仍数值稳定** —— 是"优雅退化",但精度-速度需按任务调。
- **准静态假设**:吞吐/对比基于 5s/折、Δt=0.01s 的准静态运动;快速动态(如 fling)下惯性近似与稳定性需重新评估(10× 速度已显示更强惯性耦合)。
- **碰撞检测并行**:Algo.1 第 4 行跨环境并行碰撞检测是热点,自碰撞在跨平台公平对比时被禁用 —— 复现真实任务需重新打开并验证成本。
- **CPU–GPU 搬运**:部分管线仍有传输开销(§VII),是端到端吞吐的隐藏成本。
- **域随机化范围**:零样本迁移强依赖物理(泊松比/杨氏模量/摩擦)与视觉(深度自遮挡)随机化覆盖;范围不足则真机失败(薄织物深度噪声是主因)。
- **teacher 启发式质量**:student 上限受 teacher 启发式 + FSM 设计约束;长程任务 teacher 难写好。
