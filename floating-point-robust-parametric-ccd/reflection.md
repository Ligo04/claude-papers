# 反思

## 如果由我来扩展这篇论文

1. **面 / 曲线 / 流形接触。** 头号局限。反演构造当前规定一个*孤立点*接触，使步骤 II 保持为有限线性系统。曲线/面
   接触意味着相等约束沿一个 1 维或 2 维流形成立 → 无穷多解，这正是让*正向*真值不可行的东西。扩展反演构造需要一个
   *参数族*的二进分数解（例如把接触曲线规定为一条低次二进分数 Bézier，再求解使两曲面共享它的控制点）。困难但价值高：
   真实的布料/壳接触很少是单点。

2. **对抗性 / 搜索式角落用例。** 现在角落用例是*类别化*的（EF、EE、…）并在每类内随机采样。可以*优化*以诱发 FN 的
   输入——例如生成最大化所需推开量 `δ` 的用例（近平行包络线段、近零斜率间隙），或把误差界本身用作目标来合成最难的
   二进分数构型。这会把基准从"多样"变成"可证明地有压力"。

3. **更紧、非均匀的界。** `ε_arith ≤ n₁m₁·max(…)` 是对整片的最坏情况乘积。逐线段或经区间算术细化的界能缩小保守性
   （更少 FP、更快）同时保持保证——尤其在 TDIBM-E 当前付多了的线性网格场景。

4. **完整 CAD 路径。** NURBS → Bézier 无损（已支持）。开放环节是**复杂裁剪曲面**（鲁棒地表示/查询受限的 2 维参数
   域）与**多片自碰撞**（接缝处理、相邻性）。一个针对裁剪域的鲁棒细分方案，配上同样的误差分解，看来是自然的下一篇。

5. **GPU / 并行 TDIBM-E。** 优先队列分支定界偏串行；误差界计算是局部的、可极度并行的。一个批量查询的 GPU 版本能让
   可证明鲁棒便宜到适合实时。

## 论文留下的开放问题

- **非孤立接触的精确真值**，无需 >1 天的符号求解——反演技巧对点有效；一般情形开放。
- **生成"最难"用例的有原则方法**，而非多样但随机的。
- **缩小保守性差距**，使可证明安全即便在简单几何上也几乎零成本。
- **多片模型内自碰撞的鲁棒处理**。
- 所报告的**单精度 epsilon（2⁻¹⁷）** 几乎肯定是 2⁻²⁴ 的笔误；在 float32 上部署前，值得仔细重新推导单精度的界。

## 哪些假设是脆弱的？

- **一步内控制点线性运动（式 2）。** 继承自 TDIBM。使用高阶积分器或大旋转的真实仿真器，其控制点可能在 ΔT 内*不*
  线性运动；保守性证明依赖于此。实践中靠小步长缓解，但这是关于世界的建模假设，而非保证。
- **凸包包含。** 对 Bézier/B-spline 按构造成立——稳固。但它是方法保守的*原因*；任何不具此性质的表示（如某些细分
  或隐式曲面）都会破坏整个无 FN 论证。
- **构造的二进分数友好性。** 0% 丢弃率是对*他们*所选输入约束（轴对齐 `2^k` 法向、小二进分数 UV 集）的经验结果。
  推向更丰富几何后二进分数性更难维持——约束集可能需要重新设计，丢弃率可能上升。
- **基准即预言机。** 鲁棒性主张是*相对于该数据集分布*的。若真实参数 CCD 遇到反演构造无法产生的构型（如恰好被排除
  的面接触用例），基准的"0 FN"不会自动迁移。该保证是一个*证明*（确实迁移），但*经验 FP 率*是数据集特定的。

## 它在实践中可能在哪失效？

- **更高次 / 更高阶曲面片。** 一切都在**三角二次** Bézier 曲面片上演示。界随 `n,m` 增长（如 `k_cp = 6n` 或 `5n`），
  故更高次会膨胀 `ε_constr` → 更保守、更慢、更多 FP。方法保持*安全*但在高阶 CAD 上可能变得*不实用*。
- **病态的近平行风暴。** `Iδ` 累积推开是安全的，但随预测相交的迭代数 `I` 增长。一个深度递归、反复近平行的用例会
  累积大分离 → 非常保守的结果（大量 FP、深递归）。安全，但在 ToI 上可能慢且不精确。
- **float32 部署。** 鉴于 epsilon 笔误与界的量级，单精度很可能产生重度保守；实验用双精度自有其道理。
- **集成不匹配。** 若宿主仿真器对"碰撞"的定义（如厚度/边距）或其时间积分与线性运动模型不一致，TDIBM-E 的保证是关于
  *它的*模型而非仿真器的——无 FN 性质以上游假设成立为条件。

## 可迁移的教训（值得借用）

浮现出两个可复用模板，独立于 CCD：

1. **分解—再保守偏移**，用于鲁棒的分支密集型几何：通过一个想象的中间计算拆分纠缠的误差源，各自定界，并把每个不确定
   分支偏向你能容忍的失效模式。哪里界会爆炸（近退化除法），就*重构*（推开）使误差抵消而非去度量它。

2. **反演预言机 + 强制可表示性**，用于精确基准：当正向真值计算不可行时，规定答案、用精确算术反向求解；再施加一种
   数值表示纪律（此处：二进分数）端到端，使精确结果在转换到目标格式后存活，并用往返检查兜底。

这些是最可能比 TDIBM-E 这个具体算法活得更久的部分。
