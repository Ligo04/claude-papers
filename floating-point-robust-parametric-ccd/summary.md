# 摘要总结

## 背景

**连续碰撞检测（CCD）** 回答的问题是：在一个仿真时间步内，两个运动物体是否碰撞？若碰撞，发生在**何时**
（碰撞时刻，Time of Impact, ToI）、**何处**？它是保证物理仿真与建模中物体不互相穿透的核心引擎。两类错误的
代价是**不对称的**：

- **漏报（false negative, FN）**——漏掉了一次真实碰撞——会导致穿透、卡死、仿真在视觉/物理上崩坏。**不可接受。**
- **误报（false positive, FP）**——报告了一次本不存在的碰撞——只损失性能（多一次无害的接触响应）。**可容忍。**

因此一个 CCD 方法的黄金标准是：**可证明无漏报，且误报很少，即便在浮点算术下也成立。**

对**三角网格**而言，这基本已经解决。有两类方法：(a) 用精确谓词做*精确几何计算*（EGC，Brochu 2012、
Tang 2014）；(b) *误差界*方法——推导浮点累积误差的上界并保守地放宽决策阈值（Wang 2014、TightCCD 2015）。
两者都依赖一个事实：三角形 CCD 可归约为**封闭形式的多项式谓词**。

## 问题陈述

对**参数曲面**（张量积 / 三角 Bézier 曲面片，进而 NURBS）而言，鲁棒 CCD 一直是开放问题，原因有二：

1. **表示复杂性。** 参数曲面的碰撞**没有封闭解**。其非线性产生海量的接触构型，因此无法像三角形那样符号化地
   计算真值或穷举测试用例。更糟的是，非孤立接触（沿一整条曲线碰撞）会让符号求解器（Mathematica）对单个案例
   耗时 **>1 天**——构建基准数据集根本不可行。

2. **算法敏感性。** 当前最先进的方法 **TDIBM**（Chen et al. 2024）是唯一对一般参数曲面快到可用的 CCD——但它
   依赖精巧的数值流程（对线段按斜率排序、构造分段线性包络、求包络交点），其中含**大量分支型浮点比较**。
   单个被破坏的比较不仅改变数值，更能改变所构造几何体的**拓扑**，破坏保守性保证。为封闭形式谓词设计的传统
   累积误差界分析无法处理这种拓扑性失效。

本文同时攻克**两个**子问题：让*算法*鲁棒，并造一个*基准*来证明它。

## 主要贡献

1. **TDIBM-E：一个对参数曲面浮点鲁棒的 CCD 算法**，带有*已证明*的无漏报保证。关键是一种新的**误差来源分解**
   ——把包络构造误差拆成*系数*部分（`ε_coeff`）与*算术*部分（`ε_arith`）——再加上保守的安全措施
   （阈值偏移 `θ < −ε_θ`、包络上下平移 `ε_constr`、推开偏移 `δ`、截断），而且这些措施本身也在浮点下被
   安全地实现（线性化的界、`nextafter`）。

2. **一条反演构造的数据集流水线**，在有理数域中产生带*精确*真值的 CCD 测试用例。它*反演* CCD 流程：
   规定一个碰撞结果（ToI + 接触参数坐标），再用**精确有理算术**（GMP）反向求解控制点位置与速度。一套
   **"二进分数（dyadic）性质"** 纪律保证每个最终值都能无损地用 IEEE-754 double 表示。基准覆盖 6 类接触
   （FF、EF、EE、VF、VE、VV）加上 near-hit / near-miss 运动学角落用例。

3. **对四种方法的深入评测**，揭示具体的鲁棒性/效率权衡，并验证 TDIBM-E。

## 关键结果

基准含 **24,246 个用例**（11,023 个常规正例 + 11,023 个常规负例 + 1,100 个 near-hit 正例 + 1,100 个
near-miss 负例），全部为三角二次 Bézier 曲面片。

对比的四种方法：**Trad.**（经典包含法，对 5 维参数空间做完整细分）、**TDIBM**（原始版）、**TDIBM-H**
（启发式包络推开，因子 10⁻¹⁶、10⁻¹²、10⁻⁸）、**TDIBM-E（本文）**。

| 方法 | 漏报（FN） | 备注 |
|------|-----------|------|
| Trad. | 有 FN + FP；FF 用例需*数分钟* | 慢到不实用；只能跑子集 |
| TDIBM（原始） | **大量 FN**（如 VV 860/1100、VE 452/1100、VF 212/1100） | 快但不安全 |
| TDIBM-H (10⁻¹⁶) | 仍有 FN（EE 20、VF 22、VE 196、VV 658，均 /1100） | 推开量太小 |
| TDIBM-H (10⁻¹²) | **0 FN** | 有效——但只在这个手调值下 |
| TDIBM-H (10⁻⁸) | 0 FN 但**误报过多 + 变慢** | 过度保守 |
| **TDIBM-E（本文）** | **全部六类场景 0 FN** | **可证明**，FP ≤ TDIBM/TDIBM-H |

定量要点：
- TDIBM-E 在 FF、EF、EE、VF、VE、VV 上**消除了每一个漏报**。
- 运行时开销**适中：相对原始 TDIBM ≤120%，相对 TDIBM-H ≤40%**，在常见且计算密集的 FF/EF/EE/VF 上*几乎可忽略*。
  所有 TDIBM 变体每次查询都在 ~0.5 秒以内。
- TDIBM-H(10⁻¹²) 与 TDIBM-E 的运行时分布形状几乎一致（图 9）——误差界机制**不会**让最坏情况时间爆炸。
- 在**线性网格**基准（Erleben/Wang et al. 2021）上，TDIBM-E 仍是 **0 FN**（原始 TDIBM 在 EE 上有 338 FN），
  尽管在这些过度简化的几何上它更慢、更保守——这是可证明安全性的应有代价。
- 数据集生成：常规用例约 20–60 秒/个；near-hit/near-miss 因丢弃率高而更贵（EE 的 near 用例平均高达 ~1249 秒）。
  二进分数往返验证的丢弃率：**0%**——构造纪律完全保持了 double 的精确可表示性。

## 一句话总结

通过*分离误差来源*、并把每个不确定的决策都偏向无害的误报，本文把一个"快但不安全"的参数曲面 CCD 方法变成了
*可证明安全*的方法——并在首个面向参数曲面 CCD 的精确有理算术真值基准上验证了它，而该基准是通过**反向运行碰撞
检测**构造出来的。
