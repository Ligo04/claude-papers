4核心思想 —— 分解误差（式 11）

系数不精确与算术不精确联合分析不可行。论文插入一个想象的中间包络 f̂₁ （系数不精确、算术*精确*）把总误差拆成两个各自可定界的部分。

εconstr = max|f̂ − f|  ≤  max|f̂₁ − f| + max|f̂ − f̂₁|  =  εcoeff + εarith
εcoeff —— 系数不精确、算术精确。
干净的 Lipschitz 界：一条线 aₜ+b 带误差时偏离 ≤ tᵁ·ε_a + ε_b。 "如果我的数略错但我算得完美，包络有多偏？"
εarith —— 系数精确、算术不精确。
排序/去重*不*引入误差；只有 Φ、φ 的分支决策会。 这里**拓扑**可能崩坏——丢一条线的误差有界，≤ n₁m₁·max(4Δ_b, tᵁΔ_a+Δ_b)·[(1+ε)⁴−1]。

修法：把 max-包络上移 ε_constr（min-包络下移），把每个谓词 θ<0 测为 θ<−ε_θ，求交时用推开 δ 的包络——`δ` 取得使最坏情况端点误差抵消为**恰好零** （式 18）。每个偏置都指向误报——绝不漏报。保证：TDIBM-E 可证明无漏报。
