# 心智模型

## 这是哪一类问题？

这是一篇**鲁棒几何计算**论文，处在三个领域的交汇处：

- **计算机图形学 / 物理仿真** —— CCD 是碰撞响应的基础设施。
- **计算几何 / 数值分析** —— 核心是对分支密集型算法的浮点误差界推理。
- **基准 / 数据集构造** —— 一个方法论贡献（通过反演获得精确真值）。

它*不是*学习类论文，*不是*架构类论文。没有神经网络、没有训练。它是一篇**理论 + 系统**论文：证明一个保证，
再构建展示它的装置。

在脑中把它归到：Wang 2014《Defending CCD against errors》、TightCCD（Wang 2015）、Brochu 2012（精确三角 CCD）、
Wang et al. 2021（大规模*三角* CCD 基准）旁边——本文是**那整条脉络在参数曲面上的对应物，且一次给齐**
（既有安全算法，也有基准）。

## 需要哪些前置知识？

要读得顺畅，你应当了解：

1. **IEEE-754 浮点** —— 舍入到最近、机器 epsilon、相对误差模型 `|fl(x)−x| ≤ |x|ε`。二进分数 `p/2^k` 以及
   它们为何恰好是可表示实数。
2. **Bézier / Bernstein 曲面** —— 控制点、凸包性质、de Casteljau 细分、blossom。（NURBS → Bézier 转换作为背景。）
3. **连续碰撞检测** —— FN/FP 的含义以及为何 FN 是大罪；碰撞时刻；包含/分支定界范式。
4. **线段凸包 / 包络** —— 上方（凹）与下方（凸）分段线性包络，按斜率排序 + 栈的构造（"凸包技巧"）。这是整个
   误差分析所*围绕*的数据结构。
5. **分离轴测试 / OBB** —— 盒重叠如何归约为对轴的投影。
6. **精确有理算术** —— GMP，以及为何要用有理数计算以避免浮点伪影。

若缺第 4 项，先补它——整个 `ε_arith` 论证都是关于保持这个结构的*拓扑*。

## 解锁全文的那个类比

把 max-包络的构造想象成**用一堆按斜率排好的木板（线）搭一道围栏，你只保留构成外轮廓的木板。**
保留/丢弃的决策就是一次比较。浮点会让你*错判一块木板*——于是你的围栏出现缺口或折角。本文的修法有两步：
(1) 只在*确定*一块木板在内侧时才丢它（测 `Φ < −ε` 而非 `Φ < 0`），(2) 搭完后把*整道围栏抬高*最坏情况误差
（`+ε_constr`），使它始终位于真实轮廓之上。围栏太高 → 你以为东西碰了但也许没碰（FP，没事）。围栏有缺口 → 你
漏掉一次碰撞（FN，致命）。设计使缺口不可能出现。

对数据集而言：就像**先写好答案，再倒推出考题**——并确保考卷上每个数都是计算器能*精确*显示的，使测试本身
不引入误差。

## 它在更大研究图景中的位置

```
                 鲁棒连续碰撞检测
                 ─────────────────
   三角网格（成熟）                       参数曲面（本文）
   ────────────────                       ──────────────────
   精确谓词：Brochu'12, Tang'14          算法：   TDIBM (Chen'24，快、不安全)
   误差界：  Wang'14, TightCCD'15                 TDIBM-H (启发式，无保证)
   基准：    Wang et al.'21                       ► TDIBM-E (本文：可证明无 FN)
   真值：    Mathematica（可行）          基准：   ► 有理反演构造（本文）
                                          真值：   正向 = 不可行 → 反演它
```

本文明确地补上了缺口：三角形所拥有的一切（安全算法 + 精确基准）现在在光滑曲面上也有了。*方法*不同，因为三角形的
技巧（封闭形式谓词、正向符号真值）无法迁移。

## 如何给两个贡献归类

| | 算法（TDIBM-E） | 数据集流水线 |
|--|------------------|--------------|
| **体裁** | 数值鲁棒性证明 | 精确构造式基准 |
| **核心技巧** | 分解误差（系数 vs 算术）+ 保守偏移 | 反演 CCD + 二进分数纪律 |
| **保证** | 无漏报（已证明） | ℚ 中精确真值，无损落入 float |
| **可迁移到** | 任何分支密集型鲁棒几何（布尔、排布） | 任何"正向预言机不可行但反向可行"的问题 |

## 什么时候会用到这些思想？

- 你有一个**含大量浮点比较的几何算法**，其结果是组合性的，且你需要*保证*而非启发式 → 用**分解 + 保守偏移**模板。
- 你需要**正向求解器太慢/太符号化的问题的真值** → **反演**它，反向构造。
- 你需要在目标数值格式中**精确可表示**的测试输入 → 端到端强制一种**二进分数（或类似）可表示性纪律**，并用往返检查兜底。

## 这篇论文*不是*什么

- 不是更快的 CCD 方法（它略慢——这是安全的代价）。
- 不是关于*学习*接触或数据驱动仿真。
- 不处理面/曲线/流形接触（仅孤立点接触——已声明的局限）。
- 还不是完整 CAD 方案（NURBS 通过转换支持；复杂裁剪与多片自碰撞是未来工作）。
