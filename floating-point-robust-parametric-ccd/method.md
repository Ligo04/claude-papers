# 方法详解

## 0. 问题定义

两个参数（Bézier）曲面 `S₁(u₁,v₁,t)` 与 `S₂(u₂,v₂,t)`（⊂ ℝ³）之间的 CCD 是如下约束优化（式 1）：

```
最小化   t
约束     S₁(u₁,v₁,t) = S₂(u₂,v₂,t)
         0 ≤ u₁,v₁,u₂,v₂ ≤ 1
         0 ≤ t ≤ ΔT
```

解是**最早**接触时刻及其参数位置；无解 ⇒ 无碰撞。`n×m` 阶 Bézier 曲面片的控制点在该步内做*线性*运动（式 2）：

```
S(u,v,t) = Σᵢ Σⱼ Bⁿᵢ(u) Bᵐⱼ(v) (pᵢⱼ + t·ṗᵢⱼ)
```

其中 `Bⁿᵢ, Bᵐⱼ` 是 Bernstein 基，`pᵢⱼ, ṗᵢⱼ` 是控制点的位置与速度。两条标准假设（继承自 TDIBM）：控制点在一步
内线性运动；每个曲面位于其控制点凸包之内。

---

## 1. 背景：我们要使之鲁棒的 TDIBM 流水线

TDIBM 通过对 4 维参数域 `[0,1]⁴` 加一个时间区间做**分支定界**来求解式 1。每个节点持有一对子曲面，其范围为
`[u₁ᴸ,u₁ᵁ]×…`，以及一个时间窗 `[tᴸ,tᵁ]`。每个节点的工作：

**找出潜在碰撞窗** `[t_subᴸ, t_subᵁ] ⊆ [tᴸ,tᵁ]`，即两曲面有向包围盒（OBB）在 **15 条分离轴** `{lᵣ}` 上重叠的
时间窗。对每条轴，这是两个不等式（式 3a/3b），形如"一个盒的最大投影 ≤ 另一个盒的最小投影"，总共 **30 个**不等式，
形如（式 4）：

```
max_α (a⁽¹⁾_α · t + b⁽¹⁾_α)  ≥  min_β (a⁽²⁾_β · t + b⁽²⁾_β)
```

- 左边 = **max-包络**：一组线的上方、*凹*、分段线性包络。
- 右边 = **min-包络**：另一组线的下方、*凸*包络。
- 可行（碰撞候选）窗即 max-包络 ≥ min-包络处；*不可行*区域 `[τᴸ_r, τᵁ_r]`（二者不重叠处）是单一连通区间（凹
  只能在一段连通区间上超过凸）。对全部 30 个不等式取交 → 该节点的 `[t_subᴸ,t_subᵁ]`。

若可行，则**细分**参数区间，附上时间窗，压入按 `t_subᴸ` 升序排序的优先队列；否则**丢弃**该节点为无碰撞。
递归直到区间缩到阈值以下（如 10⁻⁶ → 找到碰撞）或队列清空（无碰撞）。

### 三个数值上脆弱的步骤（TDIBM 在此舍入）

- **步骤 I —— 计算系数** `a⁽¹⁾_α, b⁽¹⁾_α, a⁽²⁾_β, b⁽²⁾_β`（细分 + 插值 + OBB 轴构造 + 投影）。这里的误差以
  *可分析*的方式累积。
- **步骤 II —— 构造包络。** 按斜率排序、丢弃斜率重复且截距更小的线，然后是**栈机**：当 `Φ < 0`（新线更早相交并占优）
  时新线 `α` *替换*栈中线，当 `φ < 0` 时*加入*。设 `γ, γ−1` 为栈顶两条线、`Γ` 为栈大小：
  ```
  Φ = (a_α−a_{γ−1})(b_γ−b_{γ−1}) − (a_γ−a_{γ−1})(b_α−b_{γ−1})    若 Γ>0      (式 5a)
      (a_γ−a_α)·tᴸ + (b_γ−b_α)                                    若 Γ=0      (式 5b)
  φ = (a_γ−a_α)·tᵁ + (b_γ−b_α)                                                (式 6)
  ```
- **步骤 III —— 求包络交点**得到 `[τᴸ,τᵁ]`。先检查 `ψ`（max 是否起始于 min 之下，式 7）；否则按索引 `α,β`
  遍历两条包络，当 `Ψ_max < 0` 且 `Ψ_min < 0` 时测试线段相交（式 8–9），再用除法算端点（式 10）。

步骤 II 与 III 做**大量分支型浮点比较**。破坏其中任一个都可能翻转哪些线被保留 → 包络**拓扑**错误 →
几何错误/无效 → 潜在 FN。

## 2. 为何经典误差界在此失效（§4.1）

在精确算术下 TDIBM 是保守的（可能 FP，**不可能 FN**）。浮点打破了这点。与三角形 CCD 不同——那里单个封闭形式
谓词可通过把阈值放宽一个推导出的界来保证安全——参数流水线有*许多*由比较驱动的决策，它们对最终答案的贡献是
**模糊且非单调的**。一个误差能改变包络的*拓扑*（非凸/非多边形几何），这超出了传统累积误差分析的范围。故需要新策略。

## 3. 鲁棒性框架

### 3.1 浮点误差模型（§4.3）

IEEE-754：正确舍入的 `â` 满足 `|a − â| < |a|·ε`，机器 epsilon `ε = 2⁻²⁴`（单精度）/ `2⁻⁵³`（双精度）。¹
对任意由 `+`、`−`、`×` 构成的 `f`，**定理 4.1**（Wang 2014）给出：

```
ε_f = |f − f̂| ≤ B_f·[(1+ε)^{k_f} − 1]
```

其中 `B_f` 是 `|f|` 的上界，`k_f` 是"指数系数"，按运算逐步更新：
- `o = l ± r`  ⇒  `B_o = B_l + B_r`，  `k_o = max(k_l,k_r) + 1`
- `o = l × r`  ⇒  `B_o = B_l · B_r`，  `k_o = k_l + k_r + 1`

> ¹ 论文正文印的是 `2⁻¹⁷`/`2⁻⁵²`；标准的舍入到最近值应为 `2⁻²⁴`（单）与 `2⁻⁵³`（双，舍入到最近）。分析只依赖
> 界的*形式*，故纪律不受影响，但对所印的单精度常数请存疑。

### 3.2 包络构造的误差分解（§4.4）—— 核心思想

定义三条包络并分解误差（式 11）：

```
f   = max_α (a_α t + b_α)      精确系数，精确算术                （真值）
f̂₁  = max_α (â_α t + b̂_α)      系数不精确，算术精确              （想象中间体）
f̂   = ˆmax_α (â_α t + b̂_α)     系数不精确，算术不精确            （真实）

ε_constr = max_t|f̂ − f| ≤ max_t|f̂₁ − f| + max_t|f̂ − f̂₁| = ε_coeff + ε_arith
```

**(a) 系数误差 `ε_coeff`。** 以每系数界 `ε_a = B_a[(1+ε)^{k_a}−1]`、`ε_b = B_b[(1+ε)^{k_b}−1]`（附录 A），
单条线偏离 `ε_line ≤ tᵁ·ε_a + ε_b`，于是（式 12）：
```
ε_coeff ≤ tᵁ·ε_a + ε_b
```

**(b) 算术误差 `ε_arith`。** 把系数视为精确。排序与去重**不**引入误差（只比较/重排）。误差经 `Φ`、`φ` 进入。
由定理 4.1：
```
ε_Φ^{γ>0} ≤ (â_α−â_{γ−1})(|b̂_α−b̂_{γ−1}| + |b̂_γ−b̂_{γ−1}|)·[(1+ε)⁴−1]          (式 13)
ε_Φ^{γ=0} ≤ (|â_γ−â_α|·tᴸ + |b̂_γ−b̂_α|)·[(1+ε)³−1]                              (式 14)
ε_φ       ≤ (|â_γ−â_α|·tᵁ + |b̂_γ−b̂_α|)·[(1+ε)³−1]                              (式 15)
```
**鲁棒修订：** 把添加/替换准则从 `Φ<0, φ<0` 改为 **`Φ < −ε_Φ` 且 `φ < −ε_φ`**。则真正 `Φ_fp < −ε_Φ`
保证精确的 `Φ_ex ≤ Φ_fp + ε_Φ < 0`——正确。这可能*丢*一条有效线，但丢线只会*增大* max-包络（图 2 左）→
扩大碰撞窗 → FP 而非 FN。错丢的损害本身有界；例如 `Φ^{γ>0}` 情形下最大偏离发生在交点 `t_Φ`，等于
`Δ_Φ = −Φ_ex/(â_α−â_{γ−1}) ≤ 2ε_Φ^{γ>0}/(…)`。由于每条线最多入栈/出栈一次，总丢弃数 ≤ `n₁m₁`，得（式 16）：
```
ε_arith ≤ n₁m₁ · max(4Δ_b , tᵁ·Δ_a + Δ_b) · [(1+ε)⁴−1]
```
其中 `Δ_a = max|â_γ−â_α|`，`Δ_b = max|b̂_γ−b̂_α|`。

**合在一起。** 把计算出的 **max-包络上移 `ε_constr`**（给每条选中线的截距 `b̂_γ` 加 `ε_constr`）；对称地把
**min-包络下移**。此后把平移后的系数视为精确，记作 `{c_α}, {d_α}`。（平移本身在浮点下计算；安全性见附录 B。）

### 3.3 包络相交的误差分析（§4.5）

系数现在是"精确"的（`c,d`），误差只来自相交算术。给 `ε_ψ, ε_Ψmax, ε_Ψmin` 定界（定理 4.1；完整形式见附录 C.1）
并相应把准则改为 `ψ < −ε_ψ`、`Ψ_max < −ε_Ψmax`、`Ψ_min < −ε_Ψmin`，例如（式 17）：
```
ε_Ψmax = (|c⁽¹⁾_{α+1}−c⁽²⁾_β|·|d⁽¹⁾_α−d⁽²⁾_β| + |c⁽¹⁾_α−c⁽²⁾_β|·|d⁽¹⁾_{α+1}−d⁽²⁾_β|)·[(1+ε)⁴−1]
```

**困难情形——近平行线段。** 当 `(c⁽²⁾_β − c⁽¹⁾_{α+1}) → 0` 时，交点端点（一个除法）会任意放大算术误差。
直接定界既贵又微妙。**解法：把两条包络额外推开 `δ`**，对*修改后*的包络 `{c⁽¹⁾_α t + d̃⁽¹⁾_α}` 与
`{c⁽²⁾_β t + d̃⁽²⁾_β}` 求交，其中
```
d̃⁽¹⁾_α = d⁽¹⁾_α + δ ，  d̃⁽²⁾_α = d⁽²⁾_α − δ ，  取  δ = 2·Δ_d·[(1+ε)⁴−1]，Δ_d = max|d⁽¹⁾_α−d⁽²⁾_β|
```
则端点误差望远镜式地归为**零**（式 18）：
```
Δ_t ≤ (2 / (c⁽²⁾_β − c⁽¹⁾_{α+1})) · ( (|d⁽¹⁾_α−d⁽²⁾_β| + |d⁽¹⁾_{α+1}−d⁽²⁾_β|)[(1+ε)⁴−1] − δ ) = 0
```
即所选 `δ` 恰好抵消最坏情况算术误差，而非去度量它。在 `I` 次预测有相交的迭代中累积推开 `Iδ` 仍安全
（望远镜求和证明，附录 C.3：`τ₀ − τ_I ≤ 0`）。

边界子情形均被处理且证明安全：式 7 误判 → 要么安全终止、要么截断到 `tᴸ`；式 8b/9b 误判 → 无害的漏掉一段。
端点 `τᴸ`（式 10）的除法误差有界（附录 C.2）：`ε_τᴸ ≤ 2(l/|r̂|)[(1+ε)²−1]`，保守地增大 `δ` 并推迟 `τᴸ`。
最终 `τᴸ` 是供合并/细分流水线使用的可证明安全值。

### 3.4 修订汇总（§4.6）→ 算法 "TDIBM-E"

1. 对每个谓词 `θ < 0`，计算其累积误差 `ε_θ` 并测试 `θ < −ε_θ`。
2. 步骤 II 之后，把 max-包络**上移**、min-包络**下移** `ε_constr`。
3. 定位交点时，在**推开后**的包络（偏移 `δ`）上计算，保守地计入除法误差，并把结果**截断**进 `[tᴸ,tᵁ]`。

**保证：** 在线性运动 + 凸包假设下，TDIBM-E **无漏报**——即便在浮点实现下，每个真实碰撞都会被检测到。

### 3.5 误差界的安全实现（附录 B）

界本身也在浮点下计算，故也会舍入。安全措施：
- 把 `ε_x = B_x[(1+ε)^{k_x}−1]` 保守地近似为 `ε'_x = 2·B_x·k_x·ε`（把指数项线性化、×2 安全），使计算出的界
  可证明 ≥ 真界。
- 构造保守数 `x ± ε_x` 时用 C++ `std::nextafter` 朝安全方向跳到下一个可表示 double，吸收最后的舍入。

## 4. 数据集生成（§5）

**洞见：反演 CCD。** 正向真值需符号/迭代求解，在困难（非孤立）接触上 >1 天。改为规定结果、用**精确有理算术**
（GMP）反向求解。流水线（图 4）：

```
步骤 I   规定 CCD 解：采样 ToI t* 与接触坐标 (u*₁,v*₁),(u*₂,v*₂)
步骤 II  构造 t* 时刻的静态配置：用线性约束方程组强制 S₁=S₂ 于该处；
         留出相匹配数量的自由度，给其余赋兼容值，用高斯消元恢复。
         （FF：加切性约束 ∂Sᵢ/∂u·n = ∂Sᵢ/∂v·n = 0，反平行法向，式 19）
步骤 III 抽取接触附近的局部曲面片（避免无关碰撞）
步骤 IV  推断初始状态：采样接触点速度（取相反半空间以促使碰前分离），求控制点速度，回溯位置
步骤 V   首次碰撞验证：在 [0,t*) 上跑有理 TDIBM；若有更早接触则丢弃
步骤 VI  定型：保存配置并标 GT=1；把步长缩为 ΔT=1−ε_T 以制造匹配的 GT=0 用例
```

**接触分类（6 类几何）：** 面-面（FF，内部×内部，常见情形）、边-面（EF）、边-边（EE）、点-面（VF）、
点-边（VE）、点-点（VV）。加上**运动学角落用例**：*near-hit*（相对速度落在切平面 → 擦过但精确接触，GT=1）与
*near-miss*（沿法向略微偏移 → 险些错过，GT=0）。

**每类几何四个数据类别：** 常规正例（RP，GT=1）、常规负例（RN，缩短步长得 GT=0）、Near-Hit 正例（NHP）、
Near-Miss 负例（NMN）。near 类约为常规的 1/10。

### 4.1 二进分数性质（§5.4，附录 E）—— 让输入精确地可用 double 表示

一个实数恰好是 double ⟺ 它是**二进分数**：`p/2^k`，`|p|<2⁵³`。威胁：高斯消元的主元除数是任意多项式，几乎从不是
2 的幂，会破坏二进分数性。对策：
- **选二进分数输入：** 控制点/速度取 `m/2^k`；UV 坐标取自满足 `u+v≤1` 的小二进分数集；**法向分量 ∈ {0, ±2^k}**，
  常用轴对齐 `(1,0,0)` 来解耦方程。
- **用 2×2 克拉默法则求解**候选子矩阵；只接受有理残差*恰好为零*的（而非完整高斯消元）。
- **往返验证：** 有理 `r` → double `d` → 有理 `r'`；仅当所有值 `r=r'` 才接受。实测丢弃率：**0%**。

### 4.2 快速静态穿透检查（附录 D）—— 一个加速器

切性是首次接触的必要但不充分条件（鞍形局部几何即便切平面对齐也可能穿透）。一个廉价的**二阶**预过滤：对采样的
切向 `d`，映回参数方向，计算二阶法向偏移 `oᵢ = n·(½Δuᵢ²∂²S/∂u² + ΔuᵢΔvᵢ∂²S/∂u∂v + ½Δvᵢ²∂²S/∂v²)`，并要求
`o₁−o₂` 在各方向上保持符号一致（一个曲面始终在另一个的同一侧）。是近似的，但严格的有理 TDIBM 验证（步骤 V）
仍保证正确性——这只是提前丢弃坏用例。

### 4.3 生成的基准（§5.5，表 4）

**24,246 个用例**，全部为**三角二次 Bézier 曲面片**，精确有理算术。计数：RP 11,023 + RN 11,023 + NHP 1,100 +
NMN 1,100。曲率多样性广（RMS 曲率从 ~0.29 到 2.2×10⁴，均值 260，中位数 ~10；图 5）。生成 ~19–59 秒/个（常规）；
near 用例更贵（EE 的 near 平均高达 ~1249 秒）因丢弃率更高。

## 5. 评测（§6）—— 对比

四种方法：**Trad.**（经典包含法，完整 5 维细分）、**TDIBM**（原始）、**TDIBM-H**（启发式包络推开，因子
10⁻¹⁶/10⁻¹²/10⁻⁸）、**TDIBM-E（本文）**。OBB 包含、收敛阈值 10⁻⁴；16 核 4.5 GHz Ryzen 9 7950X、64 GB。

由于曲面片是局部抽取的（≈ 近平面——对多片 CAD 真实，但对包含法 CCD 是*最坏情况*），所有方法都比 Chen 2024 慢。

**要点（表 1 / 图 8）：**
- **Trad.** —— FN + FP；FF 用例需*数分钟*；不实用，只能跑子集。
- **TDIBM（原始）** —— 快但大量 FN：如 EE 135、VF 212、VE 452、**VV 860**（/1100）。
- **TDIBM-H(10⁻¹⁶)** —— 太小，仍有 FN（EE 20、VF 22、VE 196、VV 658）。
- **TDIBM-H(10⁻¹²)** —— **0 FN**（Chen 2024 的经验甜点）。
- **TDIBM-H(10⁻⁸)** —— 0 FN 但 FP 过多 + 慢。
- **TDIBM-E（本文）** —— **全部六类场景 0 FN**，FP ≤ TDIBM/TDIBM-H，相对 TDIBM 开销 ≤120%、相对 TDIBM-H ≤40%，
  在常见 FF/EF/EE/VF 上几乎可忽略。运行时分布形状 ≈ TDIBM-H(10⁻¹²)（图 9）——无最坏情况爆炸。
- **线性网格基准**（Erleben/Wang 2021，表 3）：TDIBM-E **0 FN**（原始 TDIBM 在 EE 上 338 FN）——但在这些过度
  简化几何上更慢且 FP 更多。

**结论：** Trad. 不实用；TDIBM 快但不安全；TDIBM-H 需要幸运常数且无保证；**TDIBM-E 以适度代价给出可证明鲁棒。**

```
  │  规定 (t*,u*,v*) → 求配置(线性,二进分数) → 抽取曲面片    │
  │  → 推断速度 → 有理 TDIBM 首次接触验证                    │
  │  → GT=1 ; 缩 ΔT → GT=0 ; 二进分数往返检查 (0% 丢弃)      │
  └─────────────────────────────────────────────────────────┘
```

## 7. 实现陷阱与复现风险

- **§4.3 的单精度 epsilon 印错了**（`2⁻¹⁷` 应为 `2⁻²⁴`）。用正确的 IEEE-754 值；实验本就是双精度（`2⁻⁵³`）。
- **界本身也必须安全计算。** 朴素地在浮点下算 `B[(1+ε)^k−1]` 会*低估*。要用线性化的 `2Bkε` 上估 + `nextafter`
  （附录 B），否则整个保证会漏。
- **推开 `δ` 是逐迭代累积的。** 在 `I` 次预测有相交的迭代后需要 `Iδ` 的分离——要追踪 `I`，别用固定偏移。
- **二进分数纪律脆弱。** 随机有理 UV 坐标或非 `2^k` 法向会通过高斯消元除数悄悄破坏精确性。要约束输入*并*保留
  往返检查作为兜底。优先轴对齐法向以解耦线性系统。
- **用克拉默法则而非高斯消元求解**——只接受恰好为零的有理残差。
- **近平面局部曲面片是压力区。** 在*原始*（未抽取）曲面片上做基准会低估运行时与 FN 率；局部抽取是有意且真实的。
- **超参敏感性：** TDIBM-H 的推开因子是*那个*旋钮——10⁻¹⁶ 漏 FN，10⁻⁸ 让 FP/时间爆炸，10⁻¹² 是狭窄经验最优。
  TDIBM-E 用逐用例界去掉这个旋钮；别再引入全局常数。
- **收敛阈值（这里 10⁻⁴，§3 中 10⁻⁶）：** 影响运行时与报告 ToI 的粒度；对比时保持一致。
