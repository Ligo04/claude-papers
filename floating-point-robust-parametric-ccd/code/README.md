# 代码 Demo

三个自包含、无第三方依赖的 Python Demo（仅用标准库——以 `fractions.Fraction` 做精确算术）。每个隔离论文的一个
核心思想，可独立运行：`python3 <文件>.py`。

| 文件 | 论文章节 | 演示内容 |
|------|----------|----------|
| `envelope_robustness_demo.py` | §4.1, §4.4, 图 2 | 一次翻转的浮点比较如何**破坏分段线性包络的拓扑**（丢掉一条线 → 包络跌到真值之下 → *漏报*），以及论文的 `Φ < −ε` 安全措施如何通过把每个不确定分支偏向保留线（→ 无害误报）来防止它。 |
| `inverse_construction_demo.py` | §5.1, §5.4, 图 4 | **反演** CCD：规定一个碰撞，*反向*（精确有理数）求解出能产生它的曲面配置。还复现了**二进分数性质**的微妙之处——朴素的接触参数（3/4）会破坏精确浮点可表示性而被*丢弃*，而 2 的幂选择（1/2）通过往返检查。 |
| `floating_point_error_bound_demo.py` | §4.3（定理 4.1）, 附录 B | `(B,k)` 误差界递推，在 20 万随机输入上对照**精确**真值验证。关键展示*为何*需要附录 B：在 float64 下朴素计算 `(1+ε)^k−1` 会**坍缩为 0**（不安全），故界必须上估为 `2·B·k·ε` 并配合 `nextafter`。 |

## 运行时的预期亮点

- **envelope**：情形 [2] 因丢线报告 `FALSE NEGATIVE (UNSAFE)`；情形 [3] 加安全措施后恢复精确/安全。
- **inverse**：尝试 A → `DISCARDED`（非二进分数 `5/6`、`7/24`）；尝试 B → `ACCEPTED`。
- **error bound**：精确界 `violations: 0`，朴素浮点界 `violations: 200000`（坍缩），安全界 `violations: 0`。

这些被刻意简化（1 维"曲面"、合成的比较噪声），以便在几十行内让*机制*可见——它们是教学模型，不是完整的
TDIBM-E 实现。
