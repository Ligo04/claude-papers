# 方法详解：双网格映射器 与 GMCP

本文涉及大量计算几何与接触力学推导。本篇按"系统架构 → 双网格映射器 → GMCP（采样 / barrier 势 / 权重 / 自适应半径 / 步长）"的顺序，逐步拆解每个公式的来龙去脉。

---

**每个物理步的数据流**：
1. RL Policy → Articulation 产生 joint drives。
2. Articulation Constraint 读取关节驱动的刚体位姿，作为**约束**注入 libuipc。
3. libuipc 在 GPU 上求解刚体+可变形动力学（含 GMCP 接触），输出 deform. state。
4. Dual-Mesh Mapper 把仿真网格 `M_sim` 的变形插值到视觉网格 `M_vis`。
5. Fabric Bridge 把 `M_vis` 顶点位置写回 USD/Fabric stage，供 Omniverse 渲染。

**Subscene Tabular**：把仿真划分为单 GPU 上多个**完全隔离**的子场景，实现大规模并行 rollout（图 8、图 10 展示了多环境并行）。还支持**单环境 reset**（选择性重置），便于刚-柔耦合的 RL 环境。

## 1. 双网格映射器（Dual-Mesh Mapper）

### 动机
重建或程序化生成的资产（如 Hunyuan3D）通常**只有表面网格**，而可变形仿真需要**体积离散化**（如 TetGen 四面体化）。四面体化会改变网格拓扑、破坏纹理坐标参数化和材质绑定——这些恰恰是照片级渲染必需的。

解法（受骨架驱动动画的重心嵌入 [Capell 2002] 和 Embedded IPC [Du 2024c] 启发）：维护两套网格：
- `M_sim`：仿真网格（接触+变形）
- `M_vis`：视觉网格（渲染），保留原始纹理坐标、材质绑定、拓扑

### 1.1 预计算（初始化时一次性）

对每个视觉顶点 `p_i ∈ V`（i=1,…,N），通过**最近点投影**嵌入到仿真网格表面。找到最近的仿真三角形 `T_i`（顶点 {v₀,v₁,v₂}），计算重心坐标 (u_i, v_i, w_i)：

```
p̂_i = u_i·v₀ + v_i·v₁ + w_i·v₂,    u_i + v_i + w_i = 1        ...(1)
```

其中 `p̂_i` 是 `p_i` 在 `T_i` 上的投影。

**求重心坐标的推导**：令
```
e₁ = v₁ − v₀,   e₂ = v₂ − v₀,   n_i = (e₁×e₂)/‖e₁×e₂‖   （T_i 单位法向）
d  = p_i − v₀,   δ_i = d·n_i     （p_i 到 T_i 平面的有符号偏移）
```

则可把 d 分解为切向 + 法向分量：
```
d = v_i·e₁ + w_i·e₂ + δ_i·n_i        ...(2)
```

把 (2) 分别点乘 e₁ 和 e₂，由于 n_i·e₁ = n_i·e₂ = 0，δ_i·n_i 项消失，得到 **2×2 线性方程组**：

```
┌ e₁·e₁   e₁·e₂ ┐ ┌ v_i ┐   ┌ d·e₁ ┐
│              │ │     │ = │      │                          ...(3)
└ e₁·e₂   e₂·e₂ ┘ └ w_i ┘   └ d·e₂ ┘
```

解出 (v_i, w_i)，再由 u_i = 1 − v_i − w_i。这其实就是 **Gram 矩阵法求平面内重心坐标**。

> 注意：左边的 2×2 矩阵正是边向量的 **Gram 矩阵**（第一基本形式），它一定可逆（只要三角形不退化）。

最终每个视觉顶点存储一个五元组 `(T_i, u_i, v_i, w_i, δ_i)`。这个映射 `{(T_i, u_i, v_i, w_i, δ_i)}` 计算一次后存储。

### 1.2 每帧更新

仿真步后，仿真顶点更新到变形位置。视觉顶点位置通过**插值变形后的仿真顶点 + 恢复法向偏移**得到：

```
p'_i = u_i·v'₀ + v_i·v'₁ + w_i·v'₂ + δ_i·n'_i,    i=1,…,N      ...(4)
```

- `v'₀, v'₁, v'₂`：T_i 三顶点的变形后位置。
- `n'_i`：变形后三角形 T_i 的单位法向。
- 重心坐标 (u_i, v_i, w_i) 和偏移 δ_i 都是**预计算的常数**，每帧不变。
- `M_vis` 的拓扑、纹理坐标、材质绑定**全程不变**，每帧只更新顶点位置 {p'_i}。

### 1.3 性质
- **刚性不变（rigid-invariant）**：整体刚体运动下重心插值+法向偏移自动正确。
- **误差阶 O(h²)**：对一般变形是分段线性近似误差，h 为仿真三角形边长。渲染保真度随网格细化**二次提升**。

### 算法伪码

```
# 预计算（一次）
for each visual vertex p_i:
    T_i = nearest_triangle(p_i, M_sim)        # 最近点投影
    (v0,v1,v2) = vertices(T_i)
    e1 = v1 - v0; e2 = v2 - v0
    n_i = normalize(cross(e1, e2))
    d = p_i - v0
    δ_i = dot(d, n_i)
    # 解 2x2 Gram 系统求 (v_i, w_i)
    G = [[dot(e1,e1), dot(e1,e2)], [dot(e1,e2), dot(e2,e2)]]
    rhs = [dot(d,e1), dot(d,e2)]
    (v_i, w_i) = solve(G, rhs)
    u_i = 1 - v_i - w_i
    store(i, T_i, u_i, v_i, w_i, δ_i)

# 每帧
for each visual vertex p_i:
    (v0',v1',v2') = deformed_vertices(T_i)
    n_i' = normalize(cross(v1'-v0', v2'-v0'))
    p_i' = u_i*v0' + v_i*v1' + w_i*v2' + δ_i*n_i'   # 公式(4)
```

## 2. GMCP：几何 mortar 接触势

**约定**：压力在**触觉表面**上评估 → 触觉面作为 **slave（从面）**几何。对面是 **master（主面）**，其局部接触特征可能是：面片、线段、或点。slave 三角网格 S 提供局部参数化和法向场 n_s。

### 2.1 接触采样

接触样本通过**把主特征投影并裁剪到局部 slave 三角形**构建。三类样本（图 4）：

```
   T_s (slave)          T_s                  T_s
   ┌────────┐        ┌────────┐           ┌────────┐
   │  ╱╲    │  T_m   │  ╱╲    │  e_m      │  ╱╲    │  v_m
   │ ╱██╲   │ ◀面片  │ ╱│ ╲   │ ◀边段     │ ╱ •╲   │ ◀点
   │╱████╲  │        │╱ │  ╲  │           │╱   ╲  │
   └────────┘        └────────┘           └────────┘
   Face sample        Edge sample          Point sample
   (主面是面)          (主面是边)            (主面是点)
```

每个样本 k 存储：slave 上的位置 `x_s,k`、关联的 master 位置 `x_m,k`、样本权重 `w_k`、沿 slave 法向测量的有符号间隙 `g_k`。

**面样本（Face samples）**：对 slave 三角形 T_s 和 master 三角形 T_m：
1. 把两三角形投影到 T_s 的切平面。
2. 用 **Sutherland-Hodgman 裁剪**[1974] 求重叠多边形。
3. 重叠多边形**扇形三角化**，用 **2D Gauss 求积**积分。
4. 在样本 k 处，重心坐标 β^s_{a,k} 和 β^m_{a,k} 插值 slave 和 master 位置：

```
x_s,k = Σ_a β^s_{a,k}·x_s,a,    x_m,k = Σ_a β^m_{a,k}·x_m,a,   a=0,1,2   ...(5)
```

有符号间隙：
```
g_k = n_s·(x_m,k − x_s,k)        ...(6)
```

**边样本（Edge samples）**：对 master 边 e_m=(x^e_{m,0}, x^e_{m,1})，投影到 slave 三角形切平面并裁剪。用边参数 η∈[0,1]：
```
x_m,k = (1−η_k)·x^e_{m,0} + η_k·x^e_{m,1}        ...(7)
```
每个 1D Gauss 点给出 slave 重心坐标 β^s_{a,k}：
```
x_s,k = Σ_a β^s_{a,k}·x_s,a,   a=0,1,2          ...(8)
g_k = n_s·(x_m,k − x_s,k)                        ...(9)
```

**点样本（Point samples）**：对 master 顶点，投影到 slave 三角形生成点样本。用投影 slave 位置 x_s,k 和 master 顶点位置 x_m,k 按 (6)/(9) 算间隙 g_k。

### 2.2 GMCP Barrier 势

令 K_q 表示 slave 表面上类型 q 的接触样本。离散 barrier 势：

```
        ┌─ 类型(2面/1边/0点) ┐
Ψ = Σ        Σ      κ_q · w_k · γ_k · B(g_k, ε_k)        ...(10)
   q∈{2,1,0}  k∈K_q
```

各项含义：
- `q=2,1,0`：面、边、点样本。
- `w_k`：样本权重，单位对应**面积 / 长度 / 点贡献**（这是 mortar 积分的体现）。
- `κ_q`：类型 q 的 barrier 刚度。
- `γ_k`：master 特征权重（见 2.3）。
- `ε_k`：barrier 支撑半径（见 2.4）。
- `B`：barrier 函数，遵循 IPC [Li 2020]；**也可换成 GCP [Huang 2025b] 等其他函数**（可插拔）。

> **理解 (10) 的关键**：这就是把"接触面上的积分"（Σ w_k）作为权重，乘以"间隙→能量"的 barrier 函数 B(g_k)。barrier 保证 g_k→0 时能量→∞（不穿透），积分权重保证压力分布在面上正确传递。

**梯度与 Hessian**（用于牛顿法求解）：
```
∇Ψ  = Σ_q Σ_{k∈K_q} κ_q·w_k·γ_k · (∂B/∂g_k) · ∇g_k                    ...(11)

∇²Ψ = Σ_q Σ_{k∈K_q} κ_q·w_k·γ_k · (∂²B/∂g_k²) · ∇g_k·(∇g_k)ᵀ          ...(12)
```
Hessian 贡献**投影到半正定锥（PSD cone）**——这是 IPC 类方法保证牛顿法下降方向的标准做法。

> 注意 (12) 用的是 Gauss-Newton 型近似：只保留了 (∂²B/∂g²)·∇g∇gᵀ 项，丢掉了 B'·∇²g 项。这使 Hessian 天然半正定（B''≥0 时），无需额外特征值修正即接近 PSD，GPU 友好。

### 2.3 Master 特征权重 γ

权重 γ 控制 master 侧 face/edge/point 样本之间的过渡，用 **C¹ Hermite 阶跃**在主特征边界附近平滑缩放样本贡献：

```
         ┌ 0,                       x ≤ 0
H(x,δ) = │ 3t² − 2t³,  t = x/δ      0 < x < δ                ...(13)
         └ 1,                       x ≥ δ
```

**面样本**：
```
f_T = H(min_a β^m_a, δ_T)        ...(14)
```
β^m_a 是 master 三角形上的重心坐标，δ_T 是靠近 master 三角形边的过渡宽度。→ 面样本靠近主三角形边缘时衰减。

**边样本**：
```
f_e = H(η, δ_e)·H(1−η, δ_e)      ...(15)
```
η 是 master 边参数，δ_e 是靠近 master 边端点的过渡宽度。→ 边样本靠近主边端点时衰减。

**最终权重**：
```
    ┌ f_T   面样本
γ = │ f_e   边样本                  ...(16)
    └ 1     点样本
```

> **为什么需要 γ**：防止接触在 face/edge/point 之间**重复计数**。当接触点恰在主三角形边缘时，面样本权重→0、由边样本接管；恰在端点时边样本权重→0、由点样本接管。C¹ 连续保证 Hessian 平滑，牛顿法不抖动。

### 2.4 自适应 barrier 支撑半径 ε

受 GCP [Huang 2025b] 启发，每个样本用自适应支撑半径 ε_k **避免伪力**：

```
ε_k = min(0.9·g_ref,k, ε_max)        ...(17)
```
- `g_ref,k`：到关联 master 特征的间隙。
- `ε_max`：预设的支撑半径上界。

这保证 `g_ref,k > ε_k`，于是**静止态下 barrier 不激活**，伪力被消除。

### 2.5 线性化间隙步长

对当前接触样本，从**线性化间隙**计算步长上界。对使样本 k 间隙减小的位移 Δx：

```
α*_k = 0.9·g_k / (−∇g_k·Δx),    当 ∇g_k·Δx < 0           ...(18)
```

全局步长：
```
α = min_k α*_k        ...(19)
```
最小值在所有满足 ∇g_k·Δx<0 的样本上取，g_k 和 ∇g_k 在**无穿透位置**评估。

> **直觉**：g_k + α·(∇g_k·Δx) 是间隙的线性预测。令它等于 0 解出"刚好接触"的步长 g_k/(−∇g_k·Δx)，再乘 0.9 留安全裕度，保证走完这一步间隙仍 > 0。

## 3. 整体求解循环（推断的伪码）

```
# 一个 IsaacIPC 物理步
1. IsaacSim 算关节驱动 → joint poses
2. Articulation Constraint 注入 libuipc
3. libuipc 隐式时间积分（牛顿迭代）:
   while not converged:
       a. 构建接触样本 K_q (face/edge/point)：投影、裁剪、求积
       b. 算 Ψ, ∇Ψ, ∇²Ψ (公式 10/11/12)，Hessian PSD 投影
       c. 加上弹性/惯性项，解牛顿系统 ∇²E·Δx = −∇E
       d. CCD + 线性化间隙步长 α (公式 18/19) 求安全步长
       e. 线搜索（barrier 保证可行），更新位置
4. Dual-Mesh Mapper: p'_i = u_i v'₀+v_i v'₁+w_i v'₂+δ_i n'_i (公式 4)
5. Fabric Bridge 写回 USD/Fabric → Omniverse 渲染
```

## 4. 实现陷阱与复现风险

### 双网格映射器
- **最近点投影的歧义**：视觉顶点可能投影到多个仿真三角形等距处（如棱边/角点附近），需一致的 tie-breaking，否则法向 n_i 会跳变。
- **退化三角形**：若仿真三角形近退化，Gram 矩阵 (3) 病态，重心坐标不稳。需检测并跳过/正则化。
- **法向翻转**：变形剧烈时 n'_i 可能指向错误半空间，导致视觉顶点穿到内侧。需保证仿真网格变形不翻转（IPC 的无翻转保证在此帮了大忙）。
- **尖锐特征处误差**：O(h²) 是"一般变形"下的阶，在高曲率/尖锐特征处常数因子大，渲染可能露馅。

### GMCP
- **裁剪鲁棒性**：Sutherland-Hodgman 在共面、近平行、零面积重叠等退化情形下需谨慎处理浮点，否则 face 样本权重出错。
- **求积阶数**：Gauss 求积点数不足会低估接触面积、导致压力分布失真；过多则浪费 GPU。需按精度需求调。
- **κ_q 调参**：论文显示 κ=10⁶ 后误差饱和；太小（10⁴）误差大，太大数值条件差。三类样本的 κ_q 是否同值论文未明说，是复现风险点。
- **γ 过渡宽度 δ_T, δ_e**：太小过渡突兀（接近 C⁰）、Hessian 抖；太大则混淆 face/edge/point 贡献。需扫描。
- **g_ref,k 的定义**："关联 master 特征的间隙"具体如何选取关联特征，论文描述较简，是复现难点。
- **PSD 投影**：(12) 的 Hessian 投影到半正定锥的具体方式（per-sample 还是 per-element）影响收敛。

### 超参数敏感性小结
| 超参 | 太小 | 太大 | 论文取值/线索 |
|------|------|------|---------------|
| barrier 刚度 κ | 误差大 | 数值条件差 | 10⁶（patch test 最优起点）|
| 支撑半径 ε_max | barrier 难激活 | 伪力 | patch test 用 0.001，Hertz 用 10⁻⁵ |
| 步长系数 | — | 穿透风险 | 固定 0.9 |
| γ 过渡宽度 δ | C⁰ 抖动 | 重复计数 | 论文未给具体值 |
| 仿真网格 h | — | 渲染失真/接触粗 | 越细 O(h²) 越准但越慢 |

## 参考的关键外部方法
- **IPC** [Li et al. 2020]：barrier 函数 B 的原型。
- **GCP** [Huang et al. 2025b]：自适应支撑半径 (17) 的灵感来源；barrier B 的可选替代。
- **Sutherland-Hodgman** [1974]：face 样本的多边形裁剪。
- **Affine Body Dynamics** [Lan et al. 2022a]：演示中刚体用 ABD 模拟。
- **Embedded IPC** [Du et al. 2024c] / **重心嵌入** [Capell 2002]：双网格映射的灵感来源。
- **经典 mortar** [Puso & Laursen 2004; Wohlmuth 2000; Farah 2018]：mortar 积分思想来源。
