MAS-PNCG 算法流水线（点击查看详情）

接触检测 ComputeConstraintSet
检测所有距离 d < d̂ 的接触对，构建当前接触集 C_curr。用于后续 Woodbury 更新和 barrier 梯度计算。
预条件器维护（Restart / Woodbury Update）
如果 Restart=True：完全重建 MAS 层次结构（Level-0 到 Level-L）。否则：仅用 Woodbury 公式增量更新 Level-0 子域逆，粗层级保持冻结。重启判据：r_k = |g_{k+1}ᵀz_k|/(g_{k+1}ᵀz_{k+1}) > δ。
梯度计算 ∇E(x)
计算总能量梯度 = 惯性项 + 弹性项 + barrier 接触项 + 摩擦项。注意：完全避免 Hessian 矩阵的显式组装。
预条件方向 z = P·g
对每个 Level-0 子域应用（可能含 Woodbury 更新的）逆矩阵，加上冻结的粗层级校正。z_{k+1} = Σ S_dᵀ z_d + Σ C_(l)ᵀ M_(l)⁻¹ C_(l) g_{k+1}。
2D 子空间最小化 → 搜索方向 p
如果 Restart：μ = (zᵀg)/(zᵀH̃z), ν=0。否则：解 2×2 系统求 (μ,ν)，p = -μz + νp_prev。利用近似 Hessian H̃ 的曲率信息替代启发式 β 公式。
逐子域保守 CCD
每个子域 d 独立计算安全步长 α_d：单调区域识别 → 符号变化碰撞检测 → 二分搜索定位。远离接触的子域 α_d ≈ 1.0 全速推进。
位置更新 x ← x + Σ S_dᵀ α_d S_d p
每个子域用各自的步长更新位置。检查收敛（‖z‖ ≤ ε 且 Restart）。计算正交性指标 r_k 决定下一迭代是否需要重启。

接触分类与更新策略

每个接触 c 与基础状态 C_base 对比，决定 rank-1 更新向量：

新接触 (c ∉ C_base) 法线旋转 (n·n_base < ε_rot) 刚度增加 (k_curr > k_base) 刚度减少 (忽略)
新接触:   u = √k_curr · n_curr,   ΔS = k_curr
法线旋转: u = √k_curr · n_curr,   ΔS = k_curr（保留旧项作"幽灵墙"）
刚度增加: u = √(k_curr - k_base) · n_curr,   ΔS = k_curr - k_base
刚度减少: 忽略（保持较硬近似，保证 SPD）

Woodbury Capacitance 求解器

B̃_d = B_d - B_d·U_d·(I_K + U_dᵀ·B_d·U_d)⁻¹·U_dᵀ·B_d
Base Solve: z_base = B_d · g_d
用缓存的基础逆（上次重启时计算）乘以局部梯度。这是 O(N_d) 操作。
Update Projection: W = B_d·U_d, r = U_dᵀ·z_base
将更新矩阵投影到基础逆空间。O(N_d × K) 操作。
Capacitance Solve: (I_K + U_dᵀ W)λ = r
求解 K×K 小系统（K=8），代价极低。这是 Woodbury 公式的核心。
Correction: z_d = z_base - W·λ
用 capacitance 解校正基础方向，得到最终预条件方向。

2D 子空间最小化

搜索方向 p = -μ·z + ν·p_prev，在子空间内最小化二次模型：

min Q(μ,ν) = gᵀ(-μz+νp) + ½(-μz+νp)ᵀH̃(-μz+νp)

μ 的物理含义

系数 μ 起到"自然步长"的作用：

  • 包含二阶曲率信息（通过 H̃）
  • 允许 α = 1.0 作为 CCD 初始步长
  • 消除了对启发式 β 的依赖
  • 在凸区域近似于 Newton 步长
