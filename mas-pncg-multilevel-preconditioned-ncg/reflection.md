# 反思与扩展

## 如果我要扩展这篇论文

### 扩展 1：自适应重启阈值

当前使用固定 δ=0.3。可以根据场景动态调整：
- 接触集变化剧烈时降低阈值（更频繁重启）
- 接触稳定期间升高阈值（减少重启）
- 用接触集变化率（新增/释放接触数占比）作为辅助指标

**预期收益**：在接触模式变化不均匀的长序列仿真中进一步减少重启次数。

### 扩展 2：粗层级增量更新

目前粗层级在全局重启时才重建，期间完全冻结。如果弹性 Hessian 也有可利用的低秩变化结构（如大变形导致的旋转更新），可以对粗层级也应用类似 Woodbury 策略。

**挑战**：弹性 Hessian 变化通常不如接触 Hessian 稀疏低秩，需要不同的近似策略。

### 扩展 3：与 AGIPC 结合

在全局重启时使用 AGIPC 的代数粗化来加速 MAS 重建。MAS-PNCG 的"轻量迭代 + 周期性重启"模式与 AGIPC 的"减少重启代价"天然互补。

### 扩展 4：Neural Woodbury 预测

训练轻量网络预测 Top-K 更新向量的方向和权重，基于前几帧的接触演化模式。用于在正式 Woodbury 更新前提供热启动。

**风险**：引入 ML 推理延迟可能抵消预测收益。

## 尚存开放问题

1. **最优 K 的自适应选择**：固定 K=8 对所有子域可能不是最优。小子域可能需要更少，大子域或接触密集子域需要更多。自适应 K 会增加实现复杂度但可能改善精度-性能平衡。

2. **摩擦处理的增量更新**：论文使用 Baraff-Witkin 摩擦模型但未详述 Woodbury 更新如何处理摩擦力的非光滑性。摩擦方向的突变可能比法线接触更难增量追踪。

3. **并行重启调度**：在多 GPU 并行中，不同子域可能需要不同频率的重启。全局同步重启可能是不必要的瓶颈。

4. **收敛保证**：论文没有给出理论收敛证明。Woodbury 近似 + Top-K 截断引入的误差是否有界？是否存在不收敛的病理情况？

## 脆弱假设

| 假设 | 何时可能失效 | 后果 |
|------|------------|------|
| 接触 Hessian 变化低秩 | 大规模同时接触拓扑变化（如爆炸） | Woodbury 更新无法捕获全部变化，需频繁重启 |
| 粗层级变化缓慢 | 全局刚度模式快速变化（如相变） | 冻结的粗层级成为瓶颈 |
| Top-K 截断足够 | 子域内接触极度密集 | 截断误差过大，预条件器质量下降 |
| ε_rot = 25° 合理 | 大旋转接触（如滚动接触） | 要么频繁触发新接触处理，要么方向误差过大 |
| δ = 0.3 普适 | 极端病态系统 | 重启过频或过少 |

## 可能失败的场景

1. **极大规模均匀接触**：如数百万粒子同时接触（如沙粒模拟），每帧新增/释放的接触数远超 Top-K 容量，Woodbury 近似效率下降。

2. **极端刚度比**：论文展示了 500× 刚度范围，但如果刚度差达到 10⁶×（如刚体-软体混合），Woodbury 更新的 SPD 保守策略可能导致过度保守。

3. **纯压缩场景**：所有物体同时被挤压到一起，接触全部在刚度增加方向变化极快，Top-K 截断可能不够。

4. **长时间仿真漂移**：虽有全局重启机制，但在极长序列中（数万帧），反复冻结-重启的循环是否会积累系统性误差尚不清楚。
