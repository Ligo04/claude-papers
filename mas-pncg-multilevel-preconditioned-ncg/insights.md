# 核心洞察

## 一句话核心思想

**接触 barrier Hessian 的变化是稀疏低秩的，因此可以用 Woodbury 公式增量维护预条件器，而不是每次迭代重新构建。**

## 为什么这个方法有效

### 物理直觉

IPC 中接触力来源于 barrier 能量 B(x)，其 Hessian 的关键性质：

1. **稀疏性**：每个接触约束只影响 4-8 个顶点（点-三角形或边-边）
2. **低秩性**：每个接触的 Hessian 贡献以法线方向为主，近似为 rank-1 项 k·nnᵀ
3. **局部性变化**：相邻迭代间，大多数接触保持稳定；只有少量接触新增、旋转或释放

这三个性质组合意味着：**Hessian 的变化可以表示为少量 rank-1 更新的叠加**，恰好适合 Woodbury 矩阵恒等式。

### 与 Newton-PCG + MAS 的本质区别

在 StiffGIPC 等 Newton-PCG 方法中：
- 每个 Newton 步内 Hessian 固定 → MAS 只需构建一次，服务整个内循环
- **但** Newton 步本身代价高：完整 Hessian 组装 + 大线性系统求解

在 MAS-PNCG 中：
- 每次 CG 迭代有效曲率都在变化 → MAS 需要跟踪变化
- **但** 每次迭代代价极低：只需梯度评估 + 预条件方向计算
- Woodbury 更新让 MAS 维护成本降至接近零 → 兼得两个框架的优势

## 引入的概念转变

### 从"重建"到"演化"

传统思维：预条件器过时了 → 重新构建
MAS-PNCG：预条件器过时了 → 用低秩更新让它"演化"

关键判断标准：
- **新接触** (c ∉ C_base)：注入新 rank-1 项
- **法线旋转** (n_curr · n_base < ε_rot)：当作新接触处理（保留旧项作为"幽灵墙"）
- **刚度增加** (k_curr > k_base)：添加差分项
- **刚度减少** (k_curr ≤ k_base)：忽略（保留较硬近似，更安全）
- **全局重启** (r_k > δ)：正交性严重丧失时完全重建

### 从"启发式"到"最优"

传统 PNCG：用 β 公式（Fletcher-Reeves、Polak-Ribière 等）启发式组合梯度和前一方向
MAS-PNCG：在 2D 子空间内用二次模型直接求解最优系数

2D 子空间 {-μ·z_{k+1} + ν·p_k} 中求解 2×2 线性系统，可解析求解，而近似 Hessian 通过 Woodbury 更新可得。系数 μ 起到"自然步长"的作用，考虑了二阶曲率信息。

### 从"全局保守"到"局部保守"

标准 CCD：找到全局最紧的接触 → 所有区域使用同一步长
CCCD：每个子域独立计算步长 → 远离接触的区域全速推进

## 权衡与局限

| 优势 | 代价 |
|------|------|
| 避免 Hessian 组装 | 更多非线性迭代（PNCG 收敛慢于 Newton） |
| 预条件器维护近乎免费 | Top-K 截断引入近似误差 |
| 逐子域步长控制更高效 | CCD 计算分散在子域上，实现更复杂 |
| 2D 子空间最优搜索 | 依赖近似 Hessian 的质量，误差累积需全局重启 |

### 主要局限

1. **非线性迭代次数更多**：PNCG 本质上比 Newton 法需要更多迭代，优势来自于每迭代代价极低。在接触模式简单的场景（如 Armadillo），加速不明显（仅 1.03× vs StiffGIPC）。

2. **Woodbury 近似误差累积**：长时间不重启会导致预条件器退化。论文使用正交性监控（r_k > 0.3 时重启），平均每 3-10 次 PNCG 迭代触发一次重启。

3. **粗层级冻结假设**：粗层级 MAS 仅在全局重启时更新。如果全局耦合模式快速变化，可能需要更频繁的粗层级重建。

4. **仍需基础 MAS 设置**：初始构建和全局重启时仍需完整的 MAS 层次结构。

## 与先前工作对比

| 方法 | Hessian 组装 | 预条件器 | 线性求解 | 关键限制 |
|------|------------|---------|---------|---------|
| GIPC | 每 Newton 步 | MAS（固定） | PCG | 组装代价高 |
| StiffGIPC | 每 Newton 步 | MAS（固定） | PCG | 仍受 Hessian 约束 |
| Jacobi-PNCG | 无 | Jacobi | 无 | 收敛极慢 |
| **MAS-PNCG** | **无** | **MAS（增量更新）** | **无** | **迭代次数多** |

## 实际启示

- **适用场景**：大规模接触密集仿真（数十万-百万四面体），尤其是接触模式快速变化的场景
- **不太适用**：接触简单、刚度均匀的场景（Newton 法的二次收敛优势更大）
- **与 AGIPC 互补**：AGIPC 加速 Newton 内循环的线性求解；MAS-PNCG 完全跳过 Newton 外循环。两者解决不同层面的瓶颈
