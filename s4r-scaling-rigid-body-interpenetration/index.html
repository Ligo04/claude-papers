一个尺度步在做什么？

vᵢ(s)=pᵢ+sRᵢv̄
ℓᵢⱼ≈d̃ᵢⱼ+nᵀ(Δpⱼ−Δpᵢ)−Δs·Eᵢⱼ
min ½Σᵢ‖Δpᵢ‖²
s.t. nᵀ(Δpⱼ−Δpᵢ) ≥ d̂−d̃ᵢⱼ+Δs·Eᵢⱼ

支持宽度 Eᵢⱼ=eᵢ(n)+eⱼ(−n) 把“物体变大造成的间隙闭合”写进线性约束。约束只对下一步可能激活的 pair 建行，默认 `d̂=0.02`、`s_min=0.01`、`Δs_max=0.05`。

这不是每步可行性证书：witness 可能切换，缓存 normal 会漂移，最终要在 s=1 重新检测。

路径而非魔法：五阶段

01 / 缩小固定参考中心，缩到 `s_min`，验证起点。
02 / 预测SOI event bound 跳过不会接触的尺度区间。
03 / QP对 active contacts 求最小范数增量。
04 / 恢复每 `M=3` 步刷新 FCL，其间 frozen-witness cache。
05 / 验收锁定 `s=1`，最多 `K_tail=20` 次 tail QP + full evaluator。

博客的 scale 三分法

  • 整场景同比缩放：相交关系保持，不能修复 penetration。
  • Coverage Axis dilation：固定表面/候选中心，改球半径，解决 shape abstraction。
  • S4R homothetic continuation：固定 reference centers，先缩小实体制造 clearance，再恢复实体尺寸，解决布局可行性。

恢复 full size 不会抹掉 path history；几何零互穿也不等于 MuJoCo settle 后满足 upright、摩擦或任务约束。
