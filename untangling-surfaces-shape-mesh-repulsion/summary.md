# 论文总结

## 背景

曲面网格中的自相交是一个普遍问题——来自扫描、重建、建模管线的大规模 3D 数据集中广泛存在自相交。这些自相交会破坏下游的仿真（碰撞处理失败）、制造（不可制造的几何体）和学习管线（SDF/占据网格无法编码自相交）。

现有方法的局限：
- **局部碰撞处理**：将自相交视为局部碰撞事件，无法处理涉及多个远距离表面区域的复杂纠缠
- **排斥能量**（如 Tangent Point Energy）：在自相交配置上发散或病态，不适合从相交状态出发的修复
- **流方法**（如 cMCF）：通过几何平滑间接消除相交，但不显式强制嵌入性，可能引入严重变形
- **体积方法**：计算昂贵，依赖内外定义，对非可定向曲面失效

## 问题陈述

如何设计一个能量框架，使其：
1. 在自相交配置上保持有限且可优化（不发散）
2. 提供全局解缠信号（不仅是局部推力）
3. 处理离散网格的局部退化（薄尖刺、近共面折叠）
4. 不改变网格连通性
5. 适用于非流形、非可定向、多物体等广泛输入

## 主要贡献

1. **高斯自接触能量**：一种新的形状级能量，在自相交配置上有限，通过自适应带宽自动聚焦于最相关的空间尺度
2. **3D Minkowski 惩罚**：将 Minkowski 差框架扩展到 3D 三角形-三角形交互，提供光滑可微的穿透深度度量
3. **两级耦合框架**：形状级驱动大尺度解缠 + 网格级解决局部退化，配合 ARAP 正则化和 IPC 反向流
4. **广泛适用性**：非流形、Whitney 伞、cross-cap、多物体场景、固定边界、高维空间（R⁴）
5. **应用拓展**：数据集清洗、约束场景布置、多智能体路径规划、Seifert 曲面构造、显式同痕
