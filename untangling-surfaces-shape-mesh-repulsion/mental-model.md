# 思维框架

## 这是什么类型的问题？

**几何优化 + 拓扑修复**

本文解决的核心问题是：如何将一个自相交的曲面网格变形为嵌入（无自相交）的曲面，同时最小化变形量且不改变网格连通性。

这不是：
- 碰撞检测问题（不是检测，是修复）
- 物理仿真问题（没有时间演化，是静态优化）
- 重网格化问题（不改变连通性）
- 局部修复问题（嵌入性是全局性质）

而是一种**全局几何约束满足问题**，通过连续能量优化来求解。

### 在排斥能量谱系中的位置

```
经典结能量（Möbius, O'Hara）
  └── 1/r^α 型，自相交时发散 → 适合预防，不适合修复

Tangent Point Energy
  └── 需要切空间，非流形失效 → Instant Repair 的基础

高斯自接触能量（本文）
  └── exp(-r²/ε²) 型，自相交时有限 → 专为修复设计
```

## 类比理解

### 类比 1：磁铁排斥

想象曲面上每对"内蕴距离远但欧氏距离近"的点之间有一个排斥磁铁：
- **经典排斥能量**：磁铁在接触时产生无穷大的力（物理上不可能，数值上崩溃）
- **高斯自接触能量**：磁铁在接触时产生有限但很强的力（可以从接触状态开始推开）
- **自适应带宽**：磁铁的作用范围自动调整——大尺度纠缠用远程磁铁，小尺度退化用近程磁铁

### 类比 2：解绳结

解一个打结的绳子：
- **形状级能量** = 你的眼睛看到整体纠缠结构，决定"先把这个环从那个环里拉出来"
- **网格级惩罚** = 你的手指处理局部的摩擦和卡住，确保绳子的每一小段都不穿过另一段
- **ARAP 正则化** = 你不想把绳子拉得太长或扭曲太多
- **反向流** = 解开后把绳子理顺，恢复原来的形状

### 类比 3：地图投影

将一个自相交的曲面"展开"为嵌入曲面，类似于将地球表面投影到平面：
- 你需要全局视角来决定如何展开（形状级）
- 你需要局部精度来避免撕裂或重叠（网格级）
- 你希望变形最小（正则化）
