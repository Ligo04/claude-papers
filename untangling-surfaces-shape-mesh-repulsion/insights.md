# 核心洞察

## 核心思想：一句话版本

嵌入性是全局性质——用一个在自相交处有限但强烈排斥的高斯能量捕获全局纠缠，用 Minkowski 穿透深度处理局部三角形冲突，两者耦合实现可靠的解缠。

## 为什么这个方法有效

### 1. 有限 vs 发散：关键设计选择

经典排斥能量（如 Möbius 能量、Tangent Point Energy）在自相交时发散到无穷大。这对**预防**自相交很好（无穷大的势垒），但对**修复**自相交是灾难性的——你无法从能量无穷大的状态开始优化。

高斯自接触能量的巧妙之处：
- 使用 Gaussian kernel `exp(-‖x-y‖²/ε²)` 而非 `1/‖x-y‖^α`
- 当 x=y（自相交）时，指数函数 = 1（有限！），而非发散
- 能量仍然强烈惩罚接近但内蕴距离远的点对
- 结果：可以从任意自相交配置开始优化

### 2. 全局 vs 局部：为什么需要两级

**形状级（高斯能量）**：
- 捕获远距离表面区域之间的纠缠
- 提供"推开"的全局梯度信号
- 独立于离散化（连续能量的离散化）
- 但对局部三角形退化不敏感（梯度在细节处相互抵消）

**网格级（Minkowski 惩罚）**：
- 直接作用于三角形对
- 精确度量穿透深度
- 处理薄尖刺、近共面折叠等离散退化
- 但没有全局视野（只看相邻三角形）

两者互补：形状级负责"大方向"，网格级负责"最后一公里"。

### 3. 自适应带宽：让能量自己找到正确的尺度

带宽 ε 控制高斯核的作用范围：
- ε 太小 → 只看到极近距离的交互，错过大尺度纠缠
- ε 太大 → 信号被稀释，无法区分不同的纠缠结构

关键洞察：E_G(Σ; ε) 作为 ε 的函数，在 ε→0 和 ε→∞ 时都趋于零，中间必有极大值。这个极大值对应的 ε* 就是"最有效的推力尺度"。

更进一步：局部自适应带宽 ε(x) 让不同区域使用不同尺度——细节区域用小 ε，大尺度区域用大 ε。

### 4. Minkowski 差的半空间技巧

判断两个三角形是否相交 ⟺ 原点是否在它们的 Minkowski 差内。

直接构造 Minkowski 差多面体很复杂。但论文的洞察是：
- 只需要原点到 Minkowski 差的**有符号距离**
- 这可以通过有限个半空间的最大值来精确计算
- 半空间法线只来自三角形面法线和边-边叉积
- 梯度直接从活跃半空间得到，分段光滑

## 概念转变

| 传统思路 | 本文思路 |
|---------|---------|
| 自相交是局部碰撞事件 | 嵌入性是全局几何性质 |
| 排斥能量应该在相交时发散 | 排斥能量应该在相交时有限但陡峭 |
| 单一尺度的排斥力 | 自适应多尺度排斥 |
| 穿透深度需要体积信息 | Minkowski 差提供无体积的穿透度量 |
| 修复 = 检测 + 投影 | 修复 = 全局能量最小化 |

## 权衡与局限

1. **无理论保证**：不能证明一定收敛到嵌入曲面（但实践中 100% 成功）
2. **计算成本**：需要 GPU 加速，大网格需要数百到数千秒
3. **变形代价**：解缠过程会引入变形，需要反向流恢复（但可能无法完全恢复原始形状）
4. **参数选择**：虽然大部分数据集共享参数，但极端情况需要调整 λ_M, λ_reg, N

## 与先前工作的对比

- **Instant Repair (Jang et al. 2025)**：基于 Tangent Point Energy 的局部化排斥，在紧密折叠区域留下残余相交
- **cMCF (Sacht et al. 2013)**：流方法，不显式强制嵌入性，多物体场景失效，严重变形
- **IPC (Li et al. 2020)**：保证无穿透但用于动态仿真，不直接解决静态修复
- **Knot energies (O'Hara, Freedman)**：在非嵌入配置上发散，不适合修复
