# 技术方法详解

## 系统架构

```
输入：自相交网格 M = (V, F)
         │
         ▼
┌─────────────────────────────────────────┐
│         Phase 1: 解缠 (Untangling)        │
│                                          │
│  E_untangle = λ_G·E_G + λ_M·E_M + λ_reg·E_reg  │
│                                          │
│  ┌──────────────┐  ┌──────────────┐     │
│  │ 形状级能量    │  │ 网格级惩罚    │     │
│  │ E_G (高斯)   │  │ E_M (Minkowski)│    │
│  │ 全局解缠驱动  │  │ 局部退化修复   │     │
│  └──────────────┘  └──────────────┘     │
│           │                │             │
│           └───────┬────────┘             │
│                   ▼                      │
│         L-BFGS 优化 + Armijo 线搜索       │
│         终止条件：无非相邻三角形相交        │

         │
         ▼

│         Phase 2: 恢复 (Recovery)          │

│                                          │

└─────────────────────────────────────────┘
         │
         ▼
输出：无自相交网格，接近原始形状
```

## 组件详解

### 1. 高斯自接触能量 E_G（形状级）

**曲线版本（建立直觉）**：

```
E_G(Γ; ε) = ∫∫_{I×I} w(s₁,s₂)/ε · exp(-‖γ(s₁)-γ(s₂)‖²/ε²) ds₁ ds₂
```

- s₁, s₂：弧长参数
- w(s₁,s₂) = d_Γ(s₁,s₂)：内蕴弧长距离（抑制邻近点贡献）
- ε：高斯核带宽

**曲面版本**：

```
E_G(Σ; ε) = ∫∫_{Σ×Σ} w(x,y)/ε^p · exp(-‖x-y‖²/ε²) dH²(x) dH²(y)
```

- p = 2（匹配二维面积测度的缩放行为）
- w(x,y)：内蕴权重函数，对角线上为零

**离散版本**：

```
E_G[M; ε] = Σ_{i,j} A_i·A_j·w_ij·ε_ij^{-p}·exp(-r²_ij·ε_ij^{-2})
```

- A_i：顶点面积
- w_ij = 0（相邻顶点），1（其他）
- r_ij = ‖v_i - v_j‖
- ε_ij² = ½(ε_i² + ε_j²)（二次均值组合器）

**显式梯度**：

```
∇_{v_i} E_G[M; ε] = -2/ε^{p+2} · Σ_{j≠i} a_ij·exp(-r²_ij/ε²)·(v_i - v_j)
```

物理直觉：高斯加权的成对排斥力，增大空间接近但内蕴距离远的区域之间的分离。

### 2. 自适应带宽选择

**全局自适应**：

E_G(Σ; ε) 在 ε→0 和 ε→∞ 时趋于零，中间有极大值。

临界点条件：ε*² = (2/p) · M₂(ε*) / M₀(ε*)

其中 M_k(ε) = ∫∫ ‖x-y‖^k · w(x,y) · exp(-‖x-y‖²/ε²) dH²(x)dH²(y)

通过不动点迭代求解：ε_{k+1} = g(ε_k)

**局部自适应**：

每个顶点有独立的 ε_i，通过耦合不动点系统求解：

```
(ε*_i)² = (4/p) · [Σ_{j∈N_i} b_ij·r²_ij] / [Σ_{j∈N_i} b_ij] - [Σ_{j∈N_i} b_ij·(ε*_j)²] / [Σ_{j∈N_i} b_ij]
```

使用阻尼 Jacobi 迭代求解（θ = 0.25）。

### 3. Minkowski 惩罚 E_M（网格级）

**核心思想**：

两个三角形 A, B 相交 ⟺ 原点 ∈ A-B（Minkowski 差）

**半空间表示**：

```
A - B = ∩_{n∈N} H_n
```

其中 H_n = {x ∈ R³ | ⟨n, x⟩ ≤ h_n}

法线集 N 包含：
- 三角形 A 的面法线
- 三角形 -B 的面法线
- 所有边-边叉积 e_A × e_B（归一化）

**有符号距离**：

```
ϕ(0, A-B) = max_{n∈N} (⟨n, 0⟩ - h_n) = max_{n∈N} (-h_n)
```

- ϕ < 0：相交
- ϕ = 0：相切
- ϕ > 0：分离

**惩罚能量**：

```
E_M[M] = Σ_{(A,B)∈P} max{0, -ϕ(0, A-B)}
```

P = 所有非相邻三角形对中的相交对

### 4. 完整解缠目标

```
E_untangle[M] = λ_G·E_G[M; ε] + λ_M·E_M[M] + λ_reg·E_reg[M]
```

- E_reg：ARAP 能量（防止不必要变形）
- 求解器：L-BFGS，Armijo 线搜索（β₀ = 10⁻⁴）
- 终止：无非相邻三角形-三角形相交

### 5. 恢复阶段

```
E_recovery[M] = λ̃_reg·Ẽ_reg[M] + λ_IPC·E_IPC[M]
```

- Ẽ_reg：ARAP + 弯曲能 + 二次惩罚（拉回原始形状）
- E_IPC：IPC 势垒能量（防止重新相交）
- 求解器：Newton + PCG（相对容差 10⁻⁶）+ CCD 线搜索
- 固定 500 步

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 核函数 | Gaussian exp(-r²/ε²) | 自相交时有限，指数衰减允许截断 |
| 权重函数 | 简单邻接：w_ij=0(相邻), 1(其他) | 紧凑梯度，高效优化 |
| 带宽组合器 | 二次均值 ε²_ij = ½(ε²_i + ε²_j) | 保持对称性、正性、尺度不变性 |
| 穿透度量 | Minkowski 差半空间距离 | 无需体积信息，光滑可微 |
| 解缠求解器 | L-BFGS | 无需 Hessian 组装，适合大规模 |
| 恢复求解器 | Newton + IPC | 提供强无穿透保证 |
| 邻域截断 | r_ij ≤ N (N = kε) | 高斯核指数衰减，远距离贡献可忽略 |
