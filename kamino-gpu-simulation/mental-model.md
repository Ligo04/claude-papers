# 心智模型

## 这是什么类型的问题？

**计算刚体动力学 + GPU 系统工程**

核心挑战：如何在 GPU 上高效求解带有全局耦合（运动学闭环）的约束多体系统前向动力学？

这不是一个算法创新论文——Proximal-ADMM 和极大坐标表述都有先前工作基础。这是一篇**系统实现论文**，其贡献在于：将理论上已知可行的方法，工程化为可在 RL 规模下实际运行的 GPU 系统。

### 横向（同期相关工作）

- **Newton 物理引擎**: Kamino 的宿主框架，提供碰撞检测等基础设施

- **MuJoCo Warp / MJX**: 竞争方案，归约坐标路线的 GPU 加速

## 如何分类这项工作

用三个维度来定位：

1. **坐标表述**: 极大坐标（vs 大多数仿真器的归约坐标）
2. **求解策略**: 对偶空间 Proximal-ADMM（vs 直接法或纯近端法）
3. **并行化**: 异构世界 GPU 并行（vs 同构批量并行）

这三个选择共同定义了 Kamino 的独特位置：用冗余度换取拓扑通用性，再用 GPU 大规模并行弥补冗余度带来的效率损失。

## 与你已知概念的桥梁

- 如果你熟悉**有限元**: 极大坐标类似于节点法（每节点独立自由度），约束类似于刚性连接
- 如果你熟悉**凸优化**: Delassus 矩阵类似于 Hessian，ADMM 拆分类似于 proximal gradient + consensus
- 如果你熟悉**图神经网络**: 约束 Jacobian 的稀疏结构等价于机器人的连接图
- 如果你熟悉**RL 训练**: Kamino 扮演的角色与 Isaac Gym 相同，只是拓展了可仿真的机器人类型
