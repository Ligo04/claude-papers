# 深度洞察

## 核心思想

Kamino 的关键洞察是：**换一种坐标表述，闭环约束就不再特殊**。

传统仿真器使用归约坐标 (reduced coordinates)：每个关节一个广义坐标，系统状态维度等于自由度数。这天然假设树状拓扑，O(n) 递归算法非常高效。但一旦出现闭环，递归结构被打破，需要额外的等式约束来"缝合"循环。

Kamino 反其道而行，采用**极大坐标 (maximal coordinates)**：每个刚体独立携带 SE(3) 位姿和 6D 空间扭矩。所有运动学关系——无论是普通关节还是闭环约束——都作为显式代数约束统一处理。代价是系统维度更高、需要求解全局耦合的约束系统；收益是拓扑无关的统一框架。

## 为什么这种方法有效

1. **约束的统一性**: 在极大坐标下，闭环约束与普通关节约束结构完全相同（都是 f(q)=0），无需特殊的循环切割或手动拓扑分解

2. **Delassus 矩阵的结构**: 前向动力学转化为对偶空间的锥约束优化。左端矩阵 D_{η,ρ} = D + (η+ρ)I 在每个时间步内恒定，只需一次分解/预处理，ADMM 每轮迭代只需求解新右端向量

3. **GPU 友好的稀疏性**: 每个约束最多涉及两个刚体 → 约束 Jacobian 每行最多两个 6×6 非零块 → BSR 稀疏格式 → 矩阵向量乘可以在非零块上并行化

4. **异构世界的统一索引**: 通过全局偏移数组将不同拓扑的机器人映射到统一的 CUDA kernel 中

## 概念转变

这篇论文引入的核心范式转变：

> "不要试图把闭环系统塞进树状求解器的框架，而是用一个维度更高但结构更统一的框架来处理所有拓扑。"

这类似于计算机图形学中从欧拉坐标到拉格朗日坐标的转变——用冗余换取灵活性。

## 设计权衡

### 极大坐标 vs 归约坐标

| 维度 | 极大坐标 (Kamino) | 归约坐标 (Isaac Gym 等) |
|------|-------------------|------------------------|
| 状态维度 | 高 (每刚体 13 维) | 低 (每自由度 1 维) |
| 拓扑限制 | 无 | 仅树结构 |
| 算法复杂度 | 全局线性系统 | O(n) 递归 |
| 闭环处理 | 原生支持 | 需额外约束 + 调参 |
| GPU 效率 | 大规模并行弥补 | 天然高效 |

**关键洞察**: 对于简单树结构机器人 (如 BDX)，极大坐标有显著开销。但对于复杂拓扑 (如 Iron Man 200+ 关节)，手动定义基础运动树本身就是巨大负担。

### 稠密 vs 稀疏求解器

- **小系统 (< 300 约束维度)**: 稠密 Cholesky 分解更快，因为可以一次性分解并重复使用
- **大系统 (> 300 约束维度)**: 稀疏矩阵-free Conjugate Residual 更优，内存线性增长
- 论文提供了两种方案，用户可根据系统规模选择

### 固定迭代预算 vs 自适应容差

求解器使用固定 9 轮迭代而非自适应收敛判断——这是为了**确定性的 kernel 时序**，从而支持 CUDA Graph 捕获，这在 RL 训练中对性能至关重要。

## 局限性

1. **仅支持刚体**: 粒子和软体不支持
2. **不可微分**: 无法用于基于梯度的优化（如可微仿真）
3. **仅对偶表述**: 前向动力学目前只用对偶 (constraint reaction) 形式，接触约束多时扩展性受限
4. **无 sim-to-real 验证**: 仅展示了 sim-to-sim 迁移
5. **环境重置困难**: 带闭环的系统需要高斯-牛顿 FK 求解器来计算一致的全身状态，且难以保证无自碰撞

## 实践意义

1. **机器人设计空间扩大**: 不再需要为了仿真而简化机械设计
2. **四连杆传动的足式机器人**: 可以直接训练，无需 mimic joint 近似
3. **异构仿真**: 可同时仿真不同机器人，为机构设计优化提供基础
4. **与 Isaac Lab 集成**: 未来将提供完整的 RL 训练管线
