算法步骤 (每时间步)

0构建 D_{η,ρ} = D + (η+ρ)I — 整个时间步内不变
1Cholesky 分解 / 预处理 — 每时间步一次
2Warm-start 初始化 x⁰, y⁰, z⁰
3for i = 1..N:
4s ← Γ(z) De Saxcé 修正
5x ← D⁻¹_{η,ρ} · rhs 线性求解 (核心瓶颈)
6y ← Π_K(x - z/ρ) 锥投影 (解析)
7z ← z - ρ(x - y) 对偶更新
8Nesterov 加速 + 自适应重启
9return λ* ← y
