# 把这篇论文放到什么位置

这是一种部分可观测、接触丰富的局部操作策略。策略不知道零件的完整状态，需要用自身动作引发的响应识别下一步该做什么。

## 四个先修概念

| 概念 | 在本文中的作用 |
|---|---|
| 正运动学 | 把关节状态变成夹爪 pose/twist，不需要外部相机 |
| 关节阻抗控制 | 指令与接触共同决定实际关节运动，是信息产生的物理过程 |
| POMDP 与历史表示 | 当前观测有歧义，历史 latent 汇集有用的接触信息 |
| 非对称 actor–critic / 辅助监督 | 训练时利用仿真真值，部署时不依赖这些真值 |

## 在机器人系统里的位置

```text
抓取零件 → 接近夹具 → 建立初始接触 → 局部搜索与装配 → 检查与后续任务
                                   └────本文主要评估────┘
```

这幅图是任务边界示意。完整系统中的抓取、接近、重试和上层调度需要额外设计，论文没有评估全流程。

## 与相邻方法比较

| 方法 | 决策依据 | 需要关注的边界 |
|---|---|---|
| 固定螺旋搜索 | 预定轨迹，直到落入 | 通常依赖姿态或位置先验；难利用复杂接触反馈 |
| 力/触觉反馈策略 | 外力、力矩或局部触觉 | 增加传感器、标定与 sim-to-real 要求 |
| 仅 RGB 策略 | 像素历史 | 本文的对照；尺寸和形状变化会改变视觉输入 |
| 本体感知历史策略 | 动作与关节响应 | 依赖控制器和动力学一致性；局部搜索可能较慢 |
| 视觉加本体感知融合 | 外部几何线索与接触反馈 | 合理研究方向，本文未比较 |

这些是方法类别，不能把本表当成跨论文性能排名。针对具体作品的优劣还需要核对各自的任务、先验、间隙与硬件。

## 两条相互依赖的研究思路

一条研究如何从有限观测学会装配，另一条研究怎样生成足够准确且多样的碰撞资产。前者学习接触响应，后者决定接触响应是不是正确。任何一条失真，都可能造成策略在仿真中成功、在真实装配中失败。

阅读时可以反复问两个问题：这一段增加了策略实际可用的信息吗？这一段改变的是物理世界、训练监督，还是测试条件？这能帮助区分输入泄漏、训练辅助和评估泛化。
