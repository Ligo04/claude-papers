# 心智模型 (Mental Model)

> 在钻进数学之前，先建立"这是一类什么问题、需要什么前置知识、它在大图景里站在哪"的高层心智地图。

---

## 1. 这是哪一类问题？

**面向接触密集、近刚性物体的分布式/并行约束优化仿真。**

拆解这句话：
- **仿真**：每个时间步是一个变分（隐式欧拉）优化问题，求解物体的新状态。
- **近刚性物体**：用 ABD 的 12-DoF 仿射表示——比刚体多一点形变自由度（仿射），又比全软体便宜得多。
- **接触密集**：场景里有数千万到数亿候选碰撞对，接触处理是主要开销。
- **约束**：IPC 的对数障碍 + CCD 强制**严格无穿透**（硬约束，不能违反）。
- **分布式/并行**：把场景切给多个 GPU 节点，难点在于约束（接触）是**全局耦合**的，不能简单切开。

一句话归类：**"如何把一个带强全局约束的优化问题切到多台机器上求解，同时既快又不破坏约束"** ——它本质是**带可行性保证的分布式约束优化**，仿真只是它的应用外壳。

---

## 2. 假设的前置知识

### 物理仿真侧
- **ABD（仿射体动力学）**：每个物体 12 个仿射自由度（$3\times3$ 仿射矩阵 + 平移），顶点轨迹随时间线性 → CCD 友好。知道它用 ARAP 弹性能惩罚仿射矩阵偏离正交以表现近刚性。
- **IPC（增量势接触）**：内点法框架，用**对数障碍接触能**（距离趋近 $\hat d$ 时能量 $\to\infty$）+ **CCD 线搜索**保证整条优化路径无穿透。
- **隐式欧拉 = 优化**：单步仿真 = 极小化"惯性项 + 弹性能 + 接触能"。
- **CCD（连续碰撞检测）**：沿运动轨迹检测首次碰撞时刻（TOI），TOI=1 表示整段轨迹无穿透。

### 优化侧
- **ADMM（交替方向乘子法）**：把全局优化分解为可并行的局部子问题，用增广拉格朗日的对偶上升协调一致性。
- **增广拉格朗日 / 缩放对偶形式**：理解惩罚项 $\frac{\rho}{2}\|x-z+u\|^2$ 与对偶变量 $u$ 的更新。
- **共识优化 (consensus optimization)**：多个 agent 各持一份共享变量副本，约束它们相等（$x_i = z$），最小化各自局部目标之和。这是本文的骨架。
- **原始/对偶残差 (primal/dual residual)**：原始残差衡量约束违反（副本不一致），对偶残差衡量共识状态的变化；二者驱动停止判据和 $\rho$ 自适应。
- **域分解 (domain decomposition)**：把空间域切成子域分配给不同处理器的经典思想。

### 系统侧（较轻）
- 单控制器 - 多 worker 架构；阻塞 vs 异步通信；负载均衡；PD 控制器基础。

## 3. 一个类比，帮你装下整篇论文

> **想象一群人合作拼一幅巨型拼图，每人负责一个区域。**

- 每人（worker）拼自己那块（局部 ABD 解）。
- 但相邻区域的**边界拼块**两人都得碰（共享体）——这就是接触耦合。
- 大家各自先按自己的理解放边界块（局部解，各自合法），然后**协商**边界块到底放哪（共识 $z$ = 加权平均）。
- 协商出的折中位置**可能压坏拼图**（共识可能穿透）——所以在真正把它钉死之前，要**检查这一挪动会不会撞坏东西**（CCD on merge target，TOI=1 才接受）。
- 协商力度（$\rho$）要拿捏：太松大家半天谈不拢（共识慢），太紧每人被强行拽走、顾不上自己那块拼对没（局部停滞）。拿捏的标尺是**这块拼图有多"重"**（质量 $m_b$），而不是它**有多硬/边缘多尖锐**（ARAP/IPC 曲率——那是误导）。

记住这个类比，三项贡献就各就各位：分布式框架 = 分工 + 协商；质量感知 $\rho$ = 协商力度的正确标尺；CCD 合并 = 钉死前的安全检查。

## 4. 它在大图景中的位置（三条谱系的交汇）

### 谱系 A：ADMM-用于-仿真
Inglis 2017 / Pan-Manocha 2017（流体）、Overby 2017、Fang 2019、Brown&Narain 2021、Daviet 2023（弹性/布料/头发）、Lee 2023 / Ji 2025（多体子系统 ADMM）。
→ 本文把这条线推到**分布式 + 严格无穿透 + ABD**，并修正了其中 $\rho$ 标定（刚度代理）在 ABD 上的失效。

### 谱系 B：IPC 加速
IPC [Li 2020a] → ABD [Lan 2022a] → PD-IPC [Lan 2022b]、坐标下降 [Lan 2023]、GIPC [Huang 2024a]、StiffGIPC [Huang 2024b]、Barrier-ALM [Guo 2024]。
→ 本文从 PD-IPC 借来 local/merge 交替结构，但**把共识状态当中间估计、仅终止时强制可行**，这是相对该谱系的概念创新。

### 谱系 C：分布式仿真
P-cloth [Li 2020c]、SPH/Eulerian/Nimbus 流体、MPM halo [Wang 2020; Qiu 2023]、aura migration [Brown 2020]、Loki [Lesser 2022]、split-and-average [Daviet]、interface blending [Kale 2023]、mass splitting [Tonge 2012]。
→ 同属"复制界面状态 + 合并协调"家族。**本文的差异化**：在接触密集分布式仿真中实现**高精度碰撞响应 + 严格无穿透**——前人都回避了这个难点。

```
   ADMM-for-sim ──┐
                  ├──► 本文: 分布式 ABD + 自适应共识
   IPC 加速谱系 ──┤      (三谱系交汇处, 各取一块并修正)
                  │
   分布式仿真   ──┘
```

## 5. 如何在脑中归类这篇论文

- **若你来自优化**：这是"共识 ADMM 的一个高难应用 + 一个领域特定的 $\rho$ 标定洞见（用惯性谱界而非全 Hessian 谱）+ 一个把可行性从'每步'松弛到'终点'的技巧"。
- **若你来自图形/仿真**：这是"把 ABD-IPC 搬上多 GPU 集群的第一个严格无穿透方案，靠共识 ADMM 处理接触耦合"。
- **若你来自系统/HPC**：这是"单控制器多 worker、复制冗余 + 去中心化共识、PD 反馈负载均衡，但被阻塞通信和分区-迭代权衡所限"。

**一句话锚点**：*用共识 ADMM 让多个 worker 就共享物体协商一致；用惯性质量（而非误导性的弹性/障碍曲率）标定协商力度；把共识当中间估计、只在终止时用 CCD 认证无穿透。*

## 6. 阅读时主动追问的问题（帮助内化）

1. 如果接触约束**不**全局耦合，这套机制还需要吗？（不需要——耦合是问题的核心。）
2. 为什么不直接对全 Hessian 做特征分解来标定 $\rho$？（被 ARAP/IPC 的假大特征值污染。）
3. 共识 $z$ 在中途穿透了，为什么不立刻报错？（它只是估计，终止时才认证。）
4. 8 worker 为什么不是 8× 加速？（更细分区 → 更强耦合 → 更多 ADMM 迭代 + 更多同步。）
5. 异质材料变慢，是分布式的错吗？（不是——单 worker 同样变慢，是底层 ABD 问题更难。）
