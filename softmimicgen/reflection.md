# SOFTMIMICGEN — 反思与展望

## 如果要扩展这篇论文

### 方向 1: 动态子任务图
当前假设固定子任务序列。扩展为条件子任务图（DAG），根据物体实时状态动态选择下一个子任务。可以用 LLM 作为任务调度器，或用 RL 学习最优子任务选择策略。

### 方向 2: 学习配准
用可微分的神经网络替代 TPS 配准，端到端学习最优的对应关系和变形场。优势是可以处理拓扑变化（如布料翻折）和更好地处理噪声点云。

### 方向 3: 跨物体泛化
当前每个任务使用固定的物体类型。能否从毛巾操纵的示范迁移到衣物折叠？这需要跨物体类别的配准和轨迹迁移。

### 方向 4: 与基础模型结合
用 VLA（Vision-Language-Action）模型替代 BC/Diffusion Policy，利用 SOFTMIMICGEN 数据预训练，再在真实世界微调。大规模合成数据 + 基础模型可能释放更大潜力。

## 尚未解决的问题

1. **多物体交互**：当多个可变形物体相互作用时（如用毛巾包裹物体），如何定义配准？
2. **闭环数据生成**：当前是开环执行变换轨迹，如果执行中出现偏差无法纠正
3. **物理属性迁移**：同一类物体不同材质（如棉质 vs 丝质毛巾）的配准是否有效？
4. **可扩展性**：生成 1000 条 vs 10万条数据，配准的计算成本如何？
5. **子任务边界**：自动子任务分割在可变形物体上是否比刚体更难？

## 脆弱的假设

1. **A2（固定子任务序列）** — 最脆弱。多数真实任务需要自适应策略
2. **A3（可观察物体配置）** — 真实世界中完全观察可变形物体状态极其困难
3. **Ground-truth 节点假设** — 仿真专属，限制了真实世界数据生成
4. **TPS 配准的光滑性假设** — 对于剧烈变形（如布料翻折）可能失效

## 可能失败的实际场景

1. **高度随机的初始配置**：如完全随机揉成一团的布料 — 配准代价可能过高
2. **动态接触丰富的任务**：如揉面团 — 物体持续变形，单次配准不够
3. **工具使用任务**：如用剪刀剪布 — 涉及拓扑变化，配准失效
4. **多步长时序任务**：误差累积使得后续子任务的轨迹质量下降
