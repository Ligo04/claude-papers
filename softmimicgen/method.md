## 前置条件

### 假设

- **(A0)** 每个可变形物体表示为 3D 节点位置集合：O = {n_i}，n_i ∈ R³
- **(A1)** 动作空间为末端执行器位姿命令 + 夹爪命令
- **(A2)** 任务可分解为有序的物体中心子任务序列
- **(A3)** 每个子任务开始前可以观察物体配置

### 行为克隆目标

POMDP 设定下，策略 π: O → A 通过最大似然训练：
```
arg max_θ E_{(s,o,a)~D} [log π_θ(a|o)]
```

## 核心组件详解

### 1. 可变形物体表示

每个可变形物体由节点位置集合完全描述：
```
O = {n_1, n_2, ..., n_{N_O}}，其中 n_i = (x_i, y_i, z_i)
```

**为什么不用单一坐标系？**
- 刚体：一个 SE(3) 位姿完全描述状态
- 可变形体：形状随交互变化，单一坐标系无法表达局部变形
- 即使给某个节点分配坐标系，也无法描述其他节点的相对运动

### 2. 非刚体配准（Thin Plate Spline, TPS）

**问题定义：** 给定源物体节点集 O_src 和目标物体节点集 O_tgt，找到连续变形场 f(·)。

**TPS 配准流程：**

```
输入：源节点 X = {x_1, ..., x_N}，目标节点 Y = {y_1, ..., y_N}

1. 建立对应关系（最近邻 / 软分配）
2. 求解 TPS 变形场：
   f(x) = Ax + b + Σ_i w_i · φ(||x - x_i||)

   其中：
   - A ∈ R^{3×3}: 仿射部分（线性变形）
   - b ∈ R^3: 平移
   - w_i: 非线性变形权重
   - φ(r) = r: TPS 核函数（3D 情况）

3. 最小化：
   Σ_j ||f(x_j) - y_j||² + λ · 弯曲能量

   λ 控制变形的光滑程度
```

### 3. 轨迹变换

给定源段轨迹 τ = (T⁰, T¹, ..., Tᴷ)，每个 T = (p, R) 是末端执行器的位姿。

**位置变换：**
```
p_t → f(p_t)
```

**朝向变换：**
```
R_t → orth(J_f(p_t) · R_t)
```

其中：
- J_f(p_t) 是变形场 f 在 p_t 处的 Jacobian 矩阵
- orth(·) 将结果正交化为有效旋转矩阵
- 直觉：Jacobian 捕获了该点的局部变形模式

### 4. 源示范选择

对每个子任务，需要从源段库中选择最佳匹配：

```
1. 观察目标场景的物体配置 O'
2. 对每个源段，运行非刚体配准 O_src → O'
3. 选择配准代价最小的源段
4. 使用对应的变形场变换轨迹
```

**为什么这很重要？** 可变形物体有高维连续配置空间，选择与目标状态最接近的源段能显著提高生成质量。

### 5. 数据生成循环

```python
# 伪代码
for trial in range(num_trials):
    # 采样新的初始状态
    state = sample_initial_state(D')

    for subtask in subtasks:
        # 观察当前物体配置
        O_target = observe_object(state, subtask.object)

        # 选择最佳源段
        best_segment, warp_field = select_and_register(
            source_segments[subtask], O_target
        )

        # 变换轨迹
        warped_traj = warp_trajectory(best_segment, warp_field)

        # 添加插值段（平滑过渡）
        full_traj = interpolate(current_pose, warped_traj)

        # 执行
        state = execute(full_traj)

    # 验证任务成功
    if task_success(state):
        dataset.add(trial)
```

## 实现细节

### 遥操作数据收集
- 设备：Apple Vision Pro
- 映射：手部运动 → 平行夹爪 / 灵巧手
- Franka/手术机器人：相对末端位姿 + 夹爪动作
- GR1 人形：绝对手腕位姿 + 手指关节
- YAM 双臂：关节空间控制

### 策略训练
- **BC-RNN-GMM**：循环神经网络 + 高斯混合模型
- **Diffusion Policy**：基于扩散过程的策略学习
- 评估协议：3个随机种子，报告最大成功率

### Sim-to-Real 桥接
- **Point Bridge**：使用统一的领域无关点云表示
- 仿真中：ground-truth mask + 深度图提取点云
- 真实中：VLM 引导的点云提取管线
