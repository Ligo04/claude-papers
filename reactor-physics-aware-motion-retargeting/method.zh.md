# ReActor: 技术方法

## 双层公式化

### 问题设置

**上层**（运动适配）：
```
min_θ L_motion(θ, π*(θ))
```

**下层**（策略训练）：
```
π*(θ) = argmin_π L_tracking(π, θ)
```

其中：
- θ: 重定向参数
- π: 强化学习跟踪策略
- π*(θ): 给定 θ 的最优策略

### 损失函数

**运动损失** L_motion：
```
L_motion = w_pose · ||q_adapted - q_original||² 
         + w_vel · ||q̇_adapted - q̇_original||²
         + w_contact · L_contact
```

**跟踪损失** L_tracking（强化学习奖励）：
```
L_tracking = -R(s, a)，其中 R 包括：
- 姿态误差
- 速度匹配
- 末端执行器精度
- 接触一致性
```

## 梯度推导

### 简化梯度估计（方程 4-7）

完整梯度（不可行）：
```
∇_θ L = ∇_θ L_motion + (∂π*/∂θ) · (∂L_motion/∂π)
```

通过隐函数定理计算 ∂π*/∂θ 需要：
```
∂π*/∂θ = -H^(-1) · (∂²L_tracking/∂π∂θ)
其中 H = ∂²L_tracking/∂π²
```

**ReActor 近似**（方程 7）：
```
∇_θ L ≈ ∇_θ L_motion + λ · E_τ[∇_θ log π(a|s) · A(s,a)]
```

组成部分：
- **直接运动梯度：** ∇_θ L_motion（通过重定向反向传播）
- **策略梯度项：** ∇_θ log π(a|s)（策略对 θ 的敏感性）
- **优势加权：** A(s,a)（动作 a 在状态 s 中有多好）
- **平衡参数：** λ（保真度和跟踪之间的权衡）

### 实现

1. 使用当前策略 π 采样轨迹 τ
2. 使用 GAE 计算优势 A(s,a)
3. 计算运动梯度：∇_θ L_motion
4. 计算策略梯度：E[∇_θ log π(a|s) · A(s,a)]
5. 更新 θ：θ ← θ - α(∇_θ L_motion + λ · policy_grad)

## 重定向参数化

### 标称重定向（固定）

**位置匹配**（方程 8-9）：
```
p_target = scale · p_source + offset
其中 scale = height_target / height_source
```

**方向传递**（方程 10）：
```
R_target = R_source（直接复制旋转）
```

**逆运动学**（方程 11）：
```
q_nominal = IK(p_target, R_target)
```

### 可学习偏移（优化）

**每关节旋转偏移**（方程 12）：
```
q_adapted[i] = q_nominal[i] + Δq[i]
其中 Δq[i] ∈ ℝ³（轴角表示）
```

**末端执行器的每关节位置偏移**（方程 13）：
```
p_adapted[j] = p_nominal[j] + Δp[j]
其中 Δp[j] ∈ ℝ³（笛卡尔偏移）
```

**时间上恒定**（方程 14）：
```
Δq[i](t) = Δq[i] ∀t（所有帧使用相同偏移）
```

### 参数数量

**人形示例**（34 自由度）：
- 旋转偏移：34 个关节 × 3 = 102 个参数
- 位置偏移：4 个末端执行器 × 3 = 12 个参数
- **总计：** 114 个参数

**vs 逐帧：** 114 × 帧数（例如，114 × 300 = 34,200 个参数）

## 强化学习设置

### 状态空间（观测）

**本体感受**（表 1）：
- 关节位置：q ∈ ℝ^n_joints
- 关节速度：q̇ ∈ ℝ^n_joints
- 根部方向：R_root ∈ SO(3)
- 根部线速度：v_root ∈ ℝ³
- 根部角速度：ω_root ∈ ℝ³

**参考运动：**
- 目标关节位置：q_ref ∈ ℝ^n_joints
- 目标关节速度：q̇_ref ∈ ℝ^n_joints
- 目标末端执行器位置：p_ref ∈ ℝ^(3×n_ee)

**接触信息：**
- 足部接触二进制标志：c ∈ {0,1}^n_feet

**总维度：** 人形约 200

### 动作空间

**关节力矩：** τ ∈ ℝ^n_actuated

**参数化：**
- PD 控制器目标：q_target, q̇_target
- 网络输出目标位置/速度
- PD 控制器计算力矩：τ = K_p(q_target - q) + K_d(q̇_target - q̇)

### 奖励函数（表 1）

**姿态跟踪**（w=0.5）：
```
r_pose = exp(-2 · ||q - q_ref||²)
```

**速度匹配**（w=0.1）：
```
r_vel = exp(-0.1 · ||q̇ - q̇_ref||²)
```

**末端执行器跟踪**（w=0.3）：
```
r_ee = exp(-10 · ||p_ee - p_ref||²)
```

**接触一致性**（w=0.05）：
```
r_contact = -|c - c_ref|（惩罚接触不匹配）
```

**动作平滑度**（w=0.03）：
```
r_smooth = -||a_t - a_{t-1}||²
```

**力矩正则化**（w=0.02）：
```
r_torque = -||τ||²
```

**总奖励：**
```
R = Σ w_i · r_i
```

### 训练细节

**算法：** PPO（近端策略优化）

**超参数：**
- 学习率：3e-4（策略），1e-3（重定向）
- 折扣因子：γ = 0.99
- GAE lambda：λ_GAE = 0.95
- PPO 裁剪：ε = 0.2
- 熵系数：0.01
- 批量大小：32768 个转换
- 小批量大小：4096
- PPO 轮数：5

**环境：**
- 仿真器：Isaac Gym（GPU 加速）
- 并行环境：4096
- 时间步长：0.0167s（60 Hz）
- 回合长度：300 步（5 秒）

**更新计划：**
- 每次重定向更新 10 次策略更新
- 每 10M 环境步更新重定向
- 总训练：约 50M 步（RTX 3090 上约 6 小时）

### 自适应采样

**问题：** 某些运动片段比其他片段更难跟踪。

**解决方案：** 按跟踪误差加权采样回合：
```
p(segment_i) ∝ exp(β · error_i)
```

**效果：** 在具有挑战性的片段（转弯、过渡）上花费更多时间。

## 实现细节

### 网络架构

**策略网络：**
- 输入：状态（维度约 200）
- 隐藏层：[512, 256, 128]
- 输出：动作均值和对数标准差（维度约 34）
- 激活函数：ELU

**价值网络：**
- 输入：状态（维度约 200）
- 隐藏层：[512, 256, 128]
- 输出：价值估计（维度 1）
- 激活函数：ELU

### 重定向优化

**优化器：** Adam
- 学习率：1e-3
- Betas：(0.9, 0.999)
- 权重衰减：1e-4

**梯度裁剪：** 最大范数 = 1.0

**初始化：** Δq = 0, Δp = 0（从标称重定向开始）

### 终止条件

如果出现以下情况，回合终止：
- 根部高度 < 0.5m（跌倒）
- 根部方向 > 60° 偏离直立
- 违反关节限位
- 达到最大回合长度

### 评估指标

**足部滑动**（mm/帧）：
```
slide = ||v_foot|| 当足部应该接触时
```

**地面穿透**（mm）：
```
penetration = max(0, -foot_height)
```

**自穿透**（mm）：
```
self_pen = max(0, 身体部位之间的重叠)
```

**跟踪误差**（度）：
```
error = ||q - q_ref||
```

**成功率**（%）：
```
success = 无终止的回合 / 总回合
```
