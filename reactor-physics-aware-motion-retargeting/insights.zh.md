# ReActor: 深度洞察

## 为什么双层优化有效

### 顺序流水线的问题

传统方法：
1. 运动学重定向（优化视觉相似性）
2. 训练强化学习策略（优化跟踪）

**失败模式：** 第一步产生的参考在视觉上看起来不错，但在物理上不可行。第二步很困难，因为策略永远无法达到参考。

### 联合优化的解决方案

双层优化：
- **上层**根据策略跟踪效果调整参考
- **下层**训练策略，告知哪些参考是可跟踪的

**关键洞察：** 参考和策略共同演化。如果参考姿态难以跟踪，上层会调整它。如果策略改进，上层可以使参考更具挑战性。

**类比：** 就像老师（上层）和学生（下层）——老师根据学生表现调整难度，学生的努力告知教学策略。

### 为什么优于替代方案

**vs 固定重定向 + 强化学习：** 无法适应特定形态的约束  
**vs 逐帧优化：** 过拟合，不泛化  
**vs 端到端学习：** 需要大量数据，失去运动保真度

## 梯度简化的洞察

### 朴素方法

标准双层优化梯度：
```
∇_θ L = ∇_θ L_motion + (∂π*/∂θ) · (∂L_motion/∂π)
```

计算 ∂π*/∂θ 需要：
- 隐函数定理
- 策略参数的逆 Hessian 矩阵：H^(-1)，其中 H = ∂²L_tracking/∂π²
- 对于神经网络策略（数百万参数）计算上不可行

### ReActor 的近似

```
∇_θ L ≈ ∇_θ L_motion + λ · E[∇_θ log π(a|s) · A(s,a)]
```

**为什么有效：**
1. **策略梯度捕获敏感性：** ∇_θ log π 显示重定向变化如何影响动作概率
2. **优势加权：** A(s,a) 关注改善回报的动作
3. **避免二阶导数：** 不需要 Hessian 计算
4. **经验验证：** 实践中与精确梯度效果相当

**权衡：** 引入超参数 λ 来平衡运动保真度和跟踪性能。

## 物理闭环的优势

### 接触动力学

**问题：** 运动学重定向不建模足-地交互。

**ReActor 解决方案：** 优化在物理仿真器中运行，其中：
- 接触力自然产生
- 足部放置自动调整以保持平衡
- 支撑相持续时间自动调整

**结果：** 足部滑动减少 89%。

### 自碰撞避免

**问题：** 运动学重定向可能产生肢体穿透。

**ReActor 解决方案：** 物理引擎在优化期间强制执行碰撞约束。

**结果：** 自穿透减少 97%。

### 动力学可行性

**问题：** 运动学姿态可能需要不可能的力矩。

**ReActor 解决方案：** 强化学习策略在执行器限制内学习；不可行的参考会受到惩罚。

**结果：** 所有生成的运动都可以由仿真角色执行。

## 稀疏参数化的权衡

### 为什么使用常数偏移？

**优势：**
- **泛化：** 相同的偏移适用于多个运动片段
- **可解释性：** "膝盖多弯曲 5°"是人类可理解的
- **效率：** 数百个参数 vs 逐帧的数千个
- **正则化：** 防止对特定运动序列过拟合

**劣势：**
- **表达能力有限：** 无法适应特定运动的需求
- **统一调整：** 行走和跳跃使用相同的偏移

### 何时失效

**效果好：**
- 中等形态差距（人类 → 人形机器人）
- 一致的运动类型（全部是运动）
- 片段间动力学相似

**困难：**
- 极端形态差异（双足 → 四足）
- 混合运动类型（运动 + 操作）
- 特定运动约束（搬运重物）

**未来方向：** 分层参数化（全局 + 特定运动偏移）。

## 外部力惩罚

### 挑战

物理仿真包括外部力（重力、接触），但优化没有显式建模它们。

**当前方法：** 对外部力大小的惩罚项。

**局限性：** 间接——不区分：
- 必要的力（支撑期间的地面反作用力）
- 伪影（维持不可行姿态的过度力）

### 为什么不显式建模？

**计算成本：** 需要：
- 力预测网络
- 可微接触动力学
- 显著更复杂的优化

**实用选择：** 惩罚项在大多数情况下效果足够好。

**何时失败：** 具有大的有意外部力的运动（推、拉、搬运）。

## λ 超参数

### 它控制什么

```
∇_θ L ≈ ∇_θ L_motion + λ · E[∇_θ log π(a|s) · A(s,a)]
          ↑                    ↑
    运动保真度            跟踪性能
```

**高 λ：** 优先考虑跟踪性能 → 更多适应，更少保真度  
**低 λ：** 优先考虑运动保真度 → 更少适应，更难跟踪

### 调优策略

**论文使用：** 大多数实验 λ = 0.1

**依赖运动：**
- 复杂杂技：较低 λ（保留风格）
- 简单运动：较高 λ（优先考虑物理）

**依赖角色：**
- 大形态差距：较高 λ（需要更多适应）
- 相似形态：较低 λ（需要更少适应）

**未来工作：** 自适应 λ 调度或每个运动段学习的 λ。

## 为什么这很重要

ReActor 展示了**表示和策略的联合优化**比顺序流水线更有效。这一原则超越了运动重定向：

- **课程学习：** 联合优化任务难度和策略
- **Sim-to-real：** 联合优化仿真参数和控制策略
- **多任务学习：** 联合优化任务表示和共享策略

简化的梯度估计使深度强化学习的双层优化变得实用，为其他领域的类似方法打开了大门。
