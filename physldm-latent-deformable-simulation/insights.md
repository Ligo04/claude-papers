# 这篇论文真正值得学的内容

## 表示能力决定生成模型有多大空间可用

生成器输出的轨迹最终要经过 ST-VAE 解码。如果细长杆件的局部弯曲无法被固定大小的潜空间保留，再强的生成器也难以恢复这些细节。作者因此先把“已知真实轨迹能否准确压缩”当成独立问题研究。

表 1 的 2.48 mm 衡量 encode/decode 的形变重建，不是从初始状态预测未来。表 2 的 28.2 mm 才是 Objaverse held-out 上的世界坐标预测误差中位数。二者还涉及 Small/Base 配置、32/64 帧、形变/世界坐标与均值/中位数差别。不能把它们直接相减，解释成生成器单独增加的误差。[§4、附录 B、表 1–2](https://arxiv.org/html/2610.07609v3#S4)

## 分开整体运动与局部形变，节约的是表示容量

每帧写作 `x_t=R_t(r+d_t)+c_t`。`R_t,c_t` 描述整体运动，`d_t` 只描述刚体拟合后留下的残差。这样模型无需用毫米级形变通道同时表示米级平移。

论文进一步让刚体 token 使用独立的线性时间压缩通道。仅做数值归一化没有解决其小规模诊断中的问题；作者将失败归因于共享潜空间的容量竞争。这是实验支持的解释，不是对所有网络的理论定理。Rigid token 的独立通道也不意味着整体运动与形变完全不交流：前面的轴向注意力会处理联合 token。[§3.2、附录 F.2](https://arxiv.org/html/2610.07609v3#A6.SS2)

## Holistic temporal tokens 不再逐块承担局部时间片段

标准方案把若干相邻帧压成一个 latent frame，再用局部上采样恢复。撞击发生在块内何时、形变何时加速，容易丢失。结果是连续几帧不怎么动，然后突然赶上，论文称为 staircase。

Holistic 方案让每个空间 token 对整段时间使用 `M` 个可学习 query，再让每个输出帧查询这些摘要。它仍然压缩时间，但摘要无需与某个固定时间块一一对应。作者对 velocity loss、spectral loss 和自适应压缩做了比较，支持其设计在所测场景改善时间定位。它没有证明一切局部时间模型都会失败。[附录 C/E](https://arxiv.org/html/2610.07609v3#A3)

## 平方误差较低的结果，仍可能不满足形状约束

设两个等概率结果分别向左倒和向右倒。对坐标直接做平方误差回归，条件均值可能落在两个合法轨迹之间，而非任一合法轨迹。平均旋转矩阵通常不再是旋转矩阵，逐顶点平均可能缩小体积。

附带演示使用两个绕 z 轴旋转的四面体。两条轨迹各自保持体积，平均形状的末帧体积却只有原来的约 38.64%；平均轨迹的期望坐标 MSE 仍低于选择固定分支。这些数值是合成教学结果。

论文 Regression 在潜空间上训练，真实解码器是非线性的，因此不能把它严格等同于逐顶点平均。条件均值的解释说明一种风险，实际是否发生要看几何、运动与实验结果。Diffusion 能表示多个分支，但随机采样本身不保证每个样本遵守物理。[附录 A.4、D.6](https://arxiv.org/html/2610.07609v3#A4.SS6)

## “混沌”证据支持敏感性，不等于经典动力学本质随机

同一 GPU、byte-identical 输入的重复求解发生微小差异；接触顺序变化后，部分场景的终态差异变大。作者还加入很小的确定性旋转扰动做诊断。它们支持数值扰动被接触动力学放大的解释。

物理方程仍可在精确初值下是确定性的。有限精度、数值分支和未建模扰动使数据在给定条件下表现为多个可能结果。论文按两次重跑的末帧差是否超过 1% 尺寸来分组，这不是一般混沌系统的完整数学鉴定。300 场景中多数重复结果相近，也不能忽略。

Diffusion 在高、低分歧组都比 Regression 好，这说明改进并非只出现在敏感场景。多样本对高分歧组更有帮助，是分布建模有价值的证据；但两个模型的推理计算量并不相同，50 步采样与单次回归的差别仍应报告。[附录 D](https://arxiv.org/html/2610.07609v3#A4)

## 物理一致性指标需要逐项解释

DCC 可以检测“停顿后跳变”，但把形变幅度整体缩到 20%，相关性仍可接近 1。教学演示直接核验了这个性质。

体积指标只对 GT 本来近似保持体积的样本设门槛，并没有要求所有软体不可压缩。自交率是表面三角形统计，中位数显示为 0.00 不代表每个场景、每一帧均无自交。KE 指标比较形变与刚体动能的相对占比，不是总能量守恒，更不是接触力准确性。

因此这些指标共同支持预测较合理，不能合成一个未经定义的“物理正确率”。论文也没有给神经输出附加 IPC barrier 或 CCD 的不相交保证。[附录 B.3–B.4](https://arxiv.org/html/2610.07609v3#A2)

## 不显式使用本构公式，仍会继承训练数据的动力学

训练损失使用位置、运动和潜变量，而不是显式本构能量残差。但监督轨迹由 Stable Neo-Hookean 仿真生成，模型会学习它的行为，且 Young's modulus 仍是条件输入。

换成 ARAP 后，VAE 仍能重建，但预测误差增大。真实手部操作中，VAE 可重建已经观测到的轨迹，LDM 零样本预测却失败。一个只获得初始状态、没有未来手部作用条件的模型，本来就没有足够信息确定未来外力驱动。微调能拟合轨迹，但独立的新物体、新外力和新操作泛化还需另测。[附录 M](https://arxiv.org/html/2610.07609v3#A13)

## 快速可微的代理模型，适合怎样使用

对于低维材料估计、实验设计或多候选轨迹评估，神经模型可以便宜地产生一阶、二阶导数。关键是确认这个导数对实际目标有用：模型自己的 loss 下降，不足以证明真实仿真或现实任务改善。作者用原始求解器重放优化后的投掷，是较有说服力的一步。

从机器人工程角度，可把它视为候选轨迹与设计搜索的代理，再让物理求解器或实验核验选中方案。把它用于在线接触控制，需要另行解决行动条件、状态更新、时延与分布外行为。这是基于原文的工程判断，本资料没有运行机器人或本机仿真仓库。
