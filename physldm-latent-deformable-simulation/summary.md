# 方法与主要实验

PhysLDM 用空间 VAE、整体时序 ST-VAE 与条件 rectified-flow DiT，生成体积软体网格的 64 帧轨迹。它将全局刚体运动与局部形变分开，避免大幅运动吞占细节表示；整体时序 query 替代局部时间降采样与上采样，改善快速碰撞形变的时间定位。最后比较在同一 ST-VAE 上运行的确定性回归与扩散模型。[§3，PDF 第 4–6 页](https://arxiv.org/html/2610.07609v3#S3)

## 数据和比较条件

训练资产来自超过 30,000 个 Objaverse 物体。数据共含 63,397 条单物体和 16,078 条多物体轨迹，按场景 90%/5%/5% 划分。主文 ST-VAE 和 LDM 结果训练于单物体场景，多物体扩展单独训练。物体经网格处理后归一化到米量级，使用 Stable Neo-Hookean 材料，Young's modulus 范围 `3e4–3e6 Pa`，时间步长 `1/60 s`，轨迹 64 帧。[§4、附录 B](https://arxiv.org/html/2610.07609v3#A2)

ST-VAE 与 LDM 的训练顶点范围为 500–5000。GSO 和 Toys4K 是未参与训练的物体来源，但评估沿用相同仿真设置。论文明确排除 held-out 场景，所读描述未明确证明 Objaverse 划分按资产 ID 完全隔离；不要自行改写成严格物体互斥划分。

## 多模态与运行成本

在 300 个 held-out 场景中，71 个场景两次重复仿真的末帧平均顶点差超过物体尺寸的 1%。这被用作高分歧、论文称“chaotic”的操作性分组。该组 Regression、Diffusion 单样本、Diffusion best-of-8 的轨迹误差中位数分别为 63.2、54.0、44.7 mm。best-of-8 用 GT 选择，不能当作实际部署时无需额外信息的精度。[附录 D、表 5–6](https://arxiv.org/html/2610.07609v3#A4)

单卡 H200、batch 1、bf16 下，50 步 LDM 的有效输出帧率约 42–44 fps，20 步约 76–82 fps；一次完整生成 64 帧的耗时约为 1.45–1.52 秒或 0.78–0.84 秒，后两个范围由取整 fps 反算。峰值显存表列约 4.8–5.4 GiB。该吞吐并不提供同频率的逐帧闭环反馈。完整三阶段训练约需 8 张 H200、7 天。[表 10、附录 A/G](https://arxiv.org/html/2610.07609v3#A7)

## 泛化与逆问题的边界

真实捕捉数据的零样本 ST-VAE 重建误差为 6.0 mm，LDM 预测误差却为 874.9 mm；训练域是自由落体，真实域包含未观测手部外力。真实数据微调子集的预测误差从 921.3 降到 6.2 mm，但表 17 明确是在微调子集上统计，不能当成独立测试泛化。[表 16–17，PDF 第 44 页](https://arxiv.org/html/2610.07609v3#A13)

材料辨识在七个刚度设置上以 40 次 Adam 更新达到小于 0.06 dex 的误差。二阶投掷设计在约 7 分钟、30 步优化后，用原始求解器重放验证刚体运动对材料的敏感度提高约 13×。这是特定任务、局部参考刚度附近的结果；本文对 DiffIPC 和 Newton/Warp 的失败与耗时描述不能外推到全部后端、设置或任务。[附录 K、表 13](https://arxiv.org/html/2610.07609v3#A11)
