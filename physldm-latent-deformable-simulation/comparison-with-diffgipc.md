# 与刚学过的 DiffGIPC 对照

两篇都研究接触与软体运动，也都支持逆问题，但获得轨迹和梯度的方式不同。

| 方面 | DiffGIPC，2610.19091v1 | PhysLDM，2610.07609v3 |
| --- | --- | --- |
| 前向轨迹 | 求解 IPC 下的隐式动力学步方程 | 从数据学习条件轨迹生成映射 |
| 紧凑表示 | 近刚体每个 12 个 affine 运动自由度，软体用 FEM | 真实轨迹先压成时空潜变量，Base 为 4104 token |
| 对“刚体”的处理 | Affine body 是近刚体的运动模型 | Kabsch 分解是表示处理，残差仍保存软体形变 |
| 梯度 | 对收敛动力学方程做逐帧伴随 | 对神经模型与采样/解码过程自动微分 |
| 不相交性 | 依赖 IPC barrier、CCD、可行初始状态和求解条件 | 生成结果仍有自交统计，没有同类硬保证 |
| 时间 | 每个物理时间步求解，可逐帧累积 | 主模型联合生成固定 64 帧，采样另有人工 flow 时间 |
| 成本前提 | 需要数值求解与相关局部导数 | 需要训练数据和昂贵预训练，再获得便宜的代理推理 |
| 二阶导数 | 该论文重点为一阶伴随；未由其结果证明完整二阶接口 | 神经映射支持高阶 autograd，展示局部投掷设计 |
| 误差来源 | 离散化、接触模型、收敛和导数实现 | 数据覆盖、表示损失、预测偏差与采样误差 |

不能比较两篇摘要的速度数字来给出统一排名。DiffGIPC 统计不同任务的前向/反向 evaluation，PhysLDM 表 10 统计 H200 上固定窗口的神经推理，且预训练成本没有计入单次推理。

工程上可以探索组合：用物理求解器产生与验证数据，用神经模型筛选设计或提供初始猜测，再用物理求解器重放选中结果。这是学习后提出的应用设想，两篇论文并没有联合实现该方案，本资料也没有验证集成。
