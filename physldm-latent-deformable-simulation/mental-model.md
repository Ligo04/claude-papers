# 怎样理解 PhysLDM

想象一只柔软的杯子被抛向地面。输入包含杯子的四面体网格、初始位姿、线速度、角速度和 Young's modulus。输出是一段顶点轨迹，每个顶点在每一帧都有三维位置。论文主要预测 64 帧，训练数据由 StiffGIPC 生成。

一个 5000 顶点、64 帧的场景有 320,000 个“顶点×时间”位置。直接在这上面训练生成模型很贵。PhysLDM 先学习如何把真实轨迹压成 4104 个潜空间 token，再学习从初始条件预测这组 token。

这里有两个不同问题。重建时，编码器已经看过完整真实轨迹，任务是压缩后还原它。预测时，生成器只获得初始条件，必须生成未来。编码器还原得精确，说明表示能力足够；它不能单独证明未来预测正确。

每帧还可以分为整体运动和相对形变。一个物体可以移动一米，局部形变却只有毫米量级。直接压缩世界坐标容易让大幅运动占据模型容量。论文先把刚体位姿提出来，再压缩剩下的形变，并为刚体信号安排独立的时间通道。

理解之后再看扩散。若近乎相同的初始条件对应向左倒、向右倒两种合理结果，用平方误差训练的确定性回归可能倾向二者之间的平均。平均后的网格不一定是合理形状。生成模型可以输出其中一条完整轨迹，而不是把两个结果逐点混在一起。论文用重复仿真和多样本结果支持这个解释，但并未证明所有动力学都必须用随机模型。

| 前置知识 | 本文需要的理解 |
| --- | --- |
| 四面体网格 | 既有表面又有内部顶点，可以统计体积和自交 |
| 刚体拟合 | Kabsch 将整体旋转、平移与形变残差分开 |
| VAE | 用编码器压缩真实输入，再用解码器恢复 |
| Attention | 固定数量的 query 可以从变长顶点集合提取表示 |
| Flow matching | 学习噪声与数据之间的速度场，再积分生成样本 |
| 自动微分 | 对神经预测映射求导；求得的是模型的导数 |

这篇与 DiffGIPC 的问题设置不同。DiffGIPC 对接触动力学方程求解并计算伴随；PhysLDM 学习这些轨迹的近似生成映射。两者都可以支持逆问题，但其梯度来源和误差来源不同。
