# NeuralActuator 心智模型

## 一句话心智模型

> **给低成本舵机学一个"仿真器会信的油门"，顺便免费得到力觉。**

网络不去标定真实的电流-力矩物理关系，而是学"喂什么等效输入进仿真器，能让它复现真机的运动"（那个"油门"），监督全靠位姿；同一份执行器遥测里顺带把"外力多大""关节健康不健康"也读出来。

## 这是什么类型的问题？

这篇工作坐落在四类问题的**交点**上，理解它必须同时戴四副眼镜：

1. **系统辨识 (System Identification)**——本质任务是"从数据里恢复执行器的输入-输出行为"。但它是一种**非标准的系统辨识**：放弃了辨识可解释物理参数的目标（不追求 identifiability），改为辨识"仿真器等效代理"。

2. **神经代理模型 (Neural Surrogate Model)**——用 Transformer 学一个历史相关、非线性的映射，替代那条失效的 `τ = K_t·I` 直线。属于"神经增强仿真 (neural-augmented simulation)"家族，但专攻执行器这一环。

3. **无感力觉估计 (Proprioceptive / Sensorless Force Estimation)**——从本体感知 + 执行器遥测反推末端外力，不用专用力传感器。属于"actuation as sensing"这条线。

4. **可微仿真训练 (Differentiable-Simulation Training)**——训练机制的核心：把物理引擎放进计算图，用 BPTT 让位姿误差的梯度穿过动力学传回力矩预测头。这是让前三件事能同时成立的粘合剂。

**关键认知**：如果只用其中一副眼镜看，会误判这篇论文。比如只当它是"又一个 actuator net"，就会疑惑"为什么不用力矩标签"——答案在于第 4 副眼镜（可微仿真让位姿能替代力矩当监督）和第 1 副眼镜的立场转变（不追求可辨识性）。

## 需要哪些前置知识

### 必备
- **机械臂动力学方程**：`M(q)q̈ + C(q,q̇)q̇ + g(q) = τ`。必须理解 τ 如何分解为执行器力矩 `τ_act` 和外力贡献 `τ_ext = J_v^T f_ext`（式 4）。这是理解"力矩代理"和"外力头"为什么可以分开的物理骨架。
- **可微仿真 / BPTT**：理解"仿真器可微 → 位姿损失的梯度能反传到力矩输入 → 再传到网络参数"这条链（式 11-12）。没有这个，就不理解为什么可以"没有力矩标签也能训练力矩预测"。
- **Transformer encoder**：多头自注意力、pre-norm 残差、位置编码、时序池化。这里还有个变体——query 依赖的逐元素注意力门控 `A = [MHA(U) ⊙ σ(U·W_g)]·W_o`。
- **伺服电机基本原理**：coreless 有刷 DC 舵机、齿轮减速、以及非理想性——摩擦、迟滞、背隙、电流饱和、热漂移。理解这些才明白"为什么线性电流-力矩假设会崩"。

### 有帮助
- 系统辨识中 identifiability（可辨识性）的概念——理解本文为什么**主动放弃**它。
- 经典外力/碰撞检测方法：广义动量观测器 (GMO, De Luca 2005)、虚拟力传感器——理解基线为什么在齿轮舵机上失效。
- 课程学习 (curriculum learning)——rollout 视野从 128 逐步加到 320 的动机（由 Table II 梯度诊断驱动）。
- 可微渲染 + 轮廓损失（视觉监督那一节，EasyHeC/VGGT/SAM3 式）。

## 在研究版图中的位置

NeuralActuator 是三条独立研究线的**交汇点**：

```
        神经增强仿真                    Actuator Networks
   (neural-augmented sim)          (Hwangbo ANYmal / Schwendeman)
   NeuralSim / NeRD / Serifi              学执行器模型
   学残差动力学                          但需要力矩标签
              \                              /
               \                            /
                \                          /
                 +———— NeuralActuator ————+
                 |   低成本舵机执行器代理   |
                 |   + 可微仿真位姿监督      |
                 |   + 无需力矩标签          |
                          |
                          |
              Proprioceptive Force Estimation
              (无感力觉 / actuation as sensing)
              De Luca GMO / UniTac / e-skin
              但依赖可靠力矩反馈
```

- **相对神经增强仿真线**：那条线关注残差动力学（学"仿真器还差多少"），NeuralActuator 把焦点收窄到**执行器这一个组件**，并且是低成本无芯 DC 舵机这个被忽视的角落。
- **相对 actuator networks 线**：Hwangbo/Schwendeman 需要力矩传感或标定电流做标签；NeuralActuator 用位姿监督**绕开了标签依赖**——这是它在这条线上的核心贡献。
- **相对无感力觉线**：经典方法（GMO 等）依赖可靠力矩反馈，在齿轮舵机上失效；NeuralActuator 用学出来的历史相关代理，并加了接触门去掉误报。

三条线各自都成熟，但**它们的交集——"低成本、无力矩标签、齿轮舵机上同时做动力学建模 + 力觉"——是空白**，这就是本文占据的生态位。

## 如何在脑中归类这项工作

把它归档为：

> **"一个务实的工程解，用可微仿真把'缺失的力矩标签'问题转化为'人人都有的位姿标签'问题，代价是放弃物理可辨识性、换来实时可用的无感力觉。"**

记住三个"钩子"，以后看到相关工作能快速关联：
1. **监督信号替换**：力矩标签没有 → 用位姿标签 + 可微仿真绕过。
2. **代理而非辨识**：`τ̄` 是"仿真器等效输入"，不是真实力矩；未建模效应被吸收。
3. **多任务共享表征**：同一份遥测 → 力矩代理 / 外力 / 接触门 / 电机健康四个头，执行器 = 隐式传感器。
