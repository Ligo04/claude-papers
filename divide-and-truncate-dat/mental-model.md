# 思维模型与研究定位

## 这是什么类型的问题？

**约束满足 + 优化加速问题**

核心矛盾：物理仿真优化器追求能量最小化（运动自由），而碰撞约束要求无穿透（运动限制）。如何在保证安全的前提下，尽可能少地干预优化器的输出？

## 研究谱系

```
碰撞处理方法演化：

惩罚力方法 (Penalty)
  └─ 问题：无法严格保证无穿透
      │
      ▼
约束方法 (Constraint-based)
  ├─ 线搜索 (Line-Search)
  │   └─ IPC [Li et al. 2020]
  │       ├─ CCD + 全局步长限制
  │       ├─ 问题：单碰撞锁全局、CCD 昂贵
  │       └─ 后续：Local CCD [Lan 2023], 各种扩展
  │
  └─ 信赖域 (Trust-Region)
      ├─ Conservative Advancement [Zhang 2006, Tang 2009]
      ├─ OGC [Chen et al. 2025] = Isotropic-DAT
      │   └─ 问题：各向同性约束 → 阻尼 + 死锁
      │
      └─ ★ Planar-DAT [本文 2026]
            └─ 方向感知半空间 → 解决阻尼和死锁
```

## 类比理解

### 类比 1：交通管制

- **CCD 线搜索** = 红绿灯：一辆车要过路口，所有车都停
- **Isotropic-DAT** = 限速区：所有方向都限速，即使你要转弯离开
- **Planar-DAT** = 单向护栏：只阻止你冲向对面车道，平行行驶不受限

### 类比 2：安全距离

- **Isotropic** = 在你周围画一个圆，你不能出圆（圆越来越小）
- **Planar** = 在你和障碍物之间画一条线，你不能越线（但可以沿线自由移动）

### 类比 3：优化中的约束投影

- **CCD** = 沿梯度方向做线搜索，遇到约束边界就停
- **Isotropic-DAT** = 将可行域定义为球的交集（保守）
- **Planar-DAT** = 将可行域定义为半空间的交集（多面体，更紧凑）

## 前置知识要求

### 必须了解
- 三角网格表示和拓扑
- 碰撞检测基础（BVH、最近点查询）
- 迭代优化器的基本概念（梯度下降、牛顿法）
- 物理仿真时间积分

### 有助于理解
- IPC 和 CCD 的工作原理
- 信赖域优化方法
- GPU 并行编程（CUDA、atomic 操作）
- 凸优化和投影算法

### 可以不了解
- 具体的材料模型（弹性、布料）
- VBD 求解器的内部细节
- 区间算术的完整理论

## 如何分类这项工作

**标签**：
- 碰撞处理 > 信赖域方法 > 方向感知
- 后处理约束 > 求解器无关
- GPU 并行 > 原子操作 > CUDA Graph

**创新类型**：
- 不是全新范式，而是对已有范式（信赖域）的关键改进
- 核心洞察简单但影响深远（利用已知位移方向）
- 工程价值极高（实时、通用、易集成）

## 这篇论文教会我们什么

1. **利用已有信息**：优化器已经告诉你方向了，为什么还要假设最坏情况？
2. **从有限到无限**：球 → 半空间，有限体积 → 无限体积，本质性的空间利用率提升
3. **解耦的力量**：碰撞处理与求解器解耦 = 通用性 + 可组合性
4. **简单想法的工程放大**：核心想法一句话说清，但工程实现（旋转、动画、并行化）需要大量细节工作
