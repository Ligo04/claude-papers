# Divide and Truncate (DAT): 无穿透多物理耦合仿真框架

## 论文概述

本文提出了 Divide and Truncate (DAT) 框架，一种用于多物理系统耦合仿真中保证无穿透碰撞处理的统一方法。核心创新是 Planar-DAT 变体：通过方向感知的半空间划分替代传统的各向同性球形约束，仅限制朝向表面的运动，保留切向自由度，从而解决了先前方法中的人工阻尼和死锁问题。

## 难度等级

**高级** — 需要计算几何、优化理论和物理仿真背景知识。

## 关键收获

- 将空间划分为互斥区域 + 截断位移 = 保证无穿透
- 方向感知的半空间约束比各向同性球形约束保留 2.22× 以上的有效运动
- 材料无关 + 求解器无关 = 可作为后处理步骤集成到任意迭代优化器
- 200 层布料（400万顶点）在 GPU 上平均 12.6ms/步
