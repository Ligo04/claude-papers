# 技术方法详解

## 问题设定

给定三角网格 M = {V, E, T}（顶点、边、三角形集合），当前无穿透状态 X ∈ ℝ^{3×N}，以及优化器计算的位移 ΔX ∈ ℝ^{3×N}。

**目标**：修改 ΔX 使得 X + ΔX 仍然无穿透，同时尽可能保留 ΔX 的方向和大小。

## 核心框架：Divide and Truncate

两步策略：
1. **Divide（划分）**：将环境空间划分为互斥区域，每个图元分配一个独占区域
2. **Truncate（截断）**：截断位移使每个图元的变形保持在其独占区域内

## 第一阶段：Isotropic DAT（各向同性划分）

### 思路
确保每个面的移动不超过到最近面距离的一半——即使最坏情况（两面直接相向移动），也不会穿透。

### 独占区域定义

顶点 v 的独占区域（球形）：
```
S_v = {x ∈ ℝ³ | |x - x(v)| < r_v},  r_v < 0.5 * d_min,v
```

三角形 t 的独占区域（偏移体）：
```
S_t = {x ∈ ℝ³ | dis(x, t) < r_t},  r_t < 0.5 * d_min,t
```

### 截断规则
每个顶点独立缩放：
```
|t_v · Δx_v| ≤ min(r_v, min_{t∈T_v}(r_t), min_{e∈E_v}(r_e))
```

### 问题
- 球形区域只覆盖空间的有限部分
- 切向运动被不必要地限制 → 人工阻尼
- 密集接触时球体缩小到接近零 → 死锁

## 第二阶段：Planar DAT（平面划分）

### 核心创新

对于顶点-三角形对 (v, t)：
- 找到 v 到 t 的最近点 c_{v,t}
- 定义法向量 n_{v,t} = normalize(x_v - c_{v,t})
- 用一个平面将空间分为两个半空间

### 独占区域定义（半空间）

```
S^{v,t}_v = {x ∈ ℝ³ | (x - p_{v,t}) · n_{v,t} > 0}   (顶点侧)
S^{v,t}_t = {x ∈ ℝ³ | (x - p_{v,t}) · n_{v,t} < 0}   (三角形侧)
```

其中划分点 p_{v,t} = x_v - λ_{v,t}(x_v - c_{v,t})

### 自适应 λ 计算

关键：根据位移的法向分量按比例放置划分平面。

```
δ_v = max(-Δx_v · n_{v,t}, 0)           # 顶点朝向三角形的法向分量
δ_t = max(max(Δx_a, Δx_b, Δx_c) · n_{v,t}, 0)  # 三角形朝向顶点的最大法向分量

λ_{v,t} = 0.5              (若 δ_v = δ_t = 0)
λ_{v,t} = δ_t / (δ_t + δ_v)  (否则)
```

**直觉**：
- λ → 0：平面靠近顶点 → 三角形获得更多空间
- λ → 1：平面靠近三角形 → 顶点获得更多空间
- 谁需要更多法向运动空间，谁就获得更多

### 从面约束到顶点约束

**定理 3.1**：每个面的变形保持在其独占区域内，当且仅当每个顶点 v 满足：
```
Δx_v + x_v ∈ S_v          (顶点自身的半空间约束)
Δx_v + x_v ∈ S_t, ∀t ∈ T_v  (所属三角形的半空间约束)
Δx_v + x_v ∈ S_e, ∀e ∈ E_v  (所属边的半空间约束)
```

### 截断计算

对每个划分平面 (n, p)，计算射线 (x_v, Δx_v) 与平面的交点参数 t_i：
```
t_v = 1              (若 t_i < 0 或 t_i ≥ 1/γ_r)
t_v = γ_r · t_i      (否则)
```

其中 γ_r ∈ (0,1) 是松弛系数，确保位移停在划分平面之前。

## 扩展：体积反转约束

四面体反转 = 一个顶点越过对面三角形所定义的平面。

这与顶点-三角形碰撞的处理完全相同！同一个半空间截断机制直接复用，无需额外处理。

## 扩展：旋转自由度（刚体）

### 问题
刚体顶点沿曲线轨迹运动（旋转），线性截断可能遗漏弧线上的碰撞。

### 轨迹模型
```
φ_i(t) = R(θ_i + t·Δθ) · x̂_i + x_i + t·Δx_i
```

### 两阶段安全时间搜索（Algorithm 1）

**阶段 1**：均匀采样 + 二分搜索
1. 沿 [0,1] 均匀采样 K 个点
2. 计算每个采样点到划分平面的符号距离
3. 检测符号变化 → 二分搜索精确定位

**阶段 2**：区间算术验证
1. 计算轨迹段 φ_i([0, t*]) 的保守包围盒
2. 若包围盒与平面相交 → 进一步二分缩小安全区间

### 刚体截断
```
t_b = min_{v∈b} min_{(n,p)∈P_v} t*_{v,n,p}
```
整个刚体使用统一的截断比例。

## 扩展：动画对象

动画位移与优化器位移同等对待——增量施加，受相同截断约束。概念上等价于无限刚度的力驱动对象到目标姿态。

## 并行实现（Algorithm 2）

```
伪代码流程：
1. 初始化所有 t_v = 1
2. 并行遍历所有碰撞对 (f1, f2)：
   a. 计算划分平面 (n, p)
   b. 计算四个顶点的截断比例
   c. atomic_min 更新全局 t_v
3. 并行遍历所有顶点：
   a. 应用截断：Δx_v ← t_v · Δx_v
   b. 上界约束：|Δx_v| ≤ 0.5·γ_r·r_q
4. 并行遍历所有刚体：
   a. t_b = min(所有顶点的 t_v)
   b. 缩放旋转和平移
```

### 为什么按碰撞对并行而非按顶点并行？

按碰撞对并行 + atomic_min 比按顶点并行快 20×，原因：
- t_v 快速减小后，大多数线程的 atomic_min 不会实际写入全局内存
- 避免了按顶点遍历所有相邻面的串行瓶颈

## 仿真集成（Algorithm 3）

```
关键设计：
1. 碰撞检测不需要每次迭代执行（每 5 次迭代一次）
2. 累积增量位移 ΔX，仅在碰撞检测时提交到状态
3. DAT 使用碰撞检测时记录的位置计算（非 X+ΔX）
4. 固定碰撞检测频率 → 整帧可捕获为单个 CUDA Graph
```

## Divide and Project（DAP）变体

将截断替换为能量感知投影：
```
arg min_{ΔX'} ||ΔX' - ΔX||²_H  s.t. ΔX' ∈ S
```

使用 Dykstra 投影算法迭代投影到每个半空间。

**权衡**：收敛更快，但开销约 50× → 不适合实时应用。

## 计算时间分布

```
碰撞检测:        63.5%  ← 瓶颈
力和 Hessian 累积: 13.8%
Planar 截断:      12.8%  ← DAT 本身开销很小
其他:             9.9%
```

## 关键参数

| 参数 | 典型值 | 含义 |
|------|--------|------|
| r_c | 0.2mm | 接触半径 |
| r_q | 1.5·r_c | 查询半径 |
| γ_r | < 1 | 松弛系数（保守程度） |
| K | 8 (Δt=1/600) | 旋转轨迹采样点数 |
| 碰撞检测频率 | 每 5 次迭代 | 平衡精度与性能 |
