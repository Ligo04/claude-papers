# 自测问答

## 基础题（5题）

### Q1: DAT 框架的两个核心步骤是什么？

<details>
<summary>答案</summary>

1. **Divide（划分）**：将环境空间划分为互斥的独占区域，每个图元（顶点、边、三角形）分配一个区域
2. **Truncate（截断）**：截断位移 ΔX，使每个图元的变形保持在其分配的独占区域内

这两步保证了只要每个图元不离开自己的区域，就不可能发生穿透。

</details>

---

### Q2: Isotropic-DAT 中，顶点的独占区域是什么形状？为什么选择距离的一半作为半径？

<details>
<summary>答案</summary>

独占区域是以顶点为中心的**球体**，半径 r_v < 0.5 × d_min,v（到最近非邻居三角形距离的一半）。

选择一半的原因：在最坏情况下，两个相邻图元可能直接相向移动。如果每个都只移动距离的一半，即使它们正面相撞，也恰好在中点相遇而不会穿透。这是一个保守但安全的界限。

</details>

---

### Q3: Planar-DAT 相比 Isotropic-DAT 的核心改进是什么？

<details>
<summary>答案</summary>

Planar-DAT 用**方向感知的半空间**替代各向同性的球形约束：

- Isotropic-DAT：独占区域是有限体积的球 → 所有方向的运动都被限制
- Planar-DAT：独占区域是无限延伸的半空间 → 只限制朝向碰撞面的法向运动，切向运动完全自由

这解决了两个关键问题：人工阻尼（切向运动被不必要限制）和死锁（密集接触时球体缩小到接近零）。

</details>

---

### Q4: DAT 为什么被称为"材料无关"和"求解器无关"？

<details>
<summary>答案</summary>

**材料无关**：DAT 只处理位移截断，不需要知道对方物体的材料属性（弹性模量、密度等）。布料、软体、刚体都用同一个截断方案。

**求解器无关**：DAT 作为后处理步骤工作——先让任意求解器（VBD、Newton、PD 等）计算位移 ΔX，然后 DAT 截断使其安全。不需要修改求解器内部逻辑。

</details>

---

### Q5: 论文中碰撞检测的执行频率是多少？为什么不是每次迭代都执行？

<details>
<summary>答案</summary>

每 **5 次求解器迭代**执行一次碰撞检测。

原因：
1. 碰撞检测占总计算时间的 63.5%，是最大瓶颈
2. DAT 的截断保证了在碰撞检测之间的迭代中不会发生穿透
3. 固定频率允许整个仿真步骤被捕获为单个 CUDA Graph，避免 CPU-GPU 同步开销

</details>

## 中级题（5题）

### Q6: 解释 λ_{v,t} 的自适应计算公式及其几何含义。

<details>
<summary>答案</summary>

```
δ_v = max(-Δx_v · n_{v,t}, 0)     # 顶点朝向三角形的法向位移
δ_t = max(Δx_a·n, Δx_b·n, Δx_c·n, 0)  # 三角形朝向顶点的最大法向位移

λ_{v,t} = δ_t / (δ_t + δ_v)   (若非零)
λ_{v,t} = 0.5                  (若都为零)
```

几何含义：
- λ 决定划分平面在顶点和三角形之间的位置（0=在顶点处，1=在三角形处）
- 按法向位移比例分配空间：谁朝对方移动得更快，谁获得的空间越少
- 若一方远离（δ=0），另一方获得全部空间 → 远离方完全不受约束
- 若双方都不接近（δ_v = δ_t = 0），平面放在中点

</details>

### Q7: 定理 3.1 的意义是什么？它如何简化实现？

<details>
<summary>答案</summary>

**定理 3.1** 说：每个面（三角形/边）的变形保持在其独占区域内 ⟺ 每个顶点满足其关联的所有半空间约束。

意义：将**面级约束**转化为**顶点级约束**。

简化实现：
1. 不需要检查整个三角形是否在半空间内（需要检查三角形上所有点）
2. 只需确保三角形的三个顶点都在正确的半空间内
3. 每个顶点独立截断，可以高度并行化
4. 截断计算简化为射线-平面求交（一个点积和一个除法）

</details>

---

### Q8: 为什么 Planar-DAT 的并行实现选择按碰撞对并行而非按顶点并行？

<details>
<summary>答案</summary>

按碰撞对并行 + atomic_min 比按顶点并行快约 **20×**。

原因分析：
1. **按顶点并行**：每个线程需要遍历该顶点的所有相邻面及其碰撞对，工作量不均衡
2. **按碰撞对并行**：每个线程只处理一个碰撞对的 4 个顶点，工作量均匀
3. **atomic_min 的优势**：t_v 快速减小后，后续线程的 atomic_min 比较发现自己的值更大，不需要实际写入全局内存 → 大部分线程零内存写入开销
4. 甚至比 block-based 实现（每个顶点一个线程块 + 局部归约）快 2×

</details>

### Q9: 刚体旋转自由度的处理为什么需要两阶段算法？

<details>
<summary>答案</summary>

刚体顶点沿**曲线轨迹**运动（因为旋转矩阵是非线性的），不能简单用线性截断。

**阶段 1（采样 + 二分）**：
- 沿 [0,1] 均匀采样 K 个点，检测符号距离变化
- 找到最后一个安全时间点 t*
- 问题：只保证采样端点安全，弧线可能在两个采样点之间越过平面

**阶段 2（区间算术验证）**：
- 计算轨迹段 φ_i([0, t*]) 的保守包围盒
- 若包围盒与平面相交 → 弧线可能不安全 → 进一步二分缩小
- 保证整条弧线（不仅是端点）都在安全侧

两阶段结合：阶段 1 快速定位大致范围，阶段 2 严格验证弧线安全性。实践中小步长时轨迹近似线性，阶段 2 很少需要多次迭代。

</details>

### Q10: Divide and Project (DAP) 与 Divide and Truncate 的区别是什么？为什么论文最终选择截断？

<details>
<summary>答案</summary>

**DAT（截断）**：对每个顶点独立缩放位移 t_v · Δx_v，使其不越过划分平面。简单快速，但不是能量最优的。

**DAP（投影）**：将 ΔX 投影到由所有半空间约束定义的多面体可行域上，使用能量 Hessian 作为度量：
```
arg min_{ΔX'} ||ΔX' - ΔX||²_H  s.t. ΔX' ∈ S
```
使用 Dykstra 投影算法迭代求解。

选择截断的原因：
1. DAP 开销约为截断的 **50×**
2. 全局 DAP（所有顶点联合投影）在百万碰撞场景中根本无法完成一次迭代
3. 即使逐顶点 DAP 也太慢，不适合实时应用
4. 截断虽然不是最优的，但在实践中已经足够好（保留 2.22× 以上的运动）

</details>

## 高级题（5题）

### Q11: 为什么 Planar-DAT 对查询半径 r_q 的选择不敏感，而 Isotropic-DAT 很敏感？

<details>
<summary>答案</summary>

**Isotropic-DAT 对 r_q 敏感**：
- 独占区域半径 = 0.5 × 到最近面的距离
- r_q 决定了"最近面"的搜索范围
- r_q 太小 → 遗漏近邻 → 可能穿透
- r_q 太大 → 找到更多近邻 → 球体更小 → 更多阻尼/死锁
- 需要精心调参平衡安全性和动力学

**Planar-DAT 对 r_q 不敏感**：
- 半空间约束只限制法向接近运动
- 即使找到更多近邻，只要位移不朝向它们，就不会被截断
- 超出 r_q 的面退化为各向同性约束（|Δx_v| ≤ 0.5·γ_r·r_q），但这只是一个上界保护
- 方向感知使得约束的"紧度"取决于实际运动方向，而非邻居数量

本质区别：Isotropic 的约束强度与邻居距离直接耦合；Planar 的约束强度与运动方向耦合，邻居距离只影响划分平面位置。

</details>

### Q12: 论文如何处理碰撞检测和 DAT 截断之间的时间不一致性？

<details>
<summary>答案</summary>

关键设计：DAT 使用**碰撞检测时记录的位置 X** 计算，而非当前累积位置 X + ΔX。

原因：
1. 碰撞检测在状态 X 上执行，返回的碰撞对和距离信息基于 X
2. 如果用 X + ΔX 计算划分平面，可能与碰撞检测的结果不一致
3. 在两次碰撞检测之间，ΔX 持续累积但不提交到状态
4. 只有在新的碰撞检测时才执行 X ← X + ΔX 并重置 ΔX = 0

这种设计的好处：
- 保证碰撞信息和截断计算的一致性
- 允许固定碰撞检测频率
- 使整帧计算可以被捕获为 CUDA Graph（无条件分支）

潜在风险：如果 ΔX 累积过大，碰撞对可能过时。但由于每 5 次迭代检测一次，且每次迭代的位移受截断限制，实践中不会出问题。

</details>

### Q13: 如果两个顶点同时朝同一个三角形移动，Planar-DAT 如何避免它们之间的穿透？

<details>
<summary>答案</summary>

这个问题涉及 DAT 的完整性保证。

关键：DAT 不仅处理顶点-三角形对，还处理**边-边对**。

场景分析：
1. 两个顶点 v1, v2 朝同一个三角形 t 移动
2. 对于 (v1, t) 和 (v2, t)，各自有独立的划分平面和截断
3. 但 v1 和 v2 之间可能穿透——这通过**边-边碰撞对**处理

完整的碰撞对集合包括：
- 所有顶点-三角形对（防止顶点穿过三角形）
- 所有边-边对（防止边穿过边）

这两类碰撞对的组合覆盖了三角网格中所有可能的穿透模式。每个顶点的最终截断比例是所有相关碰撞对（包括其所属边的边-边对）中的最小值。

此外，定理 3.1 确保了：只要每个顶点满足其所有关联约束（包括作为三角形/边成员的约束），整个面的变形就是安全的。

</details>

### Q14: 分析 Planar-DAT 在什么情况下会退化为接近 Isotropic-DAT 的行为。

<details>
<summary>答案</summary>

Planar-DAT 退化的情况：

**1. 位移直接朝向碰撞面（最坏情况）**
- 当 Δx_v 完全沿 -n_{v,t} 方向时，δ_v 最大
- 截断量与 Isotropic-DAT 相当（都是距离的一半左右）
- 但即使在这种情况下，Planar-DAT 仍然更好：对方如果不接近，λ 会偏向给当前顶点更多空间

**2. 超出查询半径 r_q 的面**
- 论文明确说明：对于超出 r_q 的面，方法退化为 Isotropic-DAT
- 约束变为 |Δx_v| ≤ 0.5·γ_r·r_q（各向同性上界）

**3. 所有方向都有近邻且都在接近**
- 如果一个顶点被四面八方的面包围，且所有面都在接近
- 每个方向都有半空间约束 → 可行域缩小为很小的多面体
- 但仍然比球形约束好：多面体的体积 ≥ 内切球的体积

**4. 刚体的全局截断**
- 刚体使用所有顶点中的最小 t_b → 一个顶点的约束限制整个刚体
- 这类似于 CCD 的全局步长限制，但粒度是每个刚体而非全局

实践中，退化情况很少发生，因为排斥力的存在使得大多数位移是远离或切向的。

</details>

### Q15: 如果要将 Planar-DAT 扩展到处理连续介质（如流体-固体耦合），你预见哪些挑战？

<details>
<summary>答案</summary>

将 Planar-DAT 扩展到流体-固体耦合面临多个根本性挑战：

**1. 拓扑变化**
- 流体的网格拓扑在每个时间步可能改变（重新网格化、粒子分裂/合并）
- DAT 依赖固定的碰撞对关系，拓扑变化需要完全重建
- 可能的解决方向：使用粒子表示（SPH）+ 粒子级截断

**2. 无明确表面**
- DAT 需要明确的表面法向量来定义划分平面
- 流体的自由表面是隐式定义的（等值面）
- 可能需要结合 level-set 方法提取表面后再应用 DAT

**3. 不可压缩性约束**
- 流体的不可压缩性是全局约束（散度为零）
- DAT 的逐顶点截断可能破坏不可压缩性
- 需要在截断后重新投影到无散度空间

**4. 大变形和高速**
- 流体位移可能远大于网格尺度
- 查询半径 r_q 可能需要非常大，导致碰撞对数量爆炸
- 子步进（sub-stepping）可能是必要的

**5. 界面追踪**
- 流体-固体界面需要精确追踪
- DAT 的截断可能导致界面处的质量不守恒
- 需要额外的界面修正步骤

**可能的研究方向**：
- 将 DAT 与 MPM（物质点法）结合——粒子携带物质，网格用于求解
- 使用隐式表面的梯度作为法向量定义划分平面
- 分层 DAT：先处理固体-固体，再处理流体-固体界面

</details>
