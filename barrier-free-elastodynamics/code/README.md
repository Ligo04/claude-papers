# 代码演示(Code Demos)

两个自包含、可独立运行的最小 demo,复现论文的两个核心论点。仅依赖 `numpy`(`matplotlib` 可选,用于出图)。

论文:*Robust and Efficient Penetration-Free Elastodynamics without Barriers*(Zheng, Luo, Li — ACM TOG 2026, arXiv:2512.12151)

---

## 1. `al_contact_1d_demo.py` — 增广拉格朗日 vs 朴素罚(核心洞察)

复现论文 **§6.3 / Fig.19** 的核心论点:**为什么必须用增广拉格朗日而不是朴素罚函数**。

**场景**:1D 质点被外力强力推向墙(原点),非穿透约束 `c(x)=x-δ≥0`,希望停在墙外侧 δ 处。

**对比**:
- **朴素二次罚**:要消除穿透必须把刚度 μ 调到极大,但残留穿透 ≈ F_ext/μ 只能随 μ 缓慢减小,而 Hessian 条件数随 μ 线性暴涨(病态)。
- **增广拉格朗日**:用温和 μ=1e3,靠迭代更新乘子 λ 把约束精确驱动到 δ,残留穿透 ~0 且系统保持良态。

**运行**:
```bash
python3 al_contact_1d_demo.py
```

**预期输出**(关键行):
```
朴素罚 (μ=1e3)    x=-1.475   残留穿透=1.525     条件数比≈2.0e+00   # 严重穿透
朴素罚 (μ=1e6)    x= 0.047   残留穿透=0.003047  条件数比≈1.0e+03   # 病态
增广拉格朗日(μ=1e3) x= 0.050   残留穿透≈0          条件数比≈2.0e+00   # 良态!λ→3050
```

**要点**:增广拉格朗日的乘子 λ 收敛到接触力大小(=外力+弹性力),用它"记住"该施多大力,从而无需大 μ。这正是论文同时治好「TOI locking(残留穿透→零 TOI 卡死)」和「病态」的根源。输出图 `al_vs_penalty_1d.png` 展示罚函数"降穿透必涨条件数"的两难。

## 2. `convergence_order_demo.py` — 一阶时间积分精度验证

复现论文 **§6.1 / Fig.7-8** 的核心结论:本方法作为时间积分器是 **一阶 O(h) 精度**。

**场景**:1D 质点重力下落,撞 q=0 的柔性地面后回弹。用半隐式欧拉 + 柔性接触力积分,在不同步长 h 下模拟,与极小 h 参考解比较整条轨迹的累积 L² 误差。

**为什么是一阶**(论文 §4.4):光滑相位是半隐式欧拉(局部 O(h²),累积 O(h));接触切换只在有限瞬间发生,每次引入 O(h) 速度误差;总累积 O(h)。

**运行**:
```bash
python3 convergence_order_demo.py
```

**预期输出**:位置误差的 log-log 最小二乘斜率 ≈ **1.0**(干净的一阶),误差随 h 减半而减半。输出图 `convergence_order.png` 含斜率=1 参考线。

**注意**:这是极简 1D 模型,用柔性接触力代替论文的增广拉格朗日精确约束(对测"时间积分阶"是等价简化)。论文用 1D 解析解 + 3D 双球碰撞做了更严格的验证。

## 这些 demo **没有**复现什么

为保持最小可运行,demo 刻意省略了:
- **CCD / TOI locking 的多接触对动态**(需要真实几何 + BVH);交互式动画见 `../index.html`。
- **active set 的 filtering + decay**(单约束场景无需淘汰)。
- **GPU 并行 / 解析 PSD Hessian 装配**(§5,需要 CUDA)。
- **3D 弹性、摩擦、移动边界**。

这些 demo 的目的是用最少代码点亮论文**最核心的两个数学直觉**,而非完整复现 GPU 模拟器。
