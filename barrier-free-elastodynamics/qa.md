## 基础题(Basic)— 理解核心概念

### Q1. IPC 的两大效率瓶颈是什么?它们的根源分别在哪?

<details>
<summary>Answer</summary>

两大瓶颈:
1. **病态线性系统**:根源是**对数障碍函数**。当接触距离 d→0 时,log-barrier 变得极度陡峭,使 Hessian 病态,迭代线性求解器(PCG)需要大量迭代才能收敛,且依赖专门预条件子。
2. **TOI locking(碰撞时刻锁死)**:根源是 **CCD 截断的线搜索**。每次 Newton 更新被最小 TOI(最早碰撞对)截断,使最早的接触对卡住整个优化步,其它接触对无法进入约束集,要靠后续大量 Newton 迭代逐个发现。

本文用增广拉格朗日替换 barrier(治病态),用保留中间态 x̂ + 一次性纳入所有 CCD 接触对(治 TOI locking)。

</details>

---

### Q2. 本文最核心的"一个转念"是什么?

<details>
<summary>Answer</summary>

**保留中间穿透态 x̂,不要丢弃它。**

IPC 每次迭代从无穿透态 x_last 生成可能穿透的 x̂,用 CCD 截断得到新无穿透态 x,然后**丢弃 x̂**——从而丢失了 x̂ 处所有更大 TOI 接触对的信息。本文显式维护 x̂ 并从它继续 Newton 迭代,让那些接触对立即产生响应,同时维护携带拉格朗日乘子的活跃约束集 C。

这一个决定像多米诺骨牌一样强制了后续所有设计(有符号距离、放弃 barrier、增广拉格朗日、active set 管理)。

</details>

---

### Q3. 为什么"保留 x̂"就必须放弃对数障碍函数?

<details>
<summary>Answer</summary>

因为 x̂ 是**可能穿透**的状态,在穿透处接触距离为**负**。而:
1. unsigned distance 的梯度在穿透时会反向 → 必须改用在上一个无穿透态线性化的**有符号距离**约束。
2. 对数障碍函数 b(d, d̂) 只支撑在 d ∈ (0, d̂),在 d→0 时发散,**在负距离处根本无定义**。

所以一旦允许 x̂ 穿透(负距离),log-barrier 就用不了了,必须转向 barrier-free 方法。

</details>

### Q4. 本文相对 GIPC 取得了多大加速?这个加速来自哪几个因素?

<details>
<summary>Answer</summary>

最高 **103.15×**(GIPC 原残差终止);同 TOI 终止下也有 **59.18×**。Teaser 场景(squishy balls,2.61M DoF)达 98.5×。

加速来源:
1. **更少 Newton 迭代**:无 TOI locking → GIPC 需 4.4×–10.3× 更多 Newton 迭代。
2. **更少 PCG 迭代**:系统良态 → GIPC 因 barrier 病态需 3.79×–6.96× 更多 PCG 迭代。
3. **免除线搜索开销**:GIPC 每次线搜索回溯都重建 BVH;本文显式维护约束集、线搜索时约束集与形状无关,天然免除这笔开销。
4. **GPU 优化**:顶点块级 Hessian 装配等。

</details>

### Q5. δ(接触偏移)和 μ(罚刚度)分别扮演什么角色?哪个更难设定?

<details>
<summary>Answer</summary>

- **δ**:表面分离参数,类比 IPC 的 d̂。约束 `c_i = d_i + ∇d_iᵀ(x̂-x) - δ`,即希望距离收敛到正的 δ 而非 0,这样 CCD 能产生非零 TOI。δ **可按网格分辨率设定**,比较直观。
- **μ**:增广拉格朗日的罚刚度。它**不直观**:太大会使系统病态,太小约束满足不准。本文用 **conditioning-aware 估计**(每步估 μ_init,使 ∇²L 条件数与 ∇²E 同量级),并有 μ←2μ、δ←δ/2 的自适应兜底(但实验从未触发)。

μ 更难设定。关键洞察:增广拉格朗日靠**乘子 λ** 而非大 μ 来精确满足约束,所以 μ 可以相对小,保持良态。

</details>

## 进阶题(Intermediate)— 应用与机制

### Q6. 为什么朴素二次罚函数会失败,而增广拉格朗日能成功?

<details>
<summary>Answer</summary>

**朴素罚的失败**:罚力 = μ·|穿透深度|。要消除穿透要么深度→0 要么 μ→∞。在高应力下需要极大 μ,论文 §6.3(Fig.19)实测**即便 μ 调大 1000× 仍残留可见穿透**。残留穿透 → 从 {x̂} 构造无穿透路径时 CCD 立刻撞到它 → α≈0 → 永远卡死。而且大 μ 让系统病态(等于换汤不换药)。

**AL 的成功**:能量 `L = E + Σγ_i[(μ/2)(c_i-s_i)² - λ_i(c_i-s_i)]`。引入乘子 λ_i 代表接触力基线,更新规则 `λ_i ← λ_i - μ·c_i`。每当约束被违反就增大 λ,相当于"记住"这里需要多大力,而非靠瞬时大 μ 硬顶。由 N&W 定理 17.6,λ 指数收敛到真实 KKT 乘子,**用相对小的 μ 就能精确满足约束** → 良态 → PCG 快。

类比:罚是"用蛮力压穿透(会病态)",AL 是"用记忆(乘子)累积接触力(保持健康)"。

</details>

### Q7. filtering 和 decay 分别解决什么问题?为什么 decay 不能改成硬删除?

<details>
<summary>Answer</summary>

**Filtering(解决"约束太多")**:大 h/高速度下,中间态早期严重穿透,一个原语可能穿过多层表面,CCD 生成远多于实际的接触对。策略:对每个顶点只保留它参与的最早碰撞时刻的对(是至少一个顶点的最早碰撞对才保留)。这不会漏约束,因为任何持续被 CCD 检测的对终会通过过滤。

**Decay(解决"删得太急")**:失活约束(s_i>0)不影响梯度,但仍在 Hessian 留非零项,拖慢收敛。策略:失活约束 γ_i ← Γ·γ_i(Γ=0.9)平滑缩小贡献,γ<0.01 才移除。

**为什么不能硬删除**:立即删除失活约束会引起**振荡和不稳定**(§6.3 验证)。decay 是"软删除"——给约束渐变的存在感,数值上比二值切换稳定得多。

</details>

### Q8. 解释 TOI 累积终止准则 `Σ_{i<K_min} β_i^[k] < ε`。K_min=1 和 K_min=6 分别用在什么场景?

<details>
<summary>Answer</summary>

无穿透路径 `x^[k] = β₀x_t + Σβ_i x̂^[i]`,β 是各步 α 的连乘(`β_i^[k] = α^[i]∏_{j>i}(1-α^[j])`)。当 α 足够大,早期态(x_t 和早期 x̂)的权重指数衰减。终止条件:前 K_min 个中间态总权重 < ε(用 ε=1e-3)。

- **K_min=1**:退化为 [Ando 2024; Wang 2023] 的停止条件,即 β₀<ε。用于纯接触场景(论文里很多用 K_min=2)。保证孤立粒子保留至少 (1-ε) 速度,避免人工阻尼。
- **K_min=6**:用于**含摩擦和布料**的场景。这些场景需要更多迭代来精确解析摩擦/薄壳接触,过小的 K_min 会损失摩擦保真度。

本质:K_min 控制"至少做多少次有效迭代才允许终止",越大越精确但越慢。

</details>

### Q9. 本文为什么是一阶时间积分精度?这与 IPC 相比如何?

<details>
<summary>Answer</summary>

**一阶来源**:
- 无接触时,K_min=1 等价于半隐式欧拉(BDF1),局部截断误差 O(h²)。
- 有接触时,活跃集不变区间内等价于在满足约束的线性子空间做半隐式欧拉,保持 O(h²) 局部误差。
- 活跃集变化只在有限个时刻发生(假设 h→0 + 轨迹光滑),每次引入 O(h) 速度误差。
- 总累积:`O(1)·O(h) + O(h⁻¹)·O(h²) = O(h)` → 一阶。

**与 IPC 对比**:IPC 标准也是一阶(BDF1)。所以本文没有牺牲时间精度。论文在 1D 解析接触(Fig.7)和 3D 接触(Fig.8)上实验验证了 O(h) 收敛。

固有限制:增广拉格朗日的对偶更新本身是一阶收敛的,所以即便原始用超线性 Newton,整体仍是一阶。

</details>

### Q10. 本文如何处理移动边界条件?相比 IPC 有什么优势?

<details>
<summary>Answer</summary>

**IPC 的做法**:移动边界目标位置可能穿透其它几何,所以引入辅助弹簧能(可选加 Lagrangian)把边界顶点拉向新位置,再消去边界 DoF。大弹簧刚度导致额外的**病态迭代**。

**本文的做法(无罚)**:利用中间态 x̂^[k] 允许穿透的特性——
- 初始态 x̂^[0] 直接把所有边界顶点移到目标位置;
- 后续线性求解中,把对应梯度/Hessian 项清零(保留对角)来消去边界 DoF;
- 所有 x̂^[k] 都满足新边界条件,最终 x^[k] 的边界是目标位置与旧边界的线性混合(目标权重 > 1-ε);
- 边界位置误差上界 ≤ ε·h·v_boundary。

**优势**:省去 IPC 那些高刚度弹簧带来的额外病态迭代,更高效。

</details>

## 高级题(Advanced)— 分析、批判与扩展

### Q11. 本文用双精度,对手用单精度,为什么本文仍能胜出?这说明了什么?

<details>
<summary>Answer</summary>

在 RTX 4090 上 FP64 吞吐远低于 FP32,所以双精度本身是性能**劣势**。但本文对 Cubic Barrier(单精度)仍快最高 84.4×,对 OGC(单精度)快 33.1×。

说明:**算法层面的优势(良态系统 + 无 TOI locking + 更少迭代)压过了精度位宽的劣势**。具体地,Cubic Barrier 的接触 Hessian ~O(d⁻¹),d→0 时条件数发散(类 IPC),单精度下在两个难场景 PCG 不收敛而失败;本文良态系统即便双精度也只需少量 PCG 迭代。

更深的启示:本文用双精度是因为增广拉格朗日在难场景对数值精度敏感(需要双精度保证鲁棒)。这是一个有意识的权衡——用精度位宽换鲁棒,而算法优势足以补偿这点开销。

</details>

### Q12. 论文自述了哪些局限?其中哪个是"成功暴露出的新瓶颈"?

<details>
<summary>Answer</summary>

作者自述局限:
1. **CCD 成为新瓶颈**:接触密集时 CCD(尤其 broad-phase BVH 查询)成本超过线性求解(stacked cloth 里比 PCG 慢 2.69×)。broad-phase 没利用活跃集信息,做了大量无用计算。
2. **布料未充分优化**:框架支持余维(布/杆)但未专门优化。
3. **AL 一阶收敛**:对偶更新使整体一阶,无加速变体。
4. **active set 无理论保证**:缺乏对 active set 演化的原则性分析。
5. **未做精确应变限制**。

其中 **CCD 成为新瓶颈** 是"成功暴露出的新瓶颈"——正因为本文消除了 barrier 病态(线性求解变快了),原本被掩盖的 CCD 成本才浮出水面成为主导。这是典型的"优化了一个瓶颈,下一个瓶颈显现"。

</details>

### Q13. 本文与 Wang et al. 2023(LCP/impact zone)的关键区别是什么?为什么本文更鲁棒?

<details>
<summary>Answer</summary>

本文框架与 Wang 2023 相关,但有两个关键区别:

1. **统一 AL vs 解耦投影**:Wang 把每步拆成"无约束解 + 几何投影(线性化碰撞约束)"。几何投影**与物体物理性质无关**,解耦投影与动力学会产生伪影(如高应力区)。本文用统一的增广拉格朗日公式,接触响应与弹性耦合。

2. **AL vs Gauss-Seidel**:Wang 的反向投影用 projected Gauss-Seidel,**不保证所有约束被解决**,尤其碰撞模式复杂时。本文用 AL 机制自适应强化未满足约束,最终驱动到无穿透态。

**鲁棒性证据**:论文 §6.4 把主流程改成 LCP 式(单 Newton 步 + projected Gauss-Seidel 反投影),在 dolphin&funnel 测试**第 51 帧卡死**(α≈0),100 次迭代后仍有大量约束未解决。原因:LCP 试图精确强制约束,但大量线性化约束可能导致问题不可行;且 mass-weighted 投影对弹性无感知,产生难以在后续 Newton 修复的伪影。

</details>

### Q14. 如果让你把本文的思想迁移到 libuipc 的 AGIPC 分支(barrier-based + 代数粗化),你会怎么做?有哪些机会和风险?

<details>
<summary>Answer</summary>

(开放题,参考思路)

**机会**:
1. **粗化在良态系统上更稳定**:AGIPC 在 barrier 框架里做线性求解器的代数粗化。若把基础求解换成本文的 AL 框架,系统天然良态(条件数比 IPC 小 2 个数量级),代数粗化的预条件/插值算子可能更稳定、更易构造,收益更大。
2. **active set 思想反向借鉴**:本文的 filtering + decay 活跃集管理也能用到 barrier 框架,改善 IPC 的 active set 探索(IPC 也有过约束困扰)。
3. **共享的 GPU 装配模式**:两者都能用顶点块级 + warp reduction 的 Hessian 装配。

**风险/挑战**:
1. **AL 的对偶变量给粗化带来新维度**:粗化时如何处理乘子 λ 和约束集 C 是非平凡的——λ 是细粒度的,粗化后如何映射?
2. **双精度需求**:本文需要双精度,而 AGIPC 的代数粗化可能在单精度下设计,精度切换影响性能预算。
3. **active set 动态变化 vs 粗化结构**:AGIPC 的粗化是 in-solve 动态的,本文的活跃集也是动态的,两个动态系统耦合可能引入不稳定。

(这正是 README 里提到的、值得对照思考的研究方向。)

</details>

### Q15. 本文的有限步终止证明依赖哪些假设?这些假设在真实场景下有多脆弱?

<details>
<summary>Answer</summary>

**依赖的假设**:
1. **线性弹性**:N&W 定理 17.6 要求弹性模型线性,才能保证 AL 的原始/对偶误差指数衰减。
2. **足够大(但有限)的 μ**:保证约束指数收敛。
3. **δ > 0**:保证更新方向最终对齐 d_i 的正梯度方向,产生足够大的 α。
4. **α 有正下界 γ>0**:由 active set 更新(把卡 α 的对加进 C)+ AL 共同保证。
5. **一阶精度还额外假设**:h→0、轨迹光滑(活跃集只在有限时刻变化)、∇U 的 Lipschitz 连续。

**脆弱性分析**:
- **线性弹性假设最脆弱**:真实场景多用 Neo-Hookean、Stable Neo-Hookean 等**非线性、非凸、不可反转**弹性。作者承认理论只在线性下成立,非线性靠 Alg.2 的线搜索**经验性**地稳健处理(没有理论保证)。
- **active set 演化无理论保证**:作者明确承认这一点。filtering 策略"不会漏约束"是论证而非严格证明。
- **实践上的稳健性**:尽管理论有缺口,论文在大量极端场景(100 m/s 撞击、185× 压缩、窄孔穿越)实验验证了稳健终止,说明假设在实践中"够用"。但这是经验证据,不是保证——遇到病态新场景时仍可能失效(虽然有 μ←2μ 兜底)。

**总结**:理论框架优雅但保守(线性弹性),实践鲁棒性靠工程(线搜索 + 自适应兜底)补足。这是图形学 systems paper 的常见模式:理论给直觉,实验给信心。

</details>
