# Mental Model — 心智模型与研究地图

这篇文档帮你建立"坐标系":这是什么类型的问题、假设了哪些前置知识、它在研究地图上的位置、以及该如何把它归类记忆。

---

## 1. 这是什么类型的问题?

**核心问题**:如何在 GPU 上**又快又稳**地模拟可变形物体之间的**无穿透接触**(elastodynamics with guaranteed non-penetration)。

这属于**物理仿真 + 数值优化**的交叉。具体定位:
- 不是新物理模型(弹性、摩擦都沿用既有);
- 不是新几何表示(还是线性四面体 + 三角网格);
- 而是一个 **新的接触约束求解范式**:把"接触"从"障碍能量项"重新表述为"显式不等式约束 + 增广拉格朗日",并配套一个 GPU 高性能实现。

一句话归类:**"用约束优化(AL)替代内点法(barrier)来做无穿透接触求解"的 systems + theory 论文**。

---

## 2. 假设的前置知识

读懂这篇论文,你需要事先理解(按重要性排序):

### 必备
1. **隐式时间积分 + 增量势能(Incremental Potential)**:把动力学方程 `Mẍ = f` 写成每步最小化 `E(x) = ½‖x-x̃‖²_M + h²U(x)`。这是 IPC 系的基石。
2. **IPC 的障碍函数机制**:`B = E + κΣb(d,d̂)`,b 在 d→0 时发散,配 CCD 截断线搜索保证可行。**本文是在对它做手术**,不懂 IPC 就无法理解动机。
3. **CCD 与 TOI**:连续碰撞检测,沿一条直线路径找第一个碰撞时刻 α∈[0,1]。理解"为什么最小 TOI 会卡住整步"是理解 TOI locking 的关键。
4. **约束优化基础**:等式/不等式约束、KKT 条件、拉格朗日乘子。

### 进阶(理解方法细节需要)
5. **内点法 vs 增广拉格朗日法**:两种处理约束的范式。内点法用障碍把迭代关在可行域内;AL 允许违规,用乘子项 + 罚项驱动回可行。本文是从前者切到后者。
6. **投影 Newton + SPD projection**:Hessian 投影到正定锥保证下降方向。
7. **PCG + 预条件**:迭代解线性系统,条件数决定迭代数。理解"为什么 barrier 病态 → PCG 慢"。

### GPU 工程(理解 §5 需要)
8. CUDA、BSR 稀疏格式、SpMV、原子操作的写冲突、warp-level reduction、SVD 解析特征分解。

> **如果你只想抓核心思想**:1+2+3 足够读 insights。4+5 让你理解方法为何成立。8 是工程加分项。

## 3. 在研究地图中的位置

```
                  无穿透弹性动力学接触求解
                          │
        ┌─────────────────┼─────────────────────┐
        │                 │                     │
   penalty-based      barrier-based         barrier-free(本文所在新分支)
   (允许穿透,         (内点法,死守可行)        (约束优化,允许中间违规)
    刚度调参)              │                     │
        │          ┌──────┼──────┐         ┌─────┼─────────┐
   impact zone   IPC    GIPC   Cubic     本文(AL)  Wang2023  OGC
   air-mesh    [2020] [2024]  Barrier              (LCP/    [2025]
   SQP                        [Ando24]            投影)    (VBD)
```

- **谱系上游**:IPC(2020,Li et al.)是所有这些的共同祖先。
- **GPU 加速支线**:GIPC(2024)、MAS-PNCG、AGIPC——都在 **barrier 框架内**优化(更好的预条件、矩阵自由、代数粗化)。
- **本文的位置**:跳出 barrier 框架,回到更经典的**约束优化**(增广拉格朗日 active-set),但保留 IPC 的无穿透保证 + 超线性 Newton。
- **同期 barrier-free 邻居**:Cubic Barrier(Ando 2024,自适应刚度的类 barrier)、OGC(Chen 2025,offset 几何 + VBD)、Wang et al. 2023(LCP impact zone + CCD)。本文与它们都比较过,在难场景全面胜出。

**作者网络**:Minchen Li 是 IPC 原作者之一;本文与你仓库的 AGIPC(Adaptive GIPC,作者含 Zhaofeng Luo、Minchen Li、Kemeng Huang)是**同一研究群**的两条互补路线。

## 4. 怎么把这篇论文"归类记忆"

用三个钩子记住它:

1. **"保留 x̂"**——最核心的一句话。IPC 丢弃中间穿透态,本文保留它继续迭代。所有设计都从这里推出。
2. **"barrier → augmented Lagrangian"**——范式标签。内点法换成乘子法,顺带解决病态 + TOI locking。
3. **"103× over GIPC"**——结果标签。接触密集大场景的杀手级加速。

记忆口诀:**保留违规态,用乘子代替障碍,顺手治好病态和锁死,GPU 上快两个数量级。**

## 5. 类比(帮助直觉)

- **IPC 的 barrier** 像一道**电网围栏**:你永远不能碰到边界(距离→0 时斥力→∞),所以你只能小心翼翼地贴着走,而且贴得越近越难走(病态)。
- **本文的 AL** 像一个**会学习的弹簧 + 记账员**:允许你暂时越界一点点,但记账员(乘子 λ)会记下"这里你越界了多少",下次用更大的"还款压力"把你推回来。不需要无限硬的弹簧(大 μ),靠记账(更新 λ)就能精确把你停在边界外侧 δ 处。
- **TOI locking** 像**排队过窄门**:IPC 每次只让最前面一个人(最小 TOI)的信息进来处理,后面 99 个人要排很多轮才轮到。本文一次性把所有要过门的人(CCD 检测到的所有接触对)都登记在册(活跃集 C),并行处理。
