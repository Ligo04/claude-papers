# Method — 方法细节与算法

本文方法由三个核心子程序组成,对应主循环(Algorithm 1)调用的 `SolveSubproblem`(Alg.2)、`UpdateActiveSet`(Alg.3)、`MaxStepSize`(CCD)。

---

## 0. 符号与背景

- 状态:节点位置 `x ∈ ℝ³ᴺ`,速度 `v ∈ ℝ³ᴺ`,N 个节点。
- 隐式欧拉:`x_{t+1} = x_t + h·v_{t+1}`,`v_{t+1} = v_t + h·M⁻¹(f_int + f_ext)`。
- 增量势能(Incremental Potential):
  ```
  E(x, x̃) = ½(x - x̃)ᵀ M (x - x̃) + h²·U(x)
  ```
  其中惯性目标 `x̃ = x_t + h·v_t + h²·M⁻¹·f_ext`,U(x) 是总势能(含 IPC 式光滑摩擦能,见 Appendix A)。
- 无穿透约束:存在路径 L 连接 x_t→x_{t+1},使所有 vertex-face / edge-edge 对的 unsigned distance `d(x) > 0`。
- **IPC 的做法**(对比基线):`B(x) = E(x,x̃) + κ·Σ b(d_i(x), d̂)`,b 是支撑在 (0,d̂) 上、d→0 发散的障碍函数。

## 1. 总框架(§4.1)

### 问题重构
不用 barrier,而是显式维护活跃约束集 C,把每个时间步拆成一系列**线性不等式约束子问题**:

```
x̂^[k] = argmin_{x̂}  E(x̂, x̃)   s.t.  c^[k](x̂) ≥ 0
```

c^[k] 是从当前活跃集 C^[k] 生成的线性化接触约束。每次迭代 k 做一次或几次 Newton 步得到 x̂^[k] 的非精确解。

### 构造无穿透分段线性路径
中间态 x̂^[k] 不保证无穿透(C 不完整 + 约束线性化)。于是基于它们构造一条**无穿透分段线性路径** `{x^[k]}`,从 x^[0]=x_t 开始:

```
x^[k+1] = (1 - α^[k+1])·x^[k] + α^[k+1]·x̂^[k+1],   0 ≤ α^[k+1] ≤ 1
```

α 由 CCD 保证 x^[k]→x^[k+1] 的线性过渡无穿透(对 Neo-Hookean 等不可反转材料还保证无反转)。

### 终止准则
每个 x^[k] 也是 x_t 与中间态的线性组合:
```
x^[k] = β₀^[k]·x_t + Σ_{i=1}^{k} β_i^[k]·x̂^[i]
β_i^[k] = α^[i]·∏_{j=i+1}^{k}(1 - α^[j]),   β with α^[0]=1
```
当前 K_min 个中间态权重和小于阈值时终止:`Σ_{i=0}^{K_min-1} β_i^[k] < ε`。

### Algorithm 1:主时间步循环
```
输入: x_t, v_t, 活跃集 C_t
输出: x_{t+1}, v_{t+1}, C_{t+1}

1:  x̃ ← x_t + h·v_t + h²·M⁻¹·f_ext
2:  x^[0], x̂^[0], C^[0] ← x_t, x_t, C_t
3:  在 x̂^[0] 中处理移动边界            ⊲ §5.3
4:  β^[0], k ← 1, 0                    ⊲ β^[k] 存 Σ_{i<K_min} β_i^[k]
5:  while β^[k] > ε do
6:      x̂^[k+1] ← SolveSubproblem(x̃, x^[k], x̂^[k], C^[k])   ⊲ Alg.2
8:      C^[k+1]  ← UpdateActiveSet(x^[k], x̂^[k], C^[k])        ⊲ Alg.3
10:     α^[k+1]  ← MaxStepSize(x^[k], x̂^[k+1])                 ⊲ CCD 查询
11:     x^[k+1]  ← (1-α^[k+1])·x^[k] + α^[k+1]·x̂^[k+1]
12:     if k+1 ≥ K_min then
13:         β^[k+1] ← (1-α^[k+1])·β^[k]
14:     else
15:         β^[k+1] ← β^[k]
17:     k ← k+1
18:  end while
19:  return x^[k], (x^[k]-x_t)/h, C^[k]
```

**注意**:β^[k] 在前 K_min-1 次迭代保持 1,之后每次乘 (1-α^[k])。

## 2. 增广拉格朗日子问题求解器(§4.2)

### 约束线性化
对每个 vertex-face / edge-edge 对 i,在无穿透态 x 处一阶 Taylor 展开 unsigned distance,得到**有符号距离约束**:
```
c_i(x̂) := d_i(x) + ∇d_i(x)ᵀ(x̂ - x) - δ
```
δ 是表面分离参数(类比 IPC 的 d̂)。**在 x 处展开**保证线性化约束朝向正确。

### 增广拉格朗日能量
引入非负松弛变量 `s_i ∈ [0,∞)`,把 `c_i(x̂) ≥ 0` 转为 `c_i(x̂) - s_i = 0`,再加乘子项 + 罚项:
```
L := E(x̂, x̃) + Σ_{i∈I_C} γ_i [ (μ/2)(c_i(x̂) - s_i)² - λ_i(c_i(x̂) - s_i) ]
```
μ 是罚刚度,γ_i 是衰减因子。

**乘子更新**(标准 AL):`λ_i ← λ_i - μ(c_i(x̂) - s_i)`。Nocedal & Wright 保证:足够大固定 μ 下,λ_i 收敛到真实 KKT 乘子,x̂ 收敛到 Eq.5 的解(c_i - s_i → 0)。

### 交替原始求解
联合优化 (x̂, s) 是难的不等式约束问题。实践策略:交替
- 更新松弛变量(闭式):`s_i ← max(0, c_i(x̂) - λ_i/μ)`
- 用投影 Newton + 线搜索更新 x̂,使总能量 L 下降。
- **内迭代终止**:当 x̂ 的线搜索取满步长(r=1)时停止。线性弹性下一步即终止;非线性/非凸弹性下,这能有效防止 x̂ 陷在不规则地形时 λ 爆掉,且多数情况下仍一步终止。

### Algorithm 2:SolveSubproblem
```
输入: 惯性目标 x̃, 无穿透态 x, 初始猜测 x̂₀, 活跃集 C={(i,λ_i,γ_i)}
输出: Eq.5 的近似解 x̂

1:  x̂ ← x̂₀
2:  for all (i,λ_i,γ_i) ∈ C:  用 d_i(x), ∇d_i(x) 线性化距离
5:  while true do
6:      G ← ∇_x̂ E(x̂, x̃)
7:      H ← SPDProject(∇²_x̂ E(x̂, x̃))
8:      for all (i,λ_i,γ_i) ∈ C:
9:          s_i ← max(0, c_i(x̂) - λ_i/μ)
10:         G ← G + μ·γ_i·(c_i(x̂) - λ_i/μ - s_i)·∇d_i(x)
11:         H ← H + μ·γ_i·∇d_i(x)·∇d_i(x)ᵀ
13:     p ← -H⁻¹·G                       ⊲ PCG 求解
14:     r ← LineSearch(x̂, p)             ⊲ L(x̂+r·p) < L(x̂), 0≤r≤1
15:     x̂ ← x̂ + r·p
16:     if r == 1: break
19:  end while
20:  for all (i,λ_i,γ_i) ∈ C:            ⊲ 乘子 + 衰减更新
21:     s_i ← max(0, c_i(x̂) - λ_i/μ)
22:     if s_i == 0:                      ⊲ 约束紧绷(活跃)
23:         λ_i ← λ_i - μ·c_i(x̂)         ⊲ 等价于 Eq.13
24:         γ_i ← 1
25:     else:                             ⊲ 约束松弛(失活)
26:         λ_i ← 0                       ⊲ 等价于 Eq.13
27:         γ_i ← Γ·γ_i                   ⊲ 衰减
29:  end for
30:  return x̂
```

**关键细节(Line 8-11 的微妙之处)**:当 s_i > 0(约束失活)时,`c_i - λ_i/μ - s_i = 0`,所以这些约束**不影响梯度 G**,但**仍在 Hessian H 里留下非零项** `μγ_i ∇d∇dᵀ`。对真正失活的约束,这些 Hessian 项会拖慢收敛——这正是需要 decay(γ)的原因:不能立刻删(会振荡),而是用 γ 平滑缩小其贡献。

### Algorithm 3:UpdateActiveSet
```
输入: 无穿透态 x, 目标态 x̂, 当前活跃集 C={(i,λ_i,γ_i)}
输出: 更新后的 C'

1:  C' = C
2:  收集 x→x̂ 过渡中产生穿透的所有原语对 I'      ⊲ BVH & CCD 查询
3:  I' ← I' \ I_C                                ⊲ 去掉已在 C 中的
4:  for all i ∈ I':  T_i ← 原语对 i 的 CCD 碰撞时刻
5:  for all 顶点 v:
6:      T_v ← min_{i∈I', v∈i} T_i                ⊲ 顶点 v 的最早碰撞时刻
8:  for all i ∈ I':
9:      if T_i ∈ {T_v | v ∈ i}:                  ⊲ i 是某顶点的最早碰撞对
10:         λ_i, γ_i ← 0, 1                       ⊲ 新约束初始化
11:         C' ← C' ∪ {(i,λ_i,γ_i)}
14:  for all (i,λ_i,γ_i) ∈ C':                    ⊲ decay 移除
15:      if γ_i < 0.01:
16:          C' ← C' \ {(i,λ_i,γ_i)}
18:  return C'
```

新约束初始化 λ=0, γ=1;失活约束 γ 渐降,γ<0.01 时移除。

## 4. 终止理论(§4.4,直觉)

### 保运动(非接触区精度)
小 ε + K_min=1:孤立匀速粒子的净位移 = (1-β₀^[k])·h·v。强制 β₀^[k] < ε → 粒子保留至少 (1-ε) 的速度 → 避免人工阻尼。非接触区达到半隐式欧拉精度。

### 有限步终止
若 α^[k] 有正下界 γ>0,每个 β_i^[k] 是 [0,1-γ) 内值的连乘 → 收敛 0 → 终止。正下界的保证:若 α^[k] 暂时→0,则 x^[k] 和线性化约束几乎不变,Alg.3 把负责小 α 的所有原语对加进 C^[k];由 N&W 定理 17.6(线性弹性 + 大 μ),原始/对偶误差指数衰减,线性化约束 c_i(x̂^[k+1]) → 0(δ>0),更新方向最终对齐所有 d_i 的正梯度方向,产生足够大的 α^[k+1]。

### 一阶精度
- 无接触:等价 K_min 次 Newton。K_min=1 时(半隐式欧拉),局部截断误差 O(h²)。
- 有接触:活跃集不变区间内,等价于满足约束的线性子空间内做半隐式欧拉,保持 O(h²)。活跃集变化只在有限时刻(h→0 + 轨迹光滑),每次引入 O(h) 速度误差。总累积:`O(1)·O(h) + O(h⁻¹)·O(h²) = O(h)` → **一阶时间积分器**。

> 注:作者明确这是 high-level 直觉,未严格处理动量方程残差、非线性弹性等;实践中 Alg.2 的线搜索足以稳健处理非线性/不可反转弹性。

## 5. GPU 优化与模拟器设计(§5)

### 5.1 无冲突解析 PSD 弹性 Hessian 装配
- Hessian 存为 **3×3 BSR**(只装对角和上三角块);线性系统用 **CG + 3×3 block-Jacobi 预条件**,对称 BSR SpMV 用 **warp-level reduction**(同 Huang et al. 2025)减少原子写冲突。
- 碰撞检测:broad-phase 用 **Linear BVH** [Karras 2012],narrow-phase 用 **ACCD** [Li et al. 2021] 过滤。
- **核心创新**:各向同性弹性能的 9×9 Hessian 的解析特征分解 `Q_k = U·D_k(Σ)·Vᵀ`(F=UΣVᵀ 是 F 的 SVD)。D_k 对 0≤k≤2 为对角、3≤k≤8 为只有两个非零项的反对称阵 → **极稀疏**。
- GIPC 的做法:元素级并行装配 9×9 再两次稠密矩阵乘转回 12×12 → 需原子操作 → 严重写冲突;GIPC 改用矩阵自由格式(复制重叠顶点块)避免冲突,但增大后续 SpMV 开销。
- **本文做法**:在**顶点块级别**并行(warp reduction 免写冲突),利用 D_k 稀疏性减少计算。先在元素级并行算 SVD + 解析特征分解,存 U,V,ω_k;再在顶点块级别处理 i'j'-块:先算外积 (A_i'V)ᵀ(A_j'V),按 D_k 稀疏结构展开乘法,最后乘 U 和 Uᵀ。A_i' 是把 dx_i' 映到 dF 的常向量(可预计算)。

### 5.2 Conditioning-aware 的 μ 调整
- 终止保证依赖足够大(非无穷)的 μ 和小 δ。δ 可按网格分辨率设(像 IPC 的 d̂);μ 不直观,太大会病态。
- **策略**:每步开始估计 μ_init,使 ∇²L 的条件数与 ∇²E 同量级。
- **自适应兜底**:当 α^[k] < 1e-4 连续 50 次迭代,则 μ←2μ, δ←δ/2。**但所有实验从未触发**。例:twisting rods 中 μ_init 随变形从 ~10¹ 增到 ~10⁴。

### 5.3 无罚移动边界条件
- IPC:移动边界目标位置可能穿透其它几何,需辅助弹簧能(可选加 Lagrangian)把边界顶点拉到新位置再消去 DoF → 大弹簧刚度导致额外病态迭代。
- **本文**:中间态 x̂^[k] 允许边界穿透。初始态 x̂^[0] 直接把边界顶点移到目标位置,后续线性求解中把对应梯度/Hessian 项清零(保留对角)消去边界 DoF。所有 x̂^[k] 满足新边界条件,最终 x^[k] 的边界是目标位置与旧边界的线性混合(目标权重 > 1-ε)。边界位置误差上界 ≤ ε·h·v_boundary。

## 7. 实现陷阱(Implementation Pitfalls)

1. **必须在无穿透态 x 处线性化距离**(不是 x̂):否则约束朝向错误。
2. **失活约束保留 Hessian 项**:即使 s_i>0 也要加 Hessian(Line 11);漏掉会破坏 Newton 一致性。
3. **不要用朴素罚替代 AL**:μ 调大 1000× 仍残留穿透 → CCD 零 TOI 卡死(Fig.19)。乘子更新必需。
4. **filtering 的"最早碰撞对"逻辑**:per-vertex 取 min,保证持续碰撞对终会进入 C。
5. **decay 不能改硬删除**:立即删失活约束引起振荡/不稳定。
6. **CCD 是新瓶颈**:接触密集时 broad-phase BVH 主导(stacked cloth 比 PCG 慢 2.69×)。
7. **双精度的必要性**:单精度 Cubic Barrier 在两个难例 PCG 不收敛失败。
8. **K_min 选择**:摩擦/布料需 6,纯接触用 2;过小损失摩擦保真度。

## 8. 复现风险(Reproduction Risks)

- **CCD/BVH 实现差异**:ACCD 保守程度、BVH 重建频率直接影响 α 和性能,103× 高度依赖优化的 CCD。
- **μ_init 估计公式**:论文只给"使 ∇²L 与 ∇²E 同量级"的近似,精确公式需查原文/补充材料。
- **解析 PSD 装配 kernel**:顶点块级 warp reduction 是性能关键,朴素实现拿不到加速。
- **双精度 GPU 吞吐**:RTX 4090 FP64 远低于 FP32,复现需注意硬件 FP64 能力差异。

## 3. 活跃集更新(§4.3)

### 动机
若上一次 CCD 从 x^[k-1]→x̂^[k] 被某些接触对阻挡,这些对若不解决,会在新 CCD 里持续产生接近零的碰撞时刻 → 导致 α^[k+1] 极小。所以自然策略是**把上次 CCD 产生穿透的所有原语对加进 C**。

但这个朴素策略在大变形/极复杂接触下失效:大 h 或高速度 → 中间态早期严重穿透 → 一个原语穿过多层表面 → 生成**远多于实际**的活跃约束 → 冲突约束 + 计算成本暴增。

### Filtering 策略
对每个顶点 v,在新生成约束中找它参与的**最早碰撞时刻**的对;只保留那些"是至少一个顶点的最早碰撞对"的原语对。任何被 CCD 持续检测到的对最终都会通过过滤进入 C,所以不会因缺约束停滞。
