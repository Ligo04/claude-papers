# 建立心智模型

这是一篇计算几何系统论文：输入是网格，输出是碰撞近似，研究对象是如何组织 GPU 工作与中间数据。没有模型训练、推理权重、训练语料或策略控制频率。

理解它需要三个尺度：

1. 几何尺度：一刀会生成两侧网格及封口；每侧凸包与原表面之间有误差。
2. 算法尺度：看候选的后续切割效果，重复分解，再合并冗余部件。
3. 系统尺度：候选并发、warp 内合作、device heap、阶段融合共同决定速度。

可以把一个候选看成一项连续几何作业：它会变长、缩短、产生临时数组。32 个 lane 共同做这项作业，避免每个细碎步骤都要求主机重新组织任务。这个类比说明局部融合的价值，不表示公开版本已完全摆脱 host 调度。

研究图谱：CoACD 的误差度量 → 搜索策略与候选集合 → CuACD 的 GPU 几何组件 → 资产预处理 → 碰撞引擎使用凸体。CuACD 不替代物理求解器，也不直接改善摩擦模型、关节动力学或柔体接触。

三个容易混淆的词：

- V-HACD：既有算法名，也是此文 benchmark 名。Table 1 的第一组列指后者。
- Warp：本论文是 32-lane CUDA 线程组。
- Hybrid hull：极值预筛选 + 完整 D&C 凸包；不是 CPU/GPU 交替计算，也不是学习策略与规划器协同控制。

读每个速度数字时依次问：哪个输入？多少个？计时包括哪些阶段？使用哪个硬件？质量是否相近？这比孤立记住 100× 更有用。
