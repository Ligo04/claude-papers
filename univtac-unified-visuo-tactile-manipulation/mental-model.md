# 心智模型：平台—表示—基准三层闭环

## 1. 先不要把 UniVTAC 记成一个网络

最有效的分类是：

> **面向接触丰富机器人操作的视触觉数据—表示—评测基础设施。**

它有三层，每层解决一个不同的失败原因：

```text
平台层：怎样安全、丰富、可规模化地制造接触？
   ↓
表示层：怎样让 latent 同时知道形状、接触变化和外部位姿？
   ↓
基准层：怎样确认策略是真的利用触觉，而不是穿模/硬推/终点捷径？
```

如果只看 ResNet-18，会漏掉数据生成的闭环；只看仿真器，会漏掉多路径监督；只看平均成功率，会漏掉 benchmark 的物理有效性设计。

## 2. 三种感知问题的“问句”

把每条 Encoder 路径换成一个问题，最容易记忆：

| 路径 | 模型要回答的问题 | 监督信号 | 下游例子 |
|---|---|---|---|
| Shape | “接触到的物体本身长什么样？” | 带/不带 marker 的 RGB 重建 | Grasp Classify |
| Contact | “界面正在怎样压入、剪切、滑动？” | 深度图 + marker 2D 位置 | Insert Tube / HDMI |
| Pose | “这个物体相对传感器位于哪里、朝向如何？” | 3D 平移 + 四元数 | Lift Bottle / Shelf |

三条路径不是三个独立 encoder，而是同一 latent 的互补约束。共享 latent 要同时能解释全局形状、局部动力学和度量空间，才更可能跨物体/任务迁移。

## 3. 把数据生成想成“主动实验”

普通数据采集像拍录像：机器人做完动作，记录发生了什么。UniVTAC 更像做实验：主动改变一个条件，再观察触觉响应。

```text
改变 δ_th（压入深度）  → 观察法向形变
加入小旋转             → 观察剪切与 marker flow
制造轻微失败           → 观察纠正所需的接触线索
限制穿透/滑移           → 保证实验仍在物理有效区
```

这解释了为什么“随机失败”不是脏数据：它把策略将来必须处理的错位和接触转折显式展示出来。但随机性必须被安全规则包围，否则只是在采集仿真漏洞。

## 4. 平台、Encoder、策略的边界

```text
Platform 产生 observation + privileged labels
Encoder   把原始 tactile RGB 压成物理感知 latent
Policy    把 vision + latent 变成机器人动作
Benchmark 判断动作是否成功且物理有效
```

- Platform 不负责学习策略；它负责可控、可复现的接触世界。
- Encoder 不直接输出动作；它负责让触觉可被策略使用。
- Policy 可以是 ACT 或其他模型；论文用 ACT 作为统一比较载体。
- Benchmark 不只是数据集；它还规定任务、rollout、invalid 条件和成功语义。

## 5. 与已有路线的地图

```text
触觉仿真
├─ MPM：Tacchi / DiffTactile（形变、可微性等取向）
├─ FEM：TacFlex（材料/几何保真）
├─ IPC：TacEx / Taccel（接触约束与 GPU 规模）
└─ UniVTAC：在 TacEx 之上整合多传感器、采集 API、表示和 benchmark

触觉表示
├─ 像素重建：保留外观，但可能忽略接触物理
├─ 几何监督：捕捉 marker/形变，但可能丢掉丰富纹理
├─ 对比学习：跨模态对齐，但可能偏全局、任务特化
└─ UniVTAC：RGB 双视图 + 深度/marker + 位姿的多路径 MSE

操作评测
├─ 视觉为主的通用 benchmark
└─ UniVTAC：把遮挡、接触纠正、穿透和滑移纳入任务定义
```

## 6. 读表格的正确顺序

面对任何成功率表，按下面顺序问：

1. 任务是否真的需要触觉，还是视觉已经足够？
2. 策略是否有相同的轨迹数、rollout 数和观察模态？
3. 成功是否排除了穿透、滑移等物理捷径？
4. 提升来自数据量、表示、策略结构，还是任务/传感器变化？
5. 结果是仿真证据、真机证据，还是只是一张定性图？

例如 `ACT + UniVTAC` 平均 48.0% 只在固定的八任务、50 条训练轨迹/任务和 100 次测试 rollout 条件下成立；真机 68.3% 又是另一套 Marvin/双 GF225/20 rollout 条件。

## 7. 三个常见误读

### 误读一：有触觉就应该所有任务都提升

不对。Lift Bottle、Grasp Classify 等任务的收益和 VITaL/视觉基线不同；触觉的价值取决于遮挡、位姿不确定性、接触持续时间和是否需要探索。

### 误读二：预训练标签必须是真实传感器能直接测到的

不对。`I_pure`、`D`、`M`、`p` 是仿真特权信号，用来塑造 latent；部署时只保留 encoder 和真实可得的触觉输入。关键是学到的表征能否跨域，而不是把特权标签偷偷喂给策略。

### 误读三：200K 样本越多，每个任务一定越好

不对。平均值从 34.2% 上升到 48.0%，但表 III 的逐任务曲线有波动。规模和多样性提供总体收益，却不消除任务难度、采样方差和分布偏移。

## 8. 工程记忆句

**“平台造接触，路径拆因素，基准堵捷径，真机验迁移。”**

这句话可以在阅读任何视触觉仿真论文时复用：先看接触是如何被制造和约束的，再看 latent 被哪些物理目标塑形，最后看 benchmark 是否防止策略利用仿真漏洞，最后才看平均成功率。
