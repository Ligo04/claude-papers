# Summary: RoboDojo

> 依据 arXiv `2607.04434v3`（2026-07-08 修订）。榜单数字是论文冻结于 2026-07-03 的快照，不等同于项目网站的实时榜单。

## 背景脉络

近年来通用机器人操作策略（VLA / generalist manipulation policy）快速发展——π0、π0.5、GR00T、X-VLA 等模型层出不穷，各自宣称在多任务、多场景下具备泛化能力。但与策略发展速度相比，**评测基准明显滞后**：

- 现有 benchmark（如 CALVIN、LIBERO、RoboTwin 2.0、RMBench、GarmentLab、SimplerEnv）大多任务简单、短程、技能覆盖窄，变化通常只停留在物体外观/布局/语言表述这类表层维度，难以诊断策略在"泛化、记忆、精度、长程规划、开放语义理解"等不同能力轴上的真实短板。
- 仿真评测与真机评测长期割裂：仿真高效、可扩展、可复现，但抓不住真实世界的接触动力学、执行误差、感知噪声；真机评测直接可信，但昂贵、耗时、且因硬件配置/复位流程/软件接口不统一而难以复现和横向比较。

这两个结构性问题共同导致：社区难以判断一个新策略到底是"真的更通用"，还是只是在某个基准的特定分布上过拟合。

## 问题陈述

RoboDojo 要解决的两大核心痛点：

1. **任务覆盖窄、能力维度不细分**：缺少一个能够系统性拆解"泛化 / 记忆 / 长程 / 精度 / 开放语义"这五类独立挑战的诊断型任务集，导致策略的失败模式无法被精确定位。
2. **sim 与 real 割裂，互不支撑**：仿真规模化实验与真机可靠性验证之间没有统一的基础设施和策略接口，研究者要么只能在仿真里"刷分"，要么只能小规模、不可复现地跑真机。

## 主要贡献

1. **仿真基准**：42 个任务、覆盖 5 大能力维度（Generalization/Memory/Long-Horizon/Precision/Open），代表性任务覆盖 24 种操作技能，基于 ARX X5 双臂平台（两臂基座间距 0.6m），配套 3,500 条训练轨迹（1,859,602 帧，20.66 小时，25 Hz）。v3 进一步明确：仿真栈继承 MagicSim 的 manager-based runtime 与物理对象抽象，再接入 Isaac Lab 的向量化接口。
2. **RoboDojo-RealEval**：标准化、可复现的远程真机评测平台，固定机械臂/相机/灯光/工作空间相对位姿，支持 ARX X5、Piper、Piper X 三种本体的云端远程评测，用透明叠加（transparent overlay）保证初始条件一致。
3. **XPolicyLab**：统一策略集成框架，定义共享的观测更新/动作预测/策略 reset/批量查询接口，让策略"集成一次、处处评测"（仿真快速迭代 → 最小改动部署真机），目前已集成 30 个策略。
4. **异构并行仿真（Heterogeneous Parallelism）**：核心系统创新，多环境共享一个 vectorized 接口步进的同时，每个环境独立采样场景配置（不同物体类别/几何/杂物数/铰接结构/任务布局），在保留场景多样性的前提下大幅提速。

## 关键结果

**仿真榜（Table 1，2026-07-03 快照，score / success rate）**：

- 榜首 **Hy-Embodied-0.5-VLA：13.07 / 8.80%**
- 第二 Spatial Forcing：12.38 / 8.04%；第三 π0.5：11.41 / 6.91%
- **Human Expert（Teleop）参考：80.42 / 76.03%** —— 与榜首相差近 6 倍，揭示通用操作策略距离"均衡的通用能力"仍有巨大差距。
- 各维度榜首：Generalization（Spatial Forcing 14.12/9.33%）、Precision（X-VLA 18.32/12.00%）、Long-Horizon（Hy-Embodied 25.74/14.92%）、Memory（Hy-Embodied 13.37/12.11%）、Open（π0.5 仅 1.98/1.67%，几乎全崩，是最难维度）。

**真机榜（Table 2，Overall Avg score/SR）**：

- 榜首 **π0.5：22.9 / 12.8%**（ARX X5 本体 27.7/13.3%，Piper 32.0/21.7%，Piper X 仅 9.1/3.3%）
- 其后 InternVLA-A1（12.0/7.2%）、GalaxeaVLA G0（9.0/4.4%）、Xiaomi-Robotics-0（7.9/3.9%）等，多数策略在 Piper X 本体上表现接近 0，暴露策略对不同运动学配置的鲁棒性缺陷。

**效率（8×RTX 4090，每卡 1 进程 10 并行环境）**：

- 零动作 rollout：异构并行 **77.4 interactions/s** vs 非异构 40.0 → **1.94× 加速**。
- 含 π0.5 推理：异构 64.0 vs 非异构 39.2 interactions/s → **1.63× 加速**。
- 真机效率：3.4 小时完成 180 次物理 trials，平均每任务 10 trials 需 **11.2 分钟**。
- 口径限制：RoboDojo 渲染 `640×480`；论文用于横向参考的 RoboTwin 2.0 渲染 3 路 `320×240`，两者不是同分辨率/同进程配置的纯算法 A/B。

**稳定性**：

- 仿真跨 GPU：最大 SR 标准差 1.1 个百分点，最大 score 标准差 1.07；总体均值的标准差至多 `0.5 pp / 0.49`。
- 真机三轮重复：overall SR 标准差至多 1.3 个百分点，overall score 标准差至多 1.2；单个任务的方差明显更大，不能只用聚合稳定性掩盖任务级波动。

**核心 Findings**：

- 场景级随机化导致普遍性能崩塌，视觉-空间 grounding 只能部分缓解。
- **精度是主要瓶颈**——接触感知控制有限、off-trajectory 恢复能力弱，且这一问题不特定于某种动作表示（末端执行器/关节空间控制接口均不稳）。
- 记忆机制有一定帮助，但记忆条件下的执行仍是瓶颈；开放语义操作基本未解。
- 仿真表现与真机可部署性只部分对齐；真机失败主要源于标定误差、执行延迟、控制器特定动力学、接触不稳与误差累积。

## 定量指标表格

### 仿真基准规模

| 指标 | 数值 |
|---|---|
| 任务总数 | 42（5 个维度） |
| Generalization 任务数 | 12（含最多 25 个杂物随机化 + 100 条 DLC 辅助轨迹） |
| Memory 任务数 | 6 |
| Long-Horizon 任务数 | 8 |
| Precision 任务数 | 8 |
| Open 任务数 | 8（不含训练数据，专测重组与迁移） |
| 覆盖操作技能种类 | 24 种（grasp/place/push/pull/stack/insert/open/close/fold/align/tool-use 等） |
| 训练轨迹 | 3,500 条 / 1,859,602 帧 / 20.66 小时 / 25 Hz |
| 训练任务目录 | 35 个（34 训练任务 + 1 DLC 辅助目录，每任务 100 条轨迹） |
| 评测规模 | 全 42 任务 × 每任务 50 episodes = 2,100 episodes |
| 官方认证榜评测量 | 每策略 3 随机种子 × 每种子每任务 50 trials = 每任务 150 trials |

### 真机基准规模

| 指标 | 数值 |
|---|---|
| 任务总数 | 18（3 本体各 6 任务） |
| 本体 | ARX X5、Piper、Piper X（协作双臂平台） |
| 训练数据 | 1,800 轨迹 / 1,611,841 帧 / 17.91 小时 / 25 Hz（每任务 100 demo，4 个操作者） |
| 评测规模 | 每任务每策略 10 trials，3 位评委 double-blind 打分取均值 |
| 相机配置 | 1 head cam（Gemini 335L）+ 2 wrist cam（Gemini 305） |
| 平台占地 | 1.5m × 1.5m（桌面 1.2m × 1.2m） |
