# 反思 — 扩展、压力测试、开放问题

## 如果我来扩展这篇论文

1. **自动发现"事件关节"。** 当前事件切分依赖标注/字幕流水线。一个自监督的"事件边界发现器"——例如用动作速度/接触状态的突变、或视频-动作互信息的拐点来无监督地切关节——会让事件范式可扩展到无字幕的海量数据。

2. **事件单位 × 高频接触模态（接 T-Rex）。** WALL-WM 在灵巧/接触任务上偏弱（~32），而库里的 **T-Rex** 正是用高频触觉做毫米级精修。一个自然组合：WALL-WM 给出对的*粗事件结构*（伸手/对齐/插入/释放），T-Rex 式触觉专家在事件内做高频残差精修。WAM 之"world"本就预留了非视频预测模态的接口。

3. **解冻视频塔的可控微调。** 主配方冻结 Wan 视频塔以保先验，但也封顶了物理刻画上限。探索"知识隔离式"部分解冻（只在接触/形变敏感的层/时步上微调），看能否在不破坏语义先验的前提下提升灵巧任务。

4. **事件提议者的闭环学习。** 事件模式依赖外部 VLM 提"下一事件"。把提议者纳入闭环、用执行反馈（Task Progress / 失败-恢复信号）来 RL 微调提议策略，可能比固定提议者更鲁棒，尤其在指令切换/杂乱场景。

5. **Staircase 的极限与可解释性。** 研究中继深度 Nr、潜状态数 Kc 与推理质量/延迟的标度关系；并验证"潜→文本"重建监督是否真的让潜 CoT 保留了人可读的事件结构（可解释性审计）。

6. **WAM 标度律（沿用 DreamZero 的未解问题）。** 事件单位是否改变了 WAM 的标度行为？同等算力下，事件预训练 vs chunk 预训练的数据效率曲线如何？

## 还有哪些开放问题

- **"事件"的边界定义有多敏感？** 不同切分粒度（reach+grasp 合并 or 拆分）对性能影响多大？是否存在任务相关的最优粒度？
- **几何掩码的代价-收益**：视锥/管状掩码需要每机器人标定来构建（虽推理期丢弃）。在标定噪声大或无标定的数据上，这套还成立吗？
- **统一模式 vs 事件模式的部署取舍**：何时该用哪个？统一模式的 Staircase 潜 CoT 是否在所有任务上都不劣于事件模式？
- **跨本体迁移**：报告涵盖多本体数据，但事件单位是否比 chunk 更利于跨本体迁移（事件语义跨本体更稳定）？未充分量化。
- **DMuon 的普适性**：Muon/DMuon 的收敛与稳定性增益在多大模型/数据规模上成立？对 AdamW 的优势是否随规模放大？

## 哪些假设是脆弱的

| 假设 | 为何可能崩 |
|---|---|
| 任务能被干净地切成离散语义事件 | 连续、流体、双手紧耦合、或无明显"关节"的行为（搅拌、揉面、协同搬运）难以离散化 |
| 视频塔冻结仍足以指导精细控制 | 灵巧任务低分暗示：当任务需要骨干没刻画好的接触物理时，冻结成了天花板 |
| 事件提议者（VLM）会提对的下一事件 | 提议错误直接导致执行错事件；杂乱/歧义场景下提议者可能不可靠 |
| 几何掩码的标定在训练期可得且准确 | 标定漂移/缺失会污染视锥与管状掩码的构建 |
| 非对称时步的单一锚点 s★ 足够 | 不同任务/噪声水平的最优锚点可能不同；单锚点是折中 |
| Staircase 潜状态能编码足够推理 | 高度并行可能牺牲需要严格串行依赖的多步推理（如长链算术式规划） |

## 它在实践中可能在哪失败

1. **接触密集/窄公差任务**：插线、精密装配——绝对分仍低（~32），事件分解帮不上低层位姿与接触时序。
2. **无清晰事件结构的连续任务**：擦拭、搅拌、布料整理等"无关节"行为，事件切分可能反而生硬。
3. **事件提议者失灵**：开放世界新指令下 VLM 提议错误或粒度不当，事件模式随之执行错。
4. **强杂乱 + 快速指令切换**：泛化套件虽领先但绝对分（53.75）仍不高，复杂场景接地仍具挑战。
5. **复现/迁移到新本体或新相机布局**：多视角几何掩码、Camera RoPE、DMuon、Staircase 环环相扣，工程门槛高；标定/数据流水线不到位则难复现。
6. **视频骨干的系统性物理错误**：若 Wan 在某类物理（透明物、可变形、流体）上系统性出错，冻结塔会把这些错误传导到动作。

## 一个研究下注

最具杠杆、也最可迁移的思想是 **"原子单位的选择先于、且决定了对齐与泛化"**。这超越机器人：任何把连续过程切成片段来学习的序列决策问题（自动驾驶、长程 agent、流程自动化），都该先问"我是按时钟切、还是按任务的天然关节切"。WALL-WM 把这个常被默认的选择提升为一等设计问题，并给出"几何保持 + 先验保持 + 可执行因果"三原则作为选单位的判据。如果这套判据被后续工作反复验证，"event-grounded"可能成为继"chunk-based"之后具身基础模型的下一个默认范式——而它与高频接触模态（如 T-Rex 触觉）的组合，或许正是攻克灵巧操作这块硬骨头的路径。
