# 摘要 — WALL-WM：在"事件关节"处切分世界动作建模

## 背景脉络

具身基础模型近年由两类大规模先验驱动：来自多模态理解模型的语义先验，与来自视频基础模型的时空动态先验。本文用两个术语：**VLA** 泛指从视觉-语言输入预测动作的具身基础模型；**WAM（World Action Model，世界动作模型）**指显式把"未来观测建模"与"动作预测"耦合起来的模型（库里的 **DreamZero** 即一例，也是本文基线）。

绝大多数现有模型用**固定长度的动作 chunk**来适配这些先验：以当前观测+语言指令为条件，预测一段定长动作。这"chunk 中心"的形式简便有效，却隐藏了一个结构性错配——它用一个*外部时钟*去切分具身动态，而语言、视觉、动作各自运行在不同的语义与时间尺度上：

- **语言**：指定目标与事件（粗粒度语义）。
- **视觉**：通过连续场景动态演化（更密的时空接地）。
- **动作**：运行在控制级时间尺度，对接触、时序、微小扰动敏感（最细的局部精度）。

因此，把预训练视觉-语义先验适配到具身控制，**首先不是一个微调问题，而是一个"把视频-动作学习的原子单位放在哪里"的问题**。

## 问题陈述

> 定长 chunk 既可能*太短*装不下一个完整语义事件，又可能*太长*破坏上下文与预测目标之间干净的因果分离。它会从一个语义行为的中间切开、把多个行为并进一个目标、或仅仅为了搞清"这个 chunk 到底要表达什么"就需要历史上下文。那么，video-action 学习应该以什么为原子单位？

一句话立论：**Fixed chunks cut by clock; semantic events cut by embodied dynamics（固定 chunk 按时钟切，语义事件按具身动态切）。**

## 核心思路：动作对齐的语义事件

WALL-WM 用 **action-grounded semantic event（动作对齐的语义事件）**取代定长 chunk：一段时间上连贯的可执行行为（伸手 reach、抓取 grasp、抬起 lift、移动 move、放置 place），它*在语言中可命名、在视频中可观测、通过动作可实现*。事件的起止由底层可执行行为的*变化*界定，而非外部时钟。

这满足三条"对齐单位"的设计原则：
- **几何保持（Geometry preservation）**：连接语言/视频/动作，而不把它们各自的原生结构压平进同一个共享空间。
- **先验保持（Prior preservation）**：与从视频基础模型继承的"字幕→视频"结构兼容。
- **可执行因果（Executable causality）**：提供有清晰时间支撑的预测目标，同时让时长随任务而非时钟。

并明确"要从视频先验里提升（lift）出什么"：T1 推理（把全局指令与任务进度转成事件结构化意图）、T2 视觉预测（保留字幕→视频归纳偏置，同时让未来观测可由可执行事件控制）、T3 精细操作（暴露时序、接触转换、局部状态变化）。

## 主要贡献

1. **事件对齐的 WAM 预训练。** 以"动作对齐语义事件"为原子训练单位，配事件字幕，训练一个视频-动作去噪器——在保留继承的视频先验的同时，把事件对齐的视觉证据转成可执行动作。
2. **同一骨干、两种推理模式。** 事件模式做事件空间 rollout（变长可执行片段）；统一模式用基于 VLM 的 **Staircase 解码**生成事件结构化潜推理来支持定长 chunk 预测，并保持梯度连续的 VLA 通路。
3. **事件对齐具身建模的放大基建。** 事件对齐的数据生态 + 聚类均衡采样 + 基于 **Muon 优化器**（DMuon 分布式实现）的大规模预训练基建，支持跨多样行为/场景/任务的可扩展 WAM 训练。

## 架构要点（每条一句话）

- **层耦合视频-动作去噪器**：视频塔继承 Wan 系列文生视频模型（主配方中**冻结**），动作 DiT 随机初始化、与视频塔等深；每层动作 token 跨注意力读取*配对的*视频块特征，**单向**（动作读视频、不改视频）。
- **多视角**：跨视角自注意力（零初始化分支，初始不改变行为）+ **Camera RoPE**（给每个相机一个可学习、免标定的旋转身份）+ **跨视角几何掩码**（视锥掩码 sight-cone + 管状掩码 tube，仅训练期用、推理期丢弃以保持免标定）。
- **视频-动作时步映射**：主配方用**非对称 1-to-Nd**——视频冻结在某个中等噪声锚点步 s\*，动作完成全部 Nd 步、每步都从那一次锚定的视频前向读取跨注意力证据（对比"对称 1-to-1"用于小数据端到端验证）。
- **Staircase 潜 CoT 解码**：在冻结 Qwen3.5-9B 上以轻量 MoT 实现并行潜推理——在中继深度 Nr 处切分，低层共享视觉-语言接地、高层并行特化出各推理步；用冻结的小模型（Qwen3.5-0.8B）做"潜→文本"重建监督。避免串行自回归 CoT 的重复计算。

## 局限（综合全文）

1. **灵巧/接触密集任务绝对分仍低**（约 32），事件分解帮助有限——瓶颈在低层位姿精度、接触时序、窄公差对齐，而非高层事件分解。
2. **复杂杂乱场景泛化仍具挑战**，虽已显著领先基线。
3. **系统复杂度高**：多视角几何掩码、时步映射、Staircase、DMuon 等环环相扣，复现门槛高。
4. **依赖外部"下一事件"提议者**（事件模式下由微调的 Qwen3.5-VL-9B 或人/agent 给出），其质量影响整体表现。
