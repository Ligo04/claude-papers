# WALL-WM：在"事件关节"处切分世界动作建模

> X Square Robot Team · arXiv:2606.01955（2026 年 6 月）· 技术报告，45 页
> 代码：https://github.com/X-Square-Robot/wall-x
> 标题取自柏拉图《斐德罗篇》265e —— "Carve nature at its joints（在事物的天然关节处切分）"

## 这篇论文讲什么（一段话）

现有的 VLA / 世界动作模型（WAM）几乎都用**固定长度的动作 chunk**作为学习单位：以当前观测和指令为条件，预测一段定长动作。WALL-WM 指出这里藏着一个根本性的**粒度错配**——语言描述的是*语义目标与事件*、视觉是*连续场景动态*、动作运行在*控制级时间尺度*；把这三者硬塞进同一个定长预测窗口，会把 VLA 训练退化成"短时程相关性拟合"，不仅没用好预训练的视觉-语义先验，还会用 chunk 专属的动作捷径*覆盖*掉这些先验，削弱组合性与长程泛化。WALL-WM 的解法是：把原子学习单位从"定长 chunk"换成**动作对齐的语义事件（action-grounded semantic event）**——如"伸手、抓取、抬起、移动、放置"这种由底层可执行行为的变化自然界定起止的片段，它*在语言中可命名、在视频中可观测、通过动作可实现*。围绕事件来组织监督与数据，配合事件级字幕、聚类均衡采样、Muon 大规模训练基建,得到一个从视频基础模型到可执行 WAM 的**先验保持式（prior-preserving）放大配方**。同一个事件预训练骨干支持两种推理模式:**事件模式**(消费"下一事件"描述,执行变长片段)与**统一模式**(用带 Staircase 解码的 VLM 提供事件结构化潜推理,驱动定长 chunk 推理,且保持梯度连续的 VLA 通路)。真机大规模泛化评测达到 SOTA。

## 核心要点（5 条）

1. **"固定 chunk 按时钟切，语义事件按具身动态切。"** 这是全文的灵魂一句。原子单位的选择，先于、也决定了对齐与泛化——把它选错，再多微调也只是短时程相关性拟合。
2. **几何保持的对齐，而非模态融合。** 文本/视觉/动作不共享同一个"邻域"概念（语义相近的指令可能对应不同视觉轨迹；视觉相近的状态可能需要互不相容的控制）。WALL-WM 强调连接三者而*不把它们压平进同一个嵌入空间*——视频是语言与动作之间天然的"桥"。
3. **先验保持式放大，而非短暂适配。** 从 Wan 视频骨干到 WAM 是一次"提升（lift）"：要继承视频学到的语义/时间结构，同时获得可控性、接触敏感性、因果接地。做法包括：视频塔冻结、零初始化的跨视角分支、单向层间耦合（动作读视频、不改视频）。
4. **一个骨干，两种推理模式。** 事件模式按任务自然时长执行变长片段；统一模式用 **Staircase 并行潜推理** 把全局指令转成事件结构化的潜 CoT，驱动传统定长 chunk，且保持梯度连续。
5. **系统是一等公民。** Muon 优化器（DMuon 分布式实现）+ 自定义 kernel + 蒸馏 + FP8 量化，把闭环推理做到 **10Hz**。技术报告把"可放大的训练/部署基建"当作贡献本身。
