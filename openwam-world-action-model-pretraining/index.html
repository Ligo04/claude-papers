Q1 · 该继承什么世界知识§4.1

世界知识经两条通道继承：视频生成骨干里的生成式世界先验，以及视觉编码器诱导出的表征先验。第一条结论平淡，第二条反直觉。

视频骨干规模

RoboTwin2.0-Full 平均成功率 · 点图，横轴区间 89–95%（非零起点，用位置编码）

单调提升，但收益递减：14B 最强，5B 仅落后 1.40 点而参数少近 3 倍 —— 所以后续全部消融采用 5B。四个骨干在架构、预训练数据、目标上也各不相同，所以这确立了「骨干选择是重要设计变量」，而不把全部增益归给参数量。

视觉表征先验

RoboTwin2.0-Full 平均成功率 · 条形自 0 起 · 骨干权重随机初始化以隔离表征贡献

决定隐空间质量的不是「重建式 vs 表征式」的类别之分，而是隐变量本身的操作性质：时间与 token 双维度的紧凑性 + 丰富的世界信息。DiT 是为低维隐变量（Wan2.2-VAE 48 维）优化的，DINOv3 的 768 维、V-JEPA 的 1024 维直接塞进去就是架构不兼容；过一层 S-VAE 压到 48 维，两者双双反超 FLUX.2-VAE。

Q2 · 世界与动作如何协同§4.2

继承对了先验还不够。协同需要三个不同层面的决策：动作专属容量放在哪、训练时开放哪些跨模态通路、推理时是否保持这些通路被学到时的噪声关系。

Q3 · 协同如何跨域扩展§4.3

单域强不等于世界–动作知识可迁移 —— 模型可能只是拟合了目标任务的视觉与动作分布。机器人轨迹提供可执行的动作监督但视觉覆盖有限；第一视角视频视觉多样但没有动作标签。600 小时等预算下的四组对照把这件事分开了。

ID：分布内拟合

RoboTwin2.0 Clean2Clean · 点图，区间 86–89.5%

增益 ≤ 1.5 点。Robot-only 的 ID 最强 —— 机器人轨迹提供可执行的动作接地。

OOD：分布外泛化

RoboTwin2.0 Clean2Random · 点图，区间 12–28%

增益高达 +12.12 点。两个混合策略的 OOD 都更好 —— 第一视角视频拓宽视觉与交互分布。两阶段（26.50）与单阶段共训（26.62）几乎打平，说明用不用两种数据比怎么排序重要得多。

信息流偏好随预训练翻转

Figure 11 · 发散图，中点 0 为中性灰 · 数值 = Mutual − Action-Sees-Video（百分点）

from-scratch 时略微偏好单向，预训练后翻转为偏好 mutual。翻转在 C2R 的 ID（+0.70）与 OOD（+0.72）上幅度相当 —— 若是域偏移伪影两者应不同；两个协议又同向翻转 —— 排除了评测协议伪影。留下的是真实机制：预训练让世界–动作交互变成真正双向的交换，预测的未来帧为动作生成提供视觉引导，预测的动作反过来告知那些帧中机械臂运动该怎么合成。数据稀缺时两条流建立不起这种对应，反向通路只是噪声。

这是「架构选择依赖数据规模」的干净案例：小规模消融选出的最优，放大后可能不再最优。论文因此在 Finding 2 里明确把这个接近的选择推迟到预训练阶段再定，而不是在小规模上强行拍板。

OpenWAM-α：配方扛不扛得住规模§5

Wan2.2-VAE（冻结）+ Wan2.2-TI2V-5B 世界流 + 1B ActionDiT 动作流，30 对层全部桥接做 joint self-attention，mutual 掩码，同步去噪 10 步。518.5M 帧 / 6,369 小时单阶段共训，80 维统一动作空间打通 21 种具身，128 张 H200 训 7 天。

LIBERO-Plus 的例外：像素级预测的鲁棒性签名

Table 5 · 顺序编码热力图（单一蓝色调，浅→深 = 低→高）· 逐扰动成功率 %

论文用一整页解释自己为什么在这个基准上比最强基线差 20 点，给了双重归因。

数据视角：α 的单臂数据仅约 1,100 小时，只有两个来源 —— DROID（固定平台、固定视角）和 InternData-A1 的单臂部分。ABot-M0.5 有 8,000+ 小时、Being-H0.7 有 5,700+ 小时，覆盖多样具身、场景、视角，预训练时已见过接近测试场景的视觉信息。反面印证：α 的混合富含第一视角、双臂、灵巧手数据，对应基准上就都是 SOTA。

架构视角：Fast-WAM、ABot-M0.5、OpenWAM-α 共享同一预测目标 —— Wan2.2-VAE 重建式隐空间上的像素级未来视频。三者在 Camera 与 Noise 两列呈现相同的性能签名（明显低于其他扰动），只有 ABot-M0.5 靠数据补回大半。两个旁证：ImageWAM 未预训练却仍强，因为它只预测单帧未来 —— 更像编辑而非 rollout，没有跨帧误差累积；Being-H0.7 用 V-JEPA 2.1 编码，隐变量仍是时序的但是语义级而非像素重建，因此对这两类扰动明显更鲁棒。

证据强度：论证链合理且有两个方向的旁证，但没有做直接控制实验（比如给 α 补单臂数据看分项能否恢复）。这是一个有说服力的诊断，不是已验证的因果结论。

VLA 与 WAM：谁更强

Figure 16(a) · 最干净的对照：StarVLA vs Fast-WAM，两者都没有具身预训练 · 条形自 0 起

Fast-WAM（WAM） StarVLA（VLA）

ID 上 WAM 拟合更好：三项全胜，C2R Clean 上领先 31 点。机制是 WAM 训练里有视频隐变量监督，为参数优化注入了额外信息源，而 VLA 只有动作监督、没有中间隐变量目标。

OOD 上 VLA 泛化更好：完全反转，LIBERO-Plus 上 VLA 领先 22.6 点。机制正是 ID 优势的另一面 —— 长时程未来预测在分布偏移下意味着更重的误差累积，这是纯动作 VLA 从不背的负担。

但结论的第二半更重要：两个缺口都能被足够大且多样的预训练数据补偿。所以真正的建议是先把数据搞对，再纠结范式。
